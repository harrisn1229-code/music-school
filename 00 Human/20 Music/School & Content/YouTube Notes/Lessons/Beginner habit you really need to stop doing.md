# Beginner habit you really need to stop doing

![](https://www.youtube.com/watch?v=hiHl8GSt-3A)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=hiHl8GSt-3A)

## Synopsis

Short lesson arguing that thinking of strum patterns purely as "down up down up" is a beginner habit worth dropping — those arrows describe direction only, not the actual rhythmic durations that make a pattern sound like the pattern it is.

## Techniques

- **Down/up arrows encode direction, not duration.** The identical arrow sequence sounds completely different played in half notes vs. quarter notes vs. eighth notes — writing out the actual rhythmic values (or reading standard notation) is what really specifies a strum pattern.
- **Recommended learning method: ear training on real songs.** Listen closely to a song's strum pattern and try to reproduce it by ear, rather than relying on memorized arrow diagrams — framed as genuine ear training, broader than interval drills alone.
- Reading rhythm notation is offered as a more rigorous (and more effortful) alternative, worthwhile mainly if going beyond casual campfire-strumming use.
