# Synthet - How to ACTUALLY Pitch Bend

![](https://www.youtube.com/watch?v=5tRsrsmHdr0)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=5tRsrsmHdr0)

## Synopsis

A workflow-focused follow-up to [[Synthet - The +1 Pitch Trick]]: how to actually apply a slide/glide to a single note inside a chord rather than the whole chord at once, using FL's piano-roll note color-coding to select and target one note specifically — the concrete use case given is sliding just one note of a chord while the rest hold, e.g. sliding the note that turns a major chord into a minor one.

## Techniques

- **Slide-note glide length is set from the piano roll's corner control (or the "S" shortcut)** — a shorter slide setting glides faster, a longer one glides slower; useful on bass notes specifically as well as chords/melody.
- **Selecting all notes and applying a slide slides all of them together** — the default behavior when a slide is applied to a multi-note selection (e.g. a full chord).
- **Color-code one note to target it independently** — double-click a note (or use the note-color menu) to assign it a distinct color, then that note can be selected and slid on its own while the rest of the chord/selection holds still. → [[Pitch and Formant]]
- **Concrete use case: slide one note of a chord to turn major into minor (or vice versa)** — with the target note color-coded and isolated, a slide on just that note re-colors the whole chord's quality mid-sustain rather than requiring a full chord change.
