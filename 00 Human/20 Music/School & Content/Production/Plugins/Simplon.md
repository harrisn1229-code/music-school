# Simplon

![[Images/Simplon.png]]

**Category:** Modulation
**Vendor:** FabFilter

## What it is

A free simple filter plugin from FabFilter with basic low-pass/high-pass/band-pass modes and minimal controls.

## What it's used for

Quick filtering effects and DJ-style filter sweeps when a lightweight tool is enough.

## FX chain notes

A simple filtering effect, often automated for transitions.

| # | Parameter | What it is / does | Technique |
|---|---|---|---|
| ① | Filter graph | Drag nodes 1 & 2 to set the two filter frequencies visually | Band-pass a source by placing an HP and an LP node |
| ② | Filter 1 (Frequency / Peak) | Cutoff + resonance of the first filter | Sweep Frequency; add Peak for character at the corner |
| ③ | Filter 2 (Frequency / Peak) | Cutoff + resonance of the second filter | HP one + LP the other to band-pass |
| ④ | Slope + Type (per filter) | 12/24/48 dB steepness and LP/HP/BP mode | Steeper (48) for surgical band-limiting |
| ⑤ | Serial / Parallel | Routing of the two filters | Serial to band-pass; Parallel to blend two bands |
| ⑥ | Input / Output Gain | Gain staging around the filters | Trim input so resonance doesn't overload |
| ⑦ | Effect Mix | Dry/wet blend | Blend for a parallel filtered layer |
