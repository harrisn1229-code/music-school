# This Is Why You CAN'T Pick FAST! (and 6 exercises to FIX it)

![](https://www.youtube.com/watch?v=UTbAuhfc_kQ)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=UTbAuhfc_kQ)

## Synopsis

A full 6-level progression for building economy picking from zero — the technique that grafts a sweep-picking-style doubled stroke onto alternate picking at every string change, so the picking hand never has to fully reverse direction mid-transition. Framed as the fix for the specific frustration of getting "stuck between the strings" on fast scale runs.

## Techniques

- **Level 1** — isolate a single 2-string transition, sweeping (not two separate downstrokes) to build the relaxed connected motion.
- **Level 2** — extend to a short moving scale phrase on that string pair, alternating between 16th-note triplets and straight 16ths to build flexibility.
- **Level 3** — add a third string (the B string specifically): pattern **down-up-down-down-up-down**, then move the shape around the neck with the fretting hand.
- **Level 4** — reverse for descending economy picking, 2 notes per string: **down-up-up-down** looped, then applied to a real fretting-hand phrase.
- **Level 5** — combine ascending and descending economy picking into one full lick, deliberately without mixing in alternate picking, so the pattern gets isolated practice.
- **Level 6** — apply economy picking to full 3-notes-per-string scale positions (ascending first), across two different scale positions — called the most practically useful level.
