# 2-Note-Per-String Arpeggio Picking Exercise (C Minor Scale-Degree Chords)

Four-note chord arpeggios (2 notes per string), one built on every scale degree of the C minor scale, targeting the often-neglected mid-tempo (120–130 BPM) alternate-picking range.

## How to run it

- One 4-note chord shape per scale degree of C minor, picked 2 notes per string.
- Consistent picking angle (even grouping) — pick should clear the strings after each down-up pair, not get trapped between them.
- Total picking-hand relaxation is required, not optional — tension collapses the exercise (multiple strings ring together) rather than just degrading it.
- Curled (not flat) fretting fingers keep each arpeggiated note cleanly separated — this is the single biggest factor in how clean it sounds.
- Doubles as a fretting-hand independence exercise: one fretted note per string against two picking strokes.

## Why `reinforces: []` is correct here

Picking-hand/fretting-hand coordination and relaxation at a specific tempo range — the C minor scale-degree shapes are a vehicle for the technique, not a theory concept being tested.
