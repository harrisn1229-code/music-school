# Arturia KeyStep 37

**Category:** MIDI Keyboard Controller (37 keys, sequencer/arp, CV)
**Vendor:** Arturia

**Ballpark value (used, 2026):** $120–160

## What it is

Arturia's 37-key slim controller with a polyphonic step sequencer, arpeggiator, chord mode, and CV/Gate outs.

## What it's used for

The main keys input for [[Keyscape]]/[[Omnisphere]]/[[Serum 2]]/[[Model 84 Polyphonic Synthesizer]]; its arp/sequencer doubles as an idea generator.

## Signal chain notes

USB-MIDI into Ableton. **Set the velocity curve per instrument** — Keyscape especially (see its Key Parameters). Chord mode + Model 84 = instant Juno pads one-finger.
