# Top 3 EASY Shred Licks - How To Start Shredding!

## Synopsis

Three beginner shred licks, each a simple 3-note triplet-based pattern moved through the E minor/G major scale (raising F to F♯ for the harmonic color), building in string-transition complexity from lick to lick.

## Techniques

- **Lick 1 — single position, one string, triplet pattern moved through the scale.** Deliberately kept to one string/position first — beginners should isolate one challenge (hand synchronization) before adding string-transition complexity.
- **Think in groups of six, not groups of three, when playing 16th-note triplets to a click.** Grouping triplets in 3s puts an upstroke on the second group's first note, which is awkward to lock to a metronome at speed; regrouping the same notes as 6s puts a downstroke on every quarter-note pulse instead, giving a consistent, easier-to-lock accent pattern. A picking-stroke/subdivision-grouping trick specifically for triplet-based material, not a rule about accenting every first note.
- **Transitioning noise must be inaudible between scale positions** — same "listener shouldn't hear the position change" goal as BERNTH's other string-transition content this batch.
- **Lick 2 builds directly on Lick 1** by adding a string transition (3 notes on D string, 1 note on G string, back to D) — same triplet idea, one new variable at a time rather than a completely new pattern.
