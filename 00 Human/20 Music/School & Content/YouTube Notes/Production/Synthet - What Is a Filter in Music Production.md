# Synthet - What Is a Filter in Music Production

![](https://www.youtube.com/watch?v=CN8ExY1s3r0)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=CN8ExY1s3r0)

## Synopsis

A filter fundamentals lesson: low-pass vs. high-pass explained by which frequencies get through, resonance as a character/emphasis control at the cutoff point, and — the more advanced half — filters as modulation *targets*, linking a filter's cutoff to a controller (a mod wheel, an LFO, a tempo-synced step sequence) so the filter sweep becomes a performable or automatic movement rather than a static setting. Sponsored by, and demoed on, Polyverse's "Filterverse" plugin, which stacks multiple filter shapes/EQ boosts in one device.

## Techniques

- **Low-pass lets lows through and cuts highs; high-pass is the reverse** — the basic definition, stated plainly as the foundation for everything else in the video. → [[EQ]]
- **Resonance emphasizes/boosts right at the cutoff frequency**, giving the filter a distinct tonal character beyond a plain slope — sweeping a resonant filter creates a "cutting through" or "boosting" sensation at the moving cutoff point, differently colored depending on the filter's curve/shape.
- **Filters are a modulation target, not just a static shaping tool** — linking a filter's cutoff parameter to a controller (demoed: right-click the filter → Link to Controller → choose e.g. a mod wheel/pitch controller) lets a performer sweep it live; the same link can go to a tempo-synced LFO or step sequencer instead, for an automatic, rhythmic filter movement.
- **"Any parameter can be linked to anything" is the broader modulation-routing principle** — filters are the entry point in this video, but the framing generalizes: once you're comfortable linking one filter to one controller, the same routing logic (source → destination, freely reassignable) applies across a DAW's other modulatable parameters.
- **Multi-filter/EQ-boost stacked plugin (Filterverse, from the video's sponsor) isn't owned** — a device that combines several filter types with built-in EQ boosts and tempo-synced modulation in one window; not currently in the collection.
