# Instrument Preset Map

Where to go *inside* each instrument plugin — the go-to patches/categories per musical job, so sound selection takes 2 minutes instead of 40. Companion to the Step 1a sections in the chain notes. Rule: **browse by job, audition ≤5, commit** — preset surfing is the great time thief.

## [[Keyscape]] (pianos + EPs — the crown jewel)
| Job | Patch |
|---|---|
| Flagship studio grand | **LA Custom C7** (+ its "Cinematic"/softer sub-variants for ballads) |
| Character/vintage piano | **Wing Upright**, **Wing Tack** (honky-tonk lane) |
| Neo-soul/hip hop Rhodes | **Rhodes LA Custom E**, **Classic Mark I** (kill patch tremolo if using [[PanMan]]) |
| Wurli grit | **Wurlitzer 140B** (tube/warm) · **200A** (pop/rock bark) |
| Funk comping | **Clavinet C** (add auto-wah via [[Envelope Follower]]) |
| Beatles tine | **Pianet M** |
| 80s ballad digital | **MKS-20** patches (the "human nature" lane) |
- Every patch: internal reverb OFF (sends do space), velocity curve to your controller, the built-in EQ/drive knobs are genuinely good — tweak there before Ableton.
- **Hidden superpower:** Keyscape patches load inside [[Omnisphere]] as a satellite — layerable with pads, filterable, arpeggiable. Verify it's active.

## [[Omnisphere]] (pads/atmospheres/hybrid)
- Browse by **category, not name**: `Pads + Strings` for beds · `Atmospheres` for intros/textures · `Keyboards` for hybrid keys · `ARP + BPM` for pulsing beds ([[Psych-Pop (Tame Impala)]] pulse).
- The move: **layer A (dark/wide) + layer B (airy/thin)** in one multi, balance to taste ([[1 Synth Bed Track|Synth Bed Track]]).
- Search terms that consistently deliver: "analog", "juno", "tape", "choir", "glass".

## [[Serum 2]] (modern leads/bass design)
- Factory: `Leads` → start from a plain saw/unison patch and shape (per [[1 Synth Lead Track|Synth Lead Track]] recipe) rather than a finished flashy preset — finished presets rarely sit in a mix.
- `Bass` → the growl/reese starting points ([[EDM Subgenres]] DnB/future bass); keep the sub osc clean.
- Its FX rack: strip reverb/delay from any preset you keep (sends do space).

## [[Model 84 Polyphonic Synthesizer]] (the Juno)
- This one you *play*, not browse: saw (+ sub osc) → **Chorus II** → slow filter = the entire bedroom-pop/synthwave/psych pad food group in 30 seconds. Chorus I = subtler, II = wider/wobblier, I+II = broken-lush.

## [[Drift]] / [[Wavetable]] / [[Analog]] (Ableton stock)
- Drift: category presets are strong — `Pad` + `Bass` folders first; its drift/voice controls are the charm knob ([[Bedroom Pop - Indie]]).
- Wavetable: `Pads` with position-LFO movement (OTT-friendly); `Bass` folder for clean subs.
- Analog: quick 70s mono leads/basses when Model 84 is too pretty.

## [[DUNE 3]] / [[Massive]] / [[Nexus]]
- DUNE 3: `Leads/Supersaw` banks — the festival wall, unison already engineered.
- Massive: the 2010s growl/wobble archive — `Bass` categories ([[EDM Subgenres]] dubstep lane).
- Nexus: the speed tool — `Pianos/EPs/Pads` when a demo needs done-sounds NOW; swap later if the song survives.

## [[Operator]] / [[Collision]] (Ableton synthesis)
- Operator: FM e-piano (the DX lane), toy bells, clean sine subs — small patches, big charm.
- Collision: bells/mallets/plucks — the ear-candy melodic layer nobody else covers ([[Modern Pop]] signature-sound slot).

## [[Ramzoid 808 Cooker]] / [[Kick 3]] / [[XO]] (low end + drums)
- 808 Cooker: pick base tone → drive in-instrument → done ([[1 Digital Bass Track|Digital Bass Track]] Step 1a).
- Kick 3: build the exact kick when no pack sample fits (layer click/body/sub independently).
- XO: browse one-shots by *similarity map*, not folder names — fastest selection tool you own ([[2 Drums Group|Drums Group]] source note).

## [[Kontakt 7]]
- The container, not the sound — its value = which libraries you own. Factory Library covers utility band instruments; the Abbey Road drum libraries (if owned) are the [[60s - Beatles]] kit shortcut; note your libraries here as the collection grows.
