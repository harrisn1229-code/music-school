# Keyscape — LA Custom C7 Grand

**Instrument:** [[Keyscape]] · **Slot:** [[BED Slot]] · **Used by:** [[1 Acoustic Piano Track|Acoustic Piano Track]]

## What it's for
The flagship studio grand — the default pop/ballad centerpiece piano. Keyscape's duo patches (layering the C7 with a second instrument, e.g. a pad or second piano) are a fast route to instant hybrid color when a plain grand feels thin; browse those from the same patch list rather than building the layer by hand.

## Settings
- ⑥ LA Custom C7, main lid/mic position (not a "Cinematic" sub-variant — those are for ballad-specific darker/wider mixes, see [[Instrument Preset Map]])
- ⑧ Internal FX: reverb OFF always — space comes from the chain's sends, not the patch
- ① Velocity curve: set once per controller, saved as default (fixes soft-playing response, not a per-song setting)
- ⑤ Drive/EQ knob: touch only if the patch needs it — Keyscape's modeled tone stage responds like the real piano's action, so small moves go a long way
- ④ Mechanical/pedal noise: default level for a pop mix; push it up only for an intimate ballad ("musician in the room" effect)

## In context
- Patch-switching beats EQ-rescuing — if the part wants brighter/warmer, change patch before reaching for EQ downstream.
- Piano LH content can double as BASS-slot support in a sparse arrangement (per [[Sound Palette]]) — watch for masking against a bass instrument in that case.
