# Hammer-Ons and Pull-Offs (Bass)

Using the fretting hand alone to sound a note change, without a matching pluck from the picking hand — taught via a Green Day-style (Mike Dirnt) hooky bassline as the concrete example of *why* it's worth learning, not just how to execute it.

## The mechanics

- **Hammer-on:** strike the string firmly with a fretting-hand finger to sound a *higher* note than the one currently ringing, without plucking again.
- **Pull-off:** as a fretting finger lifts off the string, pluck/flick it slightly on the way off so the *lower* note (an open string, or a finger still holding a lower fret) sounds — the release itself does the plucking, not the picking hand.
- Net effect: the picking hand is freed from having to strike every single note change, which matters most in fast runs where alternating plucking can't physically keep pace with the note density.

## Why bother — the tonal-variety argument, not just the speed argument

The video's actual pitch for this technique isn't "it's faster" (though it can be) — it's that **hammered/pulled notes carry a slightly different tonal flavor than picked notes**. A line that's 100% picked reads as more uniform/flat; mixing in hammer-ons and pull-offs against picked notes gives the line more textural variety. Concrete before/after demonstrated in the source video: the same riff played with **only picked notes** sounds noticeably plainer than the same riff **with the hammer-ons/pull-offs restored** — described as "it just sounds cooler, and it flows a lot better." Worth doing your own before/after A-B on a riff you're learning to hear this for yourself, the same ear-training move the video uses.

## When it shows up

Common wherever a bassline needs to move quickly between adjacent or nearby frets without the picking hand's help — punk basslines built for speed and drive lean on it heavily (the source example is squarely in that pocket), but the technique isn't punk-specific; it's a general fretting-hand articulation tool anywhere a line needs more notes than the picking hand can cleanly strike, or needs deliberate tonal contrast between phrases.

## Counter-example: when NOT to hammer-on

Not every fast-fretted note change should be hammered — a metal-sourced example flips this note's whole framing on its head. On Black Sabbath's "Paranoid," **most bassists assume the 9th-fret notes should be hammered on** (that's how the guitar riff, played by Tony Iommi, reads by ear) — but Geezer Butler doesn't hammer them, **he plucks every single note**. The stated reason: a hammered-on note sits quieter and less driving in a mix than a fully plucked one, and this riff specifically needs that drive to not get lost. **The decision rule this adds to the note:** hammer-ons/pull-offs win when you want tonal *variety* or need to outrun the picking hand's speed limit (this note's main content, above); full plucking wins when the line needs maximum, consistent *presence* in the mix, even at the cost of some technical ease. Same underlying "hammered notes read quieter" mechanic as this note's tonal-variety section above — just applied toward the opposite conclusion because the musical goal (drive vs. texture) is different.

## From videos

- **A named fix for weak/inaudible hammer-ons, plus a drop-D tuning context note, worked on "Killing in the Name" (Rage Against the Machine, bassist Tim Commerford).** BassBuzz's diagnosis names two distinct failure modes beyond this note's existing "when NOT to hammer-on" counter-example: hammer-ons played so weakly they're barely audible, or skipped entirely in favor of plucking every note — the second is called out as sounding "really weird" on this specific riff, since the line is built around the hammer-on's tonal contrast (not just its speed). **The fix, two parts:** (1) fret harder than normal on the hammer-on itself — described as "as hard as you can" until strength builds with practice, matching this note's fretting-hand-conditioning link below; (2) keep the *previous* fretting finger held down on its note so it doesn't die early — a second, separate way a hammer-on reads as weak beyond insufficient hammer force, since a dropped anchor note undercuts the hammer's contrast even when the hammer itself lands hard enough. **Tuning context:** the riff is played with the E string tuned down a whole step to D (full tuning D-A-D-G low to high) — flagged as a common tuning choice across Rage Against the Machine's catalog generally, not unique to this song. **Full fingering:** open low D → index 3rd fret A, hammer-on to pinky 5th fret A → open low D → index 3rd fret D, hammer-on to middle finger 4th fret D → pinky 5th fret A (plucked) → open D string → index 2nd fret E, hammer-on with middle finger to 3rd fret E → pluck 2nd fret E again → loop. **The three-reasons-it-matters generalization:** (1) a second articulation option so a line isn't all-plucked; (2) notes glide into each other more smoothly than an all-plucked line; (3) easier to play fast, since the picking hand doesn't have to strike every single note — the same "frees the picking hand" and tonal-variety framing this note's method section already states, now with a third real-song confirmation. → BassBuzz, [[5 Popular Beginner Bass Lines (Are You Playing Them Wrong?)]]
- **Two slap-specific hammer-on patterns, one existing "two-fret-below" rule extended.** **Thumb-hammer** (Les Claypool, "The Awakening," a Dexter Redding cover): slap a note with the thumb, then hammer on to the next note — smacking the string hard on the way down so it vibrates without a fresh pluck — repeated back-to-back (three thumb-hammers in a row is the video's showcase use) to **double note density without speeding up the slapping hand itself**. Framed explicitly as the fix for slap lines that are exciting but not melodic (see [[Melodic Slap Lines — Avoiding Disco Octaves]]): close-interval hammered notes read as more singable than pure slap-pop-octave jumps. Practice recipe given: pick a scale (minor pentatonic named as the classic choice for slap), and experiment with thumb-hammer starting from different scale degrees to generate licks. **Thumb-hammer-pluck** (Victor Wooten, "Classical Thump," bar 17 — the piece Wooten wrote as a personal étude): a three-motion cycle — slap, hammer-on, **pop** — that never has to repeat the same motion back-to-back, which is *why* it sounds far faster and more complex than it physically is: each individual motion stays at the same tempo, but interleaving three different motions instead of alternating two doubles, then triples, the effective note density (demoed as slap-only → add pops → add hammers, each layer sounding faster without any single motion actually speeding up). Named as the single most important pattern for tackling Wooten's playing generally. → BassBuzz, [[10 Songs That Taught Me SLAP (Easy to Effin’ Hard)]]

- **Slap-specific application: the "two-fret-below" hammer-on rule.** To hammer into a target note inside a slap line, start **two frets below it**, slap or pop that starting note, then hammer up to the target — works "almost always" with no scale knowledge required; if the scale is known, start **one scale-degree below** instead for the more precise version. Worked example: for a slap-popped octave line, pop a note two frets below the octave, then hammer on to the octave rather than popping it directly. Flags a specific risk this adds: normally the plucking/slapping hand enforces rhythm, but a hammered note hands that job to the fretting hand, which — if new to hammer-ons — tends to **rush** the note in early; fix is to practice slow enough to be precise.
