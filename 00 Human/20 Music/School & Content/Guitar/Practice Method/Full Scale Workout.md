# Full Scale Workout

**The one drill in the library that carries theory content**, not just hands. Alternate picking throughout, at ♩=100, running modal shapes up and down the neck.

- 3 pages, standard tuning
- Play through [[Full Scale Workout.pdf]]

## What it actually runs

The sequence is not random — it walks the modes of one parent scale in order, then jumps parents:

**C major's modes, entered from the 4th degree:** F Lydian → G Mixolydian → A Aeolian → B Locrian → C Ionian → D Dorian → E Phrygian

**Then other parents:** C minor · F♯ Aeolian · B Dorian · C Lydian · D Lydian · E Mixolydian

That structure is worth naming, because it's the drill's real teaching value: the first run is **derivative** mode thinking (same seven notes, seven different tonics) and the second is **parallel** (different roots, compare the shapes). That is exactly the distinction in [[SCL-C04 — Parallel vs derivative mode thinking]], made physical.

## How to run it

- Say the mode name out loud as you start each one. Fingers learn the shape either way; naming it is what connects the shape to [[Diatonic Modes]].
- Listen for the **characteristic note** of each mode as it goes by — the ♯4 in Lydian, the ♭2 in Phrygian ([[SCL-C05 — Characteristic notes]]). If they all sound the same, the drill is being played as exercise rather than as music, and slowing down fixes it.
- Alternate picking is strict. A missed alternation is a repeat.
