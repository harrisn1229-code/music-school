# Connected vs. Disconnected Bass Phrasing

BassBuzz's framing of one of the biggest single feel-choices a bass player makes: whether notes run into each other (**connected**) or leave a small gap between them (**disconnected**) — "even just subtracting or adding a fraction of a second in between notes can totally change the feel of the bass line and the whole song." Presented as the first of several nuances separating a technically-correct-but-lifeless "karaoke" bass performance from a pro one — playing all the right notes and rhythms but with the wrong connectedness still reads as *something's missing* to a listener, even one who can't name why.

## What each choice does

- **Connected (legato-style) notes** — letting one note ring into the onset of the next — create a flowing feel: the line "smoothly rolls forward like you're gliding down a stream." This is the default for a bassline that's already melodic/lyrical in character.
- **Disconnected (gapped) notes** — a deliberate short gap before the next note — interrupt that flow. Used well, this is a contrast device (see Otherside below), not just a mistake; used by accident, it just sounds thin and karaoke-y.

## The rule of thumb: match the source, don't default to short notes

If a bassline was written/arranged with long, connected notes, playing it with short/disconnected notes breaks the feel — "since the bassline has already been crafted to fit the song, if you play short notes it's not going to sound right." Connectedness is a deliberate arrangement choice baked into the part, not a neutral default to override.

**Reference examples cited (all long/connected lines):**
- **Kryptonite** (Three Doors Down, bassist Todd Harrell) — notes continue all the way into the onset of the next note.
- **I'll Be There** (Jackson 5, bassist "Ron Brown" per the source video) — long connected notes create a lyrical, melodic bass sound.
- **Otherside** (Red Hot Chili Peppers, Flea) — the verses stay connected/flowing; Flea deliberately switches to short, disconnected notes in the bridge specifically to break up that flow — a worked example of disconnection used as a *contrast* move against an otherwise-connected line, not a default.

## The beginner failure mode: early hand movement kills the note's tail

**Cause:** coordination lag. While still learning, it takes real effort to get the fretting hand from one note to the next in time, so beginners unconsciously start moving toward the next shape *before* it's actually time to play it — cutting the current note's sustain short and leaving dead space before the next attack lands. Worked example: a note meant to ring a full four beats ("one two three four, change on one") instead gets cut at beat three because the hand already started shifting, leaving two beats of silence that shouldn't be there.

**Fix — the "instant jump" mental trick:** don't think of the transition as *gradually* moving from point A to point B. Imagine instead that you have the power to jump instantly from one fret/position to the other, with no travel time in between. You obviously can't actually teleport, but make-believing that you can reorients the timing of the movement itself — it delays the *start* of the hand's travel until the last possible instant, instead of creeping toward the target early, which is exactly what lets the current note ring its full value before the transition happens.

## Practice application

- Practice against the actual source recording (not just a tab), specifically listening for whether your version's note-endings land in the same place as the original's.
- If a note is cutting short and leaving unwanted silence before the next one, the fix is almost always transition *speed*, not transition *timing* — the hand should still leave late, it just needs to arrive fast once it goes, per the instant-jump reframe above.
