# Twelve-Tone & Serialism

Part of [[Music Theory]] → [[20th-Century Harmony]]. **Atonality** is the complete absence of a tonal center — the logical endpoint of the Romantic era's steadily increasing chromaticism. **Arnold Schoenberg** engineered a systematic way to guarantee it mathematically: **twelve-tone technique**.

## The twelve-tone row
- Every composition begins with a sequence of all 12 chromatic pitches, each used **exactly once** — the **row**.
- Avoid anything that suggests tonality while building it: triad fragments, familiar-scale bits.
- A complete row is a short, "pure" atonal composition on its own.

## The twelve-tone matrix
A 12×12 grid used to generate related rows from one original ("**Prime**," labeled **P-1**):
1. Place the original row across the **top row**.
2. Fill the **left column** with the row's **inversion** — flip it upside-down (a rising interval in the original becomes the same-size falling interval in the inversion).
3. Transpose the original row to start on each of the 12 pitches to fill in the rest of the **top row**, producing **P-2 through P-12**.
4. Doing the same transposition down each **column** produces the **inversion rows I-1 through I-12**.
5. Reading any row **backward** gives its **retrograde (R)**.
6. Reading backward down a column gives **retrograde inversion (RI)**.

## Composition rules
| You CAN | You CAN'T |
|---|---|
| Use any row, any time | Use a partial row |
| Restrike a note before moving to the next one | Change the order of notes within a row |
| Combine adjacent row-notes into chords | Bend the material toward tonality |
| Pass rows between voices, overlap rows | — |

Convention: start a piece with **P-1**, so an analyst can reconstruct the matrix.
