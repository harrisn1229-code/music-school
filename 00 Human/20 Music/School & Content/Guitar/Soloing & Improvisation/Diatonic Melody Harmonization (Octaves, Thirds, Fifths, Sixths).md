# Diatonic Melody Harmonization (Octaves, Thirds, Fifths, Sixths)

**Add a second voice to an existing single-note melody or solo, a fixed scale-degree interval above or below, using the scale itself (not chromatic counting) to keep every harmony note in key.** The classic twin-guitar-harmony device — this page is the scale-degree shortcut for finding the harmony note fast, plus which interval to reach for and when.

## The scale-counting shortcut (works for any interval)

For any diatonic interval, **count that many scale degrees up (or down) from the melody note, staying inside the scale** — not a fixed number of frets or a fixed chromatic distance, since the interval's actual size (major vs. minor 3rd, etc.) changes depending on where in the scale you start.

- **Thirds** — count up 3 scale degrees from the melody note (equivalently: skip one scale tone). Worked in F Dorian: melody note F → count F-G-A♭ → harmony note A♭ (a minor 3rd, because that's what F Dorian's 3rd degree happens to be from F).
- **Fifths** — count up 5 scale degrees (skip three tones). Same F Dorian example: F-G-A♭-B♭-C → harmony note C.
- **Sixths** — count up 6 scale degrees (skip four tones). F-G-A♭-B♭-C-D → harmony note D (a major 6th in this case, since F Dorian's characteristic note is the natural 6th).

The interval *quality* (major/minor/perfect) isn't chosen deliberately — it falls out automatically from the scale's own formula at that scale degree. This is the entire point of the shortcut: it removes the need to consciously track major-vs-minor-3rd-type decisions note by note, as long as the harmony line stays inside the scale.

## Octaves — the safest, easiest starting point

Double the melody exactly one octave higher and/or lower. Zero harmonic risk (it's the same notes), and easy to execute since the fretboard repeats identically after the 12th fret — the same fingering shape, just moved 12 frets. A fast way to make a lead line sound bigger/more prominent in a mix without any music theory decisions at all.

## Each interval's character

- **Octaves** — safe, "epic"/prominent, but harmonically inert (same notes, no new color).
- **Thirds** — the default, most immediately pleasant-sounding choice; described as risking sounding "stale," "predictable," or "cheesy" if used exclusively for a whole solo.
- **Fifths** — a more open, harder-edged sound (visualize the melody as the root notes of a series of power chords, then play only the top note of each). Requires more care than the scale-counting shortcut alone guarantees — see the caveat below.
- **Sixths** — a more "experimental"/unusual sound; recommended specifically as the fix when a solo harmonized purely in 3rds starts sounding too sweet or predictable.

## Caveat: the scale is safe ~90% of the time, not always

Following the scale-degree shortcut keeps every harmony note diatonically correct, which works cleanly most of the time — but it doesn't account for what the underlying chords/rhythm section are actually doing underneath. A harmony note that's perfectly in-scale can still occasionally clash against a specific chord voicing in the arrangement. Treat the scale-shortcut as a fast, reliable first pass, not an infallible rule — check problem spots by ear against the actual backing.

## Practice/writing method: build each interval separately, then blend

Harmonize the same melody fully in octaves, then fully in thirds, then fully in fifths, then fully in sixths, as separate complete passes — before attempting to mix and match. Once all four are familiar by ear, combine sections/phrases from whichever interval sounds best at each moment into a single final harmonized take, trusting your ear over a fixed rule for the final combination. Don't skip the single-interval passes to jump straight to mixing — knowing how each option sounds on its own is what makes the mixing stage effective rather than guesswork.
