# Angular Reach Exercise

A daily "always item" technique exercise from Jared's (Sound Guitar Lessons) Warm-up & Technique category, part of the broader system documented on [[The Practice Priority Pyramid]] and demonstrated on [[How I Organize My Guitar Practice (So I Never Want to Stop)]]. Purpose stated directly: it's a **reach and relaxation-under-tension drill built on alternate picking**, deliberately angular (jumping between string groups at a fixed fret pattern) rather than a straight scale run — plus chord and sweep-picking variants of the same underlying shape.

## The base pattern

- **Click = quarter notes on the offbeat**, not the downbeat — same offbeat-click convention Jared uses elsewhere (see [[Circle-of-Fourths One-Position Scale Drill]]).
- **Play 16th notes starting on the 9th fret.**
- **Angle up, then back down, across the bottom four strings**, then repeat the same up-and-down angle shape on the **middle four strings**, then the **top four strings**, then back to the **middle four**, then the **bottom four** again.
- **Shift position, then repeat the whole sequence starting from the other direction** — i.e. run it a second time starting from the pinky side rather than the pattern's original starting finger.
- **Alternate picking throughout, crossing a string on every note** — this is what makes it "excellent for alternate picking" specifically (as opposed to a same-string run).

## What it's for (stated purpose)

- **Reach** — the angular string-group jumps stretch the fretting hand beyond what a straight scale run demands.
- **Relaxation under tension** — Jared names staying relaxed through the pattern as an explicit focus alongside the notes themselves, not just a side effect.
- **Alternate-picking fluency across string changes** — every note crosses a string, so the picking hand can't fall into a same-string groove.

## Variations (same shape, different execution)

- **Chord version** — the same angular shapes played as chords rather than single notes, jumping between the shapes the way the single-note version jumps between string groups. Stated benefit: direct carryover to chord *creation* — internalizing how those same reach/angle shapes work as voicings, not just as a picking drill.
- **Sweep-picking version** — the same shape executed with a sweep-picking motion instead of alternate picking, given as a third, separate variation to rotate into once the base and chord versions are checked off.

## Milestone and worked tempo

- **Milestone: one perfect pass at any tempo, zero mistakes — a single wrong note voids the take, no partial credit.** Jared frames this as functionally identical to a recording take: "if you're recording and a single mistake happens, you're like, 'ah, shoot, we got to start it over.'" The value isn't accuracy for its own sake — it's the heightened, recording-take level of focus that a real "no do-overs" bar forces, versus playing the same pattern loosely and calling it good technique work.
- **Worked example tempo: 80 BPM, 16th notes** (offbeat click as above) — the exercise had already been checked off once by the time of the video, so this run was a demonstration rather than the actual clean-take attempt.
- Per [[The Practice Priority Pyramid]]'s Milestones/Rotation/Variation mechanic: once checked off, the exercise rotates out and a different variant (chord or sweep version) rotates in; coming back to an already-checked variant later should use a **faster tempo** than whatever it was last cleared at, rather than repeating the same speed.

## Sibling "always item": the snake exercise

A second technique exercise from the same category, mentioned alongside this one but with far less rule detail given in the source video — worth tracking here rather than as its own page until more is documented:
- **16th notes at a set metronome tempo**, aimed at **sweeping evenness and time-feel using economy picking** rather than reach.
- Checked off once at **110 BPM**; now rotating into a different version of the same underlying shape (same Milestones/Rotation/Variation cycle as above).
- No click-placement, fret-position, or fingering specification was given for this one in the source — revisit and flesh this out (or split into its own note) if a future Sound Guitar Lessons video details it further.
