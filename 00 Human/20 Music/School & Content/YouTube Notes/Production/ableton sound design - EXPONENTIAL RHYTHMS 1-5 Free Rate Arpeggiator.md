## Techniques

- **Free-Rate Arpeggiator: the core setup** — drag any sample onto a MIDI track (any MIDI instrument or VST works; the video demos a kick sample), load [[Arpeggiator]] as a MIDI effect on the track, and set **Rate Mode = Free**. This decouples Rate from BPM-dependent time divisions and instead lets it sweep a raw **10 ms–1000 ms** interval range directly — holding a note on a MIDI keyboard and moving Rate up/down live stretches and squishes the resulting rhythm in real time, feeling more like a rubber band than a tempo-locked pattern. → [[Arpeggiator]], [[Rhythm and Groove]]
- **Draw Rate automation over a legato note for precision and repeatability** — rather than performing Rate live, build a 2-bar MIDI clip with a single note on middle C, press **Legato** so the note sustains to the clip's end, then draw a Rate automation curve directly over the clip. Different curve shapes (straight ramps vs. curved vs. multi-segment) produce distinctly different resulting rhythms, and — the series' recurring core phenomenon — crossing a certain threshold of Rate values stops reading as discrete rhythmic hits and starts reading as a continuous pitched tone instead, the same audio-rate crossover [[ableton sound design - EXPONENTIAL RHYTHMS 2-5 Sample Looping in Simpler|part 2]] reaches via Simpler's Length parameter and [[ableton sound design - EXPONENTIAL RHYTHMS 3-5 Texture Mode|part 3]] reaches via Texture-mode grain size. Once comfortable, layer in more complex automation: vary breakpoint values, the curve slope *between* breakpoints, and insert distinct shapes for finer nuance. → [[Arpeggiator]], [[Automation]], [[Rhythm and Groove]]
- **Resample the arpeggiated output to a new MIDI track — the technique's real power move** — because every arp hit is a distinct MIDI note event (not just an audio modulation), it can be captured and edited: create a new MIDI track, arm it, and set its input/**MIDI From** to the arpeggiated track, then record. The result is a permanent, editable MIDI clip — each hit can now be manually stretched, compressed, or chopped in the new clip's note editor, turning a live-only modulation effect into reusable, arrangeable material. asd used exactly this in one of their own tracks: resampled the Arpeggiator MIDI output from a **hi-hat** track, then reused that resulting MIDI clip to drive the rhythms of the **bass, strings, and vocal** elements elsewhere in the same song — one resampled rhythm becoming the backbone for multiple, otherwise-unrelated parts. → [[Arpeggiator]], [[MIDI Generate and Transform Tools]] (record-generative-MIDI-to-a-new-track — same principle already documented there for other generative sources)
- **Gate modulation adds note-length variation relative to Rate** — modulating Arpeggiator's **Gate** parameter introduces variation in the resulting note lengths relative to whatever the current Rate value is, a second axis of rhythmic variety layered on top of the rate/timing changes themselves. → [[Arpeggiator]]
- **Feed chords in for pitch variation, and use Style to control how they're read** — playing or feeding chords into Arpeggiator (instead of single notes) introduces pitch variation across the arpeggiated hits, plus knock-on variation for any key-tracked instrument parameters or effects further down the chain; experimenting with the **Style** parameter changes how Arpeggiator interprets and orders the incoming chord. → [[Arpeggiator]], [[Chord]]
- **Generative rhythmic melodies for tonal/harmonic instruments: Random → Scale after Arpeggiator** — chain a [[Random]] MIDI effect immediately after Arpeggiator to randomly re-transpose the generated hits, then a [[Scale]] device after that to quantize the randomized output back into a chosen scale or set of pitches that fits the rest of the track — turns the arpeggiator from a fixed pattern generator into a self-generating melodic line. → [[Random]], [[Scale]], [[Arpeggiator]], [[Melody Writing]]
- **Trigger an instrument's own built-in LFO from every arp hit for per-note random modulation** — for instruments with a built-in low-frequency oscillator, enable its note-on/"trigger" mode and set the LFO's wave to **Random** or **Sample & Hold**; every incoming MIDI note (i.e. every arpeggiated hit) then retriggers the LFO to output a fresh random value, assignable to pitch, filter cutoff, or other synth parameters — a distinct mechanism from the Max for Live [[LFO]] device (which is mapped externally via Live's mapping system); this is the instrument's own internal LFO and trigger mode. → [[Arpeggiator]]
- **Copy Rate automation onto a second parameter for correlated movement — demoed as filter cutoff + pitch + tightened envelope for a "clicky" kick** — copy the drawn Rate automation curve and paste it onto another parameter's automation lane (pitch or filter cutoff both work), then reshape the pasted curve to taste on the new target — reuses one performed/drawn shape to drive two aspects of the sound in correlated motion instead of drawing each separately. Demoed on the kick-sample instrument: paste the Rate curve onto a **resonant high-pass filter's cutoff**, pitch the sample up, and tighten the amplitude envelope — together producing a tighter, more "clicky" sound. *(general starting point — exact filter/pitch/envelope values not given in source)* → [[Arpeggiator]], [[Automation]], [[Kick Design]]
