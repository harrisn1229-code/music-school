# How to Write Neo-Soul and R&B Chords - A Simple Method

![](https://www.youtube.com/watch?v=myUITpTwm38)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=myUITpTwm38)

## Synopsis

Max Konyi's repeatable process for writing dense, extended-harmony neo-soul/R&B chords: drums first, then a simple diatonic melody written in the upper-mid register as the top line of the eventual chord progression, THEN harmonize underneath it — either by ear (grab a diatonic bass note, add diatonic notes until it sounds good) or with theory (chord-tone role, extension choice, inversions for bass movement, functional passing chords). The distinctive move is inverting the usual write-chords-then-melody workflow, and the payoff example — resolving to A minor via a B♭9 chord (a tritone substitution for E7, the "real" V) voiced in 3rd inversion — is a genuinely useful concrete illustration of tritone substitution the vault didn't have a worked example of before. Confidence: high (clean creator captions, spoken-lesson format transcribes cleanly).

## What's taught

- **Melody-first harmonization**: write drums → write a simple, diatonic, singable melody in the upper-mid-to-high register (leaves room underneath for dense voicings) → harmonize UNDER that melody, chord by chord, using the melody note as the fixed top voice of each chord. Inverts the conventional write-chords-then-melody order.
- **No-theory-required harmonization method**: for each melody note, pick any diatonic bass note, then add more diatonic notes in between by ear until a voicing sounds good — no need to know the chord's name. Duplicate/adjust that voicing forward or pick a fresh bass note for the next melody note; chords can hold across multiple melody notes or re-attack with each one.
- **Theory-informed harmonization layer** (once basics are known): treat every melody note as either a primary chord tone (1/3/5) or an extension (7/9/11/13) and choose the chord quality/extension for the emotional color wanted; vary root position vs. inversions deliberately for smoother, less-jumpy basslines; use passing chords/secondary dominants to bridge between two "strong" chords.
- **Keep the progression mostly diatonic, with one or two non-diatonic "special" chords** — the contrast against a mostly-diatonic backdrop is what makes an out-of-key chord read as special; going non-diatonic everywhere loses that contrast entirely.
- **Worked tritone-substitution example**: targeting A minor, instead of the expected V7 (E7) the video uses **B♭9 in 3rd inversion (B♭9/A♭)** — B♭ sits a tritone from E, so B♭9 does the same dominant-resolving job as E7 while giving a smoother chromatic bass rise (D → A♭ → A) into the tonic and a "hipper" top-voice color (functionally reads as a rootless G7♭13 fragment stacked over the wrong-looking bass note).
- **Specific voicing choices from the walkthrough** (A minor key): Am9 (tonic) → Cmaj9/E (1st inversion, passing) → F6add9 (inverted C-chord substitute for the "expected" Em, deliberately left unextended) → Dm9 → Am7add11 (no 9th) → Gadd11 (2nd inversion) → Dm9 → Cmaj7/G (inverted, not a true G chord) → B♭9/A♭ (tritone sub, 3rd inversion) → back to Am9.
