## Techniques

See [[String Section Arranging]] for the complete, organized breakdown — summary here: the violin family (violin/viola/cello/double bass) covers overlapping but distinct ranges, all four able to play middle C; an orchestra effectively uses five voices by splitting violins into first and second sections; a string quartet instead uses two violins + viola + cello (no bass). Strings are written as monophonic per player, so a chord gets shared across the section — bass takes the root (the double bass being a transposing instrument sounding an octave below written pitch, historically existing to double the cello an octave down), sections can split via *divisi* to voice more notes, the viola reads alto clef (middle C sits at the clef's center line), and first violins typically carry the melody over the rest as accompanying texture ("melody-dominated homophony"). Chord-to-chord movement should be voice-led — each part moving the shortest possible distance to the next chord's nearest available note. Playing techniques: arco (bowed, default), pizzicato (plucked, default for jazz/non-classical double bass), vibrato (default expressive pitch fluctuation on long notes).
