# Master jazz comping voicings with this approach

![](https://www.youtube.com/watch?v=ND-PumPh3yw)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=ND-PumPh3yw)

## Synopsis

A 16-minute jazz-comping practice lesson from Jared Borkowski (Sound Guitar Lessons With Jared), pulled from his "Jazz Comping Mastery" course — narrower in scope than a voicing dictionary, and explicitly framed as a *practice method* rather than a pile of shapes to memorize. Working entirely on a single chord (D dominant 7), he names and demonstrates the **"hub-latching approach"**: pick a familiar root-position voicing as a "hub"/home base, build a path across the chord's other tones (3rd, 5th, ♭7), play the inversion rooted on each stop of that path, and keep returning to the hub between excursions so the sense of the root never gets lost — particularly important for solo guitar with no bass player covering the root elsewhere. He runs the full drill on two string-set roots (5th-string- and 6th-string-rooted D7), then shows a doubling trick: substitute the 9th for the root in every voicing already learned, which roughly doubles the vocabulary (~22 total voicings off one chord) without new fingerings to memorize. The most valuable content is the **practice structure**, not the specific D7 shapes — worked (fixed-order) drilling first, then random-access jumping between hub and inversions once memorized, then comping freely over a static one-chord backing track. He's explicit the same drill applies to any seventh-chord quality and that the real long-term goal is doing this across a whole progression, tracking the closest voicing chord to chord — this single-chord session is deliberately narrow so the drill itself lands before adding harmonic movement on top.

## What's taught

- **The "hub-latching approach," named and defined.** Pick one familiar root-position voicing of a chord and treat it as the "hub"/home base everything else returns to; build inversions rooted on the chord's other tones and jump out to them from the hub, back to the hub, repeatedly — rather than walking a single inversion up the neck string by string (which stays anchored to a moving root instead of one fixed hand position). Explicitly framed as closer to how comping happens in real playing. Full writeup, including the practice-progression steps and the root→9 doubling trick, on the new technique note [[Hub-Latching Approach]].
- **Why every voicing has four inversions.** Any 4-note chord (root-3rd-5th-♭7 for a dominant 7) has four inversions — root, 3rd, 5th, or ♭7 on the bottom. Stated as general theory, not specific to this chord type.
- **Manual-derivation trick for finding an inversion without memorizing it as a fixed shape.** Move a chord tone down to the closest possible other chord tone on the same string — move the root down to the closest tone and you land on the ♭7; move the 5th down to the closest tone on that string and you land on the 3rd. Repeat note by note to work out the next inversion down. Offered as a legitimate alternative to memorizing shapes directly — either order (shapes-first-then-theory, or theory-first-then-shapes) is fine, "there's no one linear path."
- **The path, worked concretely off D7 (5th-string root form):** hub (root position) → off the 3rd → back to hub → off the 5th → back to hub → off the 3rd → back to hub → off the ♭7 → back to hub → off the 5th below → back to hub → back to the ♭7 → back to the root. Repeated as a second full pass off the 6th-string-rooted form of the same chord, giving a second neck position for the identical vocabulary.
- **Once the path is memorized, drop the fixed order.** Jump freely between the hub and any inversion (not in sequence) — this is the stage that actually feeds real comping rather than a memorized scalar run. He notes not every voicing will get used equally; some feel great, some feel cumbersome, and that's expected — the point of the practice is exposure to the full set, not equal usage of every shape.
- **Rooted-vs-rootless comping judgment call, tied to whether a bass player is present.** Coming back to the hub (a rooted voicing) frequently, using rootless/upper-structure inversions as short "punches"/statements you venture to and return from, keeps a run of comping from losing the sense of the root — especially in **solo guitar**, where nothing else covers it. With a bass player in the band, this constraint relaxes and you can live in rootless upper voicings much more freely since the root is covered elsewhere.
- **Playing-hand technique, mentioned in passing while demonstrating:** slides into some voicings rather than picking cleanly; fingerstyle order is thumb first, then fingers; a pick-player should just strum. A common voicing-shape habit noted: playing the top note first, then filling in the rest underneath gives the chord "a little melody on top" — an easy way to add a chord-melody feel without deliberately arranging one.
- **Doubling the vocabulary — substitute the 9th for the root in every voicing already learned.** Take each inversion from the path (plain 1-3-5-♭7 shapes) and replace its root with the note a whole step up (the 9th) — same "shift a known shape's root a whole step to build the 9" logic already documented on [[Extended Chords]], here applied across an entire hub-latched path at once rather than one voicing. States this "doubles our voicings... without too much headache," since the hand only needs to know where the root is and slide it. Gives a rough total of **22 distinct voicings** off one D7 shape once both the plain and 9-substituted sets, across both string-set roots, are counted. Several of the 9-substituted shapes are called out as favorites: 9-on-the-bottom voicings, and a 9-substituted "off the 3rd" shape that visually resembles a half-diminished chord shape while still functioning as the dominant — described as reading closer to chord-melody or lead material even though it's still comping.
- **The long-term goal, stated but not worked in this video:** do the same hub-latching drill across every chord quality until the voice leading *between* chords becomes visible by ear — when a chord changes, see the closest available voicing of the next chord from wherever you currently are on the neck, rather than resetting to a fixed position. This session works one static chord deliberately so the drill lands before adding real chord motion.
- **Practice application, demonstrated briefly:** loop a one-chord (D dominant 7) backing track and improvise/comp freely using the full voicing set built above.
- **Named external resource (not an owned tool, captured for reference only):** a PDF booklet, "Any Jazz Chord," sold via soundguitarlessons.com — a simplified methodology using only eight shapes to reach any jazz chord type on the fly (useful for reading a lead sheet or a jam session without a memorized shape ready). Mentioned as a natural next step, not something to auto-queue.
