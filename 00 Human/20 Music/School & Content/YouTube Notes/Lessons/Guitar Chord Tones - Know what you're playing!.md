## Synopsis
Jared Borkowski (Sound Guitar Lessons With Jared) teaches episode 3 of his "How to Learn Guitar Chords" series: how to **label the individual chord tones inside any chord shape** — not the letter-note names, but the **interval/scale-degree numbers** (1, 3, 5, ♭3, ♭7, etc.) relative to the chord's root. The pitch this video makes early and returns to repeatedly: letter names only describe one spelling of a chord in one place, but interval labels describe the *structure*, so once you know a shape's chord-tone labels they transfer to the same shape anywhere on the neck, off any root. The method reuses a "measuring stick" technique from earlier in the series (episodes 2–3, referenced but not itself re-taught here) — playing the major scale in order while crossing strings, using the fact that every scale degree is a whole step apart except 3→4 and 7→1, which are half steps. Applied to a chord, you find the chord's lowest note, call it "1," then count up the major scale from there — degree by degree, crossing strings as needed — until you land on each of the chord's other notes, and you label that note with whatever scale-degree number you land on when you get there (altering it with a flat/sharp if it falls a half step off the "natural" scale degree). Worked in full for five open/first-position chords: A major, B major (same shape as A, moved up two frets), C major, D minor, and F#m — plus the naming-convention rule for what to call an altered note that sits between two integer scale degrees (default to describing it relative to the nearest 1/3/5/7, not to compound/extension names, which are deferred to a later video in the series). Ends with a homework challenge: label the chord tones of an on-screen mystery chord shape and post the answer in the comments. Pure theory/technique content, no gear or production material. ## What's taught

- **The core method — count up the major scale from the root, crossing strings, to label every chord tone.** Find the chord's lowest note (its letter name doesn't matter for the labeling, only its identity as "the root you're counting from"); call it **1**. Then walk up the major scale degree by degree from that note, using the crossing-strings technique from the earlier lesson in the series: every scale-degree step is a **whole step** except **3→4** and **7→1**, which are **half steps**; when a target note sits on another string, cross to it using whichever step-size (whole or half) the fret distance and target note require. Every time you land on one of the chord's actual notes, label it with the scale-degree number you're on. If the root isn't the lowest note in the voicing (i.e. it's not a root-position chord — an inversion or slash chord), the process is identical, you just also have to count *down* from the root to label anything below it.
- **This is interval-based, not letter-based, on purpose.** Labeling by letter name (e.g. "C, E, G") only describes one specific spelling in one specific location. Labeling by scale-degree/interval number (1, 3, 5) describes the chord's *structure*, so the same numeric pattern found on a shape applies to that same shape anywhere on the neck, off any root — a directly reusable skill for identifying "what's what and why" in any shape, including inversions, slash chords, and altered chords (his example: a "major 7 sharp 11" chord) later in the series.
- **Worked example 1 — A major (open chord).** Lowest note = open A string = **1**. Counting up the major scale across strings (whole step to 2, whole step to 3, half step to 4 — cross strings here, land on the D string 2nd fret) that note is the **5**. Continuing up: 5→6 whole, 6→7 whole (cross strings), 7→1 half (cross strings) lands on the G string 2nd fret = **1** again (the octave root). Continuing: 1→2 whole, 2→3 whole (cross strings) lands on the B string 2nd fret = **3**. Continuing: 3→4 half (this fret is the same pitch as the next open string) lands on high E open = **5**. **Full chord-tone label, low to high: 1 – 5 – 1 – 3 – 5.**
- **Worked example 2 — B major (same shape, moved up 2 frets, same open string voiced open→fret 2).** Because it's physically the identical shape as A major just relocated, the interval labels are identical without re-deriving them: **1 – 5 – 1 – 3 – 5** — direct proof-of-concept that the numbering transfers with the shape regardless of root.
- **Worked example 3 — C major (open chord).** Lowest note (A string, 3rd fret) = **1**. Counting up: 1→2 whole, 2→3 whole (cross strings) lands on D string 2nd fret = **3**. 3→4 half, 4→5 whole (this fret is the same pitch as the open string below it) — the open G string = **5**. Continuing: 5→6 whole, 6→7 whole (cross strings), 7→1 half (cross strings) lands on B string 1st fret = **1**. Continuing: 1→2 whole, 2→3 whole (cross strings) lands on high E open = **3**. **Full chord-tone label, low to high: 1 – 3 – 5 – 1 – 3.**
- **Worked example 4 — D minor (open chord) — introduces the flat-alteration rule.** Lowest note (open D string) = **1**. Counting up: 1→2, 2→3, cross strings, 3→4, cross strings toward the next target note — but the actual next note played in the chord (G string, 2nd fret) doesn't land on a clean scale degree; it's a half step **below** where a natural 3 would fall. Rule stated: **you're always hunting for some version of 1, 3, 5, or (if present) 7** — if the played note sits just below the natural version of one of those, call it **flat** that number, not the sharp of the one before it (e.g. call it **♭3**, never ♯2). Continuing: that note is followed by the D again (**1**), then **5** (A note, G string 2nd fret — same logic as before), then back to **1** (D, B string 3rd fret), landing finally on **♭3** (F, high E string 1st fret). **Full chord-tone label, low to high: 1 – 5 – 1 – ♭3.**
- **Worked example 5 — F#m (same shape as D minor, moved up/relocated).** Same shape, same relative labels, run quickly to reinforce the transfer: **1 – 5 – 1 – ♭3 – 5** (a 5 is present at the top of this voicing where D minor's open-position shape didn't reach one).
- **Naming-convention rule for altered/non-chord-tone notes.** You are always hunting for **1, 3, 5, and 7** (when present) as the chord's core tones. A note landing **just below** a natural degree gets that degree's **flat** name (e.g. a note a half step below 5 = **♭5**); a note landing **just above** gets that degree's **sharp** name (e.g. a half step above 5 = **♯5**) — **unless** the chord already has a natural version of that degree present, in which case the second, altered note gets pushed to the *next* number's flat name instead (e.g. if there's already a natural 5, a note that would otherwise be "♯5" is instead called **♭6**). Explicitly deferred for later in the series: whether to call that note ♭6 or its **extension name ♭13** is a separate naming layer (compound-interval/extension naming vs. plain scale-degree naming) — for this lesson, either is "getting the structure right," the ♭6-vs-♭13 choice is just nomenclature covered in a future video.
- **Shortcut once the labels start repeating — recognizing interval shapes across the neck.** Once you've derived a couple of chords this way, fixed interval shapes start becoming visually recognizable without recounting every time: e.g. a root on the 3rd string always has its 5 one string down at the same fret; that same 1-to-5 relationship also recurs, same-fret/adjacent-string, in multiple other places around the neck. Stated explicitly as the payoff of *not* skipping the slow counting process at first — the shortcuts emerge from having done the full count-up enough times, not from memorizing them directly. "Would you say I cheated because I counted, that's not cheating, that's how you learn."
- **Practice philosophy note (explicitly repeated theme across the channel).** Let the counting process be slow and effortful at first — don't treat needing to count as a failure or a shortcut you're supposed to skip. The harder/slower it is early on, the more it's actually building long-term automatic recognition; taking the deliberate, patient route (vs. looking up shortcuts) is what makes the skill eventually feel obvious.
- **Homework/challenge posed at the end.** A chord shape is shown on screen with the root already labeled "1"; viewers are asked to label the remaining chord tones themselves using this video's method (numbers only, not the official chord name) and post the answer, low string to high string, in the comments — creator states he'll shout out correct answers in a future video.
- **Series context.** Third video in Jared's "How to Learn Guitar Chords" series (a different numbered series than his later position-mapping series that includes [[Fretboard Logic - 2 ESSENTIAL skills for fretboard mapping]], episode 11, which references "episodes 2–3" for the same major-scale-as-measuring-stick counting technique this video reuses — consistent with this being that same early series).
