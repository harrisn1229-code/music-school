# Close Position Triad Voice-Leading Etude

Part of [[Chord Inversions]] and [[Song Practice]]. A composed practice **etude** for internalizing **close-position** triad inversions across the diatonic key of C major, by the same "move exactly one note, exactly one half/whole step, every chord change" voice-leading rule as [[Spread Triad Voice-Leading Etude]] — but worked on ordinary close-position triad shapes on strings 2-3-4 (B-G-D) instead of spread/open voicings, and walking **up** the fretboard rather than down. Labeled "#1"/"ASCENDING" by its author because it's the first half of a planned two-part series — a "part two" descending version is announced but not yet published (nothing to extract from it yet). Distinct from [[Triads as a Fretboard Map]] and [[Harmonized Scale Triads for Soloing]], which use close-position triads as **soloing** landmarks/motifs rather than a composed voice-leading study.

## Prerequisites (drill these before the etude)
1. **Major scale as scale-degree numbers**, not the whole/half-step mnemonic: 1-2-3-4-5-6-7-1, half steps only between 3-4 and 7-1, everything else a whole step.
2. **Lay that number structure out along one string at a time**, on the three strings this etude uses (worked in the key of C):
   - **String 2 (B string):** fret 1 = C = "1." Practice 1-2-3-4-5-6-7-1 ascending and 1-7-6-5-4-3-2-1-7-1 descending.
   - **String 3 (G string):** open = G = "5." Practice the same shape starting from 5.
   - **String 4 (D string):** open = D = "2." Practice the same shape starting from 2.
3. **Map numbers to letters by the alphabet from the tonic:** C-D-E-F-G-A-B-C-D up, D-C-B-A-G-F-E-D-C-B down.
4. **Two practice levels:** play the shapes only, or (recommended) actively name the chord at every step.

## The construction rule
1. **Start on an E minor close-position triad** on strings 2-3-4 (exact starting fret not captured in the source — see caveat).
2. **Move exactly one note per chord change**, by a half or whole step, whichever keeps it inside the C major scale.
3. **Which voice moves rotates in a fixed order: top (string 2) → middle (string 3) → bottom (string 4) → repeat.** Unlike the spread-triad etude (whose rotation order isn't stated explicitly in its own source video), this video states the rotation order plainly.
4. **The note that just moved always becomes the new chord's ROOT** — the load-bearing rule that makes every landing chord mechanically nameable rather than a guess. This rule is stated explicitly in this video; it isn't stated on the spread-triad etude's page, so treat it as specific to this close-position construction unless/until confirmed otherwise for the spread version.
5. **Chord chain (descending by a third each change):** E minor → C major → A minor → F major → D minor → B diminished → G major → cycle repeats. Every step moves down a third in the key (E→C, C→A, A→F, F→D, D→B, B→G, G→E), even though the shapes physically climb up the neck.
6. **Diatonic triad qualities (standard C-major harmonization):** I major, ii minor, iii minor, IV major, V major, vi minor, vii° diminished.
7. **Ends on a plain C major triad** high up the neck — no dominant-7 cadence (contrast with the spread-triad etude's G7→C close). Stop wherever the guitar's range runs out (nylon-string players won't reach the top); don't reverse direction.

## How it compares to the spread-triad sibling

| | [[Close Position Triad Voice-Leading Etude]] (this page) | [[Spread Triad Voice-Leading Etude]] |
|---|---|---|
| Voicing type | Close-position (adjacent-string stack) | Spread/open-position (middle note moved up an octave) |
| Fretboard direction | Ascending (climbs up the neck) | Descending (walks down the neck) |
| Chord-chain direction | Down a third each change (E→C→Am→F→Dm→Bdim→G) | Up a third each change (C→Em→G→Bdim→Dm→F→Am) |
| Starting chord | E minor | C major (the tonic) |
| Rotating-voice order | Explicitly stated: top → middle → bottom, repeating | Not explicitly stated in the source |
| "Moved note = new root" rule | Explicitly stated | Not stated (not confirmed either way) |
| Ending | Plain C major triad, no cadence | Real cadence: G7 → C |
| Companion piece | "Part two" (descending version) announced, not yet published | — |

Same generative idea (chain the diatonic triads a third at a time, move exactly one voice per change, land on the closest voicing), applied to the two different triad-voicing families guitarists actually use, in opposite directions on both axes (voicing type and neck direction). Treat them as a matched pair rather than duplicates.

## How to practice it
1. Drill the four prerequisites above until the scale-degree/string layout is automatic.
2. Play the etude off the page/by ear first, shapes only.
3. Then re-run it naming every chord as you land on it, using the "moved note = new root" shortcut rather than reasoning out each triad from scratch.
4. **Standalone drill this etude's logic generates:** from any close-position triad, work out which single note has to move (and by how much) to land on the triad a third below in the key, with that moved note becoming the new root — the exact move-by-move logic used to construct this etude, usable as a cold drill on any close-position shape.
5. When "part two" (the descending version) is published, work it as the companion drill — same logic, opposite fretboard direction, "slightly different" rules per the author's own teaser.
