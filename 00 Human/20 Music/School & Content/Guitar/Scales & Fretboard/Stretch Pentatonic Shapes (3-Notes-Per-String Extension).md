# Stretch Pentatonic Shapes (3-Notes-Per-String Extension)

Part of [[Guitar Positions]]. Extends the classic 2-notes-per-string pentatonic box by one extra note per string, breaking out of the standard confined pentatonic box shape without leaving the pentatonic scale's five notes — a lighter-weight alternative to jumping straight to a 3-notes-per-string heptatonic scale or full mode when a player feels stuck in the pentatonic "meme" shape. Complements [[2-3 System for Diagonal Pentatonic Shapes]] (a different diagonal reworking of the same five notes) and [[Combining Major and Minor Pentatonic Scales]] (a relocate-the-box rather than extend-the-box approach).

## The core trick — extend, then reorder to avoid ugly repeats
Take the standard 2-notes-per-string A minor pentatonic box and add one more note to each string (still only the scale's 5 notes: A C D E G). A naive extension — adding the note without adjusting the box's fret span — produces heavy note *repetition* across strings, since a 5-note scale spread over 3-notes-per-string inevitably recycles pitches within the position. Left unmanaged this repetition sounds like an accidental mistake rather than a deliberate color. **The fix:** shift the scale up slightly with every string transition (rather than keeping a fixed fret span across all six strings) so the notes stay in strict ascending order (A C D E G) with no repeats — this is the recommended starting shape, though it breaks the "one fixed box, same fret span every string" mental model most players default to and instead spreads diagonally across a wider stretch of the neck. The repeating-note version isn't wrong, either — see Lick 2 below for when the repetition itself becomes the effect.

## Three worked licks built from the extended shapes
1. **Legato stretch lick (no-repeat shape).** Built entirely from hammer-ons/pull-offs (a deliberate choice after a run of picking-focused lessons) — keep the fretting-hand motion small and relaxed rather than forcing extra force into each hammer-on, which is what actually produces a smooth, connected legato sound without audible string-transition noise. Uses hybrid picking (pick plus middle finger plucking) though a straight pick works too. Ends on a **micro-tonal bend** — bend the final note (the minor 3rd) only slightly sharp and deliberately do NOT resolve it back down — an intentionally "wrong," not-quite-in-tune note left hanging, which reads as bluesy/fusion-flavored rather than a mistake.
2. **Repeating-note lick (the "ugly" shape used deliberately).** Built from the *unshifted* extended shape (the one with repeated notes) specifically because the shape's higher symmetry makes certain fast patterns easier to execute, and the repeated-note texture itself sounds unusual/hard-to-transcribe when played fast. Adds a genuine blue note (a chromatic passing tone outside the scale) that resolves back to the root, for the bluesy color.
3. **4-notes-per-string tapped pattern.** Add a 4th note per string via right-hand tapping (rather than trying to stretch a 4th fretted note, which gets impractical) to extend the system one step further. Worked as a repeating group-of-9 pattern alternated between two adjacent strings (a string-skipping element on top of the tapping). Flagged as a genuinely difficult timing/coordination challenge — start with a simpler tapped pattern before attempting repeating irregular groupings.
