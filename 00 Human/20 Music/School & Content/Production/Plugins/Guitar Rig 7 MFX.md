# Guitar Rig 7 MFX

![[Images/Guitar Rig 7 MFX.jpg]]
*Same Guitar Rig 7 rack UI as the standalone FX version (this is the Max for Live-hosted build).*

**Category:** Drive/Color
**Vendor:** Native Instruments

## What it is

The Max for Live-hosted version of Guitar Rig 7's effects rack, allowing Guitar Rig's modules to run natively within Ableton's M4L framework.

## What it's used for

Same guitar/bass amp and effects chain building as Guitar Rig 7 FX, integrated via Max for Live.

## FX chain notes

Used as the amp/effects stage on a DI guitar or bass track inside a Live session.

## Key Parameters

| # | Parameter | What it is / does | Technique |
|---|---|---|---|
| ① | Preset / Rack | Modular FX rack (effects-only mode) | See [[Guitar Rig 7 FX]] — same modular rack |
| ② | Components | Amp/cab/stomp/mod modules | Build the chain like a pedalboard |
| ③ | Modular / Control | LFOs, envelopes, routing | Automate a component for movement |
| ④ | Output | Rack level | Level-match to the source |
