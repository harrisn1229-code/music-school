# Every possible Chord Symbol EXPLAINED

![](https://www.youtube.com/watch?v=aMLdWrZqwLg)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=aMLdWrZqwLg)

## Synopsis

A complete guide to chord-chart symbol conventions — which abbreviation maps to which chord, the "stacking rule" that governs what 9/11/13 symbols actually imply, and a worked method for naming an arbitrary, non-obvious cluster of notes as a legible chord symbol.

## What's taught

- **Basic triad symbols**: bare letter (`C`) = major; lowercase `m` or a minus sign (`C-`) = minor (uppercase `M` is ambiguous/risks being read as major); `dim` or `°` = diminished; `aug`, `+`, or `(♯5)` = augmented; `sus4` (or bare `sus`, since sus4 is the default) / `sus2` = suspended triads.
- **7th chords**: bare `7` = dominant 7 (the word "dominant" is never spelled out); `m7` = minor 7; `maj7`, `M7`, or a triangle (`△7`) = major 7; `mM7` (lowercase-then-uppercase M) = minor-major 7; `dim7`/`°7` = fully diminished 7 (a stack of minor 3rds — its top note reads like a 6th but functions as a diminished 7th); half-diminished 7 = a circle with a slash through it (`ø7`), often written instead as `m7♭5` to avoid the confusing symbol.
- **The stacking rule for 9/11/13**: a bare `9`, `11`, or `13` symbol implies **every lower extension is stacked in too** — `C9` actually means C7 with a 9th added (i.e. "C7add9," though nobody writes it that way), `C11` implies the 7th and 9th are present too, `C13` implies 7-9-11 are all present. To get *only* the named extension with nothing else stacked underneath, you must write `add` explicitly (`Cadd11` = just C major plus an 11, no 7th or 9th). `maj9`/`maj11`/`maj13` follow the identical stacking logic but with a major 7 instead of a dominant 7 as the stacked base — same for `m9`/`m11`/`m13` with a minor triad.
- **Omitting notes**: `omit` or `no` (e.g. `omit5`, `no5`) tells the player to drop that degree from an otherwise-implied full voicing — common in practice for dense chords like a full C13, since not every player voices every stacked note anyway.
- **Altered extensions, naming trap**: a flattened/sharpened 9/11/13 must be labeled off the *next extension down*, not by literally combining the root with the altered degree — e.g. a chord that's "an E13 with the 13th flattened" is written `E11(♭13)`, never `E♭13`, because that would misread as "E-flat 13." Alterations go in brackets to visually separate them from the base chord type.
- **Power chords**: `5` (e.g. `C5`) = root + 5th only, no 3rd — technically a 2-note chord, so the root is often doubled an octave up in practice.
- **Added 6th, and a common confusion**: `6` = major triad + the major scale's 6th degree (i.e. implicitly "add6"). **`m6`/`minor 6` still uses the MAJOR 6th degree**, not the minor scale's ♭6 — a frequent point of confusion, since the symbol reads like it should flatten the 6th too; a genuine flat-6th addition must be spelled out as `(♭6)`. `69` = a 6-chord with a 9th also added (i.e. add6 + add9 together).
- **Altered chords (jazz-specific)**: `alt` (e.g. `Calt`) isn't one fixed chord — it signals a dominant 7 with the 5th and/or 9th raised or lowered (any combination), left to the performer's judgment/context.
- **Slash chords**: `chord/bass-note` — not always an inversion (only when the bass note is already inside the chord above it, e.g. C/E) — sometimes it's simply the clearest way to notate an otherwise-awkward extended chord (e.g. G/A is really an A11, but "G over A" is easier to read at sight).
- **Naming an arbitrary note cluster (worked method)**: for chords not neatly built from stacked 3rds (e.g. a cluster with no obvious triad at the bottom), search the note set for *any* recognizable triad shape (in any order, even with a degree omitted), treat that as the harmonic anchor, then account for every remaining note as a stacked extension above it (7th, 9th, 11th, 13th, using `omit` for any degree that's structurally implied but absent, like a missing 5th). **Multiple equally valid names can describe the identical note set** — the choice of which note to treat as the "root"/anchor is a communication decision, not a fixed fact about the chord; the goal is picking whichever name reads most sensibly in context for the player.
