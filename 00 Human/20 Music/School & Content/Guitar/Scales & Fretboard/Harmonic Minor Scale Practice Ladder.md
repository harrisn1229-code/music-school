# Harmonic Minor Scale Practice Ladder

Brandon D'Eon's leveled, seven-stage system for internalizing the harmonic minor scale on guitar, from raw scale memorization through to free improvisation. See [[Harmonic Minor Modes]] for the underlying theory (mode construction, the five-shapes-not-seven simplification, the per-mode chord table) this ladder is built on.

## The ladder

1. **Theory + the two-octave shape.** Understand harmonic minor as natural minor with a raised 7th; memorize one two-octave fretboard shape and be able to transpose it to any root.
2. **The seven modes, by name and order.** Harmonic minor (Aeolian ♮7) → Locrian ♮6 → Ionian ♯5 → Dorian ♯4 → Phrygian dominant → Lydian ♯2 → Super Locrian. Understand that all seven share one note collection, reduced to five practicable fretboard shapes.
3. **Eighth notes at 100 BPM, through all keys.** Drill the five mode shapes across every key at a moderate, steady subdivision before adding speed or complexity.
4. **Chord construction from each mode.** Build the triad and 7th chord native to each of the seven modes (see the table in [[Harmonic Minor Modes]]); understand the borrowed-chord convention (writing in the relative natural-minor key, borrowing the harmonic-minor major V/V7 for cadential strength).
5. **Three-notes-per-string, 16th notes, 80 BPM, all 12 keys — E strings only.** Ascend on the low E string's version of the shape, descend on the high E string's version, cycling through all 12 keys at this fixed subdivision/tempo.
6. **Same three-notes-per-string drill, but rotate the starting string.** Repeat Level 5's drill starting from the A string (12 keys), then the B string, then the D string, then the G string — not just the E strings — so the shapes get internalized independent of which string you started memorizing them on.
7. **Free improvisation over a backing track, mapped by position.** Over a track in a chosen key (e.g. C minor, using the C harmonic minor scale — remember there's no true "key of harmonic minor," see [[Harmonic Minor Modes]]), work through five fretboard positions, identifying which harmonic minor mode is native to each position before improvising in it. Goal: full-fretboard improvisational freedom once every position is comfortable.

## Level 8 — The chain exercise (the hardest, most effective drill)

Pick a random harmonic minor scale/key and **improvise continuously across the whole fretboard without stopping**, for as long as possible, in a fixed rhythmic subdivision (16th notes as the source's own demo, but 8ths/triplets/quarters all work — pick a subdivision that matches your actual skill level rather than defaulting to the fastest one). Unlike the earlier levels, this one can't be played along with a fixed backing demo since it's freely improvised — it's presented as a method to internalize and practice independently, not a fixed routine to copy note-for-note. Named as the single hardest and most effective way to practice a scale, saved for last because everything before it is comparatively easier.
