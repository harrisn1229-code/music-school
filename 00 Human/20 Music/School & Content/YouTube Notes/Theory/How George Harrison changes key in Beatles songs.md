# How George Harrison changes key in Beatles songs

![](https://www.youtube.com/watch?v=s0Hpv4rkQoc)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=s0Hpv4rkQoc)

## Synopsis

David Bennett contrasts George Harrison's rare but always distinctive modulations against Lennon/McCartney's more frequent key changes, walking through three worked examples — a parallel-major swap, a surprise-then-smoothed-return modulation using a shared melody note, and a Mixolydian/relative-minor pivot-chord modulation clarified by harmonic minor.

## Techniques

- **"While My Guitar Gently Weeps"**: A minor verse, chorus modulates to the **parallel major** (A major) — the same E7 dominant chord that would normally resolve to A minor instead resolves to A major, a brighter/more surprising choice than the more predictable relative-major shift (to C major). Reverses the same way going back to the verse; the tonic note stays fixed, only the tonality (minor↔major) swings.
- **"Something"**: C major verse modulates to A major for the chorus — genuinely surprising because an earlier phrase had already trained the ear to expect a different resolution. The return to C major is smoothed by a **shared melody note** (E, common to both the A major and C major chords), so the vocal line doesn't have to change shape at the pivot point — only the harmony underneath it shifts.
- **"If I Needed Someone"**: verse in A Mixolydian, middle eight modulates to B minor — barely registers as a key change since A Mixolydian and B minor are modes of the same parent scale (D major) and share every note. Uses **B harmonic minor** specifically (raised 7th, F♯ major chord) rather than natural minor, for a clearer sense that B minor is now the tonic. Returns via a **pivot chord**: the B minor tonic doubles as the ii chord of the destination A Mixolydian, giving a genuine ii-V-I (Bm–E7–A) that resolves the old key and establishes the new one simultaneously.
