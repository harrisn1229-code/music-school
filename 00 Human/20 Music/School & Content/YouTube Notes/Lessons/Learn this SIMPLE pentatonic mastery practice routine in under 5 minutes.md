# Learn this SIMPLE pentatonic mastery practice routine in under 5 minutes

![](https://www.youtube.com/watch?v=iMFio0LEfjQ)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=iMFio0LEfjQ)

## Synopsis

A "5-minute Monday" short-form lesson from guitar teacher Jesse Glick, aimed squarely at the intermediate guitarist who knows their pentatonic box shapes but "noodles" through them without musicality. Glick's diagnosis: knowing a scale shape isn't the same as being able to use it expressively, in a more vocal, ear-led way. After a quick prerequisite pass mapping all five movable A minor pentatonic box positions up the neck (the "anchor point," transposable to any key), he runs through three escalating restriction exercises, each one stripping away a different crutch so the ear has to take over from the memorized shape: (1) play only two adjacent strings at a time, but sweep that same string pair across all five positions over a simple A7–D7 vamp; (2) reorganize the scale into repeating note groupings (4s, 6s, 8s) offset by one string per repetition — a device he credits to Eric Johnson, Joe Bonamasa, and Eric Gales — for ascending or descending; (3) play the entire five-position scale on one single string only, which he calls out as the single most valuable takeaway if a viewer only tries one of the three. It's a compact, practical routine rather than a theory-heavy lesson — no chord-tone analysis, just physical/aural constraints applied to a shape the viewer (per the video's framing) already knows.

## Techniques

- **[~0:50] Prerequisite: map all five A minor pentatonic box positions up the neck**, starting from the standard first-position box as the "anchor point" for the whole lesson — same notes, five different shapes, movable to any key by shifting the anchor fret.
- **[~1:40] Exercise 1 — two strings at a time, swept across all five positions, over an A7–D7 loop.** Take just the low E–A string pair from box position 1, then the same pair from position 2, 3, 4, 5 in turn; repeat the sweep for the D–G pair, then the B–E pair. Forces the ear to carry the line up the neck instead of leaning on a memorized full box.
- **[~4:10] Exercise 2 — grouped-note sequencing in repeating units (groups of 4, 6, or 8), offset one string per repetition, credited to Eric Johnson / Joe Bonamasa / Eric Gales.** Descending example: start a 6-note run (1-2-3-4-5-6) on the high E string, restart the same 6-note pattern on the same fret one string over (B, then G, then D…). Works ascending the same way, and across all five box positions.
- **[~6:30] Exercise 3 — single-string pentatonic: play the whole scale, all five positions' worth of notes, on one string only** (demoed on the G string). Called out directly as "the one that really separates an intermediate guitar player from the next level" — the single exercise to keep if the viewer skips the other two.
- **General framing tip: each exercise is a progressively tighter physical restriction (fewer strings → reordered groupings → one string) whose shared purpose is forcing ear-led navigation instead of box-shape memorization.**
