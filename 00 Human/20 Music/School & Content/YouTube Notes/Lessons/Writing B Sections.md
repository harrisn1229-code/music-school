## Synopsis

A short, focused harmony lesson on writing a B section that feels distinct from the A section without clashing with it: keep some elements (drums), change others (chords/bass), and specifically write the new chord progression in the A section's **relative key**. Since a relative major/minor shares the exact same set of notes as the original key, a new progression centered on that different root gives the B section its own tonal color while guaranteeing a smooth, non-clashing transition back into A. Directly complements the relative-key re-keying technique documented elsewhere in the vault (used there for pitch-matching a found sample) — same underlying music-theory tool, applied here to composition rather than sample-fitting.

## Techniques

- **Write a B-section progression in the RELATIVE key of the A section** — identify A's key (e.g. A minor), find the relative major by counting up 3 semitones from the root (A → C), then write a new chord progression centered on that new root using the identical set of scale notes — the B section gets a genuinely different tonal color (a different chord as "home") while staying guaranteed-compatible with A, since nothing outside the shared scale is introduced. → [[Arrangement and Song Form]], [[Scale]]
