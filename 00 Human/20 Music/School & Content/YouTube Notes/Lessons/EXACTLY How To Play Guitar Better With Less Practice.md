# EXACTLY How To Play Guitar Better With Less Practice

![](https://www.youtube.com/watch?v=OuF3QrSrrPw)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=OuF3QrSrrPw)

## Synopsis

Brandon D'Eon (52-Week Guitar Player, jazz degree) argues most intermediate players plateau because they only ever train one of **five core categories** — fretboard knowledge, speed/technique, rhythm, theory, and improvisation — in isolation, and most YouTube teachers avoid theory entirely because it hurts viewership. His fix is a set of **combined drills**, each deliberately engineered to touch all five categories at once so practice time compounds instead of being spent on isolated, low-transfer reps. He gives four concrete routines (random-key scale-degree naming, sweep-shape-in-all-keys, backing-track position/subdivision improv, and spoken major-scale-in-every-key) and is explicit that the point isn't to do all four — pick one, run it for 2–3 weeks daily, and it will compound into every category simultaneously.

## Techniques

- **The five-category framework.** Every drill in the video is evaluated against the same five things: fretboard knowledge, speed and technique, rhythm, theory, and improvisation. The claim: an isolated drill (scales alone, technique alone) only trains one category and wastes practice time; a well-designed drill hits all five simultaneously, which is what makes "less practice" possible for the same result.
- **Routine 1 — Random-key scale-degree naming drill (fretboard + rhythm + theory).** Use a random-key generator (randomcalemachine.com), start a stopwatch, then play through the major scale of the generated key **starting on the offbeats** (not the downbeat — most players default to downbeats). Say each note's letter name **and its scale degree relative to the key's root** aloud as you play it. Critically, **start on a string other than low E** — find the lowest in-key note on the A string (or another string) without using open strings, and anchor the scale run there instead of always defaulting to E, which he calls a crutch that leaves players unable to run a scale from anywhere but the root string. Time the full ascend-then-descend pass, write the time down, then repeat with a new random key — timing across sessions is the built-in progress metric. Metronome runs throughout for the rhythm component.
- **Routine 2 — Sweep-picking arpeggio shape drilled through all 12 keys (technique + rhythm + fretboard + theory).** Take a single sweep-picking arpeggio shape and, instead of drilling it in one key/position (which only trains technique), run the same shape through **all 12 keys with a metronome**, and vary which string you start the shape on rather than defaulting to the low E string every time. Explicitly contrasted with the common "practice the sweep shape solo, no metronome" approach, which he calls near-worthless because it only touches technique.
- **Routine 3 — Backing-track position/subdivision improv drill (technique + rhythm + fretboard + theory + improv — the one he calls the most complete).** (1) Put on a backing track in a known key. (2) Pick one fixed fretboard position/area. (3) Pick a rhythmic subdivision — quarter notes, eighth notes, triplets, or sixteenths. (4) Improvise within that position only, holding that subdivision consistently the whole time rather than drifting into whatever rhythm feels natural. Rhythmic drift under this drill is diagnosed as a technique problem, not a feel problem — "if you start to drift out of time, it's because your technique needs improvement." *(General starting-point note: this is functionally identical in structure to Daniel Seriff's Consistent Rhythms drill in [[The Five Essentials of Guitar Practice]] — same backing-track + fixed-subdivision-improv mechanism, independently taught by a different jazz-trained teacher, which is a decent signal it's a genuinely load-bearing method rather than one creator's idiosyncrasy.)*
- **Routine 4 — Spoken major-scale-in-every-key drill (theory + rhythm + fretboard, weak on technique).** Play the major scale in a key, speaking each note's letter name aloud as you play it, in time with a metronome, both ascending and descending, then move to the next key. He flags this one honestly as the **weakest of the four for raw technical development** — because it's played slowly, but notes it still forces sustained left-hand pressure (a note stops sounding the instant the hand relaxes), so it isn't a technique write-off either.
- **How to actually schedule this (the load-bearing meta-point).** Don't try to run all four routines — **pick exactly one** and stick with it daily for **2–3 weeks** before evaluating. Starting out, six of the twelve keys is an acceptable scope if all twelve is too slow to be sustainable; with reps, a session on one routine compresses down to roughly **30 minutes**. Consistency on one method beats breadth across several.
- **Improvisation's diagnostic role.** Improv is framed as uniquely useful because it's the category that most directly *exposes* weakness in the other four: staying in the same fretboard area under improv reveals a comfort-zone/fretboard-knowledge gap; failing to target chord tones reveals a fretboard-knowledge gap; not knowing what to play over a backing track reveals a theory gap; messy/out-of-time lines reveal a rhythm/metronome gap. Practicing improvisation is framed as practicing all four other categories by proxy, since real-time playing forces all of them to fire at once.
