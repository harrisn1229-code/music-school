# You Suck at Producing No. 30: Using Ableton's Reverb

![](https://www.youtube.com/watch?v=r4zTfXkFb6I)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=r4zTfXkFb6I)

## Synopsis
A foundational, parameter-by-parameter walkthrough of Ableton's stock Reverb device, using the channel's usual absurdist "kids in a house" analogies to explain what each control actually does. Covers the global controls (Size, Decay, Width), then splits the device into its two real halves — the Early Reflections side (Input Processing filter, Spin, Shape, Pre-Delay) and the Diffusion Network side (the long tail, its own filter, Density/Scale, Freeze) — before landing on the single most important workflow habit: never run reverb 100% wet on the source track itself, put it on a return with Dry/Wet at 100% and control the amount per-track with the send knob, so multiple sources can share one space. Simple by today's standards but a genuinely clear breakdown of what's usually a confusing 20+ knob device, and the send/return habit it ends on is foundational.

## Techniques
- **Size + Decay + Width are the global "room" controls** — Size scales the space (small reads metallic — the sound bumping into close walls — large reads luxurious/huge), Decay sets how long the tail rings out (pushable to a near-infinite wash), Width narrows or widens the reflections independent of the dry source. → [[Reverb]] (Ableton)
- **Early Reflections vs. Diffusion Network are two independently-auditionable halves of the device** — solo the Early Reflections side (Diffuse Reflections off) to hear just the room's character (the first few discrete slaps); solo the Diffusion Network (Early Reflections off) to hear just the long trailing wash. Each half has its own filter (Input Processing on the early side, its own on the diffuse side) so you can make either half boomy (lows only) or hissy/airy (highs only) independently, or run "Spin" on either for a built-in chorus-like smear on the reflections themselves. → [[Reverb]] (Ableton), [[Depth and Space]]
- **Pre-delay is a clarity knob, not just a distance knob** — pushing Pre-Delay to 250 ms creates an audible gap between the dry note's attack and the first reflection, giving the source time to "breathe" before the room arrives; without pre-delay, the reverb can start covering the transient/consonant detail of the note the instant it's struck. → [[Reverb]] (Ableton), [[Depth and Space]]
- **Freeze turns the diffuse tail into a sustain-forever pad** — the Freeze button on the Diffusion Network locks the current tail so it rings indefinitely instead of decaying, an instant way to turn any note into an ambient hold. → [[Reverb]] (Ableton)
- **The core workflow rule: reverb belongs on a return, Dry/Wet at 100%, controlled by the send knob** — running Dry/Wet high directly on the source track "cannibalizes" the dry signal, replacing it with the wet reverb instead of adding on top of it. Put the reverb on a return track instead, set its own Dry/Wet to 100% (pure wet), and dial how much of it any given track hears via that track's send knob to the return — this also means multiple tracks can share exactly one reverb instance/space for a cohesive room, rather than each getting its own separate reverb. → [[Reverb]] (Ableton), [[Depth and Space]]
