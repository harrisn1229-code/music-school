# MASSIVE Live Modular Synthesizer w/ P-Thugg from Chromeo

![](https://www.youtube.com/watch?v=1H-ngW1vw_c)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=1H-ngW1vw_c)

## Synopsis

P-Thugg (Chromeo) walks Anthony and Rob Rosen through building and understanding his touring modular rig — six matched, chromed Synthesizers.com voice units controlled by chromed Nord Modular/Nord Electro MIDI controllers. Far more than a gear-porn tour: this is a genuinely detailed case study in designing a modular system specifically for reliable, repeatable LIVE performance rather than studio experimentation, including a fully analog hardwired preset system, a live tuning solution, and a performance-safety discipline.

## Techniques

- **A fully analog, hardwired "preset" system with no digital memory**: a 3-position switch per voice module rewires which envelope generators feed the filter vs. the amp, plus octave/semitone transpose, giving instant sound changes live (18 total across the 6-module rig) — the same principle as a pipe organ's stop selector.
- **Design workflow runs backward from the finished record**: decide what sound is needed for which part of which song first, then hardwire preset positions to match — the sequencing has to be fully pre-planned since there's no time to patch live.
- **Manual override stays available via normalled jacks** at each hardwired switch point — inserting a patch cable overrides the preset routing on the fly, so the fixed system trades away default patchability without eliminating it entirely.
- **Hardwired rather than fully patchable, by deliberate tradeoff**: a fully patch-cabled rig this size would be too heavy to transport and would take far longer than the available 2-3-hour daily setup (sometimes only a 20-minute changeover) to reliably re-patch every show.
- **A "protected base + reserved experimentation knob" live-safety discipline**: leave certain controls completely untouched as a known-good "base" sound, and reserve exactly one control as the only thing available for live improvisation — no matter how far it's pushed, backing it off always returns to a safe sound.
- **A DIY always-on visual tuner**: a cheap clip-on guitar tuner, stripped of its clip and wired with a 1/4" jack, patched onto any oscillator's output (or a synth's headphone/aux out when only one spare output is available) for a constant visual readout while playing — necessary because analog oscillators drift with room temperature/humidity over a live show.
- **Touring reliability by hardware choice**: Synthesizers.com modules chosen specifically for through-hole, header-connector serviceability (a module swap takes ~5 minutes), with one full spare of every module traveling in a dedicated drawer.
- **Routing/logistics for a large multi-voice rig**: each voice's output mults into shared mixers to minimize cable count backstage; Nord Modular/Nord Electro units (also chromed) serve as MIDI controllers via MIDI-to-CV conversion, with poly parts routed to the Nord Modular, electromechanical-piano-style sounds to the Nord Electro, and the more robust lead/bass sounds to the analog modular voices themselves.
