## Techniques

- **A "phat bass" = 6+ single-job layers, not one patch** — sub (Serum, wobbling), gun sub (the same Serum patch with Auto Pan removed), a melodic "gun" layer (built in Loom, an unowned wavetable/resynthesis synth), a Foley layer (recorded gun sounds in a Sampler, texture only), a percussive/transient layer (extra attack, heavily distorted), an analog laser (pitch envelope + Pitch Wrap on Analog), and a heavily-processed "squishy" texture layer — each with exactly one job. → [[Layering and Stacking]], [[Bass Design]]
- **Reuse one patch as two layers by removing a single modulation** — the gun sub is literally the same Serum patch as the main sub, just with Auto Pan taken off, turning a moving/modulated layer into a plain thick anchor layer without designing a second patch. → [[Serum 2]]
- **An intentionally offbeat background layer glues the groove** — a slower, quiet rhythmic layer placed off the main grid reads as "cooler"/more interesting specifically because it doesn't line up with everything else. → [[Rhythm and Groove]], [[Layering and Stacking]]
- **Loom's wavetable-scanning resynthesis mode tries to extract the harmonics of an input sound into a scannable wavetable** — used both for easy bell tones (praised for this specifically) and for a "squishy," wet/colorful texture layer, built with low-pass-filter automation over the resynthesized wavetable. → [[Plugin Wishlist]]
- **A real 10+-stage FX chain on a single texture layer**: EQ8 (denoise a resonance) → Chorus-Ensemble (Ensemble mode, width) → a spectral-dynamics processor (brighten/flatten) → Valhalla VintageVerb (with a notch cut for a "bad harmonic" the reverb introduced) → low-cut → Auto Pan used purely as a modulation LFO ("swishy") → saturation → mid-side EQ → Soothe 2 → more spectral dynamics (compression) → Pro-Q mid-side EQ — then **rendered, chopped further, and re-processed again** because the first pass "wasn't clean enough." → [[ValhallaVintageVerb]], [[Chorus-Ensemble]], [[Auto Pan]], [[Committing and Printing]], [[Plugin Wishlist]]
- **A spectral-dynamics device in Gate mode as a high-end quality fix, not a level fix** — applied on a group/bus specifically to make a bright layer's high end read as "better" high end rather than to change its overall tonal balance or level — a gate used for tone-shaping, not dynamics control. → [[Plugin Wishlist]]
