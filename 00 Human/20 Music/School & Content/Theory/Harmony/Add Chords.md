# Add Chords

Part of [[Music Theory]] → [[Chords]]. A triad + one extra note, **no 7th** — that's what separates add chords from [[Extended Chords]] (Cadd9 = C E G D; C9 = C E G **B♭** D).

## Types

| Chord | Notes (C) | Note |
|---|---|---|
| Cadd9 | C E G D | 9th on top — the common one |
| Cadd2 | C D E G | same pitch class as add9, packed inside the triad |
| Cadd11 | C E G F | rare |
| Cadd4 | C E F G | add11's inside voicing |
| Cadd6 (= C6) | C E G A | usually just written C6 |
| C6/9 | C E G A D | 6th + 9th; common ending chord (a.k.a. "6add9") |

- add9 vs add2: same added pitch, different octave placement
- Minor versions work identically: Cmadd9 = C E♭ G D; Cmadd2 = C D E♭ G

## Usage
- Pop/acoustic color chords — add9 keeps a triad's stability but shimmers (no 7th tension, unlike [[Seventh Chords]])
- 6/9 = classic jazz/soul final-I chord
- If the 3rd is *replaced* rather than added → that's a [[Suspended Chords|sus chord]]

## From videos

- **The Cadd9-vs-Csus2 naming test is the same "check what's actually in the chord" logic as the add9-vs-maj9 test below, just applied to the 3rd instead of the 7th.** Cadd9 (1-3-5-9) and Csus2 (1-2-5) are near-identical shapes/pitch content — same added note either way (D over C) — but the label depends entirely on whether the **3rd is present**: 3rd present → the D reads as **9** (add9); 3rd absent (replaced by the D) → the D reads as **2** (sus2). General rule this comes from: a chord tone above 7 (2/4/6) is only called an extension (9/11/13) when it sits on top of a *complete* triad or 7th chord — pull the 3rd (or 7th) and the "extension" reverts to its plain scale-degree name, regardless of octave. Full rule + the Cmaj7♯11 companion example → [[Extended Chords]]. → [[Extended Chords]], [[Suspended Chords]], [[Intervals]] — Sound Guitar Lessons With Jared, [[Guitar Theory! - Demystifying Compound Intervals vs Chord Extensions]]
- **Recognize an add9 vs. a 7th-derived 9th by checking for the 7th, not by ear alone — worked from an open string doing double duty.** In a classical guitar analysis, a D minor triad with an open high E ringing on top is correctly identified as **D minor add9** specifically *because there's no 7th present* — the same open E ringing over a different chord later in the same piece (an F major triad that also has its 7th present) is instead a true **F major9** (maj7 + 9), not an add9, purely because the 7th is there. Practical check: before naming a "9" chord as add9 vs. a true 9th/maj9, confirm whether the chord's 7th is actually sounding — same physical extension note, two different chord families depending on that one fact. → [[Extended Chords]], [[Chord Voicings]] — Sound Guitar Lessons With Jared, [Gorgeous Classical Progression | Milonga Guitar Chord Theory Analysis](https://www.youtube.com/watch?v=YH6qnXR7LvI)
