# 5 EASY Licks That Sound FAST! (Learn To Shred On Guitar TODAY)

## Synopsis

Five progressively harder licks framed as BERNTH's own personal shredding-journey starting points, each teaching a specific "sounds harder than it is" mechanical trick rather than raw speed: single-string tremolo picking, gentle string-transition introduction, a repeating "cycling pattern" looped through a scale, same-stroke-per-string phrasing, and an economy-picking workaround for an awkward string-hop.

## What's taught

- **Lick 1 — single-string tremolo picking (harmonic minor flavor).** Visualize and play the whole line on one string (high E) so there are zero string transitions to manage — recommended as the actual starting point for shredding, before tackling hand synchronization and string changes at all.
- **Lick 2 — gentle string-transition introduction (3 notes per string, alternate picking).** Explicitly a step up from lick 1: only 3 notes before each string change rather than a full scale run. Diagnostic to watch: the fretting-hand pinky bending away from the fretboard right after its last use on a string, before it's needed again — keep fingers close to the fretboard through the transition, and keep the picking hand's escape from the "dead zone" between strings clean in both hands' motion simultaneously.
- **Lick 3 — a repeating "cycling pattern" moved through the scale (A minor, top 2 strings).** One small picking-and-fretting pattern (repeating the first and last note of a short cell) looped over and over while the left-hand position slides through the scale — sounds and looks far harder than it is, since only one small pattern needs to be learned; recommended specifically for building ascending, dramatic guitar-solo climax lines.
- **Lick 4 — same picking stroke opens every string (favorite/most-used device).** Rather than a straight 3-notes-per-string scale run (which constantly flips which stroke — down or up — opens each new string, a harder picking-angle problem), this lick repeats certain scale phrases across strings so **every string starts with the same stroke** — trading a small amount of melodic predictability for a much easier, one-fixed-angle picking pattern.
- **Lick 5 — economy-picking workaround for an awkward alternate-picked string hop.** A 2-notes-per-string pattern that would otherwise force the pick to hop back and forth between two strings is instead played with two downstrokes (one per string, connected as one sweeping motion) — the technique this video explicitly frames as the natural next step after lick 4's alternate-picking phrasing trick, with a cross-reference to a dedicated economy-picking episode.
