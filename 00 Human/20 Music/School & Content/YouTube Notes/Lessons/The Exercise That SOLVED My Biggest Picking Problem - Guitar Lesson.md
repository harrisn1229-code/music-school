# The Exercise That SOLVED My Biggest Picking Problem - Guitar Lesson

## Synopsis

A personal-history-framed exercise: years of favoring 3-note-per-string shred patterns left a real gap in mid-tempo (120–130 BPM) alternate picking and 2-note-per-string arpeggio work — this exercise (4-note chord arpeggios, one built on every scale degree of C minor) is presented as the direct fix, along with the picking angle, relaxation, and fretting-hand mechanics that make it work at all.

## Techniques

- **The exercise:** four-note chord arpeggios (2 notes per string), one built on each scale degree of the C minor scale — deceptively simple-looking compared to the channel's usual shred content, but demanding on right-hand consistency and clean string transitions at a previously-neglected tempo range.
- **Picking angle — confirms the even-grouping rule.** With 2 notes per string (an even grouping), holding a consistent picking angle keeps the pick clear of the strings after each down-up pair, moving naturally into position for the next string; the wrong angle traps the pick between strings and forces an audible "jump" over each string — demonstrated side by side as dramatically harder to execute.
- **Total picking-hand relaxation is non-negotiable for this exercise, not just preferred.** Any added tension/attack in the picking hand doesn't just degrade the result — it causes the hand to touch multiple strings and collapse the exercise entirely. Framed as one of the exercise's core teaching values: it fails outright unless genuinely relaxed, which forces the habit.
- **Fretting-hand angle/curl requirement, with a concrete failure mode.** A poor fretting-hand angle causes overlapping notes and missed notes from inefficient position-switching; proper curled fingers (not flat) keep notes cleanly separated, which the video calls the single most important factor in how the exercise actually sounds. Flat fingers physically block the next string, which matters directly for future arpeggio-shape work.
- **Doubles as a fretting-hand independence exercise** — only one fretted note per string (no motion there) while the picking hand executes two strokes per string, isolating each finger's job cleanly.
