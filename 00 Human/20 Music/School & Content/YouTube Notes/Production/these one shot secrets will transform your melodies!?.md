# these one shot secrets will transform your melodies!?

![](https://www.youtube.com/watch?v=TNLIX3Z4Ohk)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=TNLIX3Z4Ohk)

## Synopsis

A two-part FL Studio one-shot masterclass from loner (a melodic sample-kit/one-shot pack maker). Part one is "how to make a one shot": three sourcing methods (record a real instrument, record a VST instrument, or design from scratch), then a full from-scratch build of a textured bell one-shot in Pigments (Arturia) — sine-wave base, short attack/decay with sustain pulled to zero and release raised for a bell envelope, a pre-existing one-shot layered in via Pigments' second sampler engine for extra texture, a three-slot built-in FX chain (short-time delay, mono-width reverb with long pre-delay, wide detuned chorus), then a deeper pass using LFO-modulated pitch-shift delay for an evolving, pedal-like texture. He then bounces it in Edison (fades, loop points) and runs the dry bell through an external "get creative" chain — Outer Space (AudioThing) ping-pong texture-pan preset, wet-only mode, preamp distortion, heavy input-driven compression, and a tidy-up EQ — to get a harsher alternate version. Part two is "how to use one shots correctly": Stretch mode so a one-shot's length stays constant regardless of played octave/pitch, saved loop points (including a "ping-pong loop" that plays a reverse tail) shortened almost all the way down for a note-blurring chord effect, and his "accents and textures" library concept (one-shots tagged by key + tempo) plus how to build your own from a single chord — chop the first chord off a progression, run it through a very long Valhalla Delay, and freeze/record that smear as a new reusable texture one-shot. Closes with quick-hit tips: reverse, glide (FL's per-note glide triangle), further pitch-shifting with a "Sound Shifter," and an LFO on a longer pad-style one-shot (amount up, speed down, attack up a touch) for movement. Most value is in the *workflow* (how one-shots get made, tagged, and reused), not any single setting — nearly every specific number is FL/Pigments-specific and non-transferable verbatim, but the underlying moves map cleanly onto Ableton + owned tools (Serum 2, ValhallaDelay, Sampler/Simpler Warp modes).

## Techniques

### Part 1 — Making a one-shot

- **Three ways to source a one-shot: record a real instrument, record a VST, or sound-design from scratch.** For real-instrument/VST recording, record the note in a *higher* octave than needed and pitch it back down inside the DAW afterward — he finds this consistently gives "much nicer textures" than recording at the target pitch directly. *(~0:10–0:45)*
- **Turn any recorded sound into a pad with a granular effect** — his named tool is the free FL-native Fruity Granulizer; the tool-agnostic version of the move is running a one-shot through any granular processor to smear a short hit into a sustained pad. *(~0:45–1:00)*
- **Bell-patch envelope recipe (sine wave, short attack/decay, sustain to zero, release up)** — starting from a synth's default/init patch with a sine oscillator: attack ~1 ms, decay short, sustain pulled all the way down, release raised — that shape alone (not the oscillator choice) is what reads as "bell" rather than a sustained tone. *(general starting point — exact ms values weren't given on screen)* *(~1:15–1:45)*
- **Layer a pre-existing one-shot on top of a from-scratch patch via a second sampler engine, with its attack removed** — drag another bell one-shot into the synth's built-in sampler slot (Pigments' Engine 2), then strip that layer's attack so only its textural tail survives, blended under the from-scratch layer for instant extra character — he calls this "kind of cheating" but it's fast and effective. *(~1:45–2:20)*
- **Three-slot built-in FX chain for a bell: short untempo-synced delay → mono-width reverb with long pre-delay → wide detuned chorus.** Delay: keep time very short and deliberately NOT synced to tempo (subtle grain/texture, not an audible echo), feedback low. Reverb: dry/wet ~35%, size brought down, stereo width collapsed to full mono, pre-delay pushed well up. Chorus: a "vibrato" preset turned up close to max for a wide, slightly detuned character (he compares the result to a Frank Dukes/Q-Beats-style bell). *(~2:20–3:00)*
- **LFO-modulated pitch-shift delay for an evolving, pedal-like texture (his favorite move in the video).** Load a pitch-shift delay effect, pull dry/wet down, then map LFO1 to dry/wet at roughly halfway; sync LFO1 to tempo, slow it down (~2:1 ratio), and change its waveform shape; separately pull the effect's low-pass filter down and add LFO2 driving further movement. Result described as sounding "like something you'd get from a pedal, like a Blooper or a Chase Bliss Thermae." *(~3:00–3:45)*
- **Bounce-to-one-shot housekeeping: trim silence, right-click-reset fade in/out for click-free edges, and save loop points into the file itself before exporting 24-bit WAV.** Recording is done via a mixer channel into Edison; loop points are set at bounce time (explained further in Part 2). *(~3:45–4:15)*
- **External "get it crazy" chain for a harsher alternate one-shot: Outer Space (AudioThing) → preamp distortion → heavy input-driven compression → cleanup EQ.** In Outer Space's ping-pong section, the "Texture Pan" preset: decay shortened, reverb volume down, wow/flutter up, echo pulled back ("you don't want to be too present"), noise brought up a touch; the "wet only" button strips the dry signal entirely for a more ambient/pad-like result (works even on a percussive bell). The built-in preamp adds crunch/distortion he likes as its own harsher character. Follow with a compressor — input driven hard for a tight, aggressive sound — then an EQ pass to cut unwanted low end (and boost/cut anything else to taste). *(~4:15–5:15)*

### Part 2 — Using one-shots correctly

- **Set sample playback mode to "Stretch" so a one-shot's length stays constant across octaves/pitches.** Most modes change a sample's duration when it's played higher/lower; Stretch mode locks the length so pitched-up/down notes still fit the groove. *(~5:45–6:10)*
- **Save loop points INTO the one-shot at export time, including "ping-pong loop" (loop + reverse tail).** With ping-pong loop selected and the loop length dragged almost all the way down, playing a chord progression through the one-shot blurs/merges the notes together into a cohesive, evolving texture — a distinct effect from the note-for-note original. *(~6:10–6:45)*
- **Build a personal "accents and textures" library tagged by key + tempo** — a dedicated folder of short blips/hits and longer smears, filed so you can grab one that already matches the current song's key/tempo instead of auditioning blind. *(~6:45–7:10)*
- **Make your own accent/texture from a single chord: chop the first chord off a progression, run it through a very long Valhalla Delay, then freeze/record the result as a new one-shot.** Same recording process as a normal one-shot (via Edison) but the source is a full chord instead of one note — the long delay smears the chord into a texture/drone rather than a recognizable chord hit. Pitch the frozen result up an octave to sit over the original chord as a topline accent. He explicitly recommends doing this on any element you like in any project — save it to a folder immediately for reuse later rather than losing it. → [[ValhallaDelay]] *(~7:10–7:50)*
- **Quick-hit closing tips:** reverse the one-shot for a swelling/backwards character; glide between notes (FL-specific: double-click the note, click the small triangle icon) — something one-shots can do that a plain VST can't; further pitch-shift with a dedicated "Sound Shifter" tool; and, on a longer pad-style one-shot specifically, add an LFO with amount turned up, speed slowed down, and attack raised a little for ongoing movement (works best on longer sounds, not short hits). *(~7:50–9:30)*
