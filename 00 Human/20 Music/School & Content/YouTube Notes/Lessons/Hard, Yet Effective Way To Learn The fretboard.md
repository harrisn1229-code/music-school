# Hard, Yet Effective Way To Learn The fretboard

![](https://www.youtube.com/watch?v=UVptKt8h1oA)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=UVptKt8h1oA)

## Synopsis

A demanding but high-payoff fretboard-mapping drill: climb the entire neck playing every diatonic triad of one key, low to high, as arpeggios starting on the 3rd, using two different shape families depending on which string carries the bass note.

## Techniques

- **Prerequisite: know the key's diatonic chord-quality order** (major-minor-minor-major-major-minor-diminished).
- **The drill:** starting as low on the neck as possible without open strings, play the diatonic triads of one key in order, all the way up the fretboard as high as possible — as arpeggios (root-3rd-5th), specifically starting from the 3rd of each triad.
- **Two shape families:** one set of major/minor/diminished shapes when the triad's bass note lands on the E, A, D, or B string; a different set when it lands on the G string.
- **Cadence:** one key per day, all 12 keys, for 30 consecutive days.
- **Beginner entry point:** run the drill in a single key (G recommended) until confident before adding more keys.
- **Instrument-agnostic:** framed as applicable to any instrument, not guitar-specific.
