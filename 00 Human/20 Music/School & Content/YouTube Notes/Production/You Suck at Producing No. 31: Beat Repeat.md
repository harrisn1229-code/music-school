# You Suck at Producing No. 31: Beat Repeat

📺 [Watch on YouTube](https://www.youtube.com/watch?v=16dka0dY1HU)

## Synopsis
A short, focused walkthrough of Ableton's stock Beat Repeat device, using the channel's recurring "Derek" bit (glitch-repeating a voice/audio signal like a nervous guy repeating pickup lines) to demonstrate each control. Covers the core Gate/Grid/Variation/Chance knobs, the manual Repeat/Stop buttons as an alternative to leaving repeats to chance, the Insta vs. Gate output modes, and mapping Pitch Decay/Volume Decay for a shaped (rather than flat) stutter — a solid quick-reference for a device already owned and documented in the vault.

## Techniques
- **Gate controls how many times a captured slice repeats** — fewer repeats reads as controlled/subtle, more repeats reads as a full glitch stutter.
- **Grid controls the length of each repeated slice** — this is the actual stutter-rate control.
- **Variation randomizes the Grid size within a range on every trigger** — instead of one fixed repeat length, each new stutter picks a slightly different grid size, producing a less mechanical/locked-in repeat.
- **Chance is a probability knob for whether a repeat fires at all** — flagged as unpredictable/unreliable in practice; the video's own workflow leans toward manual control (below) rather than trusting Chance to decide.
- **Manual Repeat and Stop buttons give frame-accurate control** — pressing the device's Repeat button starts a stutter on demand, and Stop ends it exactly where wanted, instead of leaving timing to the Chance knob. Mapping the Grid knob to a MIDI controller allows real-time stutter-length changes while performing live.
- **Insta (Instead) vs. off changes whether the dry signal survives during a repeat** — with Insta engaged, only the repeated/stuttered signal is audible while a repeat plays (the dry signal is muted); with it off, the repeat blends with the still-playing dry signal. The all-or-nothing Gate mode (only the drums play during a repeat, nothing else) is called out as "pretty extreme" — the video's own habit is to reach for Insta first and save Gate for more disruptive moments.
- **Map Pitch Decay for a falling-pitch stutter, and Volume Decay for a fading stutter** — mapping Pitch Decay to a macro/mod source makes each successive repeat in a run drop in pitch (a classic glitch-slowdown effect); mapping Volume Decay makes each repeat get quieter across the run instead of holding a fixed level. Either — or both together — turns a flat, mechanical repeat into a shaped one.
