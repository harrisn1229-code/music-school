## What's taught

- **Sixths-interval scale pattern, not up/down runs.** Instead of playing a scale (or "thirds/fourths" patterns) straight up and down, skip four notes at a time to outline sixths — e.g. in A: A-F-B-G#-C-A-D-B... Described as sounding immediately more "neoclassical" and harmonically complex than a straight run, while still being a repeatable pattern, not free improvisation.
- **2-note-per-string arpeggio construction, then octave-copy.** Build an arpeggio (e.g. Em7 = E-G-B-D) as two notes per string rather than looking up a boxed shape: E (A string, fret 7), G (A string, fret 10), B (D string, fret 9), D (D string, fret 12). Once that 4-note shape is under the fingers, **copy-paste the identical fret pattern one string set higher** to extend the arpeggio into the next octave — doubles the range without learning a second shape. Moving the top (pinky) note up one fret converts the minor-7 shape directly into a major-7 shape (Em7 → Emaj7), i.e. arpeggio quality change = one-finger move within the same 2-note-per-string frame.
- **CAGED system, taught as five positions from one triad's notes.** Locate every C-E-G triple across the neck; the five resulting fingerings correspond to the C, A, G, E, and D open-chord shapes (each equivalent to that chord shape moved up the neck under a capo). Already covered from the "walk five positions over a diatonic progression" angle in [[Positional CAGED Soloing with Matched Modes and Arpeggios]]; this video adds an explicit pros/cons list:
  - *Pros:* easy to accent chord tones while improvising once all 5 shapes are memorized; shapes connect naturally across the neck (adjacent CAGED shapes are always the same two neighbors in every key); better intuitive grasp of the chord/scale/arpeggio relationship than book study; forces note-level (not just shape-level) thinking, which sounds more musical.
  - *Cons:* the 2-note-per-string fingering used for CAGED arpeggios is awkward once extended to full heptatonic (7-note) scales; resulting arpeggio shapes can be clumsy for sweep picking; only 5 patterns exist for CAGED vs. 7 needed to fully map modes/exotic scales, so CAGED alone under-serves mode study.
- **3-note-per-string symmetrical shapes = each mode, and why shredders default to them.** Extending a chord to more color tones (worked example: Am11 = A-C-E-G-B-D, i.e. Am7 + 9 + 11) and voicing it as **3 notes per string** produces 7 symmetrical shapes across the neck — one per scale degree, and each shape is simultaneously that scale's corresponding mode (2nd shape of C major = D Dorian, 3rd = E Phrygian, 4th = F Lydian, 5th = G Mixolydian, 6th = A Aeolian, 7th = B Locrian). Already the CAGE System's own logic ([[CAGE System Scale Shapes]]); this video frames it explicitly as "learn all 7 modes for free by learning the 3-note-per-string arpeggio shapes."
  - *Pros:* naturally suited to fast, symmetrical shredding; better for sweep picking than CAGED's 2-note-per-string arpeggios; gives all 7 mode shapes (vs. CAGED's 5), so it's the stronger system specifically for learning modes.
  - *Cons:* players who memorize the 3-note-per-string shapes by rote (very common among shredders) skip the underlying theory and don't connect chords/scales/arpeggios; without deliberate study the mode relationships stay invisible; some 3-note-per-string fingerings repeat a note on the same string, which can sound "off" if played carelessly — BERNTH recommends starting with non-repeating shapes.
- **Extended (3-note-per-string) minor pentatonic — the sixth trick, framed as a personal turning point.** Take the familiar 2-note-per-string A minor pentatonic box and add one extra note per string. Naively doing this in the same finger order creates audible note repeats (sounds "wrong"); the fix is shifting the added note's **string-crossing order** so the notes stay in strict pitch sequence (A-C-D-E-G ascending, no doubled note in a row). Framed as reviving a scale (minor pentatonic) many players abandon early for "boring," by making the same five notes sound modern via 3-note-per-string phrasing.
