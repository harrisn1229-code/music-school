## Synopsis

Names and analyzes the minor-key "climbing" progression ♭VI–♭VII–i (Kate Bush's "Running Up That Hill"), then works through why it's ambiguous whether to describe it in the minor key (♭VI–♭VII–i) or its relative major (IV–V–vi) — and argues for minor-key naming as the more honest description of what the song is actually doing tonally.

## Techniques

- **The progression**: starts on ♭VI (not a point of rest), climbs to ♭VII (still not resolved, one step closer), then resolves to i — a two-step climb to the tonic, giving a satisfying "arrival" that matches the song's title/theme. Song: "Running Up That Hill" (Kate Bush); the auto-transcript captures several other song clips in the intro montage but garbles the titles beyond recognition — not claimed here.
- **Roman-numeral naming convention, explained**: minor-key chords are conventionally labeled against the *major* scale of the same letter name (so C minor's chords are "flat" versions — ♭6, ♭7 — of C major's 6 and 7), specifically to avoid ambiguity about which minor scale (natural/harmonic/melodic) is implied. Using bare "6"/"7" without the flat would require specifying the mode every time.
- **Relative-major naming alternative**: the same three chords can be described as IV–V–vi in the relative major key (e.g., E♭ major for a song in C minor) — this stays diatonic-looking and avoids flat symbols, but risks misrepresenting the song's actual tonal center. **Bennett's rule of thumb**: name the key the song is *actually* centered on (established by melody, resolution point, and overall gravity), not whichever relative key happens to share the same notes and looks cleaner on paper — "Running Up That Hill" is tonally centered on C minor throughout, so ♭VI–♭VII–i is the honest label even though 4-5-6-in-E♭-major produces identical chords.
