# TN: 187 OVERMONO - GEAR LIST!

📎 [View on Patreon](https://www.patreon.com/posts/167733732)

## Synopsis

A Patreon-exclusive gear-list image post accompanying Tape Notes' Overmono episode (TN 187) — no video/audio, just a PDF/image spread of Overmono's studio: plugins they favor plus their hardware synths, drum machines, effects, and outboard. This is an inventory, not a technique breakdown — most entries carry only a one-line "what it is" (vendor-style description), not artist-specific settings or workflow, so the page below is a synthesis of what's actually shown rather than a transcript-style extraction. One genuine usage note is given: the **Oberheim OB-6 is run alongside their Sequential Prophet-10 specifically to add layers** — everything else is presence/ownership data, still valuable as "who uses what" signal for gear selection.

## What's shown

**Plugins (favorites, called out specifically):**
- Acustica Audio Ruby 3 — tube EQ plugin modeling a D.W. Fearn VT-5 hardware unit, called out explicitly as "one of their favourite plugins."
- Antares Auto-Tune — pitch correction/vocal manipulation. *(Owned: [[Auto-Tune Pro]].)*
- Waves CLA Vocal Plugin (Chris Lord-Alge collab) — six-fader vocal processing chain.
- Soundtoys MicroShift — stereo widening via micro-pitch-shift + time delay, modeled on Eventide H3000/AMS DMX 15-80S. *(Owned: [[MicroShift]]/[[Little MicroShift]].)*
- Soundtoys Radiator — tube saturation modeling an Altec 1567A mixer amp. *(Owned: [[Radiator]]/[[Little Radiator]].)*
- TAL-Chorus-LX — free stereo chorus modeling the Roland Juno-60's analog chorus circuit, captioned "we use this on everything." *(Owned: [[TAL-Chorus-LX]].)*
- Universal Audio Ampex ATR-102 — 1976 two-track mastering tape machine emulation (warmth/compression/glue).
- UA 1176 Classic FET Compressor — FET limiter emulation. *(Owned equivalent: [[UAD UA 1176LN]].)*
- PSP VintageWarmer 2 — analog-style single/multiband compression + saturation.
- Waves L2 Ultramaximizer — brickwall peak limiter/loudness maximizer.
- LiquidSonics Cinematic Rooms — high-end reverb, up to 9.1.6 immersive/Atmos formats.
- FabFilter Pro-L 2 — brickwall peak limiter for mixing/mastering. *(Owned: [[Pro-L 2]].)*
- Audiopunks Great British Spring — spring reverb modeling 1980s Bandive hardware (Accutronics tanks in a drainpipe housing).
- Maag Audio EQ4 — musical/"air band" EQ for vocals.
- SoundTheory Gullfoss — automatic dynamic EQ (analyzes 1,000×/sec, fixes tonal imbalance/masking). *(Owned: [[Gullfoss]]/[[Gullfoss Master]].)*
- Waves MV2 — "amazing on 808s and basses," boosts low-level content and/or tames peaks to tighten low end.
- Arturia Pre 1973 — 1970s British console preamp emulation.
- Clariphonic Mk3 (Kush Audio) — parallel high-frequency mastering EQ for air/clarity without harshness. *(Owned, different rev: [[Clariphonic DSP MKII]].)*
- Access Virus TI (software) — free VST/AU/CLAP/LV2 emulation of the Virus TI/TI2/Snow hardware synths, full low-level signal emulation of the Motorola DSP56300 chip, no hardware required.

**Hardware synths / drum machines / effects:**
- Black Corporation Deckard's Dream MKII — 8-voice polyphonic analog synth inspired by the Yamaha CS-80.
- Groove Synthesis 3rd Wave — hardware wavetable synth, physical front-panel controls, dedicated knobs + internal DSP.
- Marshall amp (unspecified model) — for the "crunch"/high-gain guitar-amp character. *(Owned digital equivalent: [[UAD Marshall Plexi Classic]].)*
- Sherman Filterbank — hand-built (Belgium, 1996) analog multi-filter/distortion processor.
- Roland TR-1000 Rhythm Creator — Roland's flagship 14-voice hybrid (analog circuits + digital engine) drum machine, stereo sampling.
- Vermona PERfourMER MKII — 4-channel independent monophonic analog synthesizer, desktop/rack.
- Roland RE-201 Space Echo — 1974 analog tape delay + spring reverb.
- Roland TB-303 — acid bassline synth. *(Owned: [[Roland TB-303]].)*
- Roland Juno-60 — analog polysynth. *(Owned: [[Roland Juno-6 - Juno-60]].)*
- Roland SH-2 — duophonic analog synth.
- Roland Jupiter-8 — 8-voice analog polysynth. *(Owned: [[Roland Jupiter-8]].)*
- Elektron Monomachine — discontinued 6-track digital hardware synth/sequencer (2004), crisp/digital/futuristic sound, cult status.
- **Oberheim OB-6 — 6-voice analog polysynth (Oberheim/Dave Smith collab), explicitly captioned "used alongside Prophet 10 to add layers."** The one genuine usage/technique detail on this page: layered with the Prophet-10 for additional voicing, not run alone.
- Lexicon PCM 80 — high-end 1990s digital multi-effects processor, known for lush spacious reverbs.
- Sequential Prophet-10 — 10-voice analog polysynth, modern evolution of the Prophet-5 architecture with expanded polyphony.
- Roland Jet Phaser AP-7 — 1970s analog phaser/fuzz-distortion combo effects unit, sought after for psychedelic character.
- Moog Moogerfooger MF-108M Cluster Flux — chorus/flange modulation pedal with 6 waveshapes, positive/negative feedback.
