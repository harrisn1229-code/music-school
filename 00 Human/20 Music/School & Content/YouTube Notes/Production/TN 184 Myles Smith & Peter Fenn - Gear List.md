# TN: 184 MYLES SMITH & PETER FENN - GEAR LIST!

## Synopsis

A Patreon-exclusive gear-list image post accompanying Tape Notes' Myles Smith / Peter Fenn episode (TN 184) — no video/audio, just a 7-page PDF spread of studio plugins and a handful of hardware/instrument pieces. Same shape as the other TN gear-list posts: one-line vendor-style "what it is" blurbs, no artist-specific settings or workflow given for any item — an inventory, not a technique breakdown.

## What's shown

**Plugins:**
- Audiomovers LISTENTO — audio streaming plugin for remote real-time collaboration/mix approvals over the internet.
- UAD Lexicon Reverb — emulation of the 1978 Lexicon 224 hardware reverb, 8 classic algorithmic programs + chorus, the "lush, atmospheric" 80s/90s sound.
- UAD Capitol Chambers — emulation of the underground echo chambers 30 ft beneath Capitol Studios (Les Paul-era), concrete trapezoidal rooms.
- UAD Spark — UAD's plugin-subscription platform, native (no Apollo/DSP hardware required).
- Xfer Serum — wavetable software synth. *(Owned: [[Serum 2]]/[[Serum 2 FX]].)*
- UAD 1176 — FET limiter emulation (Bill Putnam, 1967). *(Owned: [[UAD UA 1176LN]].)*
- The God Particle (Cradle) — mastering-bus plugin (Jaycen Joshua collab): multiband dynamics, harmonic saturation, EQ, adaptive limiting in one chain.
- UAD Hitsville EQ Collection — emulation of Hitsville U.S.A.'s custom "Motown Sound" graphic EQs, inductor-based, licensed from Motown.
- Waves NS1 — single-fader real-time noise suppression (AC hum, room ambience, static).
- Oeksound Soothe2 — dynamic resonance suppressor, automatically tames harsh frequencies band-by-band without dulling the tone. *(Owned: [[Soothe2]].)*
- Leapwing DynOne — 5-band parallel dynamics processor for mixing/mastering, transparent FIR filters + program-dependent ballistics + Center-Side processing.
- Valhalla DSP — algorithmic reverb/delay plugin lineup (company-level mention, no specific product named). *(Owned: several Valhalla plugins — [[ValhallaRoom]], [[ValhallaPlate]], [[ValhallaVintageVerb]], etc.)*
- iZotope VocalSynth 2 — vocal synthesis/harmonizer plugin, 5 processing engines, synthetic textures/robotic harmonies/classic vocoder-style effects.
- Soundtoys Decapitator — analog saturation, emulates classic tube preamp/console circuits. *(Owned: [[Decapitator]].)*
- Neural DSP Archetype: Cory Wong X — guitar amp/effects suite tuned for clean, edge-of-breakup tones and funk rhythm work; the "X" edition adds advanced mic modeling, a doubler, refined EQs and full Neural DSP Quad Cortex compatibility. *(Different Archetype owned: [[Archetype- John Mayer X]].)*

**Hardware / instrument:**
- EBow — battery-powered handheld electromagnetic string vibrator; replaces the pick for violin-like swells, flute-like textures and infinite sustain.
- Hofner Bass — semi-hollow "Beatle Bass"/"Violin Bass," 1955 design, ultra-lightweight short-scale build with a warm, woody, upright-adjacent "thumpy" tone.
- Shure SM7B — broadcast/studio dynamic mic. *(Documented, not owned: [[Shure SM7]].)*
