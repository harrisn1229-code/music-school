# Ableton Extensions and MIDI Tools

Live's Extensions ecosystem (the extensions-SDK add-ons, distinct from stock devices and third-party plugins) collapses several manual production steps — programming a drum fill, re-voicing a chord, chopping a vocal, designing a glitch transition — into a few clicks, while still leaving room for manual override so the result doesn't sound generic. Reach for these when you want fast idea generation or drop/transition material without leaving Live for a dedicated MIDI-generation or glitch plugin. See also [[MPE Piano Roll Tools]] for the native piano-roll (not Extensions-menu) auto-generating per-note tools added in Live 12.1.

## From videos

- **SideBrain Style Rhythm Generator — style-conditioned drum pattern + fill generation.** Right-click an empty MIDI clip → Extensions → SideBrain Style Rhythm Generator, pick a style (UK garage, trap, etc.), set pattern length (8 bars gives more variation), then **Reshuffle** to audition pattern variations without regenerating from scratch. **Generate Fill** touches only the fill/turnaround bar, leaving the rest of the pattern intact. The preview pane lets you pick the drum-sample set before committing; **Create MIDI Clip** builds both the MIDI pattern *and* a matching Drum Rack from the previewed sounds in one action. After generating, dial back individual voice density (kick, closed hat, percussion, shaker) rather than regenerating — a "busy" first pass is easily thinned to taste per voice. — Zdrewe, [Are Ableton Extensions the Ultimate Cheat Code?](https://youtu.be/RAAc3OKRYqE?is=FCKk943zkE9M74Eq)
- **"Extract Drum Channels" (SideBrain) vs. manual chain-extraction.** Functionally similar to activating a Drum Rack's chains and right-click "Extract Chains," but one click, and — notably — does **not** relocate the extracted tracks to the end of the session the way manual extraction does; it drops them in place. A way to layer just the fill/percussion character from a generator on top of an existing kick/snare: link the generated kick/snare together (for later deletion), mute them, and keep only the generated hats/percussion. — Zdrewe, [Are Ableton Extensions the Ultimate Cheat Code?](https://youtu.be/RAAc3OKRYqE?is=FCKk943zkE9M74Eq)
- **Chord MIDI tools — quick voice extraction + humanize.** From a chord clip, one-click extract just the bass note or just the top voice; apply Strum + Humanize to de-robotify a static block-chord clip. — Zdrewe, [Are Ableton Extensions the Ultimate Cheat Code?](https://youtu.be/RAAc3OKRYqE?is=FCKk943zkE9M74Eq)
- **Midnight Tools — chord re-voicing and progression variation.** Change a chord's voicing (e.g. spread voicing, 2nd inversion) from a menu and audition in place; the **Variations** menu offers alternate voicings/progressions to browse instead of manually re-voicing each chord, apply per-chord or apply-all. Its "generate additional chords from your progression" auto-write feature is unreliable — better workflow is to write your own basic triads first (know the theory), then lean on Variations to reharmonize/re-voice rather than generate from nothing. A separate Chord Progression Helper extension writes into Session View clips only, which doesn't fit an Arrangement-View-first workflow. — Zdrewe, [Are Ableton Extensions the Ultimate Cheat Code?](https://youtu.be/RAAc3OKRYqE?is=FCKk943zkE9M74Eq)
- **BB Cut ("Bend Cut") — vocal-chop / glitch generation.** Extensions → BB Cut, choose an algorithm (e.g. "Tone Pusher") — algorithm choice changes chop character significantly, worth auditioning a few. Works well specifically for vocal-chop-style glitch content, not just generic beat-repeat. Generates a batch of clips per pass; if the first pass isn't usable, Undo History → Custom Action then try a different algorithm rather than manually cleaning up unwanted clips. — Zdrewe, [Are Ableton Extensions the Ultimate Cheat Code?](https://youtu.be/RAAc3OKRYqE?is=FCKk943zkE9M74Eq)
- **Loop Mutator — randomized 4-bar drop/transition design.** Select ~4 bars of a drop, Copy → new track → Paste (bounced audio) → Consolidate → send to Loop Mutator → Randomize repeatedly, each pass mutating/glitching the loop. When a result is good, **save it as a snapshot before randomizing again** so good candidates aren't overwritten. Export a single mutated loop, or the whole snapshot queue, as drop/transition/glitch material. Constraint: 4-bar chunks per pass only. — Zdrewe, [Are Ableton Extensions the Ultimate Cheat Code?](https://youtu.be/RAAc3OKRYqE?is=FCKk943zkE9M74Eq)
