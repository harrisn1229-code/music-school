# Travis Picking Patterns

Four named, foundational fingerpicking patterns in the **Travis-picking** style (named after guitarist Merle Travis) — the signature trait is a picking-hand **thumb that keeps a constant alternating bass** (root then fifth of the current chord, 1–5, back and forth, unchanging in rhythm) while the **fingers fill in chord tones on top**, with melody optionally layered on top of *that* for the more advanced solo-guitar arrangements players like Chet Atkins built from this base. All four patterns share the identical bass line and string-grouping convention — they differ only in what the fingers do above the bass.

## String groupings (applies to all four patterns)
Which strings are used depends only on where the chord's root sits, not on which pattern is being played:
- **6th-string-rooted chord** (e.g. **G**) — thumb alternates strings **6 and 4** for the bass (skip the 5th/A string entirely), fingers work strings **3 (inside)** and **2 (outside)**.
- **5th-string-rooted chord** (e.g. **C**) — contained entirely in the four middle strings: **5, 4, 3, 2**.
- **4th-string-rooted chord** (e.g. **D**) — top four strings only: **4, 3, 2, 1**.

**Minimal left-hand fretting.** Don't fret notes the pattern doesn't actually use — for a picking-friendly G, hold only the 3rd fret on the 6th string rather than a full "textbook" G shape with extra fingers down, since the pattern only ever touches strings 6/4/3/2. Keeping the fretting hand minimal keeps the picking-hand pattern clean and leaves fingers free for later voicing changes.

## Pattern 1 — Inside-Outside
**Bass(root) → Inside(3rd string) → Bass(5th) → Outside(2nd string) → repeat** (6th-string-rooted reference; shift the same idea for 5th/4th-string chords). Named for the finger part, since the bass line is identical across all four patterns. Sounds intentionally plain/mechanical played dead-even — that's fine, it's the foundation the other three build from.

## Pattern 2 — Outside-Inside
Exact mirror of Pattern 1: **Bass → Outside → Bass → Inside → repeat.** Same string groupings, same bass line — a straight flip of which finger note lands on which beat.

## Pattern 3 — Pinch pattern
**The most useful of the four — learn this one first if you only learn one.** Built from two Outside-Inside cycles played back to back, except the very first attack is modified: instead of separately picking Bass then Outside, thumb and **m** (middle) finger pluck **together** in a pinching motion ("the pinch"), and the following beat is left to sustain/ring rather than getting a new attack ("weight"). Full 8-eighth-note figure:
1. **Pinch** — thumb (bass/root) + outside-string finger, plucked simultaneously
2. *(sustain — no new attack, let the pinch ring)*
3. Thumb (bass, alternates to the 5th)
4. Inside
5. Thumb (bass, back to root)
6. Outside
7. Thumb (bass, 5th)
8. Inside

**Preferred variant: drop the very last note** (event 8, the second "Inside") — creates extra syncopated bounce, and at faster tempos opens a beat of breathing room to switch chords cleanly. Works straight or with a light swing feel.

## Pattern 4 — Descending arpeggio
Three-note repeating figure that arpeggiates the chord top-down: **Pinch (thumb bass + outside string together) → Inside (middle voice) → Thumb (bass alone) → repeat.** Because the figure starts on the highest-pitched note (the outside string) and ends on the lowest (the bass), the perceived pitch motion descends each cycle — the bass isn't just rhythm here, it's the bottom of a melodic shape.

## Practice routine
For each pattern: play it slowly through a full chord progression → double the speed → apply it directly to a real song's verse/chorus/solo. Recommended order: patterns 1 and 2 first (mirror images, build the core alternating-bass/finger-independence coordination), then 3 (explicitly built from two cycles of pattern 2 plus the pinch), then 4 (adds genuine melodic/arpeggiated shape on top of the same mechanics).

## Why this is a separate page
Distinct enough as a **named, closed set of 4 patterns** to warrant its own reference rather than folding into [[Fingerstyle Thumb Independence]], which documents *open-ended* thumb/finger independence exercises (drones, alternating-bass drills, root-tracking through changes) rather than these specific fixed patterns. The two are directly complementary and share the same underlying engine (thumb alternates bass, fingers fill chords): drill Travis picking's fixed vocabulary first, then graduate to Thumb Independence's freer coordination work.
