# Sixth Chords

Part of [[Music Theory]] → [[Chords]]. A **6th chord** (e.g. C6) is a major (or minor) triad with the 6th scale degree added on top — milder color/tension than adding a 7th. Common in jazz/swing and has an "old-fashioned" association, though it shows up across pop and rock too.

## The minor-6th naming trap

The added 6th in a **minor** 6th chord is still the **major** 6th degree, never the minor scale's 6th — Bm6 = B minor triad (B-D-F♯) + G♯ (NOT G natural). The "minor" in the chord name describes only the underlying triad, not the added note. A minor triad + the actual flat-6 is a different chord, written m♭6 (or "add ♭6").

## Enharmonic identity with minor 7th chords

Any 6th chord is identical, note-for-note, to the minor 7th chord built a minor 3rd **lower** — its relative minor (B♭6 = Gm7; C6 = Am7) — the same phenomenon [[Chord Inversions]] documents for sus4/sus2 pairs. Which name is "correct" depends on context (which note reads as the root); when context is genuinely ambiguous (an unaccompanied vocal chord, no bass to anchor it), either name is defensible.

## Classical vs. modern "6" — a real notation collision

Classical figured-bass notation uses a superscript 6 to mean **first inversion** (the outer-note interval of an inverted triad is a 6th) — completely different from modern pop/jazz "6," which means an added 6th degree. "C6" in a classical harmonic analysis = C/E; "C6" on a jazz chart = C major + A. Context (which tradition you're reading) disambiguates.

## From videos

- **A full survey plus all three naming traps.** Straight uses: "Somewhere Only We Know" (Keane), "She Loves You" (Beatles, 6th-chord vocal-cluster ending McCartney says George Martin called "corny"), "Sun King," "Michelle" (Beatles). **Spread voicing** diffusing the 6th/5th rub (6th an octave below the 5th instead of adjacent): "The Fool on the Hill" (Beatles). **Guitar-native, especially G6** — playable fully open on the four thinnest strings, arguably the easiest guitar chord; "Big Yellow Taxi" (Joni Mitchell) builds its opening riff from major-to-6th moves exploiting exactly this. **Jazz/swing association**: "Just a Gigolo" (Louis Prima), "My Baby Just Cares for Me" (Nina Simone). **6/9 chord**: "Horse With No Name" (America) — same example independently confirmed on [[Extended Chords]]. **Minor-6th naming trap**: "God Only Knows" (Beach Boys, genuine Bm6) vs. "Bulletproof... I Wish I Was" (Radiohead, a true m♭6). **Enharmonic-inversion ambiguity, real-world case**: "Bohemian Rhapsody" (Queen)'s opening a cappella chord is genuinely ambiguous between B♭6 and Gm7 — most transcriptions land on B♭6, but the notes are identical either way. — David Bennett Music Theory, [[Songs that use 6th Chords]]
