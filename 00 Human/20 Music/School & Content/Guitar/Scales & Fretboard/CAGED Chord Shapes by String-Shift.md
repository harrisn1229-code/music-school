# CAGED Chord Shapes by String-Shift

Part of [[Guitar Positions]]. Standard CAGED teaching (see [[CAGE System Scale Shapes]]) explains the five shapes as the **same chord walked up and down the neck** — headstock to body. This page documents a different derivation Daniel Seriff calls out as rarely taught: instead of moving a shape *up the neck*, **push it sideways, one string at a time, toward the floor** (thick strings → thin strings), and the E/A/D shapes (and, separately, the G/C/F shapes) fall out of each other mechanically, with **one repeatable fix** for the guitar's one tuning irregularity. The payoff isn't a new shape to learn — it's realizing the E, A, and D shapes are literally **the same interval skeleton with one string cut off each time**, so there is nothing new to memorize once you've built the first shape.

## The core mechanism: slide down a string, then fix the B string

1. Take a chord shape you already know (say the open/barre **E shape**).
2. **Copy the exact same fretting pattern down one string** — shift every fretted note from its string to the next thinner string, one string over. The string that used to carry the lowest note (originally the low E) falls off the bottom and is no longer played.
3. Standard tuning is all perfect 4ths **except the G→B string pair, which is a major 3rd**. Any note that lands on the B string after the shift is therefore a half step flat of what the shape "expects." **Fix: raise only that one note, on the B string, up one fret (one half step).** Nothing else in the shape changes.
4. Repeat the same slide-and-fix move again and a *third* shape falls out.

This one rule — **slide a string, then bump the B string up a fret** — is the entire system. Applied to E it generates A then D. Applied to G it generates C then F.

## Family 1 — E → A → D

- **E shape** (full 6-string, e.g. open E or the E-shape barre): low-to-high intervals **R–5–R–3–5–R**. A big, doubled triad — three notes (root/3rd/5th), lots of octave/5th doubling, which is why open-position chords sound "full" without amplification.
- **Slide down one string** (drop the low-E-string note) → the B-string note now reads as a minor 3rd/awkward tone. **Compensate: raise that B-string note one half step.** Result: the **A shape** — 5 strings, intervals **R–5–R–3–5** (A string=R, D string=5, G string=R, B string=3 [compensated], high E=5). Exact same skeleton as the E shape minus the string that fell off.
- **Slide down one more string** (drop the A-string note) → raw result is a major-7th chord (wrong sound). **Compensate the B string again** (raise a half step) → the **D shape** — 4 strings (D-G-B-E), intervals **R–5–R–3** (D=R, G=5, B=R, E=3). Same skeleton again, one more string gone. *(Tip from the video: the stretchy full D-shape-pushed-again voicing is genuinely hard to play — treat it as a visualization aid and play only the strings that are comfortable rather than forcing the whole grip.)*
- Every one of these three shapes barres into a movable chord the normal way — the point of this method is realizing **all three already share one interval structure**, so learning the E shape's numbers means you already know the A and D shapes' numbers too.

## Family 2 — G → C → F

- **G shape** (classic open G, 6 strings): intervals **R–3–5–R–3–R** (low E=R, A=3, D=5, G=R, B=3, high E=R).
- **Slide down one string** (drop the low-E note), **compensate the B string** (+1 fret) → the **C shape** — 5 strings (no low E): intervals **R–3–5–R–3** (A=R, D=3, G=5, B=R [compensated], high E=3). This is the classic open C chord, arrived at as "G pushed down one string," not as a separate shape to memorize.
- **Slide down one more string** (drop the A-string note), **compensate the B string again** → the **F shape** — 4 strings (D-G-B-E): intervals **R–3–5–R** (D=R, G=3, B=5 [compensated], high E=R). This is essentially the top 4 strings of the familiar barre-F chord, but treated here as its own reusable movable grip rather than "part of a big barre chord." Especially useful for staying off the muddy low E/A strings — good as a second-guitar part playing higher, more embellished chords, and it's comfortable to decorate with pinky embellishments (Hendrix/SRV-style).
- Nate's callout on the classic 3-finger open G: the open B string in that shape "sounds really goofy" for regular rhythm use — a beefier open-string power-chord-style G is the better default for repeated use in a song; the 3-finger CAGED-style G shown here is worth knowing for *this derivation*, not necessarily as the everyday go-to voicing.

## Drill sequence (do this, don't just read it)

1. **Build the E shape** at the 5th fret (A barre) or open (open E). Say the interval numbers out loud while you play each note: R-5-R-3-5-R, low to high.
2. **Slide it down one string** without changing any fret — literally copy-paste the same finger shape onto the next string set, dropping the string that falls off. Play it raw (uncompensated) once so you hear the wrong note.
3. **Find the note now on the B string and raise it one fret.** Play the corrected shape. You now have the A shape — check that it's the same chord/root as before if you started from a barre.
4. **Slide down one more string, compensate the B string again.** You now have the D shape. Play E→A→D in sequence, same root family, saying "root-five-root-three-five" → "root-five-root-three" as you go, so the shrinking interval list is audible, not just visual.
5. **Repeat steps 1–4 starting from the G shape** to derive C then F: G (R-3-5-R-3-R) → slide+compensate → C (R-3-5-R-3) → slide+compensate → F (R-3-5-R).
6. **Cross-check the two families on one root.** Pick a key (e.g. A major). Build the A-shape barre at fret 0/open (that's just "A"), then independently build the F-shape-derived voicing and the C-shape-derived voicing that also spell A major, elsewhere on the neck. Confirm by ear/interval-count that all of them are still R-3-5 in some order/duplication — same chord, three unrelated-looking grips, one derivation rule.
7. **Speed round:** pick any root note on the low E string, build the E-shape barre chord there, then derive (don't look up) the A-shape and D-shape versions of that same chord by sliding+compensating live. Repeat starting from a G-shape root on the low E string to derive C and F. This is the actual test of whether the system is internalized — if you can derive the shape instead of recalling it from memory, the drill has done its job.

## Why this is worth having alongside the standard CAGED walk-up

[[CAGE System Scale Shapes]] and most CAGED teaching treat the five shapes as five stops on one continuous trip up the neck (headstock → body). That's the right lens for *scale/arpeggio mapping* across positions. This string-shift derivation is the right lens for **understanding where a shape's notes come from** — it explains *why* the A, D, C, and F shapes have the fret patterns they do (a mechanical consequence of guitar tuning, not five things to separately memorize), and it's the one clean explanation for **why the B string always needs a special fix** in barre-chord shapes, which otherwise just looks like an arbitrary exception to memorize per shape.
