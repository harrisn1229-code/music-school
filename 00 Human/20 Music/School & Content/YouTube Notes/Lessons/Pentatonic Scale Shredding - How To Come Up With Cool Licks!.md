# Pentatonic Scale Shredding - How To Come Up With Cool Licks!

![](https://www.youtube.com/watch?v=EULqYMXXJGI)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=EULqYMXXJGI)

## Synopsis

A composition walkthrough for a single lick built entirely from A minor pentatonic notes, redistributed into a 3-notes-per-string "stretch" shape, then extended further with tapping while deliberately staying inside the scale's five notes, finishing with a bend that breaks the self-imposed pentatonic-only constraint on purpose.

## Techniques

- **Core idea: redistribute the pentatonic scale's 5 notes into a 3-notes-per-string pattern** (rather than the classic 2-notes-per-string box), borrowing the phrasing possibilities of 3-NPS heptatonic scale playing while keeping the pentatonic's characteristic sound — matches the existing vault system for this exact move.
- **Composition process, stated directly:** search for a way to connect each scale position string-to-string in an interesting shape, rather than just running the redistributed scale straight up or down — short connective patterns are framed as sounding better than a plain run.
- **Self-imposed constraint as a compositional exercise:** deliberately limit the entire lick to the plain A minor pentatonic's five notes (no added 6th for Dorian flavor, no raised 7th for harmonic-minor color, no other extension) specifically to demonstrate a "pure pentatonic" approach — noted as a deliberate limitation for this lesson, not a permanent rule.
- **Tapping extension while honoring the constraint:** once the 3-NPS pattern repeats enough to feel exhausted on a string, add tapped notes on the D string (C-D-E, then G-A-C an octave up) — covering a full octave on one string — while still drawing only from the pentatonic's five notes.
- **Pull-off-to-open-string rule:** any pull-off phrase resolving to an open string requires that open string to actually belong to the harmonic context being played — flagged explicitly when pulling off to the open G string (which is diatonic to A minor pentatonic here).
- **Rhythmic note on the tapped section:** the first tapped pattern opens with a quintuplet grouping (5 notes available before the next string move) before settling into full sextuplet (6-note) groupings — named as a genuinely challenging rhythmic shift within the lick.
- **Deliberate constraint-break at the end — the closing bend.** Bends up to the major 2nd (B) with a G stacked on top for a minor 6th interval, plus tremolo — explicitly stepping outside the pentatonic-only limitation used for the rest of the lick. Optional extra dissonance: play the open B string underneath this bend.
