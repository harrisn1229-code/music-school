# Economy Picking

Alternate picking with a sweep-picking graft at every string change: on the note where the picking pattern crosses to a new string, the stroke direction is **not** flipped the way strict alternation would — instead the same-direction stroke is reused (usually a downstroke) so it "doubles" as both the last note of the old string and the first note of the new one, in one continuous connected motion. Distinct from [[Sweep Picking Arpeggio Shapes]] (a full arpeggio shape swept in one continuous stroke start to finish) and from [[Directional Alternate Picking System]] (the strict/beat-locked alternation this technique deliberately breaks at string changes) — economy picking sits between the two, alternate-picking most notes but sweeping through string transitions specifically.

## The mechanic

- For a 2-notes-per-string descending pattern, strict alternate picking would run down-up-down-up-down-up. Economy picking instead runs down-up-**down**-down-up-**down**-down... — the **doubled downstroke** is the string-change point, executed as one connected sweeping stroke rather than two separate picks.
- Works because the doubled stroke lands in the same physical direction the pick is already travelling — no direction reversal is needed exactly at the string crossing, which is the single hardest part of fast alternate picking (getting stuck in the "dead zone" between two strings).
- **Every note is still picked.** No hammer-ons or pull-offs are involved — economy picking is a picking-hand stroke-distribution choice, not a legato technique. Don't confuse the two.

## When to reach for it vs. alternate picking

| | Economy picking | Strict alternate picking |
|---|---|---|
| Right-hand relaxation | Lower effort — no separate stroke at string changes | Higher effort on 2-notes-per-string material specifically |
| Timing/metronome feel | Harder to place accurately at slow tempo — the doubled stroke feels counterintuitive against a click | Easier to lock to a grid; each stroke maps 1:1 to a subdivision |
| Best fit | 2-notes-per-string patterns, and any line with sweep-picking-shaped string transitions | 3-notes-per-string material, anything needing tight metronome/recording accuracy |

Not a strictly-better replacement for alternate picking — a context-dependent tool. [[4 Techniques You Need To Know To Play FAST]] makes the same trade-off explicit: economy picking removed the string-transition problem in a direct side-by-side comparison, but took noticeably longer to feel natural than the other three techniques shown (alternate, hybrid, legato) in that video.

## Getting started

1. Isolate a single 2-string transition first — one string pair, one scale-box position — rather than the full repeating line.
2. Practice the doubled downstroke as one continuous connected motion, not two individual strokes played back to back.
3. Pick angle matters more here than for pure alternate picking: point the pick tip away from the guitar so it doesn't get physically trapped between the two strings during the transition.
4. Once the single transition feels natural, extend to the full repeating pattern (e.g. a descending 2-notes-per-string pentatonic run).
