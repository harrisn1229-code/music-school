# Bass Walkup and Walkdown Fills

BassBuzz's **no-theory-required** version of the chromatic connective-tissue device also covered (from the theory side) on [[Chromatic Bass Lines]] and (from Jamerson's specific three-fret formula) on [[Jamerson's Root-Fifth-Octave Exercise]]: a short chromatic run that leads INTO a target root note rather than landing on it cold. The pitch is deliberately beginner-friendly — "count two frets and walk this way," no scale/key knowledge required — which makes it the right first stop for someone who isn't ready for Jamerson's three-fret/root-fifth-octave version yet. Fill gap: this is the vault's first note built specifically around this **two-fret**, rhythm-placed version of the device, worked on three real, fully-named recorded basslines rather than a single exercise; [[The BassBuzz 55-Step Bass Learning Roadmap]] step 40 ("Walk-ups and walk-downs") previously pointed only at [[Chromatic Bass Lines]], which covers the harmony/reharmonization side of chromatic bass motion, not this melodic-approach-fill version — now updated to point here too.

## The two-fret rule

1. **Find your target (root) note** — the note you need to land on to follow the current chord.
2. **Walkup:** start **two frets below** the target and step up chromatically, one fret at a time, landing on the target. Example: target = D (5th fret, A string) → start on the 3rd fret, walk 3rd → 4th → 5th.
3. **Walkdown:** start **two frets above** the target and step down chromatically into it. Example: target = C (3rd fret, A string) → start on the 5th fret, walk 5th → 4th → 3rd.
4. That's the entire theory requirement — count two frets, walk one direction, land on the root. No scale or key awareness needed to execute it (though [[Chromatic Bass Lines]] and [[Non-Harmonic Tones]] cover *why* it works harmonically, for when that's wanted).
5. **You don't have to walk into every target.** Real basslines skip the walk on some chord changes and use it on others (see "Gold Dust Woman" below) — it's a decoration to place deliberately, not a rule to apply every time a chord changes.

→ [[BASS Slot]] (this is a low-end melodic-fill device, not a harmonic one) · [[Bassline Writing]] step "chromatic walk-up/walk-down connects one phrase to the next, regardless of scale" is the production-side statement of the same device.

## Rhythm placement — where the walk actually starts

The walk isn't just *which* frets — *when* it starts relative to the target matters just as much, and BassBuzz gives two named default placements:

- **Walkup rhythm: two eighth notes before the target**, landing on the downbeat where the target chord starts. Counted: "...and 4 and 1" — the walk's two notes land on the "and" of 3 and beat 4, with the target landing on the following beat 1.
- **Walkdown rhythm: two sixteenth notes before the target** (a faster, more compressed lead-in than the walkup's eighth-note spacing) — counted "3 4 e and a 1," with the walk's notes on the "e" and "a" just before beat 1, landing the target on 1.
- Both placements put the walk in the same functional slot: the last one or two subdivisions of the bar *before* the chord change, never earlier — this is what keeps the walk reading as a lead-in rather than a random passing tone mid-phrase. → [[Syncopation and Metric Displacement]] (the general theory of off-beat placement this rhythm formula is a specific instance of).

## Worked examples

- **Walkup — Pixies, "Hey" (bassist Kim Deal).** Target notes B, D, G, F#, back to B. Walks up into D (two frets below, eighth-note lead-in) and into F# (open string → 1st fret → 2nd fret, same walkup pattern) using the two-eighth-note rhythm above; the G target uses a different (not walkup) pattern the video doesn't break down; the return to B (2nd fret, A string) uses the same two-frets-below walkup again. Named payoff: the walkup notes add "suspense that makes you want to hear the next bar" — they're a forward-propulsion device, not decoration for its own sake.
- **Walkdown — Fleetwood Mac, "Gold Dust Woman" (bassist John McVie).** Target notes D, G, C, back to G, back to D. Goes straight from D to G with **no walkdown at all** (confirms rule 5 above — not every change gets one); walks down into C starting two frets above (5th → 4th → 3rd fret); a different, not-walkdown pattern into G; then a walkdown back into D starting two frets above (7th → 6th → 5th fret), using the two-sixteenth-note rhythm. Named payoff: "those walk patterns give this bass line all of its character" — a direct A/B against the plain root-only version is the fastest way to hear what the fills are actually doing.
- **Combined walkup + walkdown — Earth, Wind & Fire, "Can't Hide Love" (bassist Verdine White).** Target notes F, Bb, G, C, F. Walks *down* into Bb, walks *up* into G, goes straight to C (no walk), then walks *down* into F — proof the two directions combine freely within one bassline rather than being an either/or per-song choice. Uses the same two-sixteenth-note rhythm as "Gold Dust Woman."

## Writing your own — apply it to a progression

Worked twice in the video, both times starting from "boring" (root-notes-only) basslines:

1. **Find your target notes** for the progression (each chord's root).
2. **For each target, choose a direction** — walk up (two frets below) or walk down (two frets above) — independently per chord change; both directions are always available into any target, so this is a genuine creative choice, not a fixed formula. Demoed over a G–C–F–G progression (multiple valid walk-direction combinations shown, e.g. up→C, down→F, down→G, up→low-G *and* a second variation: down→C, down→F, up→G, down→low-G — both work, proving there's no single "correct" answer) and again over an A–F–D–E progression in a different key/feel.
3. **Set the rhythm** — two eighth notes before the change (the "Hey"/walkup-style placement) is the simplest default to start from; switch to the two-sixteenth-note placement for a tighter, more syncopated lead-in once the eighth-note version feels natural.
4. **Test it, listen for anything that sounds "off."** Some walk choices land fine, others jump out as wrong-sounding in context even though the two-fret rule was followed correctly — that's expected, and it's what the fix-it hack below solves without needing to know *why* it sounded wrong.

## The fix-it hack — add a gap when a walk sounds wrong

If a walkup/walkdown sounds off in context (a real failure mode in the video's own A–F–D–E demo: the walkup into F and the walkdown into E both read as "weird," with the *first* note of the walk being the one that jumped out): **move the walk's starting note one fret further away, opening a gap between it and the rest of the walk**, instead of keeping it flush at exactly two frets away.

- **Walkup fix:** instead of two *consecutive* frets below the target, drop the first note back one more fret so there's a one-fret gap before the walk resumes chromatically into the target.
- **Walkdown fix:** same idea in reverse — push the first (highest) note of the walk one fret further above the target, opening the same kind of gap.
- **Why it's here as a hack, not an explanation:** there's a real music-theory reason this fixes the clash (a scale/key-membership issue with the flush chromatic note — see [[Chromatic Bass Lines]] and [[Non-Harmonic Tones]] for the harmony-side account), but the video deliberately withholds it to keep the technique usable with zero theory. Treat "add a gap, does it sound better?" as the practical test — if yes, the flush version was the problem; if the flush version already sounded fine, leave it alone.
