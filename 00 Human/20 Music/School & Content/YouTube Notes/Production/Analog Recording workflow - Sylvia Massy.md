# Analog Recording workflow - Sylvia Massy

![](https://www.youtube.com/watch?v=QLn6AmWKQQk)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=QLn6AmWKQQk)

## Synopsis

Sylvia Massy tracks The Melvins on a vintage Neve 8048 split console, walking through both the console's signal path (mic pre → EQ → fader → bus → recorder → monitor-section return) and her full drum-mic setup for the session. Her stated philosophy up front is the through-line of the video: get the sound right at the source so you never have to chase it later — get-the-right-sound-up-front over fix-it-in-the-mix. The mic list is a genuinely deep multi-mic drum-kit reference (kick, snare ×3, toms ×2 with phase-reversal, hats/ride, MS overheads on a rare AKG C24, room pair, plus two "special" character mics run through compression), with a strong emphasis on phase discipline whenever two mics point at each other.

## Techniques

- **Get-the-sound-up-front philosophy, stated as the session's governing rule.** "If I like the sound I don't want to have to try to chase that sound later — I get the right sound up front and then I come into that sound." Committing to mic choice/placement/preamp+EQ character before tracking rather than relying on later correction. → [[Drum Mic Technique]], [[Gain Staging]]
- **Split-console signal path (Neve 8048): mic pre → 1081 EQ → fader → bus-select → recorder, then a separate monitor section returns each recorder track back into the desk.** Understanding this two-section layout (input section vs. monitor section) explains why vintage split consoles route returns through EQ/fader again on playback — relevant when Nate references vintage-console signal flow in a chain note. → [[UAD Neve 1073]] (owned emulation of the same-era EQ circuit), [[Vintage Gear Worklist]] (Neve 8048 split console, unlogged)
- **Three-mic snare technique: SM57 on top (primary), SM81 as a secondary top mic run through a dedicated fast compressor (dbx 160) purely for snap, and a bottom mic with phase reversed.** The SM81/dbx signal is blended under the SM57 specifically to add attack/snap rather than to replace the main mic. → [[Drum Mic Technique]]
- **Phase-reversal discipline whenever two mics point at each other (opposing top/bottom pairs).** Applied to the snare bottom mic (Sennheiser 441 vs. top SM57/SM81) and both tom pairs (AKG C12A on top, Sennheiser 421 on bottom) — "when two mics are pointing at each other they'll cancel each other out unless you flip that phase." → [[Phase Alignment]]
- **MS overhead configuration on a single stereo mic (AKG C24) rather than a spaced or X/Y pair — one capsule straight down for the cymbals, the other set to figure-8 for the sides, with the side signal's phase flipped in the patch bay rather than on the channel strip** (found to sound better done that way). Same exact setup used tracking Danny Carey's kit on Tool's "Undertow." → [[Phase Alignment]], [[Width and Stereo]], [[Drum Mic Technique]]
- **Snap achieved via a fast hardware compressor (dbx 160) on a secondary mic blended in, rather than EQ boost on the primary mic** — an owned-lane parallel: [[API-2500]] or a fast VCA-style compressor for the same secondary-mic-snap trick in the box. → [[Drum Mic Technique]], [[Compression Staging]]
- **Room character built from a pair of vintage tube mics (U67) plus a dedicated "special character" mono room mic (JZ Black Hole) run through heavy compression (a de-stressor) — small room made to sound big through mic choice + compression, not artificial reverb.** → [[Drum Mic Technique]], [[Reverb]]
- **A dedicated "crush" mic inside/near the kit (a ribbon mic on the kick's right side, drummer's perspective) run hard through a Teletronix LA-2A for a deliberately over-compressed parallel drum-room layer.** Direct owned-plugin match: [[UAD Teletronix LA-2A]]. → [[UAD Teletronix LA-2A]], [[Parallel Processing]], [[2 Drums/3 Drums Bus|Drums Bus]]
