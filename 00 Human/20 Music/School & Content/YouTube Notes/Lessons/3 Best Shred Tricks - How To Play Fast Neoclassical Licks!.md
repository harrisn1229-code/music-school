# 3 Best Shred Tricks - How To Play Fast Neoclassical Licks!

## Synopsis

Three reusable devices for a neoclassical shred sound, combined into one worked lick: pedal-tone licks, the harmonic-minor substitution, and cadence-outlining arpeggios (including layering the harmonic-minor color note into an arpeggio via tapping).

## Techniques

- **Trick 1 — pedal-tone lick.** A repeated "anchor" note interleaved between descending (or ascending) scale tones — worked in A Aeolian: D-C-B-A with the open/anchor note E constantly returning between each descending tone. Named as the standard entry point into neoclassical vocabulary. Movable to any key (E minor, D minor, etc. — same pattern shape). Strict alternate picking throughout; the string-transition moment (moving from one string to the next, e.g. high E string into the B string) must be seamless — no audible gap or overlap marking where the string change happened.
- **Trick 2 — harmonic minor instead of natural minor for a darker, more exotic color.** Raise the natural minor scale's 7th degree by a semitone (worked example: G→G♯ in A minor). **Harmonic-context caveat, stated explicitly:** safe over a plain power chord (no 3rd present to clash), but check first if the underlying harmony contains the natural (un-raised) 7th degree or a minor-7th interval — playing the raised 7th against that would clash.
- **Trick 3 — arpeggios that outline the actual cadence, rather than running the parent scale.** Worked example: an i-V-i (A minor → E major → A minor) arpeggio cadence, which reads audibly as "classical" in a way a straight scale run over the same chords doesn't. **Layering harmonic-minor color into the arpeggio itself:** instead of the expected root (A) as the tapped extension note, tap G♯ (harmonic minor's characteristic raised 7th) for extra exotic color on top of the plain E minor arpeggio (root-♭3-5: A-C-E in this specific voicing).
