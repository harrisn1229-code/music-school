# How to Mix a Song Start to Finish

![](https://www.youtube.com/watch?v=UVvCfJNfSr8)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=UVvCfJNfSr8)

## Synopsis

A full-mix workflow overview from Sage Audio — mostly a sequencing/ordering lesson rather than new individual techniques (most of the specific EQ/compression/saturation moves are covered in more depth in this channel's other videos already in the vault). The value here is the explicit stage order and a couple of standalone tips: avoiding over-reliance on solo when setting levels, and BPM-timed room + ambient reverb sends.

## Techniques

- **A concrete 9-stage mix workflow order, useful as a session checklist.** (1) Route similar instruments to color-coded buses (drums → one bus, synths → another, etc.) BEFORE any processing, so there are multiple useful processing points (track, bus, master). (2) Subtractive EQ per track — high-pass for plosives/hum, a moderate bell for a broader problem range, notch for a very specific issue (e.g. click bleed). (3) Set initial levels with faders, not by soloing — phase relationships between simultaneous signals mean a solo'd instrument rarely sounds like it does in context; faders here just establish a rough balance to be refined later. (4) Compress where an instrument gets buried in some sections but cuts through in others (vocals are named as the most common candidate). (5) Saturate/distort/excite to add harmonic character — exciters add high-order harmonics for clarity, tube-style saturation adds a strong 2nd-order harmonic for warmth. (6) Process at the BUS level for cohesion across a whole instrument group at once (worked example: tape emulation on the drum bus, driven for mild compression + distortion + its own frequency-shaping character; mid-side EQ on buses for stereo control). (7) Room + ambient reverb sends off the buses, timed to BPM. (8) Rebalance levels — every effect added likely shifted perceived level, so revisit the mix (bus faders make group-level adjustments easy). (9) Automate effect parameters for movement/creativity (wet/dry sweeps, EQ sweeps, dramatic reverb-length changes) as a final creative pass. → [[Session Templates]]
- **Avoid over-relying on the solo button when setting initial levels — how something sounds alone is not how it sounds in context, because of phase relationships between simultaneously-playing signals.** Use faders to get a rough balance instead of soloing each track to judge it individually; the fader-based balance will still need revision later, but it starts from an in-context judgment rather than an isolated one. → [[Session Templates]]
- **Two distinct reverb sends off the instrument buses — room and ambient — each timed to BPM via the standard formula.** Room reverb emulates a specific physical space (studio/practice room); ambient reverb emulates a more generalized, undefined space. Worked example: `60,000 / BPM` gives one quarter note = 500 ms at the session's tempo, so room reverb decay was set to 500 ms (one quarter note) and ambient reverb to 1 second (two quarter notes) — both bus-level sends, individual tracks (e.g. vocal) can still get additional dedicated reverb on top if needed. → [[Reverb]]
- **Bus-level saturation/coloration for group cohesion, distinct from per-track saturation.** Driving a tape emulation's input on the drum bus produces mild compression + distortion together, AND shapes the whole drum group's frequency response via the tape emulation's own character — one bus-level move doing three jobs (glue, color, tone) across an entire instrument group at once, rather than processing each drum track individually for the same result.
