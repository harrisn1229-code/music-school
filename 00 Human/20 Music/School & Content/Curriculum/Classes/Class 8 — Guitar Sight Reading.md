# Class 8 — Guitar Sight Reading

An intensive daily block: work through Leavitt's *A Modern Method for Guitar* in order, playing the pages.

## The four courses

| Course | Section | Pages | Lessons |
| --- | --- | --- | --- |
| [[Course 25 — Reading I — First Position, Part One]] | One | 3–29 | 2 |
| [[Course 26 — Reading I — First Position, Part Two]] | One | 30–59 | 2 |
| [[Course 27 — Reading II — Position Playing, Part One]] | Two | 60–99 | 2 |
| [[Course 28 — Reading II — Position Playing, Part Two]] | Two | 100–123 | 2 |

They run in ID order and each depends on the one before it, so exactly one is ever open.

## What it assumes

- Nothing. Leavitt starts from zero.

## What closes it

- Finishing [[Course 28 — Reading II — Position Playing, Part Two]]. There is no written exam — the check is a performance rep, logged on the course note — but the class does now have a finish line, which it did not when it was standing.
