# Inside-Outside Picking and Pick Slanting

Brandon D'Eon's two picking-mechanics rules for fast multi-string alternate-picked lines — small physical details that materially affect achievable speed independent of raw hand speed. Complements [[Directional Alternate Picking System]] (a beat-locked default picking rule) and [[Sweep Picking Arpeggio Shapes]] (the sweep alternative to alternate picking entirely).

## Inside vs. outside picking (2 notes per string)

- **Inside picking**: each pick stroke moves *toward* the next string you're about to cross to.
- **Outside picking**: each stroke moves *away* from it, requiring an extra "hop" back over the string just left before the next stroke lands.
- **Ascending** 2-notes-per-string lines (e.g. pentatonic scales): start with an **upstroke** to stay on inside picking — the following downstroke then naturally moves toward the next higher string.
- **Descending** 2-notes-per-string lines: the rule flips — start with a **downstroke** to stay on inside picking.
- Net effect: picking-stroke direction relative to the string-crossing direction, not raw alternation speed, is what limits achievable tempo on these lines.

## Pick slanting (uneven note groupings per string)

- **Even** note-count per string (groups of 4, 6, etc.): hold the pick at a consistent **downward slant** — it clears the next string without a separate hop, and the slant angle never needs to change since the same picking-direction pattern repeats identically on every string.
- **Odd** note-count per string (3 notes per string is the common case): the required slant flips every string crossing — one crossing needs the downward slant, the next needs an **upward slant** — which is inherently less efficient than the even-grouping case, since the hand has to keep switching slant angle mid-line.
- Practical read: pick slanting is a genuine speed unlock for even-numbered groupings, but doesn't pay off as cleanly for 3-notes-per-string material without constant slant-switching.

## Picking approach is a deliberate choice, not a fixed rule to always alternate-pick

When a fast line resists clean execution even after real practice time, the fix isn't always more repetition of the same picking pattern — it can be switching part of the line to a different picking approach entirely (sweep picking, economy picking) that fits the line's actual shape better. Worked example: a line that resisted full alternate picking for 7 weeks of dedicated practice was solved by sweep-picking part of it instead.

Anchoring is still fine for material confined to 2-3 strings; the fix matters specifically once a line crosses all six. — BERNTH, [[3 Picking Mistakes That Are Slowing You Down!]]
