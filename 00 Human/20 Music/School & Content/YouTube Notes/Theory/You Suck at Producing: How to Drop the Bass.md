## Techniques

- **Diagnose a "something's wrong but the rhythm's right" bass by checking key/scale match first, before touching sound design.** When a newly-added bass part clashes with an existing loop despite being rhythmically locked in, mute the drums and solo bass + the loop's other tonal element together — if it sounds "gross" in isolation, the two parts are very likely in different keys/scales, not a mixing or sound-design problem. → [[Bassline Writing]]
- **Find a loop's actual root note with Ableton's Tuner device, keyed off the first downbeat of each phrase.** Add the **Tuner** audio effect device to the track carrying the loop's dominant tonal part; the note it displays on the phrase's first downbeat is the loop's practical root note (found to be B♭ in this example) — a definitive read instead of guessing by ear. Run the same check on the bass part to find what note it's actually hitting (D here) and confirm the mismatch. → [[Tuner]], [[Bassline Writing]]
- **Retune the bass to the loop's confirmed root note using the instrument's Transpose knob**, rather than rewriting the part or re-recording — shift semitone-by-semitone until the bass lands on the same note the Tuner read off the loop (D → B♭ in this example); once matched, the same rhythmic part reads as "hitting hard" instead of clashing. → [[Simpler]], [[Bassline Writing]]
- **An octave-up jump on a repeated bass note as a quick fill/variation**, once the root is correctly matched — same note, doubled in pitch, dropped onto one repetition of an otherwise-static bass pattern for extra movement without writing a new part. → [[Bassline Writing]]
- *(Theory recap, not newly routed — already covered in depth elsewhere in the vault):* 12 notes repeat across octaves (spot the boundary by the keyboard's 2-black-key groups); most music uses a 7-note subset (a scale); C major = all white keys from C; the same seven notes starting from A instead is A minor (the relative minor).
