# Modal Pentatonic Shapes and the Six-Level Framework

Beyond the two pentatonic shapes most players know (minor and major), there are **five pentatonic shapes total, one derived from each of the five most commonly-used diatonic modes** — treat each as "a skeleton of the corresponding mode" (the mode's notes with the tritone-forming pair omitted). A six-level practice progression takes them from bare shape recall to full improvisational fluency. See [[Diatonic Modes]] for the parent mode framework these shapes skeletonize.

## The five shapes and their modal names

Within one key (worked example: B♭ major), each pentatonic shape is named for the mode it skeletonizes, found by starting on that mode's scale degree:
- **Minor pentatonic** — from the relative minor (Aeolian), up a major 6th from the major-key root (or down a minor 3rd).
- **Major pentatonic** — from the major-key root itself (Ionian).
- **Dorian pentatonic** — up a major 2nd from the major-key root.
- **Phrygian pentatonic** — up a major 3rd from the major-key root.
- **Mixolydian pentatonic** — up a 5th from the major-key root.
- *(Lydian and Locrian pentatonic shapes are skipped — treated as the two least commonly useful modes for this framework, same "you don't hear it as much" logic as elsewhere in modal soloing practice.)*

**Naming caveat, stated deliberately:** these are informal names — the shape doesn't strictly preserve the mode's signature intervals (e.g. the "Dorian pentatonic" doesn't necessarily retain the natural 6 that makes Dorian sound Dorian; it's the *conventional* 5-note shape everyone already learns under that name, not a strict Dorian-tonality-preserving pentatonic). Named for the mode the shape's *notes overlap with*, not for guaranteed Dorian color.

## The six levels

**Level 1 — minor and major pentatonic shapes.** Baseline: if major pentatonic isn't as automatic as minor pentatonic, start here.

**Level 2 — all five modal pentatonic shapes, one key.** Learn Dorian/Phrygian/Mixolydian pentatonic alongside the familiar minor/major, all within one key first. Drill with [[randomcalemachine.com|random key generator]]: pick the shape giving the most trouble, find its scale-degree offset from the major root (2nd for Dorian, 3rd for Phrygian, 5th for Mixolydian, 6th/-3rd for minor), play it at a comfortable tempo through all 12 keys, and time + log the run each day.

**Level 3 — all five shapes, all 12 keys, changing position.** Same drill as Level 2 but faster (~125 BPM) and covering full octave completion per key — deliberately start each key on a shape without open strings so the run doesn't stall, and prefer a randomizer over the circle of fifths so the key order itself doesn't become memorized/predictable.

**Level 4 — improvise with the shapes over real backing tracks.** Move past metronome-drilling into musical use: improvise in 3 different keys over 3 different backing tracks. No hard exit criterion — move on once you can play confidently in any of the drilled keys, anywhere on the fretboard.

**Level 5 — same fretboard position, all 12 keys (the position-anchored companion drill to Level 3).** Where Level 3 changes position while staying in one key, Level 5 does the reverse: stay anchored in one fretboard zone (e.g. 7th–10th fret) and go through all 12 keys, playing whichever pentatonic shape naturally sits closest to that position for each key. Run the same drill **starting from each string in turn** (low E, then A, then D, then G, then B, then high E) — since real improvisation doesn't let you always start a line on the low E string, forcing starts from every string builds shape recall independent of a fixed entry point. Time and log each pass; expect the E-string-anchored pass to be fastest and the higher strings noticeably slower/sloppier at first — that gap is the thing being trained out.

**Level 6 — chain exercises.** Play a continuous, unbroken stream of notes at a fixed rhythmic subdivision (quarter notes, 8ths, 16ths, triplets) for as long as possible without stopping, through one key's worth of shapes — time how long you can sustain it. A genuinely challenging attempt (e.g. 16th notes at 110 BPM) should be hard to sustain much past 30 seconds; report both tempo *and* subdivision when comparing results, since the two numbers together define the actual difficulty.

## Practice cadence

**One key per day, every day, for a month** is the stated minimum dose to see real improvement across the framework — no need to combine multiple levels in a single session.
