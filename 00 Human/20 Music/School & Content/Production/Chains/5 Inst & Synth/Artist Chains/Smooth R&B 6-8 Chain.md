# Smooth R&B 6-8 Chain

**Reference/vibe:** a from-scratch "smooth/sexy R&B in 6/8" beat build, reverse-engineered from loner's own breakdown, [making a smooth/sexy rnb beat in 6/8 time signature](https://www.youtube.com/watch?v=mMZaktspUAA). Not a specific record recreation — the target is a genre/feel (name-checked as "Kehlani/Ty Dolla $ign"-adjacent) built around a single structural lever: the whole project runs in **6/8** instead of 4/4, which reshapes the chords, the drum programming, and the guitar's processing depth. The guitar chain here (9 stages) is the deepest single processing chain logged from this channel to date — most of the "reusable" value in this chain lives in that ordered device list.

## Chain overview

Kontakt guitar (4-chord harmonic-minor progression) carries the harmonic/melodic weight through a 9-stage FX chain. A simple root-following bass gets one widening move. Piano thickens the bed. Kontakt Session Horns and Spitfire Studio Strings (demo) are reserved for the hook only — the verse runs on guitar + bass alone to leave room for a vocalist. Drums are the other half of the "6/8-ness": same physical snare placement as a 4/4 beat, reinterpreted entirely by counting in 3s instead of 4s.

## 1. Foundation — project time signature

- **Options → Project → General Settings → Signature → 6/8** (3/4 named as the alternative). Set BEFORE writing any parts — every subsequent chord/drum decision is built around counting in 3s. → [[Rhythm and Groove]]

## 2. Guitar — Kontakt chord source + the 9-stage FX chain

- **Instrument:** [[Kontakt 7]], unnamed guitar patch. 4-chord progression in harmonic minor (chords 1–2 same, 3–4 switch up). Played dry first to hear the raw tone.
- **FX chain, in order:**
  1. **Bias FX (Positive Grid) amp sim** — tone source. Unowned, see [[Plugin Wishlist]].
  2. **Reverb** (early-chain, smaller) → [[Reverb]]
  3. **Chorus #1** + an EQ move boosting some frequencies
  4. **[[EQ Eight]]** — cut lows, boost some highs, cut mids *(qualitative only — no exact Hz/dB stated)*
  5. **[[TAL-Chorus-LX]]** — "the Juno chorus," a SECOND separate chorus stage, named as a repeat go-to across multiple loner videos → [[Modulation]]
  6. **[[Compressor]]** — "rhythm guitar" preset, input knob dialed to shave peaks, tightening only → [[Compression]]
  7. **[[Kramer Tape]]** — "Reels" preset, run alongside another chorus pass, for width + vintage depth, **hiss/noise turned UP** (contrast vs. other loner builds where Reels' hiss is usually pulled back) → [[Saturation and Distortion]]
  8. **[[Kickstart 2]]** — pulled back (mix low), just enough to make the part "flow in and out," not an obvious pump
  9. **Reverb** (final, heavy) — closes the chain, distinct from stage 2's smaller reverb

## 3. Bass — simple root line + one widening move

- **Root notes only, copied directly from the guitar's chord roots** — no independent bassline, no extra notes. → [[Bassline Writing]]
- **[[Ghz Midside 3]] — boost the Side channel** to widen the bass and fill the stereo frequency picture. *(general starting point — no exact dB given)* → [[Width and Stereo]]

## 4. Piano — depth layer

- A piano part layered underneath the guitar/bass foundation purely for depth, with added top-line notes for a small extra melodic hook in the background.

## 5. Brass — Kontakt Session Horns (hook only)

- **Kontakt Session Horns**, a short pattern, velocities pulled DOWN specifically because higher velocity read as "more harsh" and didn't complement the beat's soft character. → [[Kontakt 7]], [[Sound Selection Guide]]

## 6. Drums — the 6/8 groove itself

- **Snare:** same physical grid position as a straight 4/4 beat — the "6/8-ness" comes from counting in 3s around it ("one-two-three, one-two-three"), not from repositioning the hit. Reverbed percussion layered underneath. → [[Rhythm and Groove]], [[Genre Drum Patterns]]
- **Hi-hat 1:** pitch down, shifted off-grid more aggressively than a 4/4 pattern would tolerate — licensed by the slower 6/8 tempo/lower hit density. → [[Pocket and Microtiming]]
- **Hi-hat 2:** intermittent, hits "every now and then," with a roll at the end for variety.
- **Kick:** minimal/spaced through most of the pattern, landing on the downbeat each pass, breaking into a 3-hit flourish only at the very end of the phrase. → [[Kick Design]]

## 7. Strings — Spitfire Studio Strings (hook only)

- Demo version (~15-min session limit) — enough to lay one pattern and bounce to audio. Violins chosen from several available articulations. No owned equivalent tracked — see [[Plugin Wishlist]].

## 8. Arrangement — the hook/verse split

- **Strings + horns reserved for the hook only.** The verse/main groove runs on guitar + bass alone, deliberately, to leave the singer room to work. → [[Arrangement and Song Form]]

## Variations

- The 9-stage guitar chain (amp → reverb → chorus → EQ → chorus → comp → tape → sidechain-pump → reverb) generalizes to any "vintage, wide, sexy" guitar/keys part — the width specifically comes from stacking THREE separate devices (2 choruses + tape), not one wide-sounding plugin.
- The snare-stays-put / recount-in-3s trick is the cheapest way to test whether an existing 4/4 idea has a usable 6/8 or 3/4 alternate feel before rebuilding a pattern from scratch.
