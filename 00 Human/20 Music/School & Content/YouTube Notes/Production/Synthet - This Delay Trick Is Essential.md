# Synthet - This Delay Trick Is Essential

![](https://www.youtube.com/watch?v=JNkOyAfJRb8)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=JNkOyAfJRb8)

## Synopsis

A short, focused delay-routing lesson: put a delay on its own return channel with the dry signal removed so that channel only carries echoes, then automate the *send* level from the source track into that channel instead of running the delay on the source directly — this lets you delay one specific word in a phrase rather than the whole line, and opens the door to processing the echo channel differently from the dry signal (its own stereo width, pitch shift, etc.). Same core technique as the delay-channel section of [[Synthet - Every Trick to EAR CANDY]] from later in this batch.

## Techniques

- **Put delay on a dedicated return channel with dry removed, then automate the send** — instead of inserting delay on the source and fighting to control when it's audible, route a send to a return channel that holds *only* the delay (100% wet), then automate that send's level up only where you want an echo — e.g. one word in a phrase, rather than the whole line. → [[Delay]]
- **The isolated echo channel is a separate processing target** — because that channel carries nothing but the wet delay signal, it can be treated with its own stereo width, pitch shift, or other effects without touching the dry source at all.
- **Key parameters to dial in first: delay time (tempo-synced) and feedback.**
