# Mixing Guitars & Bass - Andrew Scheps

![](https://www.youtube.com/watch?v=o_IZyCWmliM)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=o_IZyCWmliM)

## Synopsis

Andrew Scheps walks a guitar-and-bass mix pass built entirely around a deliberately small plugin toolkit used the same way every time, favoring speed and familiarity over hunting: EQ Three for surgical cuts, a Helios-style channel EQ for musical/character moves (and previously an API 550/560 chain before that), applied both per-track and again as a single overall guitar-bus EQ instead of duplicating the same move twelve times. Two concrete moves stand out — using a Helios-style EQ's low-frequency circuit-switch resonance (60 Hz / 120 Hz) as a "bump" even with no boost dialed in, and finding bass presence in the 700 Hz–1 kHz range rather than reaching for the low end that was already out of control.

## Techniques

- **A guitar bus/aux EQ move to replace duplicating the same per-track EQ move across many guitar tracks: "why use twelve EQs when you can use one?"** Apply the shared correction once on a guitar aux/bus rather than on every individual guitar track. → [[EQ]], [[6 Guitars/2 Guitar Group|Guitar Group]], [[6 Guitars/3 Guitar Bus|Guitar Bus]]
- **A Helios-style channel EQ's low-frequency circuit switch (60 Hz vs. 120 Hz) creates an audible resonant "bump" purely from switching bands in, with zero gain dialed in.** "When I just switch in the 60 Hertz and then 120 Hertz you're gonna hear an actual bump even though technically I'm not adding [gain] — there's just some resonance in that circuit." A circuit-emulation quirk worth exploiting deliberately rather than only using gain knobs. Unowned — Helios already tracked in [[Plugin Wishlist]] (Waves HLS). → [[EQ]], [[Plugin Wishlist]]
- **EQ Three as the standing surgical-EQ tool, used deliberately over a "musical" EQ for problem-solving cuts.** "If I need a surgical EQ, the EQ Three, I'm done; if I need a musical EQ, usually a [character-style channel EQ] or a new-style EQ, I'm done." Direct owned match. → [[EQ Three]], [[EQ]], [[Masking and Carving]]
- **A deliberately small, memorized plugin toolkit used by habit rather than by hunting for the "best" tool each time.** "I use a really small sampling of plugins, and I actually work this way... when I don't know what to do I'll go hunting, when I do it's much easier just to go to a tool that you know will work." Explicit workflow philosophy, not a specific setting. → [[Session Templates]]
- **Bridge/fuzz guitar layered on top of rhythm guitars gets a high-pass filter to remove excess low end concentrated on one side of the stereo image, rather than EQ-cutting the rhythm bed to make room.** "The left side is pretty small, the right side actually has a bunch of low end, so I'm gonna high-pass that a little." → [[Masking and Carving]], [[EQ]]
- **Matching arrangement lifts get matching EQ lifts: when a "last chorus" guitar layer is written as one step up from the previous chorus guitar, copy the exact same EQ move (not a bigger one) onto it, so the step-up proportion in the arrangement is preserved rather than doubled.** → [[Arrangement and Song Form]], [[EQ]]
- **Bass presence found in the 700 Hz–1 kHz range (tone/string noise) rather than boosting low end that's already excessive.** "There's more than enough low-end, but a lot of these sort of tone and string noise will be down in this 700 to 1k range, so I'm gonna try adding a little bit of this — just sounds a little more present." A deliberately skipped low-frequency EQ-circuit bump (the same 60 Hz Helios move used on guitars) specifically because the bass didn't need more low end. → [[EQ]], [[4 Bass/2 Bass Group|Bass Group]], [[Masking and Carving]]
- **Historical EQ-chain note: previously reached for an API 550-style EQ into an API 560, moving away from it because the 550's frequency/bandwidth control felt more limited than the current Helios-style tool.** Both unowned. → [[Plugin Wishlist]]
