# Sting 2022 by Iftah

![[Images/Sting 2022 by Iftah.jpg]]

> [!note] Confirmed 2026-07-20 (from the panel) — Sting is a **generative MIDI step-sequencer** (Iftah), not a "stab transition effect." Controls are a scale/root, step Length/Density, Rate/Swing/Gate, and MIDI/Clip output.

**Category:** Utility (generative MIDI)
**Vendor:** Max for Live

## What it is

A community Max for Live **generative MIDI sequencer** (by Iftah) — it spins out step patterns quantized to a chosen scale/root, with controls for length, density, swing, gate, and accent, and can output live MIDI or write to a clip.

## What it's used for

Generating melodic/rhythmic MIDI patterns and evolving sequences to feed a synth or drum device.

## FX chain notes

Runs inline in the signal/MIDI chain at the point it's inserted; combines with whatever device follows.

| # | Parameter | What it is / does | Technique |
|---|---|---|---|
| ① | Rate / Swing / Gate | Step rate, swing feel, and gate (note) length | Sync the rate; add swing for groove |
| ② | Length / Density | Number of steps + how many are active (density) | Shorter length for tight loops; density sets busyness |
| ③ | Type | The scale/mode the notes are quantized to (xACEOM…) | Pick a scale so the output stays in key |
| ④ | Root | Root note of the scale | Set to the song key |
| ⑤ | Offset / Acc | Pattern rotation offset + accent amount | Rotate for variation; accent for dynamics |
| ⑥ | MIDI / Clip | Output live MIDI, or write the pattern to a clip | Clip to capture a generated pattern you like |
