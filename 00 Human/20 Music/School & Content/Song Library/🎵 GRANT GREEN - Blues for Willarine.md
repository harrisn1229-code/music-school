# Blues for Willarine — Grant Green

> A swing blues in B♭. Only one line — the closing 6-2-5-1 turnaround phrase — is transcribed here, so this is a stub rather than a full-chorus breakdown; see [[🎵 GRANT GREEN - Miss Ann's Tempo]] and [[🎵 GRANT GREEN - Number One Green Street]] for the fuller companion excerpts from the same lesson family. First vault documentation of this tune.

## Chords

**Key:** B♭ · **Form:** 12-bar jazz blues. Only the closing turnaround is transcribed in the source lesson — the rest of the chorus isn't spelled out bar-by-bar for this specific tune, so treat the skeleton below as confirmed for bars 9–12 only:

**Turnaround (bars 9–12):** G7 – Cm7 – F7 – B♭ → **VI7 – ii7 – V7 – I** — the classic jazz-blues "6-2-5-1," the same shape documented in full (all 12 bars) on the companion tunes [[🎵 GRANT GREEN - Miss Ann's Tempo]] and [[🎵 GRANT GREEN - Number One Green Street]] from the same Jack Ruch lesson family. → [[Blues Form and Harmony]], [[Turnarounds]] § *VI7*, [[The ii-V-I]]

## Solo breakdown (Jack Ruch's transcription, excerpted 6-2-5-1 line)

- **A "classic 6-2-5-1 line"** — Ruch's own description — that outlines the turnaround's chord changes primarily with **chord tones plus a few altered notes**, rather than leaning on one dense device the way the other two Green excerpts do. → [[Chord-Tone Soloing]], [[Bebop Vocabulary]]
- **Reworked by Ruch using the minor-third-transposition device** first demonstrated on the "Number One Green Street" excerpt: starts the line identically to Green's original, then takes one fragment of it and **moves it up a minor third**, before tying the result into his own existing vocabulary to close out the last few chords of the progression. → [[Connecting Licks Into Longer Lines]] § *Transposition device*

## Steal this

- **A 6-2-5-1 turnaround line built mostly from chord tones with light alteration** — a good "floor" line for the turnaround before reaching for the denser diminished-arpeggio/altered-scale vocabulary documented on the other two Green excerpts.
- **The minor-third-transposition move, confirmed a third time** — same device Green uses in "Number One Green Street," now also shown as something *Ruch* deliberately reapplies when reworking a transcribed line into his own — i.e. it's both an analysis finding (something Green does) and a usable composing tool (something you can do to any lick).
