# How I break down ANY sound

![](https://www.youtube.com/watch?v=9PXZ5S2J2rQ)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=9PXZ5S2J2rQ)

## Synopsis

A live "ear-training challenge" video — Anthony gets thrown unfamiliar reference sounds (a synth lead, thunder, another lead, a bass) with no prep and has to reconstruct each from memory in real time, narrating his decomposition method as he goes. The core content is the 4-parameter listening framework itself, plus a genuinely useful noise-shaping recipe for a synthesized thunder/foley sound.

## Techniques

- **The core sound-analysis framework: break any target sound into four parameters before touching a patch — Pitch, Timbre, Duration, Volume (amplitude).** Listen for register/pitch content first, then the harmonic/filtered character (timbre), then the envelope shape over time (duration), then how loud/dynamic it is (volume) — build the patch by addressing each in that order rather than guessing at the whole sound at once. Stated as the same underlying method behind "Think Like a Synth," reused across this channel's whole catalog.
- **Filter brightness must increase when a part is played an octave higher, to preserve the SAME perceived harmonic content — a static filter setting reads as duller up an octave, not the same.** Because higher notes push the fundamental and its harmonics higher in frequency, a filter cutoff that sounded right in one register will start cutting into content it didn't touch before; re-open the filter slightly whenever transposing a patch up.
- **Filtered noise recipe for a synthesized thunder/wind foley sound, with a clear fork based on resonance**: start from low-frequency-weighted noise (not full-spectrum white noise) through a low-pass filter; WITHOUT resonance it reads as "thunderous" (broad, rolling); WITH resonance added it reads as more "windy" (a narrower, whistling character) — the presence/absence of resonance is the deciding factor between the two, not the filter cutoff alone. Framed honestly: a synthesized nature sound is a "cartoon character version" of the real thing — a simplified, punchy stand-in, not a full recreation, and that's fine for most uses.
- **Sample-and-hold noise, shaped by an envelope over time and softened through a lag processor, for a "jagged but not too sharp" stepped/random texture** — the envelope generator rolls off the noise's high end over time (not a fixed filter setting); routing the sample-and-hold output through a lag processor before the filter rounds off the otherwise-harsh jagged edges, tunable from extreme/sharp to smoothed depending on how much lag is applied.
- **The 80% target, restated as a working discipline**: aim to get a from-memory recreation to roughly 80% right on the panel alone, without needing to A/B against the reference sound repeatedly — then use whatever the mix/track actually calls for (more brightness, less resonance, added attack, different octave) as the deciding factor for the remaining 20%, rather than chasing an exact match to the reference.
