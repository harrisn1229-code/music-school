# Jeff Buckley's guitar sound with Andy Wallace

![](https://www.youtube.com/watch?v=vUiW3mUeXJw)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=vUiW3mUeXJw)

## Synopsis

Andy Wallace, revisiting his own Jeff Buckley mix, isolates and A/B's three separate room/reverb returns he had printed on the guitar (a short "tiled room," a medium room, and a long hall/chamber), then live-recreates the printed guitar reverb from scratch using only stock reverb plugins as a demonstration of matching an existing analog reference sound with affordable modern tools. The most transferable lesson is procedural: layering multiple reverb lengths on one source rather than picking a single reverb, and where in the signal path to EQ a reverb return versus the dry/direct signal.

## Techniques

- **Layering three separate reverb sends of different lengths on the same guitar — short (tiled room), medium (room), and long (large hall/chamber) — rather than committing to one reverb.** Demonstrated individually (isolating just each reverb's return with the dry guitar muted) so the ear can hear the decay character and length of each layer on its own before they're blended together in the final mix. The short "tiled room" reverb was used only lightly in the final mix despite sounding heavy when soloed — a reminder that a reverb return should always be judged blended-in, not solo'd.
- **Reconstructing a printed analog reverb sound from scratch as a matching exercise: start from the dry guitar, bring in the long hall return alone, judge what's missing (presence), then blend in a second, shorter reverb layer to restore it, then EQ the combined return for brightness — A/B'ing continuously against the original printed reference until it converges.** Explicit process: (1) print/reference the original guitar+reverb sound, (2) start with just the long hall reverb return against the dry guitar, (3) diagnose what's missing by ear ("what's missing in that one is a little more presence"), (4) blend in a second reverb length (medium) to add back what the single long reverb lacked, (5) EQ the combined reverb return brighter to close the remaining gap, (6) keep A/B'ing against the reference throughout.
- **EQ the reverb SEND or RETURN, never the reverb'd source's dry/direct signal — and choose which one based on whether the reverb is shared.** When reconstructing the guitar reverb, Wallace deliberately EQs from the reverb return channel rather than the dry guitar track, because he still wants to hear the close-mic'd amp signal unaffected. Explicit routing rule: if a reverb is used on a single, dedicated source, EQ the RETURN; if the same reverb is shared by multiple sources (e.g., a vocal and a guitar both hitting one reverb bus), EQ the SEND for that specific source instead, so the shared return stays neutral for everything else feeding it.
