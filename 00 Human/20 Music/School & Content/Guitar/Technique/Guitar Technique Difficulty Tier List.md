# Guitar Technique Difficulty Tier List

Brandon D'Eon's S-to-F difficulty ranking of 30 guitar techniques, judged at their extreme execution (fast/accurate/musical) rather than a casual first attempt. Useful as a technique-study roadmap. Companion piece to [[Ear Training Difficulty Tier List]] (same format, applied to the ear instead of the hands).

## The ranking, easiest to hardest

| Tier | Technique | Note |
|---|---|---|
| F− | Pick scrape | Easiest technique on the list. |
| F | Vibrato | Fretting-hand only. |
| F | Open chords | First beginner chords. |
| F | Palm muting | |
| F | Natural harmonics | |
| D | Bar chords | Objectively harder than open chords, still beginner-tier. |
| D | Hammer-ons | |
| D | Pull-offs | Common mistake: passive "lift-off" instead of an active pull. |
| D | Sliding | |
| C | Tremolo picking | Fast alternate picking on one string — easier than full alternate picking, no string-crossing. |
| C | Raking | Mostly a muting-discipline challenge. |
| C | Trills | Hammer-on/pull-off combined at speed. |
| C | Tapping | Most famous lines (Crazy Train, "One") are easier than reputation; odd-time tapping (Plini) is harder. |
| B | Hybrid picking | Pick + fingers — e.g. Eric Johnson's "Cliffs of Dover." |
| B | Selective picking | Tosin Abasi style — picking + hammer-ons, left hand does most of the work. |
| B | Traditional bending | Common mistakes: bending under the string, dragging adjacent strings, bending from the fingers not the wrist. |
| B | Unison bends | Out-of-tune landings are more exposed against the sounding reference note. |
| B | Legato | Nearly all left-hand. |
| B | Regular fingerpicking | Capable of S-tier difficulty at its extreme (e.g. "Classical Gas") but most material isn't that extreme. |
| B | Thumping | Thumb-as-pick technique. |
| A | Downpicking | Judged at its extreme — e.g. Metallica's "Master of Puppets" at 212 BPM. |
| A | Sweep picking | Hard to acquire, easy once acquired. |
| A | String skipping | Fast execution needs picking-direction planning around the next string-crossing. |
| A | Tapped harmonics | Tap exactly 12 frets above the fretted note, timed against the pick attack. |
| A | Pre-bends | Bend to pitch before picking — judged by feel/tension only, no audible reference. |
| S | Alternate picking | Judged at its extreme (16ths at 180 BPM), despite being taught early. |
| S | Economy picking | Pick direction follows string-crossing direction; common failure is uneven note spacing. |
| S | Finger-style | Fingerpicking plus a deliberate percussive layer. |
| S | Slapping (guitar) | Harder on guitar than bass — tighter string spacing leaves less room for the thumb. |
| S+ | Alternate picking (promoted) | The single hardest on the list — chosen over economy picking for combining extreme difficulty with far broader practical usefulness. |
