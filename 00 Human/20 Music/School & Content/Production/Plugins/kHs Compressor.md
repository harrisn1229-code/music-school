# kHs Compressor

![[Images/kHs Compressor.png]]

**Category:** Compressor/Limiter
**Vendor:** Kilohearts

## What it is

The full-featured compressor snap-in in the Kilohearts ecosystem, with detailed attack/release/knee controls.

## What it's used for

General-purpose compression duty within a modular Snap Heap chain.

## FX chain notes

Stacked in a Snap Heap chain, after EQ, before saturation/limiting snap-ins.

| # | Parameter | What it is / does | Technique |
|---|---|---|---|
| ① | Threshold | Level where compression begins | Set for the target gain reduction |
| ② | Ratio | Amount of compression above threshold | 2–4:1 transparent; higher for control/limiting |
| ③ | Attack | Onset speed | Fast to tame transients; slow to keep punch |
| ④ | Release | Recovery speed | Auto/medium for program material |
| ⑤ | Makeup | Output gain | Match bypass for a fair A/B |
| ⑥ | Detector (RMS / PEAK / FAST) | How level is sensed | RMS for glue; PEAK/FAST to catch transients |
| ⑦ | Sidechain | External sidechain source selector | Key off a kick to duck the bass |
