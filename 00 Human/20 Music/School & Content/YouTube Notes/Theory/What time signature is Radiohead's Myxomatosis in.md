# What time signature is Radiohead's "Myxomatosis" in?

## Synopsis

A close rhythmic analysis of Radiohead's "Myxomatosis" riff — technically notated in plain 4/4, but built to feel like anything but, via a hidden 3/4 grouping AND a simultaneous 3-against-2 polyrhythm layered on top.

## Techniques

- **A riff that IS 4/4 on paper but is felt as 3/4-with-one-bar-tacked-on.** The 16-beat riff phrase's first 12 beats fall naturally into four clean bars of 3/4; only the final bar is a genuine 4/4 bar (an extra beat added onto what would otherwise be a fifth 3/4 bar) — so the riff reads as "five bars of 3/4, with the last one stretched by a beat" rather than as a run of 4/4 bars.
- **A 3-against-2 polyrhythm hidden inside the notated meter.** Stripped of bar lines, the main riff plays ten dotted-quarter notes in a row (one steady pulse) against the hi-hat's straight quarter-note pulse underneath — two simultaneous tempos, described with the mnemonic "nice cup of tea" for the felt 3-against-2 grouping. This layer necessarily gets interrupted at the same point the 3/4-grouping trick does, when the extra beat lands to complete the 4/4 bar.
- **Two variant spacings of the same core rhythm within one riff**: the riff alternates between the pure "constant dotted-quarters then one quarter note" version above and a second version with the same 11-note total but unevenly respaced (one longer half note compensated by one shorter quarter note elsewhere).
- **A purer companion example, cited for contrast**: "Daydreaming" (also Radiohead) uses a cleaner, more archetypal 3-against-2 polyrhythm — right hand playing 3 notes in the same span the left hand plays 2 — without the extra layer of hidden 3/4 grouping that "Myxomatosis" adds on top.
