# VOI-C07 — Move the least: the common-tone pivot

**Q.** Give the algorithm for choosing which voicing of the next chord to play — and name the one voice it does not apply to.

> [!question]- Answer
> **Find the note the two chords share, hold it exactly where it is, and move every remaining note to the nearest note of the next chord.** Repeat chord to chord. The exception is **the lowest voice** — the bass, or a piano left hand — which usually stays on each chord's actual root, because the bass is what the ear reads the chord's identity from.

## Why it matters

It is the difference between comping that sounds like a list of chords and comping that sounds like music: the same progression in strict root position loses its character while keeping every note. You never have to name the resulting inversion — the rule is about minimising motion, not about labelling the result.

## Drill

15 min: play a four-chord loop on piano twice — once all root position, once voice-led by common tone with the left hand still on the roots. Same chords. Hear the difference.
