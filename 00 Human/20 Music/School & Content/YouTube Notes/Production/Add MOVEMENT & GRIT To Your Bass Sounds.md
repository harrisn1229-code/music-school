# Add MOVEMENT & GRIT To Your Bass Sounds

![](https://www.youtube.com/watch?v=3fExmMtMMzk)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=3fExmMtMMzk)

## Synopsis

A "DJ Kaybomb" comedy-character video (Burning Man/stoner persona, same recurring bit as the channel's other Kelly-voiced videos) building two wobble-bass patches from scratch in Wavetable. Underneath the joke framing are two genuinely useful, non-obvious techniques: using a **looping amp envelope** as the wobble's core pulse instead of an LFO, and turning OFF an LFO's note-retrigger so it runs free and makes every wobble hit sound subtly different rather than mechanically identical. Rounds out with a standard but well-demonstrated FX chain (Unison → Reverb → OTT → Erosion → Utility) and a second "scary bass" patch reusing the same chain with different Wavetable/filter settings.

## Techniques

- **A looping amp envelope IS the wobble pulse — no LFO required for the base movement** — shape the amp envelope into a "wah" contour (quick fade-in, Sustain lowered, Release tightened) and turn on the envelope's own **Loop** setting so it repeats continuously on a held note — this alone produces the classic wobble pulse. Pair with the filter cutoff swept the same way (resonance up, filter steepness/type to taste) for the matching timbral half. → [[Wavetable]]
- **A free-running (non-retriggering) LFO makes every wobble hit sound organically different** — route a small amount of FM/Warp modulation to an LFO, then turn OFF that LFO's retrigger-on-note-start behavior — instead of resetting its phase every note (sounding identical each time), the LFO keeps cycling continuously in the background, so each new note lands at a different point in its cycle and the wobble's exact character varies hit to hit. → [[Wavetable]], [[Randomized Rack Design]]
- **Standard wobble-bass finishing chain: Unison (width) → tight Reverb (short Decay) → OTT (Amount + highs pulled back) → Erosion (Wide/Noise mode for grit) → Utility (mono)** — a fast, repeatable FX stack for gluing and dirtying a wobble bass without much fuss; reused on a second "scary bass" patch by literally copying the chain across and adjusting individual amounts (less noise) rather than rebuilding it. → [[OTT]], [[Erosion]], [[Utility]], [[Layering and Stacking]]
- **A second bass patch built from the same building blocks, different settings** — Mono voice mode + Glide for slides, a Sub oscillator (Octave 0, Gain up) for weight, filter type switched to a "Drive"-style mode for extra hardness, Sustain maxed, and an LFO routed to Pitch (moderate Amount, fast Rate) for a different flavor of wobble — demonstrating the same handful of moves (envelope/LFO shaping, sub layer, filter character) recombine into a distinct-sounding second bass.
