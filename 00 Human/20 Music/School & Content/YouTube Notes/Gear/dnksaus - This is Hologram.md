# dnksaus - This is Hologram

📺 [Watch on YouTube](https://www.youtube.com/watch?v=IuoJVaia2J0)

## Synopsis

A short showcase of dnksaus's own Max for Live device, **Hologram** — a spectral gate whose Amount knob filters out noisy content while preserving harmonic content, with an FFT-size trade-off (bigger = more spaced-out/high-quality, at the cost of latency), an Advanced tab that shapes FFT-bin enveloping for a grainier texture, and a **Dirty mode** that wave-inverts the signal for a widened, bass-friendly result. This is the dedicated video the earlier "Scale-Aware Abuse" note deferred to, and it resolves an identification question from that earlier batch: the device's real name is simply **Hologram** (a paid Patreon Max for Live device by dnksaus), not "Hologram Microcosm" — the placeholder name an earlier note guessed based on a vague "outboard pass" reference, apparently confused with the Hologram Electronics "Microcosm" hardware pedal. It is software, not outboard hardware.

## Techniques

- **Amount knob preserves harmonic content over noise** — the device's core spectral-gate function: filters a signal so more of its harmonic content survives relative to its noisy/inharmonic content, rather than a simple level-based noise gate. → [[Plugin Wishlist]]
- **FFT size trades latency for spaciousness/quality** — turning FFT size up gives a more spaced-out, higher-quality sound at the cost of added latency — the same fidelity-vs-CPU/latency trade-off other spectral tools (e.g. [[Spectral Time]]) expose. → [[Spectral Time]]
- **Advanced tab shapes FFT-bin enveloping for grain/texture** — a secondary tab controls how individual FFT bins are enveloped, reading as a grainier, more textured result than the main Amount/FFT controls alone.
- **Dirty mode = wave inversion, useful on bass** — a toggle that wave-inverts the signal; described as more useful on bass than on other material, widening the sound and letting you invert *what's* being cut so only the spectral texture remains over the dry signal underneath. Demoed on [[Operator]].
- **Ships alongside a free Expression Control edit; more spectral devices in progress** — the Patreon currently hosts Hologram plus an edited version of [[Expression Control]]; two further spectral devices ("Spectral Grain" — fully randomizable — and "Acid Rain") are unfinished/unreleased.
