# Bass Design

Reinforcing a bass patch's fundamental and harmonic body with **tuned** devices — saturators and resonators dialed to the note being played, not just broadband drive — instead of only reaching for EQ after the fact. The sound-design sibling of [[Kick Design]] and [[Snare Design]] for the low end, and the synthesis-side companion to [[Bassline Writing]] (which covers the composition/arrangement side: grooves, octave patterns, 808 slides). A bass patch straddles [[SUB Slot]] (20–60 Hz, the felt fundamental) and [[BASS Slot]] (60–250 Hz, the harmonic body/growl that reads on small speakers). See also [[Operator]]'s "FM bass growl" Patch Recipe and [[Wavetable]]'s Reese-bass technique for the synthesis side of this same territory.

## Tune supporting devices to the note, not just the patch

The core idea from the source video below: instead of driving a generic saturator or resonator across the whole signal and hoping it lands somewhere useful, **tune each supporting device to the actual note being played** so its harmonic reinforcement lines up with the bass's own fundamental instead of fighting it.

- **Two (or three) Saturators, each tuned to the note** — on an Operator/Serum/Wavetable bass note, add a [[Saturator]] and set its tunable pre-filter/tone stage to the note's fundamental frequency (e.g. ~156 Hz for D♯), then add a second Saturator tuned an **octave up**, and optionally a third a further step above that — each one reinforcing a different harmonic of the same note rather than one saturator doing everything broadband.
- **Corpus tuned to the same sub frequency** — set [[Corpus]]'s resonator type and tuning to match the same note (the sub frequency, D♯ in the source example) so its physically-modeled resonance reinforces the fundamental the Saturators are already emphasizing, rather than adding an unrelated ringing pitch. → [[Corpus]]
- **A free, pre-tuned rack version exists** — the source video's creator built this exact dual-Saturator + Corpus recipe as a downloadable rack with each note pre-tuned, released free in the video's description — worth grabbing directly rather than rebuilding the tuning-per-note manually every time.

## Escalation ladder for extra thickness *(from the same source — diminishing returns past a point)*

Each further rung adds more density; the video's own conclusion is that the later steps stack into "too much" fast, so treat this as a menu to sample from, not a checklist to always run in full.

1. **Resample, then add a parallel high-passed harmonic layer** — bounce the tuned bass to a new audio track, run it through another [[Saturator]] into an [[EQ Eight]] high-pass set somewhere around **150–300 Hz**, so this new layer keeps only the driven upper harmonics — blend it back under/over the clean tuned bass without muddying the actual sub. → [[EQ]]
2. **Multiband compression + a notch EQ, fine-tuned by ear** — a multiband-compression pass (built from the [[Multiband Dynamics]] device) glues the stacked layers together; add a narrow notch EQ cut wherever the stack has built up too much resonance, then fine-tune every EQ in the chain to taste. → [[Multiband Dynamics]], [[EQ]]
3. **Tune a phase-disperser to a harmonic multiple of the note (unowned: Kilohearts Disperser)** — calculate a harmonic multiple of the bass note's fundamental (roughly 1244 Hz off a ~156 Hz D♯ — an ~8th-harmonic multiple) and tune an all-pass phase-disperser device to that frequency for further metallic motion/smear on top of the stack. → [[Plugin Wishlist]]
4. **Add grit (unowned: iZotope Trash), then duplicate the whole chain** — a lo-fi/distortion plugin stacked right after the disperser for extra grit, then duplicate the entire processing chain for even more density if the sound can take it. → [[Plugin Wishlist]]
5. **A Limiter as a safety net** — once the stack gets this dense, add a Limiter before going further so the result doesn't clip/blow out unpredictably — explicitly framed as ear protection, not a mix decision.
6. **Optional extreme layer: OTT and/or Vocoder for a longer tail/texture** — reached for only when chasing an especially long, wild tail; both are explicitly called out as "feeling really wild" territory rather than a standard step. → [[OTT]], [[Vocoder]]

## From videos

- **Duplicate one live bass take and process the two copies differently per section, rather than automating one chain across the whole song.** Arlo Parks & Baird, on Heaven: the identical Squier Jazz Bass take (through an amp simulator) is copied into two tracks — the verse copy has lows trimmed to leave room for the kick, while the drop/instrumental copy runs **Bassment** (UnitedPlugins, unowned — see [[Plugin Wishlist]]) specifically to add low end back in, making the same performance read noticeably bigger without re-recording or a complex automated EQ move. → [[Plugin Wishlist]], [[Arlo Parks Vocal Chain]] — Arlo Parks & Baird (Tape Notes), [[TN 183 Arlo Parks & Baird - Full Video Episode]]
- **Five bass oscillator configurations, as a starting-point framework matched to what the bass needs to DO in a track — not by synth model, by function.** (1) **Single oscillator** — one audio oscillator, one waveform — the clarity baseline. (2) **Sub oscillator** — a dedicated sub layer for room-shaking low-end weight, at the cost of a less focused pitch center. (3) **Overtone oscillator** — layer additional oscillators ABOVE the fundamental at overtone-series intervals (an octave-and-a-fifth, and two-octaves-and-a-third demonstrated) for "character," balance blended to taste. (4) **Unison oscillator** — a polyphonic synth's unison mode stacking many voices on one note for a massive, wide, "slams like a ton of bricks" bass, trading pitch clarity for scale. (5) **Audio-rate modulation** — modulate an oscillator/filter/amp/ring-mod with ANOTHER OSCILLATOR in the audio range (not a slow LFO) for genuinely complex harmonic content, described as making an analog patch "start to sound like digital"; often layered under a plain single-oscillator base. Match the configuration (or combine several) to what the track actually needs — clarity, room-shake, character, size, harmonic complexity are separable qualities, and mixing configurations is normal when one quality alone isn't enough. → Anthony Marinelli, [[I Can Finally Tell You What Ive Been Working On]]
- **Audio-rate modulation, expanded: pitch-modulation and filter-modulation are two DISTINCT routes for the same audio-rate modulator oscillator, not interchangeable.** Route the modulator into oscillator 1's frequency input for a subtle "ripping"/shaking texture that helps a bass cut through; route the same oscillator into the filter's modulation input instead for a different, separately-tunable result (pull resonance back "so it's not so over-enhanced" on this route). The modulator's own detune amount and waveform (triangle vs. square demonstrated) are further character controls, and modulating BOTH pitch and filter at once with the same source gives a more extreme "shred," near-guitar-like result — audio-rate pitch modulation can shift perceived pitch enough to need a master-tune recheck afterward. **General ordering principle**: fix the oscillator stage before reaching for the filter — oscillators come before the filter in signal flow, so getting their content right first gives the filter more usable material to shape, on any patch, not just bass. → [[LFOs and Modulation]] — Anthony Marinelli, [[How to Make Huge Sounds with 1 Oscillator]]
- **A comprehensive "make the preset fit YOUR track" checklist: start from a single oscillator for the most stable pitch, use an ODD number (3, not 2) when unison-detuning for thickness without note-to-note phase cancellation, and add a harmonic octave-up oscillator for MIDDLE fullness without perceived brightening.** Two identical oscillators at the same pitch phase-cancel unpredictably note to note (some notes read stronger, some weaker, on a repeated line) — a single oscillator gives the most consistent pitch; if unison width is wanted, detune three oscillators (one down, one up, one centered) rather than two, which thickens without the same phase inconsistency. Separately: adding a low-level oscillator an octave above the fundamental (same 32'/16' stop-style spacing used elsewhere in this pattern library) adds harmonic "middle" richness distinct from brightness — demonstrated NOT raising the filter's brightness while still audibly adding fullness, since harmonic content and perceived brightness are separable controls. Reconfirms from a different worked example: resonance thins the fundamental (compensate with a same-pitch sine oscillator blended in low), self-patched output→external-input feedback for distortion, fractional keyboard-tracking switches (off for bass), decay timed to the track's tempo/subdivision so gaps let other elements through, and softened filter attack for a "funkier" onset. → [[Filters and Resonance]], [[Saturation and Distortion]] — Anthony Marinelli, [[The Number One Reason Your Basslines Dont Hit]]

- **Tune the filter decay time to a NOTE VALUE of the track's tempo (quarter, half, or eighth note), not by ear alone — and toggle keyboard tracking live for an instant alternate "voice" from the same patch.** Michael Jackson's "Man in the Mirror" bass (2 oscillators — square an octave below a sawtooth, both full volume, filter closed with moderate resonance): decay time is deliberately set to a specific rhythmic value that matches the song's feel (a quarter-note decay reads different from a half-note or eighth-note decay on the identical patch), so decay should be dialed in relative to tempo/subdivision, not just "until it sounds right" in isolation. Two secondary knobs: raising filter ATTACK time (normally left at zero) adds a "talking"/funkier onset without changing anything else; a small amount of portamento (glide) adds "slipperiness" that can be pushed further for an obviously sliding bass. **The live-toggle trick**: flipping keyboard filter tracking ON mid-performance instantly turns the same patch into a noticeably brighter alternate bass voice for a different part of the song, then flipping it back OFF restores the original — a fast way to get a second usable bass sound without building a whole new patch. → [[Filters and Resonance]] — Anthony Marinelli, [[MJ's Man in the Mirror Minimoog Bass Synth Breakdown]]
- **Three saw oscillators stacked a clean octave apart (no detune, no modulation), swept open by one filter envelope while pitch glides down — a one-off "growl" transition sound, not a groove bass patch.** Equal volume across all three octaves; the sound's only movement comes from a slow filter-envelope sweep (light initial cutoff, high resonance to clear low-end mud from the dense sweep, full sustain, zero decay/release so it cuts cleanly on key-up) plus a "reverse glide" pitch descent into the note. Meant to be used exactly ONCE, at a song's structural high point, not repeated — see [[Arrangement and Song Form]]. → [[Filters and Resonance]] — Anthony Marinelli, [[MJ's Thriller Monster Growl Bass Synth Breakdown]]
- **A dual-oscillator PWM "chorusing" recipe, driven into overdrive at an outboard preamp, plus a strict long/short phrasing pattern — the full Herbie Hancock "Chameleon" ARP Odyssey bass patch.** Both oscillators start on a narrow (skinny) pulse width, then the ADSR envelope is switched to modulate pulse width on each — starting skinny and widening toward "fat" over the envelope's shape, with the two oscillators' envelope starting points offset slightly so the pulse-width sweeps land out of phase; the resulting phasing between two independently-widening PWM oscillators (in unison, not detuned) IS the "chorusing" character, not a chorus effect. Filter: no keyboard tracking at all (confirms the standard no-tracking-on-bass rule below) and no portamento; envelope has a touch of attack, fast decay, some sustain, and — deliberately — a short but nonzero release so single-trigger notes don't clip on release. **Phrasing discipline**: the original part isn't uniform-length notes — it's a repeating long-long-long-SHORT rhythm (three held notes, one deliberately clipped short) that has to be played, not just patched; getting the patch right without matching that phrasing still won't sound like the reference. → [[Saturation and Distortion]] — Anthony Marinelli, [[Herbie Hancock Chameleon Synth Bass Breakdown]]
- **On a single-trigger synth (Minimoog), raise sustain specifically for a fast fill so the envelope doesn't drop between legato notes — a per-passage setting, not a fixed one.** Single-trigger mode doesn't re-trigger the envelope on legato playing, so a busy fill with the groove's normal (lower) sustain setting "dies" between notes; the fix is more sustain just for that denser passage, then back down for the main part. Independently reconfirms, from a second unrelated source, two rules already on this page: **never track keyboard control voltage on a bass patch** (tracking on reads "too bright, just not a bass" the moment you play a higher note) and **time the envelope's release so the note recedes before the next beat's transient needs the space** — here specifically framed as leaving a hole for the snare to hit into. → [[Arrangement and Song Form]] — Anthony Marinelli & Alissia, [["Baby Be Mine" Bass with Alissia - 2025 Grammy Nominated Producer of the Year]]

- **Keep a bass patch's tonal "vowel" consistent across notes by parking the filter cutoff at a fixed formant instead of shaping tone through the VCA envelope's sustain level.** Get sustain-stage tone from the filter cutoff (small or no envelope-generator amount there) rather than from VCA sustain, so held notes always land on the same formant frequency regardless of duration; then let the envelope generator control only the ATTACK portion of the filter for a brief "bite" transient on top, without disturbing that fixed sustain tone. → [[Filters and Resonance]], [[Envelopes and ADSR]] — Anthony Marinelli, [[The Most Misunderstood Knob On Your Synth]]
- **Use TWO different bass sounds for two different arrangement roles in the same song — one for character/melody (thin on actual low end), one for low-end weight — rather than one patch trying to do both.** From an MS-20 recreation of Daft Punk's "Da Funk": a series HP+LP filter chain carves a "middle-only" shred with limited highs and no real bass, deliberately, because the arrangement reserves a separate, genuinely low "pumping" bass for elsewhere in the song — the character bass doesn't need to carry weight it isn't going to be asked to carry. → [[Filters and Resonance]] — Anthony Marinelli, [[How To Make The Synth Bass from Da Funk by Daft Punk]]
- **Check an instrument's physical keyboard RANGE before committing to it as a bass-patch candidate — tone match doesn't matter if the keyboard can't reach the notes.** From a Prophet-5 recreation of Tyler, the Creator's "Igor's Theme" bass: both a Jupiter-8 and Oberheim OB-X got close tonally but their keyboards don't go low enough to play the actual line from the keys; the Prophet-5 was the only vintage synth on hand whose range reached it. Separately, intentional oscillator detuning (two sawtooths an octave apart, unison, then deliberately detuned for "shredding" character) is a real EXCEPTION to the usual keep-it-in-tune-and-favor-one-oscillator bass rule — worth breaking specifically when the bass is exposed/featured rather than buried under other parts. → [[Arrangement and Song Form]] — Anthony Marinelli, [[How to program the synth bass from Tyler the Creators Igors Theme]]
- **Modulate pulse width at the SAME RATE as the filter envelope (not a free-running LFO) so pulse width shifts once per note in sync with that note's own envelope — a note-synced "inner growl" distinct from constant LFO-driven PWM chorusing.** From the ARP 2600 "Thriller" bass: patched from the same ADSR driving the filter into oscillator 2's PWM input, compared directly against static PWM ("kind of a house bass" vs. "more like a Fender bass" with envelope-synced PWM). On an instrument with no velocity/aftertouch, deliberately set the filter envelope's decay LONGER than the part's actual note durations — full decay is never heard during normal fast playing (notes get cut off, staying bright/punchy), but a held long note reveals the full decay, giving the part an expression parameter tied to note length instead of velocity. Also: adding a spare oscillator's sine wave directly into the filter mix reinforces low-end fundamental without changing the main timbre — a synthesis-stage alternative to EQ boosting. → [[Envelopes and ADSR]], [[Voice Architecture]] — Anthony Marinelli, [[How I Programmed Michael Jacksons Thriller Bass on my Tonus ARP 2600]]
- **The mechanism behind "favor one oscillator's level" on a two-oscillator bass: closely in-tune oscillators can partially cancel each other's fundamental, and a deliberate, barely-audible level imbalance guarantees the fundamental is always present from at least one dominant source.** From the ARP 2600 (Tonus) bass on Michael Jackson's "P.Y.T.": pulse wave (~22% width, "reedy") an octave up for definition, sawtooth an octave down for low-end support — neither alone has enough personality, the combination does. The envelope-to-filter modulation amount has a real, narrow sweet spot on bass: too low reads as "plucky doll" (thin/toy-like), too high loses the bass fundamental entirely. → [[Voice Architecture]] — Anthony Marinelli, [[How I Programmed The Bass On Michael Jacksons PYT]]
- **Sawtooth + square in UNISON (same octave, not layered an octave apart) is a distinct bass-layering option — the waveform mix alone, not a register split, supplies the harmonic complexity.** From the Minimoog bass on Michael Jackson's "Baby Be Mine": square-only read noticeably boomier/rounder, sawtooth-only thinner/harsher, the combination as the chosen middle ground. A small amount of natural oscillator mistuning produced audible chorusing and was kept deliberately as character rather than "fixed" — general advice is still to tune regularly (drift compounds on older/analog gear), but a little residual imperfection can be the point. Filter sustain level (brightness while held) and VCA sustain level (loudness while held) are two DIFFERENT controls doing two different jobs, not the same "sustain" duplicated — both need dialing in independently to keep a held note "alive." → [[Envelopes and ADSR]] — Anthony Marinelli, [[How I Programmed the Baby Be Mine MiniMoog Bass on Thriller]]
- **Time the filter envelope's DECAY explicitly to the track's tempo/meter — the note should audibly cut off before the next beat, not ring through the bar — and resonance thins the low end at the same time it's enhancing "talk" character.** From "Dream Weaver" (Gary Wright): two oscillators in plain unison (both sawtooth, no octave offset, no filter key-tracking so tone stays even across the range) cranked full; decay timed so the note is unmistakably off before the next hit; resonance narrows the effective pass band as it's raised, so it thins overall low-frequency weight even while making the resonant peak louder — useful to know when reaching for resonance purely for "talk," since it changes bass weight too. VCA sustain ridden UP during a walking-bassline fill for longer note lengths only where the arrangement calls for it, then back down for the main groove. → Anthony Marinelli, [[Talking Bass - Dream Weaver by Gary Wright]]
- **A clipped, sustain-free envelope (Decay/Release combined on one knob, sustain at zero) leaves room for the kick/snare to speak — and monophonic single-trigger legato behavior is a performance FEATURE for a growl bass, not a limitation.** From a Minimoog "Flashlight" (Parliament) bass recreation: filter cutoff closed to zero, envelope-to-filter amount doing all the brightening; because the instrument doesn't retrigger its envelope inside a legato phrase, fast note runs read as one continuous "growl rip" rather than separate attacks — deliberately letting some attacks get "thrown away" is part of the expressive character. Glide turned on specifically for an expressive downward pitch "rip" after a high note (contrasted directly against glide-off, straight-to-pitch); LFO/vibrato keyboard-tracking turned OFF so vibrato rate stays constant across the range, rather than speeding up on higher notes. → [[Filters and Resonance]] — Anthony Marinelli, [[Parliament Flashlight Synth Bass Tutorial]]
- **Sawtooth + square, one octave apart, with the square's pulse width modulated by a slow LFO, is a chorusing bass recipe — and a synth WITHOUT PWM can't fully substitute for it via detuning.** From a multi-synth (Prophet-5/Jupiter-8/ARP 2600/Minimoog) recreation of "Hot To Go!" by Chappell Roan: PWM rate is a real sweet spot (too fast reads as "sick," too slow has "no attitude"); resonance used deliberately as an informal high-pass to thin excess low end on the bass patch, not for a resonant peak; VCA envelope given a small nonzero attack for a "suction" onset instead of a percussive chop. Tested on the Minimoog (no PWM) as a negative case: detuning oscillator 2 as a substitute reads as "sour"/out-of-tune rather than chorused, because PWM keeps the center frequency locked while harmonics wrap around it, whereas plain detuning genuinely shifts pitch — check for PWM before assuming a detune workaround will pass for it. → [[Filters and Resonance]] — Anthony Marinelli, [[Lets Make the Bass from Hot To GO! by Chappell Roan]]
- **Square-wave-plus-an-octave-up-Sawtooth is a reusable go-to bass layering formula: the square carries a fundamental with fewer competing harmonics ("basier"), and a Sawtooth an octave up adds harmonic "teeth" without crowding it, since the octave gap keeps its harmonic content out of the square's territory.** Full patch recreation of the Minimoog bass from The Gap Band's "Burn Rubber on Me": both oscillators mixed at full level deliberately for extra saturation/edge, filter cutoff closed to zero so the filter envelope does all the tonal shaping, and specific ADSR character mapped out — slowed attack for a "talking" onset (but not so slow it can't be played in time), decay speed directly controlling the downward pitch-slope character, sustain level needed for a held note to actually sustain rather than just decay away. Performance treated as inseparable from the patch: playing behind the beat, vibrato via mod wheel, pitch bend brought back down before release — the same patch reads flat without it. → [[Envelopes and ADSR]] — Anthony Marinelli, [[Burn Rubber on Me - Legendary Synth Bass REVEALED]]
- **Build the patch from the oscillator up before reaching for processing: square-wave fundamental + a same-oscillator sine blend + disciplined tuning/level balance across voices + minimal filter key-tracking + a nonzero release + real-time performance controllers — a full synthesis-side checklist that this note's existing "tuned devices" section (above) picks up AFTER.** Ten programming tips from a 40-year film/record synth veteran (Michael Jackson's *Thriller* bass among his credits), all upstream of processing: (1) retune oscillators before every session — analog drift is real, and if deliberately running multiple detuned voices, weight them unevenly around one true-pitch anchor rather than symmetric (a piano-tuner "Wyoming" stretch-tuning move) → [[Voice Architecture]]; (2) on a 2-oscillator bass, fix note-to-note phase-cancellation thinness by favoring one oscillator's level, not by re-tuning → [[Voice Architecture]]; (3) start the waveform on a square, not a saw, for a more focused bass fundamental; thicken via PWM (LFO- or envelope-driven) before adding a second oscillator → [[Oscillators and Waveforms]]; (4) blend in a sine wave from the SAME oscillator generating the main waveform (the Yamaha CS-80 trick) for extra weight with zero tuning/phase risk → [[Oscillators and Waveforms]]; (5) don't zero out sustain/release — a little of each is what lets a bass note be held/played expressively instead of just decaying or clipping on every retrigger → [[Envelopes and ADSR]]; (6) turn filter keyboard-tracking OFF/minimal for bass — real bass guitars get duller, not brighter, going up the neck, so tracking makes upper notes unnaturally thin → [[Filters and Resonance]]; (7) use real-time performance controllers (pitch bend, glide/portamento, vibrato, mod-wheel-to-cutoff, an expression pedal if available) to give a part personality live rather than only programming it — the same "slap"-like character a bassist gets from technique, not patch design; (8) mix long held notes and short/muted ones deliberately (the *Thriller* line is cited as the model) and know whether the instrument is single-trigger/legato or multi-trigger so phrasing behaves the way you expect → [[Voice Architecture]]; (9) mult the dry signal in parallel with an effects-pedal-processed copy and blend rather than committing fully wet → [[Parallel Processing]]. General framing tip (10, uncodified): treat every sound-design choice — an unusual filter type, a pitch bend at the right moment — as a small contribution of "personality," the way a session musician would. → Anthony Marinelli, [[10 Tips For Synth Bass]]
- **Where you drive a bass patch in the signal chain (before vs. after the filter) changes its character, and either can be blended back in parallel with the clean/undriven filter output — from a head-to-head Moog System 55 vs. ARP 2600 bass-patch shootout.** Both patches used a broadly similar recipe (3 oscillators, 2 envelopes — one filter, one VCA — mixed into the filter, then driven through a preamp for "fried" harmonic distortion), but at different points: the Moog patch drove its preamp AFTER the filter (frying the already-filtered signal), while the ARP patch drove its preamp BEFORE the filter (frying the raw oscillator mix, which the filter then carves) — both musicians independently praised the other's placement, and neither treated one as objectively correct. Both also mixed the driven ("fried") signal back in parallel with a clean, undriven path into the VCA rather than committing the whole signal to distortion — the same wet/dry-blend logic as [[Parallel Processing]] and this note's other "From videos" entries, applied at the synthesis stage instead of the mix stage. Try both placements on a patch (drive → filter vs. filter → drive) rather than assuming one is default; blend either back with a clean parallel path if the raw drive is too much. General framing from the same video, worth carrying into any vintage-inspired patch: **you don't need to exactly match an iconic reference tone to get a great sound** — "it depends what song they're in... you just want kick-butt sounds," achievable on very different gear than the reference used. → [[Parallel Processing]], [[Saturation and Distortion]] — Anthony Marinelli & Rob Rosen, [[Battle of the Modular Giants Moog vs ARP - Clip]]
- **A bass-specific EQ frequency map, muting discipline, and playing-position tone mechanism — from a classically-trained bassist's own playing/production perspective.** EQ map: **~1.5-2 kHz** = brightness/top-end presence (where the bass "speaks"), **~800 Hz** = a secondary presence point, **~50-60 Hz** = sub extension/foundation, **~300 Hz** = the specific frequency where bass becomes audible on very small speakers (phone/tiny speaker) — sweep a boost through on a small speaker and this is where it clicks in. Playing/picking position changes tone via literal string length: near the bridge = brighter/thinner/mid-forward (cuts, good for solos); near the neck = fatter/mellower/more low end (more string length set ringing). Mute every unplayed string with the fretting hand, even mid-chord — un-muted ringing strings are a recurring, diagnosable cause of a bass sounding bad in a mix. Distortion (even light amp overdrive) adds midrange harmonic content that helps a clean DI (which reads "hollowed out" in the mids) cut through a dense mix — can be applied selectively via split-band processing (distort highs/mids, leave lows clean). String age shifts tone too: new strings carry more top AND bottom, older strings settle into a more consistent midrange (some bassists never change strings for exactly that character). Compression should preserve the transient then hold a longer gradual release, for consistent low end across a performance. → [[EQ]], [[Saturation and Distortion]], [[Compression]] — Rick Beato, [5 Things EVERY Bass Player SHOULD Master](https://youtu.be/9Vhl5HBS8Nc)
- **Heavy compression on a pure sine-wave sub bass to fix note-to-note loudness inconsistency (not glue/character) — the reasoning: no distortion/harmonic content means "each moment at each frequency generates a different volume level," and compression is what evens that out, with a bit of perceived definition as a side effect.** Mosty (reggaeton mixer, Mix with the Masters): starts every mix with the bass — first because it's "an easier instrument for me to find" and second because in reggaeton the bass is specifically what "moves the song" for the club/dance-floor context the genre is written for; a small extra frequency boost is layered on top of the compression purely "to raise the frequency a little" for more definition. On this particular track he skipped sidechaining the bass against the kick entirely, by choice, favoring a simple/low-processing-count approach — a reggaeton data point for the "sidechain isn't mandatory" counter-school already logged on [[Sidechaining]]. *(transcript low-confidence — machine-translated; no ratio/threshold/Hz survives)* → [[Compression Staging]], [[SUB Slot]], [[Sidechaining]], [[4 Bass/1 Digital Bass Track|Digital Bass Track]] — Mosty (Mix with the Masters), [[Mosty mixing a reggaeton track]]
- **Mix 808 low-end/color decisions primarily on a monitor that's stingy on sub, and add distortion purely for grit/cut-through rather than tone-matching.** Marcella Araica: "they're usually really difficult to hear on NS-10s, but... I'm trying to do everything on the NS-10, and then if I have to, I'll go up on the mains just to kind of get the feel of it" — using a sub-poor monitor as the primary judgment call (if it reads right there, it reads everywhere) and the mains only as confirmation. Distortion then gets added "because it just brings it a nice grit... little tricks that I use to kind of cut things through" — qualitative (no plugin/drive figures given), consistent with this chain's own thesis (below) that driving the *heard* mids, not the *felt* sub, is what makes an 808 audible on small speakers. Finished with the [[UAD Pultec EQP-1A]] as a named go-to for low end — "I love this Pultec EQP-1A EQ... it just brings a sense of bottom that is emulated pretty much like the exact hardware," used here for its low-boost warmth after the distortion pass. → [[Saturation and Distortion]], [[UAD Pultec EQP-1A]], [[Referencing and Translation]], [[SUB Slot]], [[4 Bass/1 Digital Bass Track|Digital Bass Track]] — Mix with the Masters (Marcella Araica), [[Blending melodies with Marcella Araica]]
- **A two-stage, tremolo-controlled bass entrance: withhold real bass until the second chorus, route it into the GUITAR bus (not the bass bus) specifically to cap its low end, then only add real sub bass once the vocal returns after the bridge — both parts tremolo'd to stop them "taking over."** Peter Katis's arrangement/mix combo: the demo has no real bass until the second chorus (first time the actual electric bass guitar appears); Katis "stuck it in the guitar bus, because I did not want it to have a lot of low end" — a deliberate routing choice to borrow the guitar bus's tonal ceiling instead of the bass bus's full-range treatment (owned lane: [[3 Guitar Bus|Guitar Bus]]) — plus [[Auto Pan]] set to amplitude tremolo so the bass "doesn't let the bass take over like it would otherwise." A second, genuinely low sub-bass layer joins only once the vocal comes back in after the bridge — also tremolo'd, "so it doesn't completely take over the track." - **Full neurobass build order: odd-harmonic oscillator stacking → dual filter macro → parallel BP/dry blend → saturation/OTT/EQ → limiter, then flavor-palette it** — a complete, reusable recipe: (1) **Operator**, algorithm **Parallel** (oscillators independent, none modulate each other), **Voices = 1** (mono), **Glide** on (~150 ms) for the signature pitch-slide between notes; (2) approximate a square wave's odd-harmonic spectrum from scratch by layering 3–4 oscillators, each a plain sine tuned via **Coarse** to a successive odd harmonic of the fundamental (roughly 3rd, 5th, 7th — square waves contain ONLY odd harmonics, at odd-integer multiples of the fundamental frequency), plus a touch of **Fine** detune (~15 cents) on the fundamental oscillator for subtle thickening/chorus; (3) group into a rack (Cmd/Ctrl+G), map the filter's **Frequency** to a Macro, then — this is the key move — **clamp the macro's own max value to wherever the filter actually stops doing anything audible** (e.g. ~300 Hz), so the full macro throw covers only the musically useful range instead of wasting travel on an inaudible tail; (4) add a SECOND filter (Auto Filter, Band-Pass mode, steepness reduced to 12 dB/oct from the 24 dB/oct default for a gentler cut) and map IT to the **same macro** after finding its own useful ceiling (~600 Hz) — one knob now sweeps two filters together for a denser wobble; (5) split that band-pass into an Audio Effect Rack with a second, unprocessed "Thru" chain, and blend a little of the dry/unfiltered signal back in so the band-pass doesn't eat all the top-end crispness; (6) **Saturator** (Drive +25 dB, Output pulled down to match, Soft Clip on) to "toast" the harmonics; (7) **OTT** at a reduced amount (~70%, not 100%) as a brightness/"MSG" pass; (8) **EQ**: boost around **120 Hz** specifically (the frequency floor most phone/laptop speakers can still reproduce — the "translation" boost) and cut everything just above it so nothing competes, plus a high-shelf/bell boost for extra top-end "crisp";
