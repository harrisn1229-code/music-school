# Improvisation Difficulty Ladder — Pentatonic to Coltrane Changes

A practice-sequencing framework: six stages of soloing harmony, each isolating exactly one new harmonic tool over a deliberately simple vamp before moving on. The ladder is organized by *which harmonic tool unlocks the level*, not by tempo or technical difficulty — a genuinely different axis from [[Positional CAGED Soloing with Matched Modes and Arpeggios]] (which is about neck coverage within one harmonic context) or [[10 Hidden Soloing Mistakes and Constraint-Based Fixes]] (about phrasing constraints).

## The ladder

| Level | Tool unlocked | Vamp (worked example, key of B) | Why this vamp |
|---|---|---|---|
| 1 | Minor pentatonic, one box shape only | i–♭III (Bm–D) | Bm and D share 2 of 3 tones — near-substitutes, so the harmony stays effectively static |
| 2 | Blues scale (pentatonic + ♭5), moved across positions | i–iv (Bm–Em) | The 1 and 4 chords of the key — blues progressions typically run 1–4–5 |
| 3 | Major scale modes, applied modally | i–♭VI (Bm–G) | Bm/G again function as substitutes — a modal (one-chord-feel), not functional, progression |
| 4 | Mid-solo modulation ("bimodal harmony") | i–♭VI shape shifted down a whole step mid-phrase (B→A) | Forces a real key change *inside* one improvised line, not just between takes |
| 5 | Jazz changes — ii–V–I, m7♭5 | A tune's real changes (worked over "Black Orpheus," transposed to Bm) | Functional harmony with real cadential motion, swung 8ths |
| 6 (bonus) | Rapid, widely-spaced key changes | "Giant Steps"-style changes, key center shifting roughly every 4 beats | The extreme end — minimal overlapping notes between adjacent keys |

## How to use it

Each level should be practiced as its own isolated vamp before combining — the point is that levels 1–3 deliberately hold the harmony still (via substitute-chord vamps) so the only variable changing is the scale/mode being applied, then levels 4–6 introduce actual harmonic motion on top of an already-comfortable scale toolkit. Skipping straight to level 5 or 6 without having drilled the scale vocabulary in isolation first (levels 1–3) is the likely failure mode — same principle as [[Positional CAGED Soloing with Matched Modes and Arpeggios]]'s point that new positions don't fix a chord-tone-targeting gap, more scales alone don't fix an unfamiliarity with functional harmony.
