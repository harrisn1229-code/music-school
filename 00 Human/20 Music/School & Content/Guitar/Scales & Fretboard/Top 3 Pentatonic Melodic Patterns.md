# Top 3 Pentatonic Melodic Patterns

Part of [[Guitar Positions]]. Jared Borkowski's (Sound Guitar Lessons With Jared) three go-to **melodic patterns** — playing scale notes out of order but still in a logical sequence, also called melodic/tonal sequences — for the pentatonic scale specifically. This is the video referenced (as an unowned downloadable PDF) from [[Root-to-Root Scale-Form Mapping Method]] and [[Scale Sequences in Thirds]]; those pages already carry his "maze view vs. map view" framing from a different (harmonic minor) video in the same series — this page is the actual worked-out pentatonic patterns behind that PDF, extracted from the source video itself.

## Why melodic patterns matter (framing, ties into the existing "maze view / map view" concept)
Two stated reasons: **(1) sound** — playing a scale strictly up and down makes an improvisation "sound like a scale," not like a melody; melodic patterns are one of the main tools improvisers/composers use to break that up and make a scale application sound genuinely melodic. **(2) fretboard awareness** — running a scale purely in order only ever shows you the *next* note (the **maze view**, same term used in [[Scale Sequences in Thirds]] and [[Root-to-Root Scale-Form Mapping Method]]); deliberately jumping around inside a pattern forces you to see bigger chunks of the scale at once, building the **map view** — knowing exactly what any note is and being able to jump to it on demand, not just step to the next one.

## Scale form used
Demonstrated on the most common pentatonic box shape on guitar, played in the **fifth position** — viewable as either A minor pentatonic or C major pentatonic (relative major/minor pair) with the root on different notes of the same shape. **Don't worry about which note is the root when drilling these patterns** — just get the sequence itself correct; the shape is what matters, the root-naming is secondary.

## Pattern 1 — Every other note
Skip every other scale note going up (and coming back down) rather than running the shape in stepwise order. Stated as a pattern that should generalize to **every single scale you ever learn**, not just pentatonic — the general-purpose version of this shows up as the "melodic thirds" / "skip up, come down one" pattern in [[Scale Sequences in Thirds]] and [[Root-to-Root Scale-Form Mapping Method]] (same underlying idea: skip-based reordering to escape strict scalar motion).

## Pattern 2 — Back-neighbor pattern
**Play a scale note → go back one note → play the first note again — that's one 3-note unit.** Move to the next scale note and repeat the same unit, working up (or down) the shape one unit per scale degree. Because the first unit needs a note *below* it to go back to, **start the pattern on the second-lowest note of the scale form**, not the very lowest. Also stated as a pattern to be able to apply to **every single scale you ever learn**, not just pentatonic.

## Pattern 3 — Five-note pentatonic pattern (pentatonic-specific)
**Unique to the pentatonic scale — explicitly not meant to be applied to other scale types** (unlike patterns 1 and 2, which the source calls general-purpose). Most commonly used as a **descending lick**:
- Start on the high note. Play **five notes in one direction** (1-2-3-4-5) — that's one unit.
- **Jump back up the same direction, skipping a note** (skip the note you'd otherwise land on next), then repeat the same 5-note unit starting from there.
- Continue down the shape this way; **when you run out of room, just stop** — it's fine if the final repetition doesn't complete all five notes.
- **Two equivalent ways to count it** depending on where you start the 5-count relative to an extra note tacked on at the front — they produce the identical run, just phrased with the count starting one note earlier or later. Works ascending too, not just descending.
- **Often played starting on the second string** as the anchor for the descending lick.

## How much to drill
You don't need to master every possible pattern for every scale — "that would be impossible." But for any scale/scale-form you actually want to use effectively, aim for **at least three different melodic patterns, playable in both directions** — directly the "top 3" bar this video sets for the pentatonic shape.
