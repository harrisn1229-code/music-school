# Kontakt 7

![[Images/Kontakt 7.png]]

**Category:** Instrument
**Vendor:** Native Instruments

## What it is

The current version of Native Instruments' Kontakt sampler, with updated browsing, a modernized interface, and expanded scripting capabilities over older versions.

## What it's used for

Same sampled-instrument playback role as Kontakt, with newer library compatibility.

## FX chain notes

Used as the instrument source in a track's chain.

## Used in my chains

A **sampler host** (instrument source, not an FX slot) — the container for third-party sampled libraries:

- **[[1 Acoustic Piano Track|Acoustic Piano Track]]** — felt/intimate or cinematic piano libraries, as an alternative flavor to [[Keyscape]].

## Key Parameters

Kontakt is a host — the "parameters" are the library's own macros plus Kontakt's per-instrument controls:

| # | Parameter | What it is / does | Technique | Artist / record example |
|---|---|---|---|---|
| ① | Library / Patch | The loaded sampled instrument (each library exposes its own UI + macros) | Pick the patch first — the library's baked-in sampling/round-robins are 90% of the sound | — |
| ② | Instrument macros | The library's mapped macro knobs (dynamics, mic mix, character, release) | Felt/mic-position/dynamics macros shape intimacy vs. cinematic scale before any EQ | — |
| ③ | Amp / Tune / Voices | Kontakt's per-instrument level, tuning, polyphony | Trim voices/tune per part; keep level calibrated (~−18 dBFS avg) into the chain | — |
| ④ | Insert FX (per instrument) | Kontakt's built-in effect chain per instrument | Usually bypass — do EQ/comp/color on the Ableton track chain, not inside Kontakt | — |
| ⑤ | Output routing | Which output/bus the instrument feeds | Route multi-out libraries to separate tracks so each element hits its own chain | — |
