## Synopsis

Makes the case for building scale vocabulary in **4-notes-per-string** shapes rather than the more common 3-notes-per-string system, with a graphic-backed explanation of why the extra note per string evens out the picking pattern.

## Techniques

- **The problem with 3-notes-per-string scales:** with an odd note count per string, alternate picking has to start on a downstroke on some strings and an upstroke on others (since only two stroke values exist and three notes doesn't divide evenly) — this is what makes fast, clean string transitions on 3-note-per-string scales genuinely difficult, distinct from a pure speed problem.
- **Why 4-notes-per-string fixes it:** with an even note count, every string starts with a downstroke — down-up-down-up on each string, then down again on the next string — a single consistent, evenly-distributed picking pattern across the whole scale instead of an alternating start-stroke per string. Familiar from classic chromatic/semichromatic picking warmups, extended here to real scale material.
- **Stated benefits beyond picking evenness:** easier string transitions at speed, and more raw material per position to build creative licks from (4 notes to choose from per string instead of 3).
- **The tradeoff:** a real left-hand stretch is required to add the extra note per string — described as feeling "almost impossible" at first, especially for smaller hands — so the lesson opens with an easier looping exercise specifically designed to ease into the stretch before attempting full scale runs.
