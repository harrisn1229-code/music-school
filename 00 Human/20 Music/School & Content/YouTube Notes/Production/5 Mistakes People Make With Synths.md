# 5 Mistakes People Make With Synths

![](https://www.youtube.com/watch?v=6azfKWsYCpM)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=6azfKWsYCpM)

## Synopsis

A general-methodology video (not a single-song recreation) covering five recurring synth-programming mistakes: sloppy tuning, ignoring keyboard filter tracking, no real-time expression, presets left un-timed to the track, and turning knobs blind without reading the panel first. Dense with reusable technique, most of it not song-specific.

## Techniques

- **Mistake 1 — Tuning: build a reference chain, not independent tunings.** Tune oscillator 1 to an external pitch reference by listening for zero beating, then tune oscillator 2 against oscillator 1 (not the external reference again), then oscillator 3 against oscillator 1 as well — always referencing back to the same "anchor" oscillator rather than each new oscillator to the last one tuned, which would compound drift. To deliberately detune for effect afterward: detune ONE oscillator and pull its level down in the mix (a quiet, detuned color voice under an in-tune primary) — same principle as the Wyoming-tuning/quiet-harmony pattern seen elsewhere on this channel, generalized to "keep one true reference, treat detuned voices as seasoning."
- **Mistake 2 — Filter keyboard tracking, including an inversion trick.** A bass patch that sounds right in its low register can lose its identity entirely in the upper register if keyboard tracking is left on (brightens with pitch) — the fix is turning tracking off or down for bass so it stays consistently dull/full-bodied across the range (real bass gets duller, not brighter, going up the neck). The less obvious move: **tracking can be inverted** (via a CV inverter on synths that allow it, e.g. ARP 2600) so the filter gets DULLER as you play higher — useful when a part needs the opposite of the usual brightening behavior.
- **Mistake 3 — Add real-time expression hardware beyond the pitch/mod wheels.** Two cheap, easy additions: (1) a passive volume pedal after the synth's output, into an amp/preamp — recreates the "synths were originally designed to run through amps" workflow, and backing off input level into the pedal then re-boosting through a preamp is a free way to add "fun" distortion as a side effect; (2) a CV foot pedal (e.g. a Korg foot controller sending ~0–4V) patched directly into a filter-cutoff CV input, freeing both hands to keep doing pitch bend + vibrato on the wheels while the foot sweeps the filter — three simultaneous expressive dimensions instead of two.
- **Mistake 4 — Time a preset's envelope to the track's phrase before doing anything else to it.** Workflow: identify the song's rhythmic phrase length, adjust ONLY the filter envelope's attack/decay/sustain so the sound's onset and cutoff line up with that phrase (e.g., attack slowed if the sound "speaks" too fast/hard, sustain lowered if it rings past the phrase, decay tuned so it "dies" exactly on time) — then, and only then, layer in tonal changes (brightness, resonance, detune, PWM) for character, since chasing tone before timing means redoing the timing work later. A useful decision rule for "should this sound be brighter": check whether it's carrying the melody at that moment — the sound "isn't always the star," so brighten it (via the filter, not the oscillator or envelope) only in the sections where it actually is.
- **Mistake 5 — Read the front panel systematically before touching any knob.** Same left-to-right, signal-flow-order method as seen on the ARP Odyssey breakdown elsewhere on this channel: identify each labeled section (oscillators → filter → envelope generators → VCA → mixer) by its printed name, infer what a knob does from which section it's physically located in and what's patched into/out of it, rather than turning knobs and listening for the result. Stated as approachable even on an intimidating, non-color-coded panel (the ARP 2600) if given "a minute" of deliberate reading first.
