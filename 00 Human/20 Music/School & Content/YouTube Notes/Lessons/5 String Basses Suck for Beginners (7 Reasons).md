# 5 String Basses Suck for Beginners (7 Reasons)

![](https://www.youtube.com/watch?v=WOjDPaJ-Vns)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=WOjDPaJ-Vns)

## Synopsis

A BassBuzz gear-choice video arguing against the five-string bass as a beginner's first instrument — not because five-strings are bad, but because the extra B string taxes every skill a beginner is already fighting to build on four strings. Josh frames it personally (he played five-string as his only bass for a year or two early on and now considers that a mistake) and structures the case as seven distinct reasons, split roughly into a compounding-difficulty cluster (muting, string-targeting accuracy, slapping, fretboard memorization, four-string disorientation), a physical/ergonomic cluster (weight, floppy B-string tension), and a tonal/stylistic cluster (genre-inappropriateness and overuse risk). The video closes with real nuance rather than a blanket ban: every one of the seven problems is fixable and none of them makes a five-string a bad instrument, but they all add avoidable load to an already-steep beginner curve, so the advice is a "strong no" for a first bass unless the player is committed to a genre that structurally needs the extended range (orchestral, certain metal sub-genres) or just wants it badly enough to accept the extra difficulty deliberately. The most reusable concrete technique buried in the argument is the **floating thumb technique** — the standard five-string fix for B-string rumble, where the plucking thumb rests across and tracks along the lower strings as a continuous mute bar.

## What's taught

- **Reason 1 — Muting gets harder.** The B string is bigger/fatter than the other four strings and rings/rumbles more readily; the rumble is deceptively hard to hear on a small practice amp but becomes a real mess through a bigger amp or a venue PA, so a beginner practicing quiet at home won't notice the problem they're creating.
- **The floating thumb technique** (the standard five-string fix): rest the plucking-hand thumb flat across the strings below the one currently being played and let it follow along, string to string, as the plucking fingers move — a continuously-repositioning mute bar. It solves the B string's rumble but is one more coordinated motor skill layered onto muting itself.
- **Reason 2 — Hitting the right string gets harder.** Wrong-string mistakes are already a normal beginner failure mode on four strings (fret, pluck, hear an unexpected note because the fingers landed on the wrong string); a fifth string is one more target to miss, and most five-string basses run tighter string spacing than a four-string, cramming more strings into a similar neck width and shrinking the physical target further.
- **Reason 3 — Slapping gets harder, on both halves of the technique.** Slap accuracy is already hard for beginners (thumb tends to clip the neighboring string); the B string adds a bigger, closer target to clip, plus the tighter spacing shrinks the hitbox. Slap muting is also harder because the thumb can't be used to mute while it's busy striking, so clean slap muting already leans entirely on fretting-hand muting — a fifth string means covering one more string with that same hand, with no floating-thumb-style helper available mid-slap.
- **Reason 4 — More fretboard to memorize.** Learning note names is already a challenge on four strings; a five-string adds 25 more notes to memorize before the four-string map is solid.
- **Reason 5 — Disorienting for anyone with existing four-string muscle memory.** Putting the B string where the E "should" be actively fights four-string muscle memory rather than building on it. Josh's own anecdote: he brought a five-string to a gig underprepared and repeatedly played the wrong string that day because his hands kept expecting the B string to be the E.
- **Reason 6 — Physical downsides: weight and floppy B string.** More neck, strings, bridge hardware, and tuners make five-strings generally heavier — a thick padded strap helps but a heavy bass will still strain the back on a long gig. Separately, the B string runs the *same* scale length as the other strings despite being thicker, so it sits under comparatively less tension and can feel floppy; the dedicated fix is a multi-scale/fanned-fret bass (Dingwall named as the example) where the B string is physically longer, but these are expensive enough that a beginner is better off spending that money on instruction instead.
- **Reason 7 — Not the "classic" sound in many genres, and easy to overuse even when it fits.** Example given: reaching for low B/C/D notes on a Motown tune "just don't sound right" — a beginner is also least equipped to make that stylistic judgment call since the ear for when a style calls for extended low range takes time to develop. Even in a genre where a five-string does fit, new owners tend to sit on the low notes constantly because the extra range is exciting, which reads as "five-string noob" to experienced ears; the low notes work best used sparingly, as a deliberate intensity jump, not a default register (the video's analogy: a constant four-on-the-floor kick gets monotonous, but building from mellow into intensity with purpose is what actually lands).
- **The two exceptions where five-string does make sense for a beginner:** (1) genre commitment — orchestral playing or certain metal sub-genres that structurally need the extended low range; (2) wanting it badly enough, for its own sake, to accept the extra learning-curve tax deliberately.
- **Framing note:** all seven problems are explicitly called fixable — the point isn't that five-strings are bad instruments, it's that they add avoidable difficulty to an already-steep beginner curve, and the fix for all seven is simply starting on four and adding the fifth string later once the underlying skills are solid.
