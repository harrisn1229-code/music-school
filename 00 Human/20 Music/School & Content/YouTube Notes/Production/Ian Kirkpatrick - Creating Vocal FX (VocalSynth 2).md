# Ian Kirkpatrick — Creating Vocal FX (VocalSynth 2)

![](https://www.youtube.com/watch?v=S1P8MJy3hzI)

## Synopsis

One-minute Splice clip: Ian's favorite "unorthodox" use of iZotope **VocalSynth 2 — sidechain mode**, where an *external* signal modulates the vocal. He sends a synth loop into VocalSynth's sidechain input so the synth's spectrum shapes the vocal, producing "combinations of sounds that don't exist anywhere."

## Techniques

- **VocalSynth 2 sidechain mode** — instead of the vocal driving the effect, route a separate synth (or drum) loop into VocalSynth's sidechain so *it* modulates the vocal. Talk-box / vocoder-adjacent territory but far weirder. → [[Ear Candy and Hiding Synths]], [[Modulation]]
- **Pick a synth loop with strong character** — the modulator's timbre defines the result; he found a synth loop he liked first, then fed it in. → [[Sound Selection Guide]]
- **VocalSynth is unowned in Ableton land** — the *behavior* (external-signal-modulates-vocal) can be approximated with Ableton **Vocoder** (external modulator) or a talk-box style rack; the specific plugin goes to the wishlist. → [[Plugin Wishlist]]
