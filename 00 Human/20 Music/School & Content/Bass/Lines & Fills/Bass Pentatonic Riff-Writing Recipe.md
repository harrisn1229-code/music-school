# Bass Pentatonic Riff-Writing Recipe

BassBuzz's answer to a gap [[Bass Scale Shapes — Major, Minor, Pentatonic & Blues]] deliberately leaves open: that note teaches the five scale *shapes* (where the notes live on the neck), but knowing a shape doesn't automatically make someone able to write a good riff with it — running the analogy hard, learning the shapes is "buying a bunch of meat and veg with no recipe and expecting to be the Iron Chef." This note is the recipe half: a small, repeatable set of composition rules for turning five pentatonic notes into a riff that actually sounds intentional, plus the companion choice of *which hand shape* to play them in. Taught entirely through worked examples — a real riff first, then the same recipe steps used to fix a deliberately bad improvised riff on the spot, twice (once for minor pentatonic, once for major pentatonic).

## The riff-writing recipe

Four steps, the first three demonstrated on "Bombtrack" (Rage Against the Machine) using the **minor pentatonic static shape**, the fourth added via "August 10" (Khruangbin):

1. **Start on the root note.** The riff's low starting note should be the scale shape's root — it's what tells the listener's ear what key/context they're in. Skipping this and jumping in mid-scale is the single biggest reason an otherwise-fine set of notes reads as directionless.
2. **Favor sequential (stepwise) motion through the shape.** Move to the next note up or down in the scale shape rather than leaping around it — "never jumping beyond the next note in the shape in either direction." Stated explicitly as *not* a hard rule, just a foolproofing default for beginners: sequential motion gives a riff a flowing, non-angular sound almost automatically. *(General starting point — break it once the flowing version is boring; see step 3.)*
3. **Add a longer phrase through variation, not repetition.** A riff played identically four bars in a row gets boring fast — the fix demonstrated on "Bombtrack" is to keep the riff mostly the same but change it up slightly every other repeat (bar 2 varies from bar 1, bar 4 varies again), so a listener hears one long interesting 4-bar idea instead of one short idea looped four times. This single move is called out as **the trick beginners miss most** — it's cheap (a tiny per-repeat tweak) and doubles the effective length of a riff without doubling the writing effort.
4. **Extend the shape's range with the copy-paste octave technique.** Once steps 1–3 are second nature, this step (taught via Laura Lee's playing on "August 10") breaks past the scale shape's fixed note pool: take one or two notes from within the shape and replay them **one octave higher**, reached on bass by moving **two strings up and two frets over** for the same note name. Because it's the same note name an octave up, it still "fits" the scale and carries the same harmonic vibe, but it opens up melodic movement that doesn't fit inside the original box shape — visually, some of the riff's notes end up sitting *above* the drawn scale-shape box. This is what pushes a riff from merely-competent toward the more melodically adventurous "Khruangbin level" sound cited in the lesson.

**Applied demo (the method in miniature):** starting from a deliberately "kind of crappy" improvised riff (shown twice — once in minor pentatonic, once in major pentatonic, both starting on G/C), running it through steps 1–3 in order — anchor on the root, reorganize toward sequential motion, then vary every other repeat — visibly and audibly fixes it each time, without needing any new notes or theory. Step 4 (copy-paste octave) is layered on top only once 1–3 already sound decent, per the "August 10" walkthrough.

## Static shape vs. shifting shape — pick the shape the riff needs

The lesson introduces a second axis, independent of the four-step recipe above: **which hand shape** plays those five notes. [[Bass Scale Shapes — Major, Minor, Pentatonic & Blues]] only teaches the static shape; this is the shifting-shape counterpart the sibling note doesn't cover.

- **Static shape** — the version already taught in [[Bass Scale Shapes — Major, Minor, Pentatonic & Blues]]: the whole scale is fretted from **one hand position**, no shifting required, at the cost of a wider stretch (roughly a **4-fret span** from the root to the next scale note).
- **Shifting shape** — the same five notes, but split across **two different hand positions**, requiring a mid-riff shift. Worked fingering for the minor pentatonic shifting shape: **pinky** on the root, **index-pinky** for the next two notes, then **shift the hand up two frets** and finish the remaining notes there. A tighter, more relaxed **~3-fret span** per position is the tradeoff for the extra hand motion.
- **Neither shape is "better" — they just fit different riffs.** Some riffs (the "August 10"-style riff, and the major-pentatonic riff credited to bassist "Deacy") land certain notes on strings/frets that the static shape simply can't reach cleanly, or can't reach with the specific slide the riff wants; forcing the static shape onto a shifting-shape riff is described and demonstrated as sounding "super awkward." Conversely, the shifting shape "wouldn't work as well for My Girl" — it feels clunky there. **Practical rule of thumb:** try the riff in the static shape first (it's the default and the wider-reach option); if a phrase keeps landing wrong, fighting the fretting hand, or needs a slide the static shape's fingering can't set up, switch to the shifting shape for that riff instead of forcing the static one.
- **What the shifting shape buys you that the static shape can't: slides.** Because the shifting shape already requires the hand to physically travel between two positions, that same motion doubles as a **slide** opportunity — sliding into the note that the hand-position shift would move to anyway. The static shape can't offer this on the same notes, because the target note sits on a different string with nowhere to slide to. → [[Bass Slide Technique]] for slide mechanics generally (pressure, tracking, destination-not-origin).
- **No-slide alternative, same "different sound" payoff:** "you can get a similar effect using hammer-ons and pull-offs" — swap the fretting-hand slide for a fretting-hand hammer-on/pull-off when a slide's physical shift isn't wanted or possible. → [[Hammer-Ons and Pull-Offs (Bass)]].

## Laura Lee's (Khruangbin) fretting approach

The shifting shape's real-world source in this lesson: Khruangbin bassist **Laura Lee**, quoted directly on her own technique. She frets with only **three working fingers** — index, middle, pinky — because she keeps her **ring and pinky fingers physically attached together**, rather than fretting with all four fingers independently. That constraint is exactly why she doesn't default to the static shape's 4-fret stretch: she prefers to stay inside a **relaxed 3-fret span**, which in her own words "creates a limitation" — but one she frames as a feature, not a compromise: *"for me it's fun and bouncy."* Her playing on "August 10" is the worked example for both the shifting shape's fingering (above) and the copy-paste octave technique (recipe step 4).

## Worked examples — riff → scale → shape → recipe steps used

- **"Bombtrack" (Rage Against the Machine)** — minor pentatonic, **static shape**. Uses recipe steps 1–3 only (root start, sequential motion, longer-phrase variation); the reference example the whole recipe is taught from.
- **"August 10" (Khruangbin, Laura Lee)** — minor pentatonic, **shifting shape**. Uses all four recipe steps, adding the copy-paste octave technique (step 4) on top of the same root/sequential/variation base as "Bombtrack."
- **"My Girl" (The Temptations, 1964; guitar riff by Robert White of the Funk Brothers)** — major pentatonic, **static shape**. Only a **two-step** recipe (root note + sequential motion) — no built-in phrase variation, and left on a loop it does get repetitive. The song solves that repetitiveness a different way than "Bombtrack" does: guitarist Robert White **moves the whole riff to a new starting root note every bar**, tracking the chord progression, rather than varying the riff's internal shape. Cross-reference: this is the same riff [[Bass Scale Shapes — Major, Minor, Pentatonic & Blues]] uses to teach the major pentatonic shape itself — that note covers the shape/fingering, this one covers *why the riff is built the way it is*.
- **An untitled major-pentatonic riff credited to bassist "Deacy"** (video doesn't name the song on-camera in the transcript — near-certainly **John Deacon of Queen**, given the phrasing and the slide-driven pentatonic style described; treat the song ID as a strong inference, not a confirmed quote) — major pentatonic, **shifting shape**, described as adapted from "a super common blues pattern." The riff mostly follows the sequential-motion rule but deliberately **skips the second note in the shape**, and its signature move is a **bass slide baked into the position shift itself** — a slide that's only possible because the shifting shape already relocates the hand there; the static shape has no path to that note to slide from.
