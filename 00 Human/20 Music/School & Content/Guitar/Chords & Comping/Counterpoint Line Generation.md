# Counterpoint Line Generation

Part of [[Jazz Harmony]] — a two-voice line-generation exercise for producing comping *and* soloing lines, using a loose (non-species) reading of counterpoint: **one note moving in one direction while another note moves in the other.** This is a practical generative device, not the formal Fux system on [[Species Counterpoint]] — no consonance/dissonance rules are enforced, the whole point is a simple, repeatable recipe for two contrary-moving voices that a jazz player can turn into vocabulary fast. Credited by Nathan Borton to **Steve Kabal** *(name as captioned — possibly a transcription/spelling artifact of the source's actual name; verify against the channel link in the video description before citing further)*.

## The base exercise (no chord yet)
1. Pick a **key center** — worked in the video in the key of C.
2. Take **any note in that key** as a starting point for the top voice — worked starting on A (G string).
3. Play **a second below it** in the same key as the starting bottom voice — A down to G, a diatonic 2nd.
4. **Move the top note up three notes** (three diatonic steps up the key) while **moving the bottom note down three notes** (three diatonic steps down the key) — the contrary motion is the whole exercise: one voice climbs while the other descends, both diatonically within the fixed key center.
5. **Repeat the whole process starting from every note of the key** — run it as a full diatonic cycle, one starting pair per scale degree, the same "walk it through every degree of the key" logic used elsewhere in this vault for fretboard-mapping drills (e.g. [[Chords by Key]]'s tonic-to-tonic routine).

## Adding a chord underneath
Once the two-voice line is comfortable on its own, drop a chord under it:
- Worked over a **G7**, but **any diatonic chord in the key works** the same way — the two-voice contrary-motion line isn't tied to one specific harmony.
- Walk the **top note up** through the exercise until it lands on a note that actually works against the held voicing — in the video's worked case, walking up eventually produces a usable **G13** color once the top note reaches a tone the G7 voicing can absorb as an extension.
- The same contrary-motion exercise can be run **against every note of the key, over the one held chord**, generating a whole family of usable lines against that single harmony rather than just one.

## Using it as comping/soloing vocabulary
Take one of the generated two-voice lines and run it through a **2-5-1** progression (see [[The ii-V-I]]) — this is the payoff step: a line built from the abstract contrary-motion exercise becomes real comping vocabulary once it's applied against moving changes, and the same lines work equally well lifted an octave or thinned to a single voice as **soloing** material, not just chordal comping.

## Combine with the other two secrets
Explicitly stackable with the other two devices from the same lesson: run a counterpoint-generated line as the source material, then apply [[Breaking Up Voicings]] to fragment it further, and/or build it from a [[Multifunctional Voicings|multifunctional]] shape so the same line implies more than one chord depending on the bass underneath.
