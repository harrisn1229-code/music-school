# Parallel Scale Alternate-Picking Drill (One-Note Mode Switching)

BERNTH's own answer to "how do I combine technique and theory practice instead of doing them separately" — one alternate-picking exercise, run first on a base scale, then re-run with a single note manually altered to produce a related mode/scale, forcing [[SCL-C04 — Parallel vs derivative mode thinking|parallel mode thinking]] (alter the tonic scale in place) instead of derivative thinking (recite a different parent-scale rotation).

## The exercise

A continuous 3-note-per-string alternate-picking pattern (strict down-up-down-up, no economy picking), played **horizontally across just two adjacent strings** (worked example: D and G strings) ascending the scale degree by degree, rather than boxed in one position. Base pattern: **E natural minor** (E F♯ G A B C D).

## Picking-angle fix for the string change

Over-exaggerate the pick's angle **away from the guitar body** (not into it) when crossing from one string to the next. The wrong angle leaves the pick physically trapped between the two strings at the transition point; angling away clears it for the next stroke in both directions (D string → G string and back).

## The theory layer: alter one note, don't relearn a shape

Once the E natural minor version is comfortable, run the *identical* fingering pattern but manually alter one scale degree at every occurrence, without looking up a scale diagram — the whole point is training the ear/hand to make the substitution live, not memorizing a second shape:
- **E Phrygian** — lower the 2nd (F♯ → F) everywhere it occurs. All other notes/fingerings stay identical to the E natural minor pattern.
- **E Harmonic minor** — raise the 7th (D → D♯) everywhere it occurs; the 2nd stays F♯ (untouched, unlike the Phrygian variation).

Recommended order: master the natural-minor pass first (technique + note-naming, not just finger position), then Phrygian and harmonic minor, since both are named as the most frequently needed scales in metal/shred soloing. Once comfortable, extend the same method to any other parallel relationship (major → Lydian, natural minor → Dorian/melodic minor, etc.).

## How to run it

- **10-15 minutes daily.** Change the scale/mode pairing weekly (e.g. next week: major → Lydian; the week after: natural minor → Dorian or melodic minor).
- Rotate which string pair you use (low E/A, B/high E, etc.) once the D/G pair is comfortable, so the horizontal-visualization skill generalizes across the neck.
- Think the actual note names while playing, not just finger positions — the drill is explicitly framed as failing its purpose if you memorize "where fingers go" for each variant instead of "which note I'm altering."

## Why it works (per BERNTH)

Combines a mechanical alternate-picking/speed workout with active mode-derivation theory in a single repetition, rather than treating them as separate practice blocks — the technique exercise stays musically grounded (not purely mechanical), and the theory stops feeling abstract because it's tied to a physical, audible change.
