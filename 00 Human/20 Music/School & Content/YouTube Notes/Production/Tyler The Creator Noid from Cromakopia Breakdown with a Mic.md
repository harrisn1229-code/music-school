# Tyler, The Creator "Noid" from Cromakopia Breakdown with a Mic!

## Synopsis

An attempt to recreate the irregular, jittery filter sweeps on Tyler, the Creator's "Noid" (Chromakopia) — Anthony's read is that the sweeps are too "emotional"/irregular to have come from a knob or slider, and rebuilds the effect using an envelope follower fed by his own voice into a microphone.

## Techniques

- **An envelope follower converts an external signal's loudness into control voltage** — louder input, more output voltage — a genuinely underused module that can drive any CV-controllable parameter (here, filter cutoff) with whatever dynamic shape the source signal has, rather than a smooth hand-drawn sweep.
- **Full patch chain**: microphone → preamp (for a hot enough signal) → mult (making multiple copies), one copy into a ring modulator for a robotic texture, another copy driving the filter directly via the envelope follower. Blend in white noise and a keyboard-played pitched oscillator to taste; the same envelope-follower voltage also gates a VCA, so nothing sounds unless you're actively vocalizing into the mic.
- **The result is a sweep with irregular, "spontaneous" dynamics** — genuinely hard to replicate manually with a slider/knob — worth reaching for specifically when a part needs to read as emotional/unpredictable rather than a clean, deliberate filter automation curve.
