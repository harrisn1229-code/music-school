# The BEST Daily Finger Exercise! | Guitar Lesson

## Synopsis

A dedicated legato (hammer-on/pull-off) technique exercise built on the chromatic scale specifically because it forces equal use of all four fretting fingers, unlike 2- or 3-notes-per-string scale shapes which favor the stronger fingers. Pairs the physical exercise with an explicit pull-off mechanics correction (a snapping motion, not a passive lift) and a no-wrist-rotation rule for the fretting hand during legato playing.

## What's taught

- **Why chromatic, specifically:** heptatonic/pentatonic scale fingerings typically use 2-3 notes per string, which under-exercises the pinky and ring finger relative to index/middle; the chromatic scale forces genuinely equal use of all four fingers for hammer-ons and pull-offs alike.
- **Exercise shape:** worked on the two lowest strings first (E and A) before extending to other string pairs (D/G, B/E) — deliberately starting on the strings most players are already comfortable with from riff-based rock/metal playing.
- **Pull-off mechanics correction: an active flick/snap, not a passive lift.** A common beginner failure produces weak, ringing-out-inconsistently pull-offs because the finger is simply lifted off the string; the fix is actively flicking the string sideways as the finger releases, which is what actually sets the string back in motion (matches the existing checklist rule, restated here with the practice-routine framing).
- **No wrist rotation during legato** — unlike bending/vibrato, which benefits from wrist involvement, this exercise's hammer-ons/pull-offs work better with the wrist locked in place and the motion isolated to the fingers; named as a personal technique correction that improved control once adopted.
- **Equal dynamics/articulation across picked and legato notes is the actual quality bar** — the goal is a listener being unable to tell which notes were picked and which were hammered/pulled, which requires deliberately not accenting the first (picked) note of each phrase harder than the legato notes that follow.
- **Advanced main workout: 14 notes per string, notated as 16th notes in a 7/8 measure** — beyond the technique payoff, explicitly framed as a simultaneous odd-meter/note-spacing exercise, since the irregular grouping forces active subdivision counting rather than autopilot.
