# FND-C07 — Letter distance decides the interval number

**Q.** C→A♯ sounds identical to a minor 7th. Why isn't it called one?

> [!question]- Answer
> Because **the interval number comes from letter distance, not from sound.** C D E F G A spans six letter names, so C→A♯ is a **sixth** — an augmented 6th. C→B♭ spans seven letters, so that's the m7.

## Why it matters

The rule underneath all correct spelling. It's why a fully diminished 7th on G is spelled G B♭ D♭ F♭ rather than using E — the chord needs a 7th, so it needs an F of some kind.

## Drill

Name and explain: C→A♯ vs C→B♭ · C→D♯ vs C→E♭ · G→F♭ vs G→E.
