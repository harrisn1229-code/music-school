# Notepad

![[Images/Notepad.jpg]]

**Category:** Utility
**Vendor:** Max for Live

## What it is

A Max for Live utility device that embeds a text note directly inside a Live set for session documentation.

## What it's used for

Leaving in-session notes (mix decisions, TODOs, credits) that travel with the project file.

## FX chain notes

Runs inline in the signal/MIDI chain at the point it's inserted; combines with whatever device follows.
