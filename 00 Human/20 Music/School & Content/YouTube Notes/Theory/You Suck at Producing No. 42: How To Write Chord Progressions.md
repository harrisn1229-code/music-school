# You Suck at Producing No. 42: How To Write Chord Progressions

## What's taught
A practical, bass-first method for writing a chord progression: since the bass already establishes the root note of every chord, let an existing bassline dictate both the key AND the root of each chord in the progression, then stack triads over those roots by leapfrogging within the scale. The second half fixes the resulting progression's voice-leading by octave-shifting a jumpy top note into an inversion, using shared common tones between adjacent chords as the guide — while making clear that inverting a chord never changes its identity, and the bass still has to play the actual root regardless of which inversion sits on top.

## Techniques
- **Let an existing bassline dictate the chords** — since the bass's main job is playing the root note of whatever chord is currently sounding, a bassline written first has already predetermined which chords can go over it; copy the bassline into a chord track and use its notes as the roots to build from. → [[Bassline Writing]], [[Chord Progressions]]
- **Determine the key/scale from those root notes before building anything** — fold the piano roll to see which notes are actually in play, identify the scale they belong to (here, a scale built on A), and restrict all chord-building to that scale's notes. → [[Scales]], [[Keys]]
- **Build each triad by leapfrogging strictly within the scale, not the raw chromatic keyboard** — root, skip a scale note, add a note, skip, add — done on the FOLDED (scale-only) piano roll so the skips always land in-key; doing the same shape on the unfolded/chromatic view produces wrong notes. → [[Chords]]
- **Smooth a jumpy progression by octave-shifting one voice into an inversion** — when a big interval jump appears between two chords' top notes (e.g. one note has to leap a large distance to the next chord's top note), shift that offending note down an octave; look for shared/common tones between adjacent chords first (notes that don't need to move at all) as the guide for which note to invert. → [[Chord Inversions]]
- **Inverting a chord doesn't change its identity, and the bass still plays the actual root regardless** — a chord voiced with a non-root tone on top (or even functionally "on the bottom" of the upper voicing) is still the same chord; the bass part underneath keeps playing that chord's true root note the whole time, inversions only affect the upper voicing. → [[Chord Inversions]]
