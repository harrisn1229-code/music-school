# The 6 BEST Guitar Solo EXERCISES (finally learn to SHRED!)

![](https://www.youtube.com/watch?v=wuHyGs-GwJM)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=wuHyGs-GwJM)

## Synopsis

BERNTH generalizes the classic "broken thirds" scale-sequence idea to any interval size — running A harmonic minor as intervallic patterns in 3rds, 4ths, and 6ths, ascending and descending (6 exercises total: 3 interval sizes × 2 directions). The core reusable idea: bigger interval skips sound progressively more unusual/less predictable and more "neoclassical," and the same skip-through-the-scale system that works for 3rds generalizes cleanly to any interval, not just the common third.

## What's taught

- **Exercise 1–2 (3rds, up then down):** the standard broken-thirds pattern applied to A harmonic minor — A C B D C E D F♯... (skip one note in the scale, then step back), ascending, then the identical pattern reversed descending through the scale. Alternate-picked throughout (down-up-down-up, no exceptions).
- **Exercise 3–4 (4ths, up then down) — the video's stated "main takeaway."** Same skip-pattern logic, but skip TWO scale notes instead of one, producing a run in perfect/augmented 4ths through the scale: A D B E C F D G♯... Explicitly framed as an underused sound outside jazz/fusion — because listeners are so used to hearing lines built on 3rds, a 4ths-based line sounds noticeably less predictable/melodically surprising even using the exact same scale. Harmonic minor's own structure means some of the 4ths land as dissonant augmented 4ths rather than plain perfect 4ths, adding extra color. Same pattern reversed descending.
- **Exercise 5–6 (6ths, up then down) — BERNTH's stated personal favorite.** Skip FOUR scale notes for a run in 6ths: F B G♯ C A D B... Framed as the "neoclassical, complex-sounding" effect players often hear and assume is hard to replicate — it's the identical skip-pattern system, just with a bigger interval. Requires **string skipping** to execute the wide jumps while maintaining strict alternate picking throughout — flagged as a genuinely useful picking-hand/string-skipping exercise on top of its melodic value, and specifically recommended for anyone actively working on string-skipping technique.
- **General rule, stated explicitly as the real lesson:** the skip-N-notes-through-the-scale system generalizes to *any* interval size, not just 3rds — bigger jumps = more unusual/exciting sound, at the cost of technical difficulty (string skipping, wider stretches). Once internalized, these interval-pattern phrases start appearing naturally in improvised solos and songwriting, not just as isolated drills.
- **Practice-scheduling method (his own daily routine):** organize practice into topic "blocks" (alternate picking, sweep picking, chord theory, improvisation, scales, etc.), ~20 min per block per day for a balanced session; pick 4–5 topics that are actually needed for the music you want to play (don't add a technique like sweep picking if you don't want that sound in your own playing); rotate which specific exercises fill each block weekly/monthly to keep practice fresh. Recommends featuring at least 2 of today's 6 patterns inside an alternate-picking block, and specifically exercises 5–6 inside a string-skipping block.
