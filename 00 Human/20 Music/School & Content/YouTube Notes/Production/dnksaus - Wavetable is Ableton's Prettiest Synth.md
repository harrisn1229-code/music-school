## Techniques

- **Unison Shimmer/Noise modes for instant lushness** — even on a basic wavetable shape, switching Unison mode to **Shimmer** and turning up Attack + Release gets a lush pad fast; **Noise** unison mode is similarly an instant-character shortcut. → [[Operator]] (sibling instrument, Wavetable's own Unison row)
- **Wavetable's MIDI tab has a native per-note "Random" toggle — no external randomizer device needed** — turn on **Random** for Wave Position (and separately for Warp) on the MIDI tab and every triggered note lands on a different point in the table/warp amount automatically, without wiring up an [[Expression Control]] or [[LFO]] device — a built-in equivalent to the external random-per-note tricks documented elsewhere in the vault. → [[MPE Piano Roll Tools]], [[Randomized Rack Design]], [[Expression Control]]
- **A 7 Hz LFO into a small Pitch amount for a "pitch-bendy" character** — Matrix-map an LFO at roughly 7 Hz to Pitch with a small amount (and the LFO's own amount turned down to ~1) for a gentle wobble/bend rather than a full vibrato.
- **Velocity → oscillator wave position** — with velocity-sensitive playing, map velocity so different notes/voices land on different wave-table positions, giving natural per-note timbre variation from dynamics alone.
- **Modulate Time in the Matrix for live, phrase-tied expression** — rather than a fixed modulation amount, move the Matrix's Time modulation live while recording a phrase (start subtle, get more frantic) so the wavetable's internal movement tracks the actual performance rather than a static automation curve. → [[Automation]]
- **MPE controller (Push 3) XY pad mapped to wave position** — map an MPE-capable controller's per-pad XY position to Wave Position so where you press on each pad selects a different point in the table — a chord/keys-style expressive-playing use case. → [[MPE Piano Roll Tools]], [[Expression Control]]
- **Classic oscillator-FX mode stretches a dragged-in sample's frame end** — when using a custom dropped-in sample as the wavetable (rather than a factory table), switching the oscillator effect to **Classic** mode stretches out the end of that frame — makes an otherwise-short, non-loopy imported sample read more like a sustained texture/pad instead of a one-shot. → [[Operator]] (Oscillator FX row)
- **Reese bass: skip OTT, lean on compression of the noise content** — for a Reese-style bass, avoid OTT (as with most basses), but compressing the noisy/distorted content specifically reads as a good, characterful move; keep the low end protected/preserved from that same processing. → Drum & Bass (Reese entry in [[EDM Subgenres]])
- **Confirmed: key-tracked envelope loop rate, negative amount example** — following on from the previously-documented "loop an envelope, key-track its rate with a negative amount so lower notes loop/sustain longer" trick: demoed live here with a low note running fast and a high note running at roughly -30 by comparison, confirming the earlier general description with a concrete example.
