# Kenny Beats — Auto-Tune Process

![](https://youtu.be/dyr6F9DLG7c)
📺 [Watch on YouTube](https://youtu.be/dyr6F9DLG7c)

## Synopsis

A live walkthrough on 03 Greedo's "Disco Shit" of exactly how Kenny sets Auto-Tune: the only controls that matter (key, scale, **input voice type**, retune speed, style), what each retune range actually sounds like, Legato vs Soft/Hard EFX, calibrating tune-amount to the *artist's identity* (Greedo wants to hear it; singer-songwriters need it invisible), varying settings between mains and ad-libs, and why he never touches Humanize. The definitive companion to the [[Auto-Tune Pro]] stage in [[1 Main Vocal Track|Main Vocal Track]].

## Techniques

- **Five settings, that's the whole job:** input voice type → key → scale (major/minor) → retune speed → style. "Set your input type, set your key, set your scale, set your retune, set your style — boom, you're done." → [[Auto-Tune Pro]]
- **Set the input voice type — the most-forgotten setting** — Low Male for deep voices, Alto/Tenor for mid voices (Omar Apollo/Dominic Fike lane), Soprano when you want falsetto tracked; it's not a gender switch, it's a range switch, and **if it's wrong the pitch tracking misreads everything**. → [[Auto-Tune Pro]], [[1 Main Vocal Track|Main Vocal Track]]
- **Find major vs minor by ear** — darker/sadder/harsher = usually minor; brighter/upbeat = major. Set key + scale before anyone records ([[Kenny Beats - How to Start Recording Vocals the Right Way]]). → [[Auto-Tune Pro]]
- **Retune speed map:** ~30–40 = invisible support ("someone spotting you while you bench — hands there in case it gets heavy"); **~7 = deliberately audible tune** (Greedo/Travis/Migos bite); **>10–12 = full T-Pain** chippy glitch jumps. Calibrate to how much the artist wants to *hear* it, not to a "correct" number. → [[Auto-Tune Pro]], [[1 Main Vocal Track|Main Vocal Track]]
- **Style: Legato vs Soft/Hard EFX** — Legato corrects target notes to the scale but keeps bends/passing notes smooth (no chip); Hard EFX = maximum computerized; **Soft EFX at low retune = the in-between** — perfects missed notes with audible character but no full glitch. → [[Auto-Tune Pro]]
- **Disable/enable individual scale notes for one-off passing tones** — when a singer wants a half-step outside the scale once in the song, toggle that note on the keyboard rather than loosening the whole retune. (Same move as the Chromatic-minus-notes trick already in [[1 Main Vocal Track|Main Vocal Track]].) → [[Auto-Tune Pro]]
- **Mains vs ad-libs get different tune** — same key/voice-type, but vary retune/style per lane: ad-libs Legato when mains are Soft EFX (smoother bed) or ad-libs *more* tuned when the artist reaches on stacks (Smino falsetto example). → [[1 Backup Vocal Track|Backup Vocal Track]]
- **Ad-lib spatial layout** — two ad-lib tracks panned wide L/R + one center ad-lib running [[PanMan]] auto-pan drifting between them: static width plus one moving element. → [[1 Backup Vocal Track|Backup Vocal Track]], [[Width and Stereo]]
- **He never uses Humanize** — retune speed + style covers it; note this is the opposite of Nate's default ([[1 Main Vocal Track|Main Vocal Track]] runs Humanize 100 with retune 35–50) — both land at "natural," via different knobs. Keep one philosophy per song.
- **Tune amount = artist identity, communicated** — artists will tell you tune-on vs tune-off per song (Greedo: rap verse dry, hook tuned); match their records unless told otherwise, and never make a natural-voice artist feel "too corrected" or they'll perform worse. → session craft
