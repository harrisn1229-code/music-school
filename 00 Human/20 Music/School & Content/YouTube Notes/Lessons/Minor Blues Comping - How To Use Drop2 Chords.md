# Minor Blues Comping - How To Use Drop2 Chords

![](https://www.youtube.com/watch?v=bfec6PJme78)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=bfec6PJme78)

## Synopsis

Jazz guitarist Jens Larsen works through a full 12-bar minor blues in C minor twice, using **Drop 2 voicings on the top string set** as the fixed vocabulary and varying only *which scale each chord is drawn from*. The video's real teaching point isn't the voicings themselves (he explicitly skips the "what is Drop 2" explanation, pointing to an earlier series) — it's a **scale-first framework for choosing chord extensions on a minor blues**: attach every chord to a scale first, and the scale tells you what extensions are available and which ones fit together, rather than picking colour tones ad hoc. He runs the identical 12-bar form through two contrasting scale systems — a **melodic minor system** (C minor 6/maj7 tonic sound, giving altered and Lydian-dominant colours on the V chords "for free" because they're modes of the same scale family) and a **Dorian system** (C minor 9/11 tonic sound, i.e. the notes of B♭ major, giving a different, less "inside" set of colours on the same dominants since the tonic scale itself is different). The most valuable structural insight, repeated multiple times, is that **because the whole chord scale for a section comes from one parent scale, a single physical Drop 2 grip can be slid to a new root and reused note-for-note across chords that are a half step or whole step apart** — the C minor voicing becomes the C7 altered voicing by sliding up a half step, and the A♭7/G7alt voicings reuse the exact same shapes because both are drawn from A♭ melodic minor. A short third pass at the end shows the two systems mixed within one chorus rather than used in isolation, plus one small "counter-movement" voicing trick on the final G7. This is a comping/voicing lesson, not a soloing lesson, and it assumes drop-2-shape familiarity already in place.

## What's taught

**The minor blues form used (C minor), matching [[Blues Form and Harmony]]'s documented minor-blues shape (`i7 iv7 v7`, ♭VI at bar 9, V stays dominant) with one extra structural detail not yet on that page:**
- Bars 1–3: **Cm7** (i, tonic).
- Bar 4: **C7 altered** (C7♭9) — a **secondary dominant, V7/iv**, used specifically to pull from the tonic minor chord into the iv chord, not just a passing color tone.
- Bars 5–6: **Fm7** (iv, subdominant).
- Bars 7–8: **Cm7** (i again).
- Bar 9: **A♭7** (♭VI, substituting for the "two" chord of a normal ii–V — i.e. the minor-key turnaround runs ♭VI7 instead of a ii chord).
- Bar 10: **G7♭5♭13** (V, altered dominant) — the "five" of the closing two-five, confirming this page's rule that the V stays dominant even though the ii slot goes to ♭VI7.
- Resolves back to Cm7 (bar 11–12/top of form).

**System 1 — the melodic minor system (tonic sound: Cm6 / C minor-major, i.e. C melodic minor):**
- Tonic **Cm6** as the base voicing; a first variation swaps in the **major 7th (B natural)** for extra colour, since melodic minor's own 7th degree is a natural 7 — turns Cm6 into a Cm(maj7)-flavoured sound without leaving the same scale.
- **The whole row of tonic voicings transfers directly to the iv chord (Fm)** — same shapes, same string set, just relocated — because Fm is voiced from F melodic minor the same way Cm is voiced from C melodic minor; no separate voicing set has to be learned for the iv chord.
- **C7 altered (bar 4) is the literal same voicing as the Cm6 tonic voicing, moved up a half step** — because C7alt's parent scale (C# melodic minor, i.e. Db melodic minor) sits a half step above C melodic minor, the physical grip barely changes.
- **A♭7 also comes from a melodic minor parent (A♭ melodic minor)**, and its Lydian-dominant colour (heard here as a D♭7♯11-type sound) shares the identical voicing already used for the Cm6/C-melodic-minor material — same shapes again, no new grip.
- **G7 altered reuses the same row of voicings too**, since altered = the 7th mode of the melodic minor a half step above the root — G7altered's parent scale is A♭ melodic minor, i.e. the *same* parent scale as the A♭7 chord right before it, so G7alt and A♭7 literally share voicings.
- **Net practical result: one melodic-minor-derived Drop 2 row, relocated by half or whole steps, harmonizes the entire minor blues** — Cm(6/maj7) tonic, Fm iv, C7alt, A♭7 (Lydian dominant), and G7alt all draw from the same small set of physical shapes.

**System 2 — the Dorian system (tonic sound: Cm9/11, i.e. C Dorian / the notes of B♭ major):**
- Tonic voiced as **Cm7(9,11)** — flagged as a genuine stretch on guitar; the easy-mode substitute is to **drop the 11 back to a plain 5th**, which is described as "very easy" and still sounding good — an explicit fallback for players who can't make the stretch work yet.
- **C7 in bar 4 reuses the System-1 C7alt shape with one note changed**: swap the ♭9 (D♭) in the melody for a **♯9** instead — same underlying grip, one altered extension substituted for another.
- **Fm (iv) voiced as Fm7(9,11)** — the direct Dorian-system analogue of the tonic voicing, built the same way.
- **A♭7 voiced as F♯7(13)** (enharmonic respelling) and **G7 voiced as G7(♯9,♭5)** — both still drawn from melodic-minor dominant colours (same underlying logic as System 1's dominants), confirming his point that *the dominant chords pull from melodic minor either way* — only the **tonic and iv chords** actually change character between the two systems; the dominant vocabulary is shared.
- **The whole Dorian-system tonic row is derivable by harmonizing the B♭ major scale** (C Dorian's relative major) starting from F on the high string — F G A B♭ C D E♭ F — and stacking Cm chords under each scale tone, the same "harmonize the parent scale, then relocate the resulting row to the next chord" method as System 1, just with a different parent scale.

**Voicing-substitution moves demonstrated on the Cm7(9,11) tonic shape (reusable on any Drop 2 minor-9/11 voicing, not just this tune):**
- **Root → 9th, 5th → 11th** substitution: the base "9/11" voicing is explicitly derived by taking a plain Cm voicing and swapping the root for the 9th and the 5th for the 11th — a named, repeatable extension-substitution recipe, not just "add colour tones."
- **Keep the root, drop just the 11th** variant — a half-step-back version of the full 9/11 voicing when only one extension is wanted.
- **5th → 13th** substitution ("more spicy") — Cm13(9) built by swapping the 5th for a 13 instead of leaving the plain 5th.
- **11-in voicing with the 13th standing in for something else** — a fourth combination mixing the 11 and 13 substitutions in the same grip. *(Exact fingering not specified in the transcript — described only as "this" with the shape shown on camera; treat as "a fourth workable combination of the same substitution menu" rather than a distinct named voicing.)*

**Third-chorus example — the two systems blended within one chorus, plus one new device:**
- Tonic bar 1 kept simple: **Cm6(♭9)**-type sound (melodic-minor system), then bar 2 adds motion by moving to the natural 7 for more melodic minor colour.
- The dominant move off the root is built explicitly as **C7♭13♯9 → C7♭9 → Fm** — a two-step alteration walk-down into the iv chord resolution, repeated as a short phrase motif rather than played once.
- F7 (iv-area dominant) reuses the same Cm-family shape, just relocated, matching the "reuse the row" principle above.
- **Small counter-movement trick on the closing G7** (the one new device flagged directly as not covered earlier): play the System-1 G7alt voicing, then the System-2 G7(♯9♭5) voicing back to back — because the two voicings' top notes move in **contrary motion** to each other, stringing them together creates a brief inner-voice/top-voice counter-movement effect on a single static chord, purely from alternating which of the two systems' voicings is used, before resolving to Cm6(9).
