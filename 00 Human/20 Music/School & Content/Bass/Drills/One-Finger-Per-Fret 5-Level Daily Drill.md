# One-Finger-Per-Fret 5-Level Daily Drill

BassBuzz's second five-level daily drill in the vault (see [[Slap Bass 5-Level Daily Drill]] for the first) — and the one that finally closes the gap [[Drill Index]] flagged after that first drill landed: *"a fretting-hand warm-up, a stamina tempo ladder, and something that connects to scale/mode material"* the slap drill didn't cover. One riff, five progressive levels, 10 minutes a day, explicitly pitched as working for beginners and advanced players alike (the BPM target scales, the theory layer and moving-root variations are where the advanced ceiling lives). Same underlying shape as the slap drill: each level adds exactly one new layer onto the same core pattern rather than being a separate exercise.

## The five-fret position (context before level 1)

The exercise is deliberately built around a beginner blind spot: bassists tend to think in **four-fret chunks** because they have four fretting fingers, but the bass's strings are tuned in **perfect fourths — five frets apart** (E → A = E, F, F♯, G♯, A, five notes before the next string's open pitch). Worked example of the trap: going from G to C by four-fret logic (G, G♯, A, A♯) skips **B**, the note immediately before C. **A full position on bass is actually five frets, not four** — that's the fix for getting lost/missing notes on the neck. This exercise spans frets 2–6 (a five-fret window) specifically to build that awareness. It doesn't require a big physical stretch — **microshift** (a small in-position hand creep, not a full position change) within the five-fret span as needed, the same mechanism documented in [[Fretting-Hand Strength, Stretch, Stamina, and Finger Control#Exercise 2 — Stretch|Exercise 2 — Stretch]] and in [[Look-Ahead Position Shifting]]'s companion shifting-*between*-positions skill.

## Level 1 — Basic pattern and tempo target

**The riff**, one finger per fret starting on the middle finger, frets 2–6: middle–index–index–ring–pinky, then index–middle–ring–pinky–middle–index, then a small shift, pinky–ring–middle–index.

**BPM targets** *(general starting point — same three-tier shape used across BassBuzz's other beginner routines in this vault)*: **100 BPM** beginner, **150 BPM** intermediate, **200 BPM** advanced and beyond, played as smooth quarter notes.

## Level 2 — Fix flying fingers

**Ascending fingerings (index → middle → ring → pinky):** add each finger **without lifting the one before it** — index stays down as middle comes down, both stay down as ring comes down, all three stay down as pinky comes down. Microshift within the position if needed rather than forcing a stretch.

**Descending fingerings (pinky → ring → middle → index):** the opposite shape — start with all four fingers down at the pinky, then **subtract fingers one at a time** as you move back down rather than lifting the whole hand: from pinky, lift the pinky and ring together while middle and index stay planted; then lift the middle, leaving index down. *(This segment's auto-captions were slightly garbled around the exact lift order — described qualitatively above rather than over-precisely, per the transcript's actual wording.)*

**Two tips to avoid overwhelm while fixing it:**
1. **Take it super slow first** — no rhythm or tempo at all, just one note after another, focused entirely on fretting-hand coordination; only add a tempo once that's smooth.
2. **Chunk it** — work a small handful of notes (e.g. just the first five) in slow motion until it feels smooth, then add the next chunk, then the next, then piece them together. This is the same **additive/chunking** method as [[Interleaved Practice, Chunking, and Deliberate-Practice Drills#The additive approach (chunking)|The additive approach (chunking)]] — build the piece up from solid sub-pieces rather than drilling the whole thing at once.

**BPM target before moving to level 3:** the same 100/150/200 ladder as level 1, now with fingers not flying.

## Level 3 — Fix your plucking hand

Slow tempos let you cheat by plucking everything with one finger — this level forces the plucking hand to actually build a real fingering:
- **Option 1 — strict alternate:** index-middle-index-middle the whole way through. Simple, scalable, the default.
- **Option 2 — incorporate raking:** reuse a plucking finger across a string crossing instead of alternating through it, at two named spots in this riff — coming **down from the octave, G string → D string**, and coming down again **D string → A string**.

This riff is a direct worked instance of [[String Crossing and Plucking Patterns#Drill 2 — decide rake vs. alternate on every direction change|the rake-vs-alternate decision]] — pre-deciding which option a given crossing uses, same principle, applied here to a real fretted riff instead of an open-string drill.

**How to bring it in:** drop the tempo back down to whatever speed lets the plucking actually land clean, then rebuild back up toward the level-1 BPM target.

## Level 4 — Root, fifth, octave theory + three walking patterns

The riff's core is only **three notes — root, fifth, octave** — the same harmonic skeleton documented in [[Jamerson's Root-Fifth-Octave Exercise]]; every other note in the exercise is a **walk-up or walk-down** connecting them. Bar shape: root → walk to the fifth → walk to the octave → walk to the fifth → root.

- **Pattern 1 — chromatic walk up to the fifth (and the same walk up to the octave).** Chromatic = half steps, ignoring the scale. Three half steps leading into each target.
- **Pattern 2 — chromatic walk down.** Same chromatic logic, three half steps, played back down across the strings — visually a "weird looking shape," but mechanically identical to pattern 1 in reverse.
- **Pattern 3 — scale walk down.** Uses the C major scale (diatonic, not chromatic) to walk back down to the root.

The riff sits in a bluesy context in the source video, but the three patterns are named as portable well beyond blues — walking jazz bass, gospel, and even the opening of "Smoke on the Water" are called out as other places to reuse them.

**BPM target:** unchanged from levels 1–3 — the point of level 4 is holding the root-fifth-octave-fifth-root theory framing in mind while playing the same notes, not a new tempo goal.

*Cross-link:* the chromatic-walk-down and scale-walk-down variants here are new content for [[Jamerson's Root-Fifth-Octave Exercise]] (which previously only documented the chromatic walk-**up** device) — added there with this video as the source.

## Level 5 — Moving root notes (chord changes)

Real songs change chords, so root-fifth-octave over one static root isn't the whole job — the exercise's advanced variations practice **connecting** roots smoothly.

**Intermediate — add one more root.** Move the exercise up a string to **F**, starting the pattern in **C on the E string** instead of the A string, so F is reachable without a full position change. The first three bars stay identical to levels 1–4; bar four changes because the target root has moved — a **scale walk-up** leads into F on the next downbeat, then the riff repeats on the A string starting from F, and bar four changes again with a scale-walk-down variation to resolve back to C to loop the exercise. *(The transcript's exact note names for this walk-up/walk-down are auto-caption-garbled — described qualitatively above rather than guessed precisely; re-check against the source video or its companion PDF before treating the note names as exact.)* Same level-1-through-3 checks (fretting, plucking, tempo target) apply on top of the moving root.

**Advanced — all 12 roots.** A free companion PDF, linked in the source video's description, walks the same exercise through all 12 notes as root notes. Not accessible from the transcript — noted here for completeness, matching the convention already used on sibling BassBuzz notes with the same PDF-in-description pattern (see [[Fretting-Hand Strength, Stretch, Stamina, and Finger Control]], [[Fretting-Hand Finger Independence Drill]]).

## How to run it

- **Don't skip levels** — each one adds exactly one new layer onto the same core riff (fingering → flying-fingers fix → plucking → theory → moving roots), same non-skippable-levels logic as [[Slap Bass 5-Level Daily Drill]].
- The five-fret-position framing above isn't a sixth level — it's the reason this specific riff (rather than an equivalent four-fret pattern) is worth drilling at all.
- Go slow enough to actually clear each level before adding tempo — the source video is explicit that rushing costs you the flying-fingers fix, the plucking pattern, *and* the theory layer all at once, not just speed.
