# The Last Fretboard Video You'll Ever Need

![](https://www.youtube.com/watch?v=QCVEy1K0xw4)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=QCVEy1K0xw4)

## Synopsis

A direct, numeric fret-counting system for instantly finding every instance of a given note across the fretboard, argued against the common "memorize note names in alphabetical order along one string" method (criticized as memorizing order, not location, and too slow for real-time playing). Covers the same underlying skill as the vault's existing [[Octave and Unison Shapes for Fretboard Navigation]] (Jared's scale-degree-chunking version) from a different angle — fixed string/fret offsets instead of a mental scale-counting bridge — genuinely useful as an alternate, faster-to-apply lookup table for the same relocate-a-known-pitch skill.

## Techniques

- **Two-strings-up, two-or-three-frets-up rule (same note, non-adjacent string).** From a known note, go up two strings: up two frets lands the same note *except* crossing the G→B string pair, where it's up three frets instead (the one pair tuned a major 3rd apart rather than a perfect 4th, same tuning exception documented in [[Octave and Unison Shapes for Fretboard Navigation]]). Works from any starting string, low E through B.
- **Three-strings-up, three-frets-down rule (same note, non-adjacent string, other direction).** From a known note, go up three strings and down three frets — except starting from the A string, where it's down two frets instead (the same B-string tuning exception showing up on this offset too).
- **Same-string octave: add or subtract 12 frets.** Below the 12th fret, add 12 to find the octave above; above the 12th fret, subtract 12 to find the octave below. The simplest of the rules, given as the anchor point for the others.
- **One-string-down unison: 5 frets below** (i.e. same pitch, adjacent lower string) — **except G string to B string, which is 4 frets below** — the same tuning exception again, and directly consistent with [[Octave and Unison Shapes for Fretboard Navigation]]'s Skill 2 (5-6-7-1 chunking) landing on the identical 5-fret-below relationship from a different counting method. E string to E string requires no fret change at all (same fret, adjacent string), called out as the one truly trivial case.
- **A full worked example, C on every string starting from the low E (8th fret):** A string = up one string, down 5 frets; D string = up two strings, up two frets; G string = up three strings, down three frets; B string = find it on D first, then up two strings and three frets from there; high E = same fret as low E (up 12 frets from the 8th-fret low-E C, or same-fret octave relationship). Repeated as a second full worked pass starting from the A string (3rd fret) to confirm the rules transfer.
- **Application: diagonal pentatonic lines.** Once the two-strings-up-two-frets (or three-frets, crossing G→B) relationship is second nature, a five-note pentatonic cell can be walked diagonally up the neck by repeating it at each newly-found same-key position — a direct escape from the fixed "box" shape using the exact fret-offset math above rather than a separately memorized diagonal fingering.
- **Why this matters, stated as the actual payoff:** the claimed gap between an intermediate and a professional player isn't theory knowledge or raw chops — it's fretboard-navigation speed. Faster note-finding directly enables faster chord-tone targeting when soloing and faster access to alternate voicings when comping, because the physical search time drops to near zero.
