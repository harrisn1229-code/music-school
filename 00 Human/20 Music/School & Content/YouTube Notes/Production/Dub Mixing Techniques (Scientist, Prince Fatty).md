## Synopsis

Short but genuinely dense — a real dub-mixing recipe in the style of Scientist/Prince Fatty, built entirely around treating the mixdown as a live performance rather than a static automated pass. The centerpiece technique is a self-feeding Echo return: routing the return track's own send back into itself so a single fader controls both the echo's volume AND how much it feeds back into its own delay line, producing the genre's signature runaway, spiraling echo escalation live rather than through automation.

## Techniques

- **Map physical faders to individual track volumes (≤0 dB) and mix the dub version live, not with automation** — dub mixing is fundamentally a performance: ride real faders for drums, bass, guitar, and vocals during the take rather than programming the moves afterward.
- **100%-wet Echo return, simple straight-16th delay time, sends on everything EXCEPT the bass** — a return track with Echo at Dry/Wet 100% (a return should contribute pure wet signal) and an uncomplicated straight-16th-note delay time; the bass alone stays off the send so the low end remains solid and centered while everything else gets thrown into the echo.
- **Low Feedback for a single clean echo repeat, not a long trail** — pull Feedback down so only one echo repeat is audible after the source hit, a deliberate, controllable throw rather than an always-decaying wash.
- **The genre-defining move: route the return track's own send back into itself, so its fader controls both volume AND feedback amount** — enabling a send FROM the Echo return back INTO itself means raising that one fader doesn't just make the echo louder, it also increases how much signal re-enters the delay line — producing a runaway, self-reinforcing echo escalation that can be ridden live in real time, rather than a fixed feedback amount. → [[Echo]], [[Delay]]
