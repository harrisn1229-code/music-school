# Mapping 6ths Across the Five CAGED Positions

Part of [[Guitar Positions]]. A full-fretboard mapping drill for the **diatonic 6th** (two scale notes played together, a 6th apart — in C major, C up to A) worked through **all five CAGED scale-form positions** of a single scale (C major, worked example) rather than one fixed string-set shape. Where [[Six Devices for R&B Rhythm Guitar Fills]] §3 treats 6ths as one movable double-stop fill run diatonically through a scale in a single area, this page is the deeper, position-by-position version of the same interval: learn the plain scale-form fingering in each of the five CAGED positions first, *then* harmonize each position's shape into 6ths, so the interval is available anywhere on the neck rather than in one comfortable spot. Stated motivation, generalizable to any interval or lick: **"extract a sound that I love and get control over it everywhere so I can be fully creative with it."**

## The five positions, in order

Walked up the neck through C major's five CAGED scale forms. The video names four explicitly (G, E, D, C) and demonstrates a fifth, unnamed first position before them — by CAGED sequencing (the standard low-to-high walk starting from the A-shape) that first position is almost certainly the **A-shape** *(inferred from the demonstrated order and CAGED convention — not stated by name in the video)*:

1. **A-shape (unnamed in the video)** — the lowest position demonstrated.
2. **G-shape** — named because the chord built off the root at the bottom of the shape is a G-chord shape (standard CAGED chord-to-scale logic, cf. [[CAGE System Scale Shapes]]).
3. **E-shape**.
4. **D-shape** — called out directly as **"kind of a trickier one for sixths"** — the hardest of the five to get clean, worth extra reps.
5. **C-shape** — the final, highest position. If it's physically too high up your particular guitar's neck, transpose the whole system down: it's a movable shape, so "you translate the same thing to any position, changing keys, moving the shape to a different place."

## Fingering is the actual puzzle, not the shape

The tab/notes are the easy part — **the fingering choice is where the drill actually lives**, and the source reports having "taken the time to decide on the best fingering" for each position rather than defaulting to symmetric finger patterns.

- **A-shape fingering example:** beat 1 = finger 2 then finger 1; beat 2 = finger 3 then finger 1; beat 3 = finger 1 then finger 4 — all straightforward — but beat 4 breaks the pattern: **finger 3 then finger 2**, not the "expected" 2-then-1. The natural-looking option (stay put, play 2-1) is playable, but the recommended fingering instead **hops the first finger** to the next position. Framed explicitly as "an easy relaxed kind of just shift... not tense at all," not a stretch to avoid.
- **Ascending vs. descending bar asymmetry (intentional, not an oversight):** the A-shape position bars certain notes going **up** the neck but does **not** bar the same notes coming back **down** — same two notes, different technique each direction, because ascending and descending feel physically different under the hand. Apply this same "bar on the way up, no bar on the way down" logic when working out your own fingering in any position, rather than assuming one fixed bar choice must hold both directions.
- **G-shape — the "ideal" bar option:** bar at fret 5 *ahead of time*, before the notes that need it, to prep the finger change and avoid hopping. Fingering with the bar held: last three beats = **3-2, then 3-1** (bar still held), then **4-1**. Hopping the finger instead (no bar) is explicitly fine too — "if you want to hop the finger and you're okay with a little gap there, that's fine" — the bar is the smoother option, not a hard requirement.
- **C-shape — bar, not essential:** a bar with fingering **1-to-4, 3-1**. "The bar is not essential but it's pretty slick feeling if you do it. It feels really ergonomic and nice" — same non-mandatory framing as the G-shape bar.

## The five-step build order (the actual drill)

1. **Learn each position's plain single-note scale-form fingering first, up and down, both directions, before touching the 6ths.** Treat the shape as a map you can see on the fretboard, not a lookup table — "just see it as a map on your fretboard." Skipping this and jumping straight to the harmonized 6ths defeats the point.
2. **Harmonize that same position into 6ths** — work out the diagonal, string-crossing 6th-interval shape inside the position you just mapped, slowly and deliberately, using the specific fingering choices above (not whatever falls under the hand by default).
3. **Improvise independently within each position, one at a time,** over a chord progression/backing track in the key (worked in C major). Mix in single notes; deliberately **target a melody note, then land the 6th on/under it** — a "target first, then harmonize" habit, not random double-stop noodling. Fingering will drift from the strict version while improvising — that's expected, not a mistake.
4. **Once each position is solid on its own, connect/switch between positions.** Crossing strings *within* one position (step 2) is the harder skill; moving *along* strings *between* positions is comparatively easy once each shape is known well, because adjacent CAGED positions physically overlap — "it's not as hard as you think." Don't skip straight to this step before steps 1–3 are solid in each position individually.
5. **Alternate between strict and loose passes on an ongoing basis** — loosely improvise for a while, then go back to strictly running the scale-form fingering up and down; the strict pass is what actually improves and is revealed as needing more work by the loose pass, and vice versa. This isn't a one-time sequence — cycle back and forth as an ongoing practice habit.

**Homework (stated directly):** find a backing track in your own key and run this whole five-step process yourself, rather than only ever drilling it in C against this video.
