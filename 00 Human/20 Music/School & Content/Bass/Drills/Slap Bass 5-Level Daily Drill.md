# Slap Bass 5-Level Daily Drill

The vault's first bass drill — fills the gap flagged in [[Drill Index]] ("Bass — 0 drills"). One exercise, five progressive levels, meant to run 10 minutes a day, forum-tested by BassBuzz students from a real day-one struggle through two weeks of practice.

*(Tempo fields are a general starting point, not from the source — the video gives no BPM numbers, only "practice slow enough to be precise." 60→100 follows the same shape as the guitar tempo ladders in this folder; recalibrate against Nate's own actual starting tempo once he's run it.)*

## The five levels

1. **Slap fundamentals (no pops).** Accuracy (consistent thumb angle E→A), muting (cover unplayed strings with the fretting hand), note length (slap-mute pattern to cut notes off cleanly), rhythm (lock to the kick drum as a timing grid). Full mechanics: [[Slap Thumb Technique — Angle, Anchoring, and Muting]].
2. **Add pops — [[Teeter-Totter Slap-Pop Technique]].** One continuous down/up forearm cycle for slap + pop instead of two round trips. Test pattern: slap–mute–slap–slap–pop. Harder variant: pop finger moves G string → D string.
3. **Add ghost notes — [[Ghost Notes (Slap Bass)]].** Muted, unfretted slaps/pops for texture and as a rhythmic anchor (denser "click" for the ear to lock to). Marked `X` in tab.
4. **Add hammer-ons — [[Hammer-Ons and Pull-Offs (Bass)]].** Two-fret-below rule: pop/slap two frets under the target note, then hammer up to it (or one scale-degree below, if the scale is known). Watch for rushing — the fretting hand now controls rhythm for those notes.
5. **Make it melodic — [[Melodic Slap Lines — Avoiding Disco Octaves]].** Straight octave-jumping ("disco octaves") stops feeling like a melody once the mechanics are solid; fix is sprinkling in close-together, non-jumpy notes so the line reads as singable rather than purely percussive.

## How to run it

- **Don't skip ahead.** The source video is explicit: jumping to advanced-sounding riffs before levels 1–4 are solid produces sloppy slap, because the fundamentals (clean strike, clean mute) aren't there to support it yet.
- Levels 1–4 are the noob-to-intermediate gate; level 5 is the "make it actually music" level layered on top once the mechanics hold up at tempo.
- Each level adds exactly one new element to the same underlying exercise shape rather than being a separate drill — level 2's pattern is level 1's plus pops, level 3 adds ghosts on top of that, level 4 swaps in hammer-ons, level 5 is a phrasing lens applied to the same notes.
- Keep listening to the drums (kick especially) as the timing reference throughout — named once in level 1 but treated as a running requirement through every level.
- A free PDF with the exact fingerings for every level is named in the source video's description — not yet pulled into the vault; grab it from the video description if working from tab rather than by ear.
