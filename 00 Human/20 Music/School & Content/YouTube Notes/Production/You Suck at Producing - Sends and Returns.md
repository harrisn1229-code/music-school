## Synopsis
A basic-mechanics walkthrough of Ableton's send/return system, wrapped in the channel's usual joke framing (sends as "love," returns as "people" — a good one and a horrible one). Under the bit, it covers the actual UI: the R button to open the returns panel, the S button to reveal each track's per-return send knobs, deleting and inserting return tracks, and — the one genuinely useful piece of routing knowledge in the video — that a return track can itself send into *another* return track, but that behavior is off by default and has to be manually switched on per return via right-click → Enable Send. Short and basic, but that last point is a real, easy-to-miss Ableton routing capability worth knowing.

## Techniques
- **R and S are the two panel toggles that make sends/returns usable** — **R** (bottom-right of the screen) opens the Return Tracks panel where each return's own device chain and Dry/Wet live; **S** reveals, on every track, one small send knob per existing return (labeled A, B, C…) — turning a track's send knob up is how much of that track's signal reaches that return's effect. → [[Reverb]] (Ableton), [[Delay]] (Ableton)
- **Delete and Insert Return Track manage how many returns exist** — select a return and hit Delete to remove it entirely; right-click any return (or the return panel) → **Insert Return Track** adds a new empty one, ready for its own effect chain. Add as many as the song needs — one per distinct "space."
- **A return can send into another return, but it's off by default** — right-click a return track → **Enable Send** switches on that return's own send knob(s) to other returns, letting one return's processed signal feed into a second return's chain (e.g. a delay return feeding into a reverb return, so the echoes get sent through the same room as everything else) rather than every return only ever receiving from source tracks. → [[Reverb]] (Ableton), [[Delay]] (Ableton), [[Depth and Space]]
