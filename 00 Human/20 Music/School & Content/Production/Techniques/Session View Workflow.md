# Session View Workflow

Using Session View as a flexible drafting tool for arrangement, before committing to a fixed linear timeline in Arrangement View — and the Session-View-specific mechanics (per-clip automation, scene stop-behavior, recording a live performance into Arrangement) that make that drafting workflow actually work. Companion to [[Arrangement and Song Form]] (the structural decisions being drafted) and [[Live Performance Setup]] (performance-oriented Session View tricks like Follow Action).

## From videos

- **Sketch multiple melodic ideas per song section as color-coded Session View clips, delete the rejects as you go, and keep only the best one or two.** Workflow: jot several quick melodic sketches for a section, color-code every clip belonging to that section the same color, then move on to the next section/file once it's settled — "when I have a section of a song, I'll put everything, all the ideas on that section, in that color, and then move over to the next file." Rejected sketches normally get deleted immediately rather than allowed to accumulate; the survivors are whichever ones are genuinely liked on relisten. → [[Melody Writing]] — Alex Kapranos (Mix with the Masters), [[Writing songs using simple sounds with Alex Kapranos]]
- **Launch written parts live from a controller (Push, or an equivalent keyboard/pad controller from another vendor) rather than clicking clips with the mouse.** "I guess I'd quite often use Push to do this, I'm using this keyboard which does exactly the same sort of thing... same principle, you can launch the parts that you've written from that." Treated as interchangeable hardware for the same Session View clip-launch function — the controller doesn't have to be Push specifically, any grid/pad controller mapped the same way does the job. → [[Live Performance Setup]] — Alex Kapranos (Mix with the Masters), [[Writing songs using simple sounds with Alex Kapranos]]
- **Draft section order and length in Session View before committing to Arrangement View** — lay ideas out as clips in vertical rows (scenes) rather than horizontally on a fixed timeline; the scene-launch buttons let you freely test how sections flow into each other and reorder or resize them without the cost of restructuring a committed linear arrangement. Starting in Arrangement View directly makes this kind of exploratory reordering far more cumbersome. → [[Arrangement and Song Form]] — You Suck at Producing, [You Suck at Producing #48: Using Ableton's Session View](https://www.youtube.com/watch?v=1aIOxEcxT7I)
- **Build lead-in variations by duplicating a section and progressively stripping/adding elements** — duplicate a full section's scene (e.g. the main "Part A") to create an "Intro," then remove most elements down to a sparse core; duplicate again for an "Intro Plus" that reintroduces a few (not all) of the full section's elements, smoothing the jump between the sparse intro and the full section rather than cutting abruptly from one to the other. → [[Arrangement and Song Form]] — You Suck at Producing, [You Suck at Producing #48: Using Ableton's Session View](https://www.youtube.com/watch?v=1aIOxEcxT7I)
- **Per-clip automation via the clip's own Envelopes button, with an explicit reset before the next clip** — click the small **Envelopes** button (bottom-left of the clip view) to automate a device parameter (e.g. an Auto Filter's cutoff) tied specifically to that clip/scene, so the automation plays out fresh every time that scene triggers rather than living on the Arrangement timeline. The gotcha: the automated parameter snaps back to its default when a DIFFERENT clip is triggered next, so if a filter was automated open across a clip, add a point automating it back closed at the very end of that same clip — otherwise the transition into the next scene reads as an abrupt, unintended reset rather than a smooth handoff. → [[Automation]], [[Auto Filter]] — You Suck at Producing, [You Suck at Producing #48: Using Ableton's Session View](https://www.youtube.com/watch?v=1aIOxEcxT7I)
- **Remove a scene's automatic Stop-Clip slots so triggering it doesn't cut off clips already playing on other tracks** — by default, launching a scene fires an implicit "stop" on any track that scene doesn't have its own clip for, cutting off whatever was already playing there. To layer a new element INTO an ongoing scene rather than restarting everything, right-click that track's stop-clip slot in the new scene and remove it — the previously-triggered clips on other tracks then keep playing straight through when the new scene launches. → You Suck at Producing, [You Suck at Producing #48: Using Ableton's Session View](https://www.youtube.com/watch?v=1aIOxEcxT7I)
- **Record a live Session View performance directly into Arrangement View, then switch the transport's play-source toggle** — hit the global Record button and trigger scenes in the desired order in real time; Ableton captures that performance as a linear Arrangement-View timeline automatically, no manual copy-paste of clips required. The Arrangement content shows greyed-out immediately afterward because the transport is still set to play from Session View — click the orange play-source button (top-right corner) to switch playback to Arrangement View and hear/edit the captured result. Recommended overall workflow: draft loosely in Session View for section-order/length flexibility, THEN move to Arrangement View for the finer transitions, automation, and drop-outs that are easier to sculpt on a fixed timeline. → You Suck at Producing, [You Suck at Producing #48: Using Ableton's Session View](https://www.youtube.com/watch?v=1aIOxEcxT7I)
