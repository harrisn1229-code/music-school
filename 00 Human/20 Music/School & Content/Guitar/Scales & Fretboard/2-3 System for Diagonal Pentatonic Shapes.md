# 2-3 System for Diagonal Pentatonic Shapes

Part of [[Guitar Positions]]. **The named, fret-mapped version of the "diagonal pentatonic" shape this vault had already met twice without a canonical page for it** — [[Dorian from the Minor Pentatonic Box]]'s "Fingering 2" and [[Diagonal Pentatonic Blues Soloing]]'s "diagonal 3-2 major pentatonic" both use the same underlying two-notes-then-three-notes logic across adjacent strings, but neither gives the full six-string fret map or the string-crossing compensation rule. This page is that missing base layer: **the minor pentatonic scale built as a chain of "2-note sets" and "3-note sets" laid diagonally across the neck**, instead of the five stacked CAGE-style box positions. Seriff explicitly frames it as an alternative to those boxes for players who "couldn't really quite coax music out of" them — one repeating two-piece pattern instead of five separate shapes to memorize. Also sold as a paid course ("Diagonal Pentatonic Method," same branding as [[Diagonal Pentatonic Blues Soloing]]'s sponsor mention) — noted for context only, the free video's technique content is fully captured below.

## The core idea

Minor pentatonic has five scale degrees: **1 (root), ♭3, 4, 5, ♭7**. The 2-3 system splits them into two building blocks that alternate string by string:
- **The 2-note set: ♭7 → root**, a whole step apart on one string, root on the higher fret.
- **The 3-note set: ♭3 → 4 → 5**, three notes in a row, each a whole step apart, on the next (higher-pitched) string.

One 2-note set plus one 3-note set = all five pentatonic degrees, spread across exactly two adjacent strings. Chain more of these pairs up or down the neck (each subsequent pair one octave higher/lower) and the same two small shapes cover the entire fretboard — "you just need one pattern." Worked throughout in **D minor** (root D), but the whole system is movable to any key: find any root note anywhere on the neck, drop a 2-note set a whole step below it, add a 3-note set on the neighboring string, and the shape is built.

## The starting shape — D string + G string

1. **D string, 12th fret** = D, the root. Ring finger.
2. **D string, 10th fret** = C, the ♭7 ("the little bonus note"). Together, frets 10 & 12 on the D string = the first 2-note set.
3. **G string, frets 10, 12, 14** = F (♭3), G (4), A (5) — the 3-note set, one whole step between each note.

That's a complete D minor pentatonic scale (D C · F G A) across just two strings.

## The B-string compensation rule

Standard tuning is all perfect 4ths **except** G→B, which is a major 3rd — one semitone narrower. Every time the 2-3 pattern crosses onto or off the B string, **shift one fret toward the nut** to compensate, or the shape lands a fret off. Worked instance continuing the shape above:
- **B string, frets 13, 15** = C (♭7), D (root) — the next 2-note set, one octave up from the D string's. Without the -1-fret compensation this would fall at 14/16; the B string's narrower tuning interval pulls it back one fret.
- **High E string, frets 13, 15, 17** = F, G, A — the 3-note set, back to normal spacing (E→B and B→e straddle the compensation symmetrically, so the high E string itself needs no adjustment relative to the B string).

This is the one rule to internalize — every other string transition (E-A, A-D, D-G, e-B on its own) carries the exact same fret numbers up or down a string with no adjustment.

## Full ascending diagonal — three octaves, low E fret 8 to high E fret 17

Stacking the compensation rule onto the starting shape in both directions gives the complete map, worked in D minor:

| String | 2-note set (♭7, root) | 3-note set (♭3, 4, 5) |
|---|---|---|
| Low E | frets 8, 10 (C, D) | — |
| A | — | frets 8, 10, 12 (F, G, A) |
| D | frets 10, 12 (C, D) | — |
| G | — | frets 10, 12, 14 (F, G, A) |
| B *(compensated -1 fret)* | frets 13, 15 (C, D) | — |
| High E | — | frets 13, 15, 17 (F, G, A) |

Read top to bottom, low E to high E, this is one continuous diagonal line climbing in pitch and fret across all six strings — three octaves of D minor pentatonic from one repeating two-piece pattern.

## The mirrored lower-position shape — descending diagonal, fret 1 to fret 10

A second, independent diagonal region lower on the neck, rooted at **high E string, 10th fret (D)**, worked the same way but built downward (high strings to low strings) instead of upward:

| String | 2-note set (root, ♭7 — played high-to-low) | 3-note set (5, 4, ♭3 — played high-to-low) |
|---|---|---|
| High E | frets 10, 8 (D, C) | — |
| B | — | frets 10, 8, 6 (A, G, F) |
| G *(compensated -1 fret)* | frets 7, 5 (D, C) | — |
| D | — | frets 7, 5, 3 (A, G, F) |
| A | frets 5, 3 (D, C) | — |
| Low E | — | frets 5, 3, 1 (A, G, F) |

**The scale doesn't have to start or end on the root for the position to sound like the key** — this shape's lowest note is F (♭3), not D, and it still reads unambiguously as D minor because the backing track's harmonic context establishes the key, not which note you start or end a lick on. Between the two diagonals above (fret 1–10 and fret 8–17), the system covers nearly the entire usable neck in D minor with only two shapes and one compensation rule.

**Octave-up extension (lower confidence — captions garbled the fret list):** the same starting shape can be shifted a further octave up, beginning around the 22nd fret of the high E string on a 22-fret guitar and working back down. ## Why this beats hunting box-to-box

The five classic CAGE-style pentatonic boxes are vertical — each one a fixed fret-span shape you memorize separately and jump between. The 2-3 system is diagonal — one small repeating unit that **copy-pastes**: a lick played on the D string/G string pair transposes directly onto the B string/high E string pair an octave up with the same fingering (modulo the B-string compensation), so vocabulary learned in one spot is immediately available everywhere else the shape repeats. This is the same "copy-paste anywhere" property [[Dorian from the Minor Pentatonic Box]]'s Fingering 2 describes for its own diagonal shape (same key, D minor, same B string/high E string pair — that page's 3-note set frets, left unconfirmed there, are exactly the 13/15/17 mapped above) and the same diagonal logic [[Diagonal Pentatonic Blues Soloing]] applies to a *major* pentatonic over a blues progression.

## Drill sequence

1. **Build the two-string starting shape from memory.** D string frets 10/12 (2-note set, ♭7-root), then G string frets 10/12/14 (3-note set, ♭3-4-5). Say the note names out loud as you play them (C, D · F, G, A) — the goal is naming, not just shape memory.
2. **Isolate the B-string compensation.** Play the D-string/G-string unit, then the B-string/high-E unit back to back (frets 10/12→10/12/14, then 13/15→13/15/17), stopping to notice the -1-fret shift going into the B string. Do this slowly enough to catch yourself if you land on the "expected" 14/16 instead of the correct 13/15.
3. **Chain the full ascending diagonal**, low E fret 8 to high E fret 17, one continuous pass, alternating 2-note/3-note sets string by string per the table above. Use slides, hammer-ons, pull-offs and a bend on the 3-note set's middle note (his tip: "the middle note of the three note set is always just the perfect bend") rather than picking every note cleanly — this is meant to sound like music, not an exercise.
4. **Chain the mirrored lower-position diagonal**, high E fret 10 down to low E fret 1, same alternation, played descending.
5. **Copy-paste a lick.** Improvise one short phrase inside the D-string/G-string 2-note-and-3-note set, then play the identical fingering one octave up on the B-string/high-E pair (with the compensation) — confirm it's recognizably the same lick, just relocated.
6. **Anchor-and-improvise challenge (stated directly in the video):** pick any D anywhere on the neck — "there's at least one on every string and two on some" — and improvise from that root using only the 2-3 system, live over a D minor backing track. Don't pre-plan which diagonal region you'll land in; find it in real time from wherever the root happens to be.
7. **Transpose to a new key.** Once D minor is solid, pick a different root note and rebuild the same two starting shapes (2-note set a whole step below the new root; 3-note set ♭3-4-5 on the next string) from scratch, without re-deriving frets from D first — the payoff of a movable shape is that this should take seconds, not minutes.
