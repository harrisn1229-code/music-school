# Pinky-Finger Control Ladder (Chromatic Hammer/Pull-off Progression)

A 4-note A minor pattern (frets 5-7-8 on the low E string, 5-7 on the A string), moved chromatically across all six strings, layered up in three stages to fix pinky "flying" between string changes.

## The ladder

1. Picked, slow — focus purely on keeping the pinky close to the fretboard after each string change rather than letting it drift.
2. Add a hammer-on — only one picking stroke per string, the rest hammered.
3. Add a pull-off after the hammer-on — start in one position (E/A strings only) before moving across the neck; avoid a large pull-off motion that grazes neighboring strings.
4. Hardest variation — add one more hammer-on to fill the remaining 8th-note rest, producing a continuous gapless eighth-note stream.

Every note (picked or legato'd) should be equally audible and articulated — the target is that a listener can't tell which notes were picked.
