# 2000s R&B Piano Sample Chain

**Reference/vibe:** a from-scratch sample deliberately styled on the **2000s R&B era** — reference tracks named on-screen are Ne-Yo's "So Sick" and T-Pain/Chris Brown's "Best Love Song" — then flipped into a modern-day R&B trap beat aimed at a Tory Lanez/Bryson Tiller lane. Reverse-engineered from a loner (YouTube) breakdown, [how to make a 2000's r&b sample & flip it into a beat for tory lanez/bryson tiller](https://www.youtube.com/watch?v=sPqBmZLaDM4). Distinct from [[Tory Lanez Underwater Synth Chain]] (a minimal two-melodic-element build) and [[Kendrick Lamar Soul Sample Chain]] (heavily vintage/worn processing) — this chain's defining move is **restraint**: because the 2000s reference material "isn't too vintage," no tape/wear stage is added anywhere, keeping the piano and vocal comparatively clean while still reading as period-appropriate.

## Chain overview

Four melodic sources stack around a piano bed (piano, counter-melody, chopped string loop, second string layer for a vocal-free section), plus a full lead-and-harmony vocal — then the whole finished sample gets a 3-stage lo-fi push (EQ → reverb → stretch/tempo-drop) before a compact drum pattern (snap, rim shot, hi-hat roll, switch-up bass) turns it into a beat. The reusable core idea: **genre-appropriate restraint is itself a production decision** — skip the default aging/vintage stage when the reference material doesn't call for it — paired with a simple, repeatable "flip a finished sample" recipe (EQ → reverb → stretch) that works on the whole sample rather than per-layer.

## 1. Piano — Kontakt "Gentleman"

- **Instrument:** Kontakt's "Gentleman" patch — "super clean, super simple." → [[Kontakt 7]]
- **Chords:** built entirely from the **A minor scale (all white keys)** — "a great way to instantly get a more melodic sound" without hunting for voicings by ear. → [[Melody Writing]], [[Chord Progressions]]
- **Voicing detail:** top-line notes double as both the part's bounce AND its melody.
- **Chain:** [[Compressor]] ("tighten the sound up, make it super together") → **small room plate reverb** ([[Little Plate]]) → [[Pro-Q 4|Pro-Q 3]] (low-end cut + a **Make Dynamic** threshold-gated carve — "almost like compression").
- **Deliberately no tape/vintage stage** — "these types of songs often have really clean sounds... not too vintage." → [[Sampling and Sound Selection]]
- 🎬 *From video:* try a single diatonic scale (all-white-keys) as a shortcut to guaranteed-melodic chords before reaching for more complex voicings. → [[Melody Writing]]

## 2. Counter-melody — Analog Lab "softy lead"

- **Source:** Arturia Analog Lab, "softy lead" preset (Layers bank) — a super simple melody. → [[Plugin Wishlist]]
- **Chain:** EQ (low-end cut) → [[Cassette]] "Crushed" preset → a pretty light reverb.
- 🎬 *From video:* keep a counter-melody deliberately plain/simple so the crush stage does the character work, rather than writing a busy line. → [[Melody Writing]]

## 3. Strings — Splice loop + SRX Orchestra

- **Layer 1 (main strings):** no VST string sound "sounded really good," so a **Splice string loop** was chopped up and layered directly on top of the piano. → [[Splice Sounds]], [[Sampling and Sound Selection]]
- **Layer 2 (vocal-free section):** **SRX Orchestra** (unowned — see [[Plugin Wishlist]]), a simple counter-melody, used specifically to fill the space of a section with no vocals. → [[Arrangement and Song Form]]

## 4. Lead vocal + harmonies

1. **Pitch up an octave.** → [[Pitch and Formant]]
2. **[[Little AlterBoy]]** — no specific preset named.
3. **[[Pro-Q 4|Pro-Q 3]]** — cut highs AND lows.
4. **[[Decapitator]]** — reached for ONLY when the vocal isn't cutting through / lacks grit. Preset: **"mild tube vox."**
5. **Reverb** — unconfirmed "Intensity" reverb, **"vocal distance sci-fi"** preset, almost all the way wet (third confirmed sighting of this named tool — see [[Plugin Wishlist]]).
6. **A super light delay** (owned-lane [[Echo]]/[[Delay]]).
- **Harmonies:** underneath the lead, hit only at the end of each 4 bars, run "pretty much exactly the same" chain. → [[Vocal Stacks and Ad-libs]]
- 🎬 *From video:* a vocal saturation/grit stage doesn't have to be a default chain step — reach for it conditionally, only when the vocal audibly needs it. → [[Saturation and Distortion]]

## 5. The flip — sample-to-beat processing

1. **EQ** — a restrained band cut (some highs, some lows, "not go too crazy"), pushing the whole finished sample toward lo-fi/distant/airy.
2. **Reverb** — kept fairly short, low end cut from the return, Size reduced.
3. **Time-stretch + tempo drop** — stretch the sample and bring the tempo down to roughly **145 BPM**.
- 🎬 *From video:* EQ → reverb → stretch/tempo-drop, applied to the WHOLE finished sample (not per-layer), is a compact 3-stage recipe for distancing an already-complete sample before drums go under it. → [[Sampling and Sound Selection]]

## 6. Flip drums

- **Snap:** the starting element, trimmed to hit only twice.
- **Rim shot:** placed in between the two snap hits.
- **Hi-hat:** one small roll, "nothing crazy."
- **Second bass (switch-up layer):** a **short and stabby** bass, layered in purely so the pattern "switches up." → [[Bass Design]]
- 🎬 *From video:* build a flip's drum pattern starting from the snap/rim-shot pair rather than the kick — a lighter, sample-forward alternative to a kick-first drum build. → [[Genre Drum Patterns]]

## Arrangement

**Two moves here, both explicitly structural:**

- **The second string layer exists to fill a vocal-free section.** SRX Orchestra plays a simple counter-melody *only* where there's no vocal — the arrangement writes the part, not the other way round.
- **The second bass is a switch-up device.** A short, stabby bass layered in purely so the pattern changes. It has no tonal job.

| Section | What carries it |
|---|---|
| With vocal | piano · counter-melody · chopped strings · lead + harmonies |
| Vocal-free | piano · **SRX counter-melody** filling the gap |
| Switch-up | + the stabby second bass |

**The move — write parts for gaps.** Both additions above are answers to "what's missing in this section," which is the opposite of writing a part and then finding somewhere to put it.

**Drums start from the snap/rim pair, not the kick** — a lighter, sample-forward build order. → [[Genre Drum Patterns]]

## Variations

- **Any clean-era reference (2000s–2010s) where the usual tape/vintage default would read wrong** — the reusable lesson is checking the reference era BEFORE reaching for the aging stage, not skipping it universally.
- **The flip recipe (EQ → reverb → stretch/tempo-drop) generalizes to any finished sample**, independent of the specific piano/vocal/string sources used here.
