## Synopsis

A genuinely well-structured composition lesson on writing two melodies that complement rather than compete — framed as two "children" with distinct personalities. One melody ("Roger") is written rhythm-first: a single repeated note turned into an interesting groove, with pitch variation added only afterward. The other ("Harold") is written harmony-first: long, sustained notes concentrated on the strongest scale degrees (root, fifth), with weaker scale tones used only as brief passing connectors. Closes with a genuinely useful workflow trick: turning a chord progression into a melody via a Random-style Arpeggiator, then capturing that otherwise-uneditable generative output as real, editable MIDI. This is the third video (with the earlier hyperpop and remix videos) to cover multi-melody arranging, enough to warrant a dedicated **Melody Writing** technique note.

## Techniques

- **Rhythm-first melody: one repeated note, written for groove, pitch added after** — pick the scale's root, write an interesting rhythmic pattern using only that single note, and only once the groove itself works start shifting individual notes up/down the scale for melodic shape.
- **Harmony-first melody: long sustained notes on strong scale degrees, weak tones as stepping-stones** — concentrate duration on the root and the fifth (the strongest scale degrees), using briefer notes on weaker scale tones purely to connect one strong note to the next — a harmonically-anchored complement to a rhythm-first line played alongside it.
- **Random-style Arpeggiator to turn a chord progression into a melody, then capture the result as real editable MIDI** — an Arpeggiator set to Random picks a random note from each held chord per step for an unpredictable-but-usable melodic idea; since the arpeggiator's live output isn't directly saveable/editable, create a new MIDI track, set its MIDI From to the arpeggiator's output, arm and record it, then move that captured MIDI onto a normal track and turn the arpeggiator off — now free to edit like any other clip.
