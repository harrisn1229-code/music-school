# Right-Hand Pinky Fingerstyle Technique

Bringing the picking-hand **pinky (classical letter *c*, "chiquito")** into fingerstyle/classical guitar — a finger almost no player plucks with. Not a required technique: plenty of players get everything they need from **p-i-m** or **p-i-m-a**. The payoff is narrow but real — passages that want all five right-hand digits on one chord (a five-note stab, a full block chord) without strumming or skipping a string. Nine-exercise build sequence, each one grafting the pinky onto a picking-hand skill already built with the other four fingers.

Right-hand finger labels (classical/Spanish convention): **p** = thumb, **i** = index, **m** = middle, **a** = ring, **c** = pinky.

## 1–2. Calibration (foundation before any pinky-specific work)

- **All-finger calibration.** Rotate up/down the open strings one finger at a time: **plant** (rest the fingertip lightly on the string first) → **pluck** → move to the next string, repeat. The point is a consistent tone/volume/attack point per finger — not missed strings or flailing. Works with or without nails, any guitar.
- **a/c alternating calibration.** Same plant-then-pluck, alternating ring and pinky: **c-a-c-a-c**, then reversed **a-c-a-c**. Isolates the a↔c coordination specifically, before folding pinky into bigger patterns.

## 3. Pinky/ring warm-up (grafted onto an existing warm-up)

Take whatever left-hand finger-permutation warm-up you already run (1-2-3-4 chromatic patterns and their orderings) and pick the **entire thing** with only **c-a alternation** (pinky-ring-pinky-ring…) instead of your normal picking-hand fingers, for an extended stretch — this is how Jared built initial pinky comfort. No prescribed nail angle or shape for the pinky stroke; it's genuinely idiosyncratic per player. If the pinky's tone doesn't match the other fingers, experiment with picking angle and nail shape (see [[Guitar Nail Care]]), or play it nail-less, until it does.

## 4. p-i-m-a-c arpeggios across string groups

Run the standard classical right-hand arpeggio through all five fingers: **p-i-m-a-c** ascending on strings **6-5-4-3-2**. Rotate string groupings since 5 fingers ≠ 6 strings: **6-4-3-2-1** (thumb skips the a-string), then hop the thumb up for **5-4-3-2-1**. Cycle bottom-five-skip-a-string → top-five-skip-a-string. Turn it into a real étude by adding chord color underneath — **Em** on the first grouping, **B7** on the second. Then reverse: same groupings **descending**, and finally chain **ascending→descending** (up-down-up-down) through both groups with the chords under it.

## 5. Full-plant arpeggio version

Same p-i-m-a-c arpeggio, but **planting** technique added: after the thumb plucks, **plant all four fingers (i-m-a-c) at once** on their strings before playing them individually, going **up**. Coming back **down**, plant **sequentially** (one at a time, as in exercise 4). So: sequential-plant descending / full-plant ascending. Very hard, but "quite secure feeling" once it locks in. Add an **Am** chord underneath for the full version.

## 6. Five-note block chords

Pluck all **five strings simultaneously** (p-i-m-a-c together) — any five-string combination, aiming for every string ringing at equal volume. Apply the same bottom-five/top-five-skip-a-string groupings from exercise 4. Directly useful for arrangement/comping chord stabs and jazz voicings — anywhere you want a full block-chord hit rather than a roll.

## 7. Tremolo with the pinky (six variations)

Tremolo = rapid repeated plucking on one string to mimic a sustained note; called "one of the best plucking-hand conditioning drills, period" — worth doing even if you never use tremolo musically. All variations built around a repeating thumb pluck on a bass string:

- Reference: standard tremolo is **p-a-m-i** (thumb, then ring-middle-index).
- **Pinky swap-in: p-c-a-m** (thumb, then pinky-ring-middle).
- Same pattern **slow and even** — don't chase speed — while letting the top note ring; optionally arpeggiate a chord underneath, walk the thumb through other bass notes, or play a moving bass-line melody (e.g. an A minor scale on the 3rd string) under the held tremolo note.
- **4-finger tremolo, no thumb** — just i-m-a-c repeated, slow.
- **4-note tremolo with thumb+pinky struck together** on the same beat, then the tremolo continues.
- **5-note tremolo** (flamenco-style, not normally pinky-driven): **1-2-3-4-5** repeated across all five fingers.

## 8. Thumb + pinky alternating single notes

Where players commonly alternate thumb+index or thumb+middle for single-note lines, alternate **thumb-pinky-thumb-pinky…** instead. Apply to a scale or blues-scale improvisation, with the hard constraint that only thumb and pinky ever touch a note — no other finger sneaks in.

## 9. Thumb pedal-tone + four-finger chord-shape improvisation

Not a drilled exercise — free play, and flagged as the **most musically useful of the nine**. Thumb holds a repeating open bass note (low **E** or **A** string) while **i-m-a-c together** voice a chord/inversion on the top four strings. Concretely: play the open **Em7** shape (low E + open top four strings), then walk its **inversions** up the neck with the four fingers while the thumb keeps pulsing the open E, adding melody on top for a chord-melody feel. Repeat on **A7** (open A string + top-four-string inversions). Keeping the thumb pedal going continuously while the fingers move freely on top is the version worth practicing toward.

## Suggested drill order for a session

Ex. 1–2 (calibration) → ex. 3 folded into your existing daily warm-up → ex. 4–6 (arpeggio/plant/block-chord family, same session) → ex. 7 (tremolo) as a separate conditioning block → ex. 8–9 as the "make it musical" pair once 4–7 feel stable.

## Where it pays off

In Jared's own "Georgia on My Mind" solo-guitar arrangement, several early passages need all five right-hand fingers on one chord (an open **Em7** stab, an **A7** stab, a **G13** voicing) — without the pinky he'd have had to strum or drop a note. It's explicitly optional per-arrangement: skip/strum those spots without the pinky, or use it once these drills are solid.
