# Hub-Latching Approach

A memorization/comping-practice method for internalizing every inversion of a single chord voicing — Jared Borkowski's (Sound Guitar Lessons With Jared) named strategy from his "Jazz Comping Mastery" course. It answers the same underlying problem [[Chord Voicings]] and [[Guide Tones]] already frame theoretically (many possible voicings per chord, guide tones defining which notes matter) with a concrete drill order for getting them under the fingers on one physical position of the neck.

## The core idea

Pick one **familiar root-position voicing** and treat it as the **"hub"** — the home base every other voicing is measured against and returned to. Instead of practicing inversions by walking a single scale tone up the neck (staying anchored to a moving root), the hub-latching approach works **all the inversions of one chord in roughly one hand position**, jumping out to a voicing rooted on a different chord tone and back to the hub, over and over — closer to how comping actually happens in real playing than a straight-line inversion drill is.

## Building the "path"

1. **Lay out the chord tones as a path**, using a dominant 7 (1-3-5-♭7) as the working example: root → 3rd → 5th → back down to 3rd → root → ♭7 → 5th (an arpeggio shape, not a fixed order — any traversal of the chord tones works).
2. **For each stop on the path, play the voicing whose lowest note is that chord tone** — i.e. an inversion "off the 3rd" means the physical voicing has the 3rd on the bottom, mentally renumbered against the *root* you're still tracking (same renumbering logic already documented for chord-melody work on [[Chord Melody Arranging]]).
3. **Drill it worked, then drill it random.** First run the path in the fixed order above to learn where each inversion physically sits; once memorized, jump to *any* inversion and back to the hub, not in sequence — this random-access stage is what makes the voicings usable in actual comping rather than only as a memorized scale-like run.
4. Repeat the entire path on a **second string-set root** (worked in the video off both the 5th-string-rooted and 6th-string-rooted forms of D7) to get the same chord's vocabulary in a second neck position.
5. **Manual-derivation trick**, if you'd rather work out a missing inversion than memorize it as a fixed shape: move a chord tone down to the *closest* other chord tone on the same string — root down to the nearest tone lands on the ♭7; the 5th down to the nearest tone on its string lands on the 3rd. Repeating this note-by-note produces the next inversion down without needing the shape pre-memorized.

Applies identically to **any seventh-chord quality** (maj7, m7, m7♭5, dim7) — the video works it only on a dominant 7, but the drill structure is chord-quality-agnostic.

## Why keep returning to the hub

- **The root-position hub is the anchor that keeps the "bottom end" from disappearing.** Rootless/upper-structure inversions sound great in isolation but, played back-to-back with no rooted return, can leave the harmony feeling ungrounded — especially in a **solo-guitar context with no bass player**. Returning to the hub frequently, and treating the excursions as short "punches"/statements you venture out to and back from, keeps a stretch of pure inversions from losing the chord's identity.
- **When a bass player is present, this constraint relaxes** — you can live in rootless/upper voicings much more freely since the root is already covered elsewhere in the band.

## Doubling the vocabulary: root → 9 substitution

Once the plain 1-3-5-♭7 path is learned, **take every voicing in the path and replace its root with the 9** (the note a whole step up from the root) to generate a second, more colorful set of shapes without learning new fingerings from scratch — same "shift one known note a whole step" logic already documented on [[Extended Chords]] for building 9ths/13ths from a 7th-chord shape, just applied across an entire hub-latched path at once rather than to a single voicing. Run the same hub-latching drill against the new 9-substituted set. On a single dominant-7 chord across two string-set roots, this produces roughly **22 distinct voicings** from one starting shape — most of them still comping-appropriate (not chord-melody-dense), several read as a related-but-different chord color (e.g. the 9-on-bottom voicings, or a 9-substituted shape that visually resembles a half-diminished shape while still functioning as the dominant).

## Practice progression

1. Learn the plain path (root/3rd/5th/♭7 inversions) in order, on one string-set root.
2. Repeat on the second string-set root.
3. Once memorized, drop the fixed order — jump freely between the hub and any inversion, spending more time on the hub than any single excursion.
4. Loop a **static one-chord backing track or vamp** and comp freely across the full voicing set (plain + 9-substituted), using the hub as a resting point between more colorful excursions.
5. Scale the whole drill up to **every chord type across a real progression**, tracking the closest-voicing connection chord to chord as the long-term goal (the same "move the least" voice-leading principle already on [[Chord Voicings]]) — the video frames this session as one chord in isolation, deliberately, so the drill itself doesn't get lost in a full tune too early.
