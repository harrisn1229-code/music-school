# The Bingo Method — Number-Pattern Riff Generation

BassBuzz's last-step answer to "I know the scale shape, I've stolen a few melodies, now what?" — a named method for pulling **original** basslines and solo ideas out of a scale shape rather than only copying existing melodies (the companion move to [[Steal Like a Bassist — Ear-Training from Known Melodies]]). The claim: this same underlying trick — **making simple number patterns from scale notes** — is embedded in music "from Bach to Bob Marley to Beach Boys," and Jaco Pastorius is cited playing a version of it too. It's a generative/compositional tool, not a listening or ear-training one.

## The core trick

A scale shape is normally learned and drilled **in order** — 1, 2, 3, 4, 5, 6, 7, 8 — which is great for practicing the shape but "not so great for making music." The Bingo method breaks that order deliberately:

1. **Invent a short number pattern** using scale degrees instead of playing straight through — worked example: **1-2-3-1** (first, second, third, back to first note of the scale). On its own this is a short, unremarkable idea.
2. **Transpose the same pattern up the scale by adding 1 to every number, once per repeat.** 1-2-3-1 becomes 2-3-4-2, then 3-4-5-3, and so on — each repeat is the identical shape of pattern, just walked one scale degree higher than the last. Chaining these transposed repeats together turns one small idea into a longer line that sounds deliberately composed rather than like scale practice.
3. **The pattern itself can be arbitrary — even randomly generated.** Demonstrated live in the source video with an improvised pattern, run through the same "add 1 per repeat" transposition and played with varied rhythm — "you can literally play bingo with a random number generator and come up with some patterns." The name comes from this arbitrariness: any short number sequence is fair game as a seed.

## Use 1 — a technique/speed workout

Because the pattern still uses the same scale shape and roughly the same fingering skeleton as playing the scale in order, but forces different **string-crossing and plucking-hand patterns**, it functions as a genuinely different technical workout from straight scale practice — not just a musicality exercise. *(General starting point)* pick one pattern for the week, set a metronome goal, and drill it 5–10 minutes a day for a dedicated speed/coordination gain, rather than switching patterns every session.

## Use 2 — connecting chords in a real bassline

The method's more "real-world" payoff, independent of the speed-workout use: **linking two chords together** — cited as most of what a bass player actually does in a song — with a pattern instead of a plain scale walk. Worked example: in the key of B major, linking the **I chord (B)** to the **IV chord (E)** — a plain 1-2-3-4-1 walk-up into the next chord is functional but "boring"; using a **descending 8-7-6-5** pattern to flow from the first chord into the fourth chord instead produces a noticeably more interesting connective line, using exactly the same B major scale shape, just a different note-order through it.
