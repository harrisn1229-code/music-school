# Ghz Panpot 3

![[Images/Ghz Panpot 3.png]]

**Category:** Pan/Imaging
**Vendor:** Goodhertz

## What it is

Goodhertz\'s panning tool, built around the idea that panning can be achieved four different ways — **level, delay, spectral and phase** — each with its own realism and mono-compatibility trade-off. You set the position once, then choose how much of each method produces it.

## What it's used for

Precise, law-accurate panning decisions when the stock Ableton panner's behavior isn't sufficient.

## FX chain notes

Placed wherever stereo placement decisions are made in a channel's chain.

| # | Parameter | What it is / does | Technique |
|---|---|---|---|
| ① | Pan | Master pan position, L to R. | Everything below decides *how* this pan is achieved — the position itself is just this one slider. | — |
| ② | Level | How much of the pan is done by **level difference** between channels — the classic pan-pot method. | Leave this dominant for a normal, mono-safe pan. It's the only method that survives a mono fold-down cleanly. | — |
| ③ | Delay | How much is done by **inter-channel delay** (the Haas/precedence effect). | Adds width and realism, but it's the one that collapses in mono — check before committing. See [[Stereo Field]]. | — |
| ④ | Spectral | How much is done by **spectral/tonal difference** between the channels. | Mimics how a real source sounds different at each ear. Subtle, and it survives mono better than delay does. | — |
| ⑤ | Phase | How much is done by **phase difference**. | The most fragile of the four in mono — use sparingly and always mono-check. | — |
