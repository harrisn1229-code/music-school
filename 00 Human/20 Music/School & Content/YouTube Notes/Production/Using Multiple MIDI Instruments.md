## Synopsis

A practical Ableton workflow lesson on playing/splitting multiple instruments at once: turning off Arm Exclusive to arm several tracks simultaneously, a naive (and flawed) approach to a keyboard split using the Pitch MIDI effect's range limiting on two separate tracks, and the actual clean solution — combining both instruments into one Instrument Rack and using its Key Zone editor to assign each chain's playable range without any dead-zone gap.

## Techniques

- **Turn off Arm Exclusive to play multiple instruments/tracks at once** — right-click a track's Arm button and deselect Arm Exclusive so several tracks can be armed simultaneously, rather than Ableton's one-track-at-a-time default.
- **Why two separate Pitch MIDI-effect range limiters is the WRONG way to split a keyboard** — restricting each of two separate tracks' playable range with the stock Pitch effect works until the two ranges aren't perfect complements, at which point a dead zone appears where BOTH devices block the same overlapping notes and neither instrument sounds.
- **The correct fix: one Instrument Rack, two chains, and the rack's own Key Zone editor** — drag one instrument into the same Instrument Rack as the other via the chain list, then use the rack's **Key** zone tab to assign each chain's playable range directly in one unified editor — no configuration mismatch possible, clean split every time.
- **Route separate physical controllers to separate tracks when you have more than one** — set each track's MIDI input to a specific hardware controller instead of "All Ins," so multiple controllers each drive their own instrument automatically without needing any key-split workaround.
