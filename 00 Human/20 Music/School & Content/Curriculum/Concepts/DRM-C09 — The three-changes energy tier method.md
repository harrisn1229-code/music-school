# DRM-C09 — The three-changes energy tier method

**Q.** How do you build Intro / A / B / Outro drum clips, and what counts as a change?

> [!question]- Answer
> Write the **sparsest** Intro clip that still works, duplicate it for A, and make exactly **three changes**, each of which is either an existing element made *more active* or a *new* element added — every change immediately obvious and present throughout the whole loop. Then three more for B. A **swap** counts too (jingle bell → ride, toms transposed up into a new voice). Past a point, thin out rather than stack: delete the closed hats sitting under a new open hat. Crashes at the start and tom fills at the end are transitional and **don't count** as one of the three.

## Why it matters

It's the concrete cure for loop-itis at the clip level: start a song with four energy-tiered clips already built and you have four jumping-off points instead of one basket to overfill.

## Drill

Build Intro → A → B → Outro from one pattern using exactly three changes per tier. Write down what the three were each time.
