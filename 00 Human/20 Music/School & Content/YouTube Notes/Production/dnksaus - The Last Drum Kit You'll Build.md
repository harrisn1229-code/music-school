# dnksaus - The Last Drum Kit You'll Build

![](https://www.youtube.com/watch?v=VfOPVl0tzCE)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=VfOPVl0tzCE)

## Synopsis

A full masterclass in building a "**Sketch Kit**" — a [[Drum Rack]] where every pad is a [[Sampler]]-based mini-rack loaded with many samples of one drum type, wired so a single Randomize press (or a mapped Push wheel) both picks a new sample combination across the kit *and* reshapes each chosen sample via macro-mapped ADSR/transient/pitch/start-point controls — meaning a kit built from even a modest personal sample stash can generate a huge number of usable, characterful variations, at low CPU cost, without ever leaving the project to hunt more samples. dnksaus walks through building selector-based snare, kick, and 808/stab racks (Sampler Zone → Selector mode, chain-select bar mapped to Macro 1) and a key-based hi-hat rack (Zone → Key mode, using pitch itself as the "which hat" selector instead of a chain bar), then layers on: Sampler's ADSR-as-transient-shaper (Trigger mode + Initial/Sustain/Decay), Global Time as a one-knob transient control (deliberately excluded from randomization), Transpose ranges per drum type, a workaround for Sampler's missing sample-start macro (MPE Slide → Sample Offset via the stock MPE Control device), pitch-envelope punch on kicks/808s, Sampler's Shaper section and FM section for generating new textures from existing samples, Drum Bus's Transient/Damp knobs, a chord-device-based "multi-textural" hi-hat/stab flare, a scale-aware chord-locked 808/bass technique via the creator's own in-beta "Chord Sauce" device, and a built-in sidechain-routing section inside the rack itself (kick/snare chains feeding a shared, high-passed sidechain-trigger chain that keys a compressor on the 808/stab chains) — closing with a Drum Bus glue stage as the alternative to sidechaining.

## Techniques

- **The Sketch Kit concept** — build a [[Drum Rack]] up front from your own favorite, proven samples (sample selection is still the foundation — "sample selection is key"), wired so pressing Randomize both (a) picks a new sample per pad via each pad's own chain-selector macro and (b) reshapes the chosen sample via macro-mapped ADSR/transient/pitch/start-point controls at the same time — turning a handful of go-to samples into a huge combinatorial space of usable variations, loadable at the very start of any project so you're never blocked on curating sounds before an idea gets down. Push-compatible: the hardware's randomize wheel works the same way, with Auto Select keeping the currently-selected pad's inner rack in view. → [[Drum Rack]], [[Randomized Rack Design]]
- **Sampler's Zone section — three sample-selection modes** — dragging a sample into a Drum Rack pad loads Simpler by default; switch to **Sampler** to access the Zone section's selection modes: **Key** (incoming MIDI note picks the sample — irrelevant for choosing *between* samples on one drum-rack pad, since the pad always receives the same note, but see the hi-hat use below), **Velocity** (hit strength picks the sample), and **Selector** (a draggable blue bar picks the sample, independent of note or velocity — the one used for snare/kick/808/stab racks here). **Round Robin** is a fourth zone-triggering mode (sequential/random cycling with resettable count) mentioned but not used in this build. → [[Sampler]]
- **Building a Selector-mode sample rack (snares → kicks → 808s/stabs, same recipe)** — drag in many samples of one drum type (100+ is fine), Command-A select all in the Zone editor, right-click **Distribute Ranges Equally**, delete any samples pushed past the useable range, Command-G to group into an Instrument Rack, then map the Selector's blue bar to **Macro 1** (named e.g. "snare select") — this one macro is now the entire basis for choosing which sample plays. Turn on the **RAM** button afterward to reduce CPU load in a heavy project. → [[Sampler]], [[Drum Rack]]
- **ADSR as a transient shaper** — set the sample's Loop dropdown to **Trigger** mode so a hit always plays the entire sample regardless of note length. For a snare/kick's transient, don't use Attack to fade in — instead turn up **Initial**, which creates a plateau at the top of the attack; **Sustain** then acts as transient emphasis, and enabling **Decay** starts shaping the tail into a more percussive shape. Map Initial (limit ~0–100/200 ms), Decay (limit ~50 ms–2 s), and Sustain to macros so a single sample can be reshaped from tight/clicky to long/boomy. → [[Kick Design]]
- **Global Time as a one-knob transient control — and why to exclude it from randomization** — Sampler's Global Time knob scales Attack/Decay/Release together, giving one-knob control over a sample's overall transient character (Sustain still needs separate control). When wiring a rack for randomization, macros can individually be **excluded from the randomize action** — Global Time is a good candidate to exclude, since it's a broad, deliberate creative choice you'd rather set yourself than leave to chance, unlike the per-sample micro-variation macros. → [[Randomized Rack Design]]
- **Transpose as a sample-refresh macro, with per-drum-type ranges** — mapping Transpose to a macro dramatically refreshes a single sample into many different-feeling hits. Recommended starting ranges from the video: snares **-12 to +24** (lots of headroom), kicks **-5 to +7** (too much either direction stops sounding like a kick). → [[Kick Design]]
- **A makeshift sample-start macro via MPE Slide → Sample Offset** — Sampler has no native macro-mappable start-point control. The common workaround (Velocity in Fixed mode → Sample Offset) conflicts with drums that already use velocity for dynamics; instead, route **Slide** pressure (an MPE expression axis) to Sample Offset: add the stock **MPE Control** Max device, group it into its own rack, and on its Slide section map both the minimum and maximum to a single macro (save this as a reusable utility). Moving that macro scrubs the sample's start point. The **Snap** toggle (on by default) minimizes clicks/pops at the new start point — usually fine to leave on for snares, but worth an exposed on/off option for kicks where pops are more audible. Also map **Sample Start** itself directly, restricting its range on samples with silent tails so the macro only sweeps useful territory. → [[MPE Control]], (new) [[Drum Bus]]
- **Pitch-envelope punch on kicks/808s** — Sampler's pitch envelope (Amount + Peak, mapped to a macro, plus Decay) adds extra transient "knock" to a kick or 808 — moderate values (Amount ~48, Peak limited to a narrow range like 0–33 rather than the full 0–100, which read as too extreme) give a subtle additional punch on top of the sample's own transient. → [[Kick Design]]
- **Sampler's Shaper section (4 modes) and FM section for texture** — the Shaper section's 4 waveshaping modes reshape a sample's harmonic character (Soft judged the best starting mode for kicks); the **FM section** can generate genuinely new-sounding textures out of an existing sample rather than just distorting it — an underrated way to squeeze more variety out of the same source material without hunting new samples. Map Shaper Drive to a macro for a "how aggressive" dial across the whole kit-piece. → [[Sampler]]
- **Drum Bus's Transient and Damp knobs, macro-mapped** — Drum Bus's **Transient** knob emphasizes the initial hit when pushed up (can get harsh) or shortens the decay when pulled down, which is specifically useful *after* a reverb send since it also transient-shapes the reverb tail, not just the dry hit; a sensible mapped range is roughly -50/-60 to 0 depending how snappy the drum should read. **Damp** rolls off top end — useful after Transpose has pushed a small sample brighter than wanted (e.g. limiting the mapped range to ~2–12 kHz). → (new) [[Drum Bus]]
- **A macro-controlled on/off "kill switch" for a whole rack** — set a macro's minimum to **1** and maximum to **0** (inverted) so that at the macro's default/zero position the *entire linked rack* (e.g. a "Beef-later" glue/saturation rack) is off, and moving the macro up gradually brings it in — a quick way to A/B or performance-fade a whole processing stage from one knob.
- **Key-based hi-hat selection instead of a chain-selector bar** — for hats, use Sampler's Zone **Key** mode (not Selector): distribute ranges equally so each MIDI key maps to a different hi-hat sample, then map **Pitch** itself (not a separate blue-bar macro) to a macro — since pitch effectively walks across the mapped keys, this turns pitch into the "which hi-hat" selector while simultaneously retuning the chosen sample. A genuinely different selection mechanism from the Selector-bar approach used on snares/kicks/808s. → [[Sampler]]
- **"Multi-textural" hi-hat/stab via a Chord-device chain selector** — build a rack containing every [[Chord Generator]] preset, chosen through a chain selector (a "chord selector"), with a Strum pattern (limit Strum range to roughly ±50) and Tension/Crescendo also macro-mappable — strumming an otherwise-plain hi-hat or stab through this gives it an expressive multi-note "flare." Also handy repurposed as a "snare enhancer" chain (same chain-selector-of-chord-presets technique, applied to a different drum role). → [[Chord Generator]]
- **Scale-aware chord-locked 808s and stabs** — the creator's own in-beta "Chord Sauce" device has a solo-bass section; mapping its Pitch parameter to a macro (ranged 0–11, one per scale degree) lets an 808 (or a duplicated chain built into a chord stab, with the drum-bus/beef-later/shaper-drive stripped off) always land on an in-key note/chord regardless of what's played — a scale-aware alternative to manually re-tuning 808 hits per section. → [[Plugin Wishlist]] (Chord Sauce, unowned/beta)
- **A saved-search "voice" shortlist for random ear-candy fills** — save a Samples-tab search (One Shot + Voice, filtered further by solo/synth/vocal/speech) as a reusable sidebar shortcut labeled "voice," then drag a batch into a selector rack for random ad-lib-style vocal texture fills — extends the same Selector-rack recipe to a completely different sound category (foley/vocal one-shots), not just drums.
- **Built-in sidechain routing inside the rack itself** — rather than routing sidechain sources externally, have the kick/snare/clap/rim chains' audio output feed a shared internal **"sidechain trigger"** chain (muted/inaudible on its own), then set the 808/stab/bass chains' compressor sidechain source to that trigger chain, **high-passed** so only the transient content keys the duck — a self-contained sidechain setup that travels with the rack as a single exportable unit, no external routing required in the wider session. → [[Sidechaining]]
- **Drum Bus as the non-sidechain glue alternative** — when a rack-wide sidechain isn't wanted, route everything to a shared Drum Bus (saturator-style glue) instead, optionally adding a "bass shaper" stage or the creator's own Multi-Shaper device (mapped across the chord/foley chains at a very slow rate) for overall flavor. → (new) [[Drum Bus]]
