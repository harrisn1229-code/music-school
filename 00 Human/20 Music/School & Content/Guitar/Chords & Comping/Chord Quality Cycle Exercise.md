# Chord Quality Cycle Exercise

A single-root drill for internalizing how 7th-chord qualities relate to and transform into each other, and for training the ear to hear exactly which chord tone changes between neighboring qualities — distinct from practicing chords in the context of a key (see [[Chords by Key]] for that complementary approach).

## The cycle

Six chord qualities, each one half-step-moving note away from its neighbor:

**Major triad → Major 7 → Dominant 7 → Minor 7 → Half-diminished (m7♭5) → Fully diminished 7** — then reversed back down through the same sequence.

Each step moves exactly one note by exactly one half step:
- Triad → maj7: root moves down a half step (to the major 7th)
- maj7 → dom7: that same note moves down another half step (to the ♭7)
- dom7 → m7: the 3rd moves down a half step (major 3rd → minor 3rd)
- m7 → half-diminished: the 5th moves down a half step (natural 5 → ♭5)
- half-diminished → dim7: the (already-flat) 7th moves down one more half step (♭7 → 𝄫7)

## How to practice it

1. **Pick a root and a template shape** — a major triad voicing rooted on the 6th, 5th, or 4th string (see [[Chord Voicings]] for the underlying shapes).
2. **Walk the cycle up**, moving one note at a time between each chord quality, keeping every other note fixed.
3. **Walk it back down** through the same sequence in reverse — deliberately harder, since the "which note moves" logic isn't as automatic in reverse.
4. **Repeat off all three string-root templates** (6th, 5th, 4th string) for the same root.
5. **Repeat off every root, moved through the circle of fourths** (C → F → B♭ → E♭ → A♭ → D♭ → G♭ → B → E → A → D → G) — full 12-key coverage.

Skip a shape entirely rather than forcing an uncomfortable stretch (especially relevant high on the neck or on instruments with less upper-fret reach) — there are three templates specifically so a cramped shape in one position can be dropped without losing key coverage.

## Why it works

Practicing chords that exist together diatonically within a key (the complementary drill) doesn't put chord qualities directly next to each other for comparison — you don't have to locate *which specific chord tone* differs between two chords. Cycling through qualities off a single shared root forces exactly that: "minor 7 has to have a flat 3rd — where is that on this shape?" It's an ear-training and fretboard-relationship drill, not a harmony-in-context drill, and works best as a targeted tool for those specific goals rather than a daily-practice default.

## In real music

Full six-chord runs like this rarely appear back-to-back in actual songs, but fragments do:
- **"Something" (The Beatles, George Harrison)** opens with exactly the cycle's first three chords off one root — major triad → major 7 → dominant 7.
- **A minor ii-V-i** is essentially a half-diminished → fully-diminished → tonic-minor fragment of the same cycle.
