## Synopsis

A tremolo-vs-vibrato clarifier: tremolo modulates volume, vibrato modulates pitch — easy to confuse because both are rhythmic/cyclical modulation effects, but the parameter being modulated is different. Covers practical setup for each (tremolo synced to tempo, vibrato via an LFO on a pitch knob), a lo-fi-adjacent "slow drift" vibrato use case, a mention of a dedicated panning-modulation plugin (Panomatic) for a related pan-cycling effect, and a closing tip to experiment with different LFO/automation shapes rather than only the default sine.

## Techniques

- **Tremolo = volume modulation, vibrato = pitch modulation** — the core distinction; tremolo gives rapid, rhythmic volume changes (syncable to tempo via a gross-beat-style tool or free alternatives, or by hand-automating volume), vibrato gives pitch changes via an LFO on a pitch knob — gentler vibrato settings read as more emotional, more exaggerated settings read as intentionally "wonky." → [[Modulation]]
- **Slow vibrato/pitch-drift as a lo-fi character effect** — a slow, subtle vibrato applied as constant pitch drift (rather than a fast, obvious wobble) is the mechanism behind the "slightly out of tune" character common in lo-fi production; exaggerating the same setting makes the effect obvious for demonstration.
- **A dedicated panning-modulation plugin (Panomatic) gets a related cyclical pan effect** — grouped with tremolo/vibrato as the third axis (pan) of the same "modulate a parameter cyclically" family.
- **Try non-default automation/LFO shapes** — experimenting with different curve shapes on any of these modulation automations (not just a plain sine) was the closing tip, without a specific worked example.
