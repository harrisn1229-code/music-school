# SZA R&B Guitar Chain

**Reference/vibe:** a nostalgic, ambient R&B guitar sound built from **two layers of the same guitar part** — a dry, tightly processed signal chain, plus a second reamped pass through a hardware pedal that detunes/delays the signal out of time, layered on top as a wash. Recreated (not a confirmed session breakdown) by loner from *Blind*, on SZA's *SOS* — [the secrets behind sza's 'sos' production!?](https://www.youtube.com/watch?v=qbkFwpExtVQ).
**Signal source:** a clean electric guitar, arpeggiated chord progression, for a nostalgic feel. Works over [[1 Electric Guitar DI Track|Electric Guitar DI Track]].

## Chain overview

Layer 1 (dry) sets the main tone: EQ → compressor → spring reverb → short slap delay → flanger → shaper box. Layer 2 (texture) re-runs the *same performance* through a Montreal Assembly Count to 5 hardware pedal (set to detune/delay the signal out of time), then shaper box → EQ → reverb → pan, and sits underneath/behind Layer 1 as an ambient wash rather than replacing it. The two layers are meant to be heard together — Layer 1 carries the part, Layer 2 blurs it.

## Step 1 — Layer 1: dry signal chain

Clean guitar, arpeggiated, tracked simply — no drive/distortion at the source, since the color comes from the FX chain, not the amp.

1. **[[EQ Eight]]** — general tonal shaping. *(general starting point — no specific curve given; start subtractive, cut mud below ~200 Hz, gentle presence lift ~2–4 kHz)*
2. **[[Compressor]]** — light-to-moderate leveling ahead of the space effects, so the reverb/delay tails that follow have a consistent input to work with.
3. **Spring reverb** — a short, "boingy," lo-fi-leaning reverb character (as opposed to a hall/plate) for the nostalgic feel. No dedicated spring-reverb plugin owned; closest owned options: [[ValhallaVintageVerb]] (has a spring-modeled algorithm) or [[UAD RealVerb-Pro]]. → [[Reverb]] (effect)
4. **Short slap delay** — a tight, single-repeat-feeling slap delay (short time, low feedback) rather than a rhythmic multi-tap delay. → [[Echo]], [[Delay]] (effect)
5. **Flanger** — [[Phaser-Flanger]] or [[kHs Flanger]] for movement/width after the delay.
6. **Shaper box** — a rhythmic/transient/volume-shaping stage as the final coloring device on the dry layer. No ShaperBox (Cableguys) owned — see [[Plugin Wishlist]] (medium-impact item, already reused across multiple videos).

**Why:** each stage in Layer 1 is doing one job — EQ shapes tone, compressor levels dynamics, reverb + delay set space, flanger + shaper add movement/texture right at the end — a fairly standard "clean guitar → space → movement" build, but kept restrained so it reads as the main, in-focus part.

## Step 2 — Layer 2: reamped ambient texture layer

Re-run the *exact same guitar performance* (not a new take) through a second processing path:

1. **Montreal Assembly Count to 5** (hardware pedal) — set to delay/detune the signal so it reads as slightly out of time with the original. No hardware equivalent owned/tracked; substitute a modulated pitch/delay device (e.g. [[Shifter]] or [[Pitch Loop 89]] detuned + a short delay) to approximate the "out of time" character. → [[Plugin Wishlist]]
2. **Shaper box** — same role as Layer 1's shaper stage, on the reamped signal.
3. **EQ** — carve this layer so it sits behind/around Layer 1 rather than competing with it (e.g. scoop the frequencies Layer 1 already owns). → [[EQ Eight]]
4. **Reverb** — a second, likely larger/washier reverb than Layer 1's spring, to push this pass further back in the mix. → [[Reverb]] (effect)
5. **[[PanMan]]** — pan the finished ambient layer, last in the chain, to place the wash in the stereo field (spread wide or offset from center, distinct from Layer 1's placement). → [[Width and Stereo]]

**Why:** reamping the *same* performance (instead of a new take) through a second, differently-processed path guarantees the two layers stay rhythmically/melodically identical while sounding texturally distinct — the ambient layer reads as an aura around the dry part rather than a separate, competing element.

## Arrangement

**Where it sits:** two layers of the *same* part — the dry chain in **MIDS**, the reamped detuned wash in **BED/AIR**. One performance, two slots.

**When it plays:** the wash layer is the section device. Dry alone for a verse, both layers for the hook — the part never changes, the second layer's send does. Same timbre-over-density habit as [[Psych-Pop (Tame Impala)]].

**Watch for:** the ambient layer is out-of-time by design, so it blurs anything sharing MIDS with it. Give the strummer the gaps or move one of them ([[Session Layout]] § guitar adds).

## Variations

- If the Count to 5 pedal isn't available, a modulated delay (long-ish time, moderate feedback, pitch-modulated repeats) run through the same shaper → EQ → reverb → pan stages gets close to the "detuned, out-of-time double" character.
- The same two-layer dry/reamped-texture idea generalizes beyond guitar — any clean melodic source (Rhodes, synth pad) can use the same "process it straight, then reamp the same performance through a wilder chain and blend underneath" structure.
