# Automation

**What it is:** the fourth dimension of mixing — a static mix is a photograph; automation makes it a film. Every playbook in [[Genres Index]] leans on it: the chorus that "opens up" is almost never new plugins, it's automated sends, width, and level.

## The hierarchy of what to automate (most value first)
1. **Vocal level rides** — ±1–2 dB phrase-by-phrase so every word sits (use a [[Utility]] *before* the wet sends, not the fader, so the fader stays free for balance). The single highest-leverage automation in any mix.
2. **Send levels per section** — verse dry/intimate → chorus blooms ([[Reverb Send Long]], [[Width Send]], [[Delay Send Other]] up). This IS the verse/chorus contrast in [[Modern Pop]] and the wet/dry drama in [[Travis Scott Vocal Chain]].
3. **The crush return** +1 dB in choruses ([[Parallel Comp Send]]) — energy without level.
4. **Filter/macro moves across sections** — one LPF opening over 8 bars beats three new parts ([[House - EDM]], [[EDM Subgenres]]).
5. **Single-word events** — delay throws on line-ends, one distorted word, a formant flip ([[Charli XCX Vocal Chain]]), the reverb-drenched word. Small, surgical, memorable.
6. **Mute automation as arrangement** — A.G. Cook / trap school: the arrangement is which elements are *off* ([[Hip Hop - Trap]], [[Dance Pop (Dua Lipa, Charli XCX)]]).

## Craft rules
- **Automate late:** balance → then automate. Automating a bad static mix bakes the badness in.
- Draw section-level moves in blocks (bar-aligned), performance-level rides by hand/controller — different tools for different resolutions.
- Automate *sends and inserts' parameters*, not track faders, wherever possible — keeps the mix re-balanceable afterward.
- Effects with musical time (delay feedback, phaser rate, RC-20 wobble) reward being ridden like instruments — the psych moves in [[Psych-Pop (Tame Impala)]] are literally knob performances (automate EchoBoy's time knob for the detune-warble).
- Name a pass: one playthrough automating ONE thing (vocal rides pass, send pass, mute pass) — passes beat noodling.

## Quick recipes
- **Chorus lift without level:** width send +, long verb send +, crush return +1 dB, hat/air shelf +0.5 dB — reads as "bigger," measures the same.
- **Verse intimacy:** kill the width send, halve the room send, vocal up 0.5 dB.
- **The last-chorus trick:** everything from the chorus lift *plus* a key element you've been muting since intro (saved for last).
- **Transitions:** riser send into the downbeat, then cut ALL sends for beat 1 (the dry slam — [[1 Drums FX Track|Drums FX Track]]).

- **Automation silently overrides manual fader/knob moves — edit the automation, or insert a device underneath it, rather than fighting the parameter it's already driving** — once a parameter (fader volume, pan) carries drawn automation, touching that same control by hand during playback has no lasting effect: the automation snaps the value right back to whatever the curve says the instant playback continues. To make a lasting change to an already-automated parameter, either edit the automation curve itself, or — when the goal is an overall level/position shift rather than reshaping the automated move — insert a *second*, un-automated device ahead of it (e.g. a [[Utility]] Gain knob standing in for the fader) so the new control sits underneath the automated one instead of competing with it. A basic but easy-to-forget craft rule worth stating plainly since it silently wastes time otherwise. → [[Gain Staging]], [[Width and Stereo]], [[Utility]] — Max Konyi, [Creating a Solid First Mix (Specific Process)](https://www.youtube.com/watch?v=dXBNtKHt2r0)
- **Live-record a macro sweep timed to the groove, then clean it up with Simplify Envelope + manual point nudges** — rather than hand-drawing a filter/macro automation curve, play the bass part on a controller while manually turning the mapped macro knob in time with the drum groove during a live recording pass — captures a genuinely musical, human-timed movement a drawn curve would take much longer to fake. Afterward, select the recorded automation region and run **Simplify Envelope** to reduce the noisy, over-dense breakpoints a live take generates down to a clean, editable curve, then nudge individual points left/right by small amounts to fix any timing that lands just off the groove. → [[Randomized Rack Design]] — You Suck at Producing, [How to make (and PERFORM) a Neurobass](https://www.youtube.com/watch?v=5RNBLgC455s)
- **A filter cutoff automated open across an ENTIRE arrangement section (bars, not beats), then fully bypassed at the payoff moment — "training wheels come off"** — rather than a quick sweep, drag a filter's cutoff automation as one long, slowly-rising ramp spanning a whole intro/build section, so the sound gradually opens/brightens over dozens of bars as the arrangement develops; reshape WHEN the opening accelerates by dragging individual breakpoints earlier/later along that same ramp rather than adding new points. - **The gray-dot override + orange "back to automation" button** — nudging an automated parameter outside of deliberately editing its automation makes the current breakpoint turn gray, Ableton's way of flagging the live value has strayed from what's written; clicking the small orange arrow that appears above the device/track snaps the parameter back to the automated value without manually re-matching it by ear. - **Option-drag exponential curves for a reverb "wash-in," and automate Size for a repitching tail** — automating a reverb's Wet (and Decay) as a straight ramp reads mechanical; holding Option while dragging the automation curve bends it exponential instead, so the wash builds slowly then blooms — a more natural swell into a texture layer.
