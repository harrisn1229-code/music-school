# Drop Chords Guitar Lesson - Drop 2 & Drop 3 voicings explained for guitarists

## Synopsis

Jared Borkowski demystifies "drop 2" and "drop 3" chord terminology for guitarists specifically — the labels come naturally from a piano/stacked-thirds view of a chord, but on guitar the derivation isn't obvious, so he works it fretboard-first: build a **close-position** seventh chord (all four notes stacked in thirds, spanning less than an octave), then derive drop 2 and drop 3 by physically dropping a specific chord tone — counted from the top down — an octave lower. He worked two build-from-scratch examples (Cmaj7 → drop 2, Gmaj7 → drop 3) and, more usefully, a **general diagnostic trick**: given *any* seventh-chord shape you already know (no construction history required), move its bottom note up an octave and count down from the new top note to find where the moved note lands — 2nd from the top means the original shape was a drop-2 voicing, 3rd from the top means drop-3. This is a companion/derivation video to the vault's existing [[Chord Voicings]] page, which already documents the drop-2/drop-3 family (string sets, "workhorse" framing) without showing the construction — this video is the missing "why it's called that" piece, worked slowly and concretely on the fretboard. ## What's taught

**Core definitions, both derived the same way — from a close-position 4-note seventh chord (all tones within one octave, stacked as if in thirds on a piano):**
- **Drop 2** = count down from the highest note (top note = "1"); the **2nd note from the top** is the one you drop an octave lower.
- **Drop 3** = same counting method; the **3rd note from the top** is the one you drop an octave lower.
- The naming is purely about *which* note gets moved down, counted from the top — "it's not that we're calling those chord tones any particular number, you're just saying okay, one, two, drop two."
- Stated scope: drop 2/drop 3 as a labeling system is specifically a **seventh-chord (4-note)** thing — that's when the terms are actually used.

**Worked example 1 — Cmaj7, drop 2 (close position → common movable shape):**
- Start: close-position Cmaj7 — root, 3rd, 5th, major 7th stacked within an octave.
- Drop the 2nd-from-top note (the 5th) down an octave → lands as an **open**, less-familiar-looking voicing.
- To make it recognizable, Jared re-derives it as a **direct inversion along the same string set**: move each chord tone down to the *next closest chord tone* on its own string, repeating the cycle (5→3, root→7, 3→root, 7→5, then again) until it resolves into a shape most players already know.
- **Result: root - 5 - 7 - 3 (bottom to top)** — explicitly named as "the most common shape of major seven that's not an open-string chord" — i.e. the standard movable Cmaj7 grip. Confirms/derives-from-first-principles the "workhorse" A-string-root drop-2 shape already referenced generically on [[Chord Voicings]].
- Moving the same shape to other frets transposes it (e.g. same shape two frets up = Emaj7).

**Worked example 2 — Gmaj7, drop 3 (close position → common 6th-string-root shape):**
- Start: close-position Gmaj7 (root-3-5-7), root on the low E string.
- Drop the 3rd-from-top note (the 3rd) down an octave, then move a resulting unison note over to a cleaner string position (same pitch, different string) for playability.
- Re-derive as a direct inversion the same string-cycling way as example 1 (3→root, root→7, 5→3, 7→5) until it resolves into a familiar shape.
- **Result:** named as "one of the most common major seven voicings if the root is on the sixth string" — i.e. the standard movable 6th-string-root Gmaj7 grip. Confirms the drop-3 "root-on-low-E" framing already on [[Chord Voicings]].

**The general diagnostic trick (the video's most reusable takeaway — works on *any* known 7th-chord shape, no construction history needed):**
1. Take any seventh-chord voicing you already play.
2. Move the **bottom note up an octave.**
3. Count down from the new highest note (1, 2, 3, 4...).
4. Find where the moved note landed: **2nd from the top → the original shape was drop 2. 3rd from the top → the original shape was drop 3.**
- Demonstrated on a **Bm7** inversion shape (moved bottom note up, landed 2nd from top → confirmed drop 2).
- Demonstrated a second time on the **same C-major-family minor-7 inversion shape** used earlier in the Cmaj7 derivation (the "b note" voicing) — same result, confirmed drop 2, cross-checking the two methods against each other.
- Demonstrated on the Gmaj7 shape from example 2 (moved bottom note up, counted 1-2-3-4, landed 3rd from top → confirmed drop 3).
- Jared's own practical caveat: he says he mostly **ignores** the drop-2/drop-3 distinction day-to-day because it's "impractical on the guitar to think of it" in the moment — the value of the trick is being able to answer the question when the term comes up (reading charts, talking to other musicians, jazz-theory contexts), not as a live-playing framework.

**Not covered in this video (scope note):** no drop-2-and-4 or drop-2-and-3 variants, no minor/dominant-specific worked shapes beyond the Bm7 diagnostic example, no explicit string-set numbering (Jared works by ear/eye on the fretboard rather than naming string sets the way [[Chord Voicings]] does) — the existing page's string-set specifics (5-4-3-2 / 4-3-2-1 for drop 2, 6-4-3-2 for drop 3) aren't contradicted, just not independently re-stated here in those terms.
