# Chord-Tone Labeling by Scale-Degree Counting

Jared Borkowski's (Sound Guitar Lessons With Jared) method for identifying **what each note in a chord shape actually is** — not its letter name, but its **interval/scale-degree role relative to the chord's root** (1, 3, 5, ♭3, ♭7…). The point of doing it this way rather than by letter name: a letter-name spelling ("C, E, G") only describes one specific chord in one specific spot on the neck. A scale-degree/interval labeling describes the chord's *structure*, so once a shape's chord-tone labels are known, they transfer to that identical shape anywhere on the neck, off any root — the same skill this page's worked A-major/B-major pair demonstrates directly (same shape, two frets apart, identical labels). Distinct from [[Chord-Tone Soloing]] (a jazz improvisation practice ladder built on top of already-known chord tones) and [[Triads as a Fretboard Map]] (relocating a soloing triad shape across fixed neck zones) — this page is the more basic, prerequisite skill of *deriving* the chord-tone labels of an arbitrary shape in the first place, useful on any chord including inversions, slash chords, and altered/extended voicings.

## The method
1. **Find the chord's lowest note and call it 1.** If it's a root-position chord (root is the lowest note — true of all basic open-position triads), this is just the bottom note of the voicing. If the root isn't the lowest note (an inversion or slash chord), the process is identical — you just also count *down* from the root to label whatever sits below it.
2. **Count up the major scale from that note, crossing strings as needed, using the whole-step/half-step "measuring stick" from earlier in the series (episodes 2–3 — the technique itself isn't re-taught in this video, only reused).** Every scale-degree step is a **whole step** except **3→4** and **7→1**, which are **half steps**. When the next scale degree lands on a different string than the current one, cross to it, picking whichever whole/half-step shape the target note and fret distance call for.
3. **Every time you land on one of the chord's actual played notes, label it with the scale-degree number you're currently on.** Keep counting past chord tones that aren't hit yet; only notes physically present in the voicing get a label.
4. **If a played note falls a half step off the natural scale degree, name it as an alteration of the *nearest* 1/3/5/7 — never as the sharp/flat of the scale degree before or after it.** You are always hunting for some version of **1, 3, 5, and 7** (when present) as a chord's core tones. A note a half step **below** a natural degree → that degree's **flat** name (e.g. a half step below 5 = **♭5**, not ♯4). A note a half step **above** → that degree's **sharp** name (e.g. a half step above 5 = **♯5**) — **unless a natural version of that degree is already present in the chord**, in which case the altered note gets pushed to the **next** number's flat name instead (e.g. if a natural 5 is already in the chord, the note that would otherwise be "♯5" is instead called **♭6**). Whether that same note should ultimately be called ♭6 or its compound/extension name **♭13** is a separate, later naming layer (see [[Extended Chords]], [[Intervals]]) — for the purposes of this method, either is "getting the structure right."
5. **Don't skip the slow counting.** The shortcuts (recognizing "oh, that's always the 5" on sight) emerge from having done the full count-up enough times, not from memorizing them directly — counting it out by hand is "how you learn," not a workaround to graduate past.

## Shortcut once labels start repeating
Fixed interval *shapes* start becoming visually recognizable across the neck once you've derived a few chords this way — e.g. a root on the 3rd string always has its 5 one string below at the same fret; that same same-fret/adjacent-string 1-to-5 relationship recurs in multiple other spots around the neck too. These are the payoff of having done the manual count-up repeatedly, not a substitute for it early on.

## Worked examples (open/first-position chords)
All labels given low string to high string, only for the strings actually played:
- **A major (open):** 1 – 5 – 1 – 3 – 5
- **B major (same shape, moved up 2 frets from A):** 1 – 5 – 1 – 3 – 5 — identical labels, direct proof the numbering travels with the shape, not the root.
- **C major (open):** 1 – 3 – 5 – 1 – 3
- **D minor (open):** 1 – 5 – 1 – ♭3 — first worked example of the flat-alteration rule (the note is a half step below where a natural 3 would fall).
- **F♯m (same shape as D minor, relocated):** 1 – 5 – 1 – ♭3 – 5
