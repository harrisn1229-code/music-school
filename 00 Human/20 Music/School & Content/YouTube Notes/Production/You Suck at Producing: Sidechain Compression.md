# You Suck at Producing: Sidechain Compression

![](https://www.youtube.com/watch?v=zeR2vPvrjU4)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=zeR2vPvrjU4)

## Synopsis
The foundational, from-scratch sidechain-compression lesson: ear-train on reference songs first (listen for the rest of the mix "ducking away" every time the kick hits), then build the exact same effect step by step — add a Compressor to the track that should duck, open its sidechain section, point the sidechain input at the drum track, and lower the Threshold while the song plays to hear the duck deepen in real time. The one genuinely useful problem-solving moment: once built, both the kick AND snare are triggering the duck because they live on the same drum track, so the fix is filtering the compressor's *sidechain input* itself (not the target) down to just low frequencies, so only the kick's energy reaches the detector and the snare stops triggering it.

## Techniques
- **Basic compressor sidechain, built from zero** — add a Compressor to the track you want to duck, click the small triangle to open the sidechain panel, set the sidechain input to the other track (the drums), then lower Threshold while the song plays so gain reduction — and the resulting duck — deepens progressively; matches ear-trained reference tracks where the mix visibly "ducks away" from the kick. → [[Sidechaining]]
- **Isolate the kick from the snare by filtering the sidechain INPUT, not the target** — when a shared drum track triggers the duck on both kick and snare hits, enable the compressor's sidechain EQ and set it to pass only low frequencies; only the kick's low-end then reaches the detector, so the snare stops triggering the compressor while the kick keeps working exactly as before. → [[Sidechaining]]
