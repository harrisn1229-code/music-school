## What's taught

### Popping essentials, recapped up front
- Slap technique recap (forearm rotation, don't wiggle the thumb, hit with the outside edge, relax the thumb so it bounces off the string) — already fully covered in [[Slap Thumb Technique — Angle, Anchoring, and Muting]]; the video names an earlier "idiot proof slap" video as the source for this recap, which isn't yet in the vault as its own note.
- Popping defined: using a finger hooked under the string, pulled against the fretboard, to create a pop/snap sound.

### Popping technique — base mechanic, thumb-up, thumb-down, and two variations
- **Base mechanic:** hook the popping finger under the target string, rotate the forearm back (not an isolated finger motion) — very little actual finger movement, the string traces a diagonal line across the finger. Easiest to learn on the G string (no strings above to catch on).
- **Thumb-up popping** (Larry Graham, Victor Wooten, Rhonda Smith, Les Claypool): index finger hooked under the G string, string rides the **thumb-side edge** of the finger. Taught this way in BassBuzz's paid Beginner to Badass course.
- **Thumb-down popping** (Tim Commerford, Chris Wolstenholme, + a third name the auto-captions garble unrecognizably): same hook-and-rotate mechanic, but the changed hand angle **centers** the string on the finger instead of riding an edge.
- **Variation — Flea's middle-finger pop:** hooks the **middle finger** instead of the index finger under the D string and pulls up, in his own words on camera. Feels more natural specifically when the slapping thumb sits at an extreme downward angle, as Flea's does.
- **Variation — Louis Johnson's arm-assisted pop:** adds extra **arm motion** to snap the string off the fretboard on top of the normal forearm rotation — more muscle and more visual performance, at some cost to technique efficiency.
- **Anti-pattern, explicitly not recommended:** popping with an isolated finger motion, or by flexing the wrist upward. Both tire the forearm, create muting issues, and break the teeter-totter cycle.
- Full extraction, cross-linked → new note [[Popping Technique — Thumb Up vs Thumb Down, Hook, and Minimum Viable Pressure]].

### Minimum viable pressure (MVP) — and its link to action height
- Use just enough finger tension to get the pop/snap sound and no more — too little sounds like a plain pluck (no snap); too much wastes effort and wears the finger out faster than needed; way too much and the pop doesn't release at all, the finger just holds the string.
- **Quick-check on action height:** if there's more than **~5 mm of clearance between the E string and the 12th fret wire**, get a setup — a high action forces more finger pressure to get the same pop, which wears the finger out faster. Cross-references the existing [[Bass Setup — Truss Rod, Action, Intonation, and Pickup Height]] procedure (that note's own medium-action starting point is ~2–3 mm on the E string — a tighter target than this video's much looser "you're now hurting your pop finger" ceiling).

### Teeter-totter technique — full re-teach plus a new drill
- Core motion restated: if the slap thumb bounces off the string (rather than rotating all the way back up first), the hand is automatically positioned to rotate forward into the pop, then back to slap position — one continuous down/up cycle instead of two separate round trips. Beginners commonly break this by adding an extra rotation cycle (down–up–down–up instead of down–up), which wastes time/energy and makes speed impossible.
- **New open-string drill, with a tempo ladder:** slap the open E string, pop the open G string — no fretted notes — tab marked `T` (thumb) and `P` (pop). Start at **quarter notes, 70 BPM**, increase gradually, working toward **eighth notes at 100 BPM** as the eventual goal (flagged as realistically taking months of daily practice). Then the same drill with the pop moved from the **G string to the D string** — a harder popping-finger placement since there's no G string to tuck against as a guide, confirming the same difficulty spike this note's existing "From videos" content already flags from an earlier source.
- Full technique + drill, cross-linked into the existing note → [[Teeter-Totter Slap-Pop Technique]].
