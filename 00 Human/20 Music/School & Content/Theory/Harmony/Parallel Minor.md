# Parallel Minor

Part of [[Music Theory]] → [[Keys]]. The **parallel minor** of a major key is the minor key that shares the **same tonic note** (C major ↔ **C** minor). Distinct from the **relative** minor, which shares the same *notes* but a different tonic (C major ↔ A minor — see [[Keys]]).

## Parallel vs. relative — don't confuse them
| | Shares | Example (from C major) |
|---|---|---|
| **Relative minor** | the same **notes/key signature** | A minor (no sharps/flats) |
| **Parallel minor** | the same **tonic**, different notes | C minor (3 flats) |

- Relative = same neighborhood, different home. Parallel = same home, different mood.

## Why it matters
- The parallel minor is the source pool for **[[Borrowed Chords]]** (modal interchange): iv, ♭III, ♭VI, ♭VII borrowed into a major key all come from the parallel minor.
- **Parallel-minor modulation** (a whole section moving to the parallel minor) is a classic contrast move: keep the tonic anchored so the change reads as a *mood* shift (bright → dark) rather than a full key change — the ear stays oriented because "home" hasn't moved.
- Flipping the tonic triad major↔minor (**picardy third** the other way, or a minor-key song ending on the major tonic) is the smallest version of this.
