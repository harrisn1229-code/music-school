# Disclosure - Making 129bpm shizzz Beat Jam

Another from-scratch **sample-browsing beat jam** with Howard — even lower technical density than the 134bpm one, mostly hunting through new packs (**Scott Diaz** garage loops, Roland Cloud **Zenology** synths, a Splice kit) plus a running Logic bug (rogue numbers on screen from a Roland Cloud plugin) and banter. ## Techniques
- **Pro-Q 3 speed shortcuts** (worth memorizing): **pull the *ring* around the gain knob → dynamic mode** (instead of dragging the gain); **double-click** on the curve makes a frequency node instantly (great with a touch/Apple mouse); the **scroll wheel adjusts the Q/sharpness** of the selected bell. A scroll-wheel mouse noticeably speeds up EQ work. → [[EQ]].
- **Two-drop demo structure for fresh-ears choice** — build drop 1 = everything + chords but *minimal drums*, drop 2 = *all drums* but just bass; keep both in the demo so tomorrow you have two options in one file to choose from. → [[Automation]] / arrangement.
- **Browse fresh sample packs to spark a beat** — a producer (Scott Diaz) sent free garage loops; start from sounds, not a blank grid. Make a **Drum Machine Designer** kit (multi-output, like Battery) from the hits. → [[Sampling and Sound Selection]].
- **Bury a garage loop *low* in the mix for swing/energy** — kept quiet, a loop adds swing you don't consciously hear but miss when it's gone ("it loses a lot of energy"). Reinforces the "element you only notice when removed." → [[Sampling and Sound Selection]].
- **Tighten a drifting off-beat ride by sidechaining it + adding one hit on the beat** — anchors a loop that "drifts in and out" of time. → [[Sidechaining]].
- **Bounce CPU-heavy Roland Cloud / Keyscape / JP-7 synths to audio early** — they peak the CPU (a system-overload mid-jam); commit to audio to keep moving. → [[Gain Staging]] / workflow.
- **A loop-kick usually needs "a serious amount of top end"** to cut in the mix (reinforces the kick-click move). → [[Kick Design]].
- **Arrangement = clean groups/buses + repeat/cut/drag-as-group** to move fast; the creative part is instinct ("try stuff"). Howard's joke tips: "turn it up, put it in order, leave it." → arrangement.
