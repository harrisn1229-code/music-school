Second entry in asd's five-part series on building "exponential rhythms" — evolving, self-varying rhythmic patterns rather than static loops. Where part 1 used the free-run arpeggiator (referenced but not detailed here) and part 3 (already in the vault, see [[ableton sound design - EXPONENTIAL RHYTHMS 3-5 Texture Mode|Texture Mode]]) used Live's clip-level Texture warp mode, this installment builds the same rhythmic-depth idea entirely inside **Simpler's sample-looping engine** — no audio-clip warping required, just Simpler's Loop/Length/Start/Fade/Transpose parameters on a loaded one-shot. The video has two clear halves: first, a single-Simpler deep-dive on the mechanics of audio-rate sample looping (loop a sample, then shrink its Length toward zero via automation until the loop repeats fast enough to read as pitch/tone rather than rhythm) plus the pitch/loop-length coupling that comes from looping real audio (unlike MIDI-triggered repetition, an audio loop's rate is tied to its pitch, so Transpose becomes a second rhythm-design lever); second, scaling the trick to a whole Drum Rack — using "copy value to all siblings" and "map to all siblings" to push one Simpler's loop settings and a single shared macro across every pad at once, so triggering the original beat while riding that one macro superimposes an "exponential groove" over the whole kit. The key structural insight, stated directly and central to the whole series: Simpler's Length parameter is a **percentage of each sample's own length, not a fixed time value**, so the exact same macro automation produces a genuinely different (and non-repeating, polyrhythmic) result on every differently-sized sample in the kit — something the fixed-time free-run arpeggiator from part 1 cannot do. ## Techniques

- **Audio-rate sample looping from a sustained note via Length automation** — load a one-shot (an impact sample here) into [[Simpler]], enable **Loop**, disable **Zero Crossing Snap** (so the loop point isn't forced to a zero-crossing), set **Sample Start = 0** and both **Loop** and **Length** to 100%, and drag the sample's end marker in slightly toward the tail. Build a MIDI clip with a single sustained (legato) note, and automate the **Length** parameter over that note — because Length is a **percentage of the sample's own length (Start-to-End span), not milliseconds or a tempo-synced value**, shrinking it continuously drives the loop from a normal audible repeat down through audio-rate territory (the loop repeats fast enough to be heard as pitch/tone rather than a discrete rhythm) — a more extreme range than the free-run arpeggiator (part 1) can reach, since that method is capped at fixed, tempo-locked time values. → [[Granular Synthesis]], [[Rhythm and Groove]] (Polyrhythms) — asd, [EXPONENTIAL RHYTHMS \[2/5\] Sample Looping in Simpler](https://www.youtube.com/watch?v=QRj6sxdimkQ)
- **Transpose is a second rhythm-design lever, because audio-loop length and pitch are coupled** — since this is a real audio sample looping (not a MIDI-retriggered one), its playback rate/loop length is proportionally tied to pitch: modulating **Transpose** proportionally modulates the loop's length/rate, giving a second way (besides automating Length directly) to reach the same family of results — drive it from the automation lane, Simpler's own pitch/LFO modulation, or simply by playing different notes on a MIDI keyboard. → [[Simpler]]
- **Voices = 1 + Glide (generous time) for smooth pitch/loop-length glissandi** — reduce Simpler's polyphony to a single voice, enable **Glide**, and set a generous glide time so playing overlapping notes slides smoothly between pitches (and therefore between loop lengths/rates) instead of retriggering discretely — turns the Transpose-as-rhythm-lever technique above into a continuous glissando rather than stepped jumps. → [[Simpler]]
- **Region-based params (Start / Loop / Fade) interact for granular/textural results** — beyond Length, Simpler exposes **Start** (nudges the overall playback starting point), **Loop** (adjusts where within the region the loop point sits), and **Fade** (crossfades the looped region to smooth the seam); deliberately exploring how these three interact with each other — not just tuning them independently — is called out as the route to genuinely granular/textural results rather than a clean rhythmic loop. → [[Granular Synthesis]], [[Simpler]]
- **Warp mode severs the pitch/loop-length coupling — and mangles the sample as a side effect** — any sample inside Simpler can be Warped and pushed through the same warp-mode abuse as an audio clip in Arrangement (see [[ableton sound design - EXPONENTIAL RHYTHMS 3-5 Texture Mode|part 3]]'s deep dive on Texture mode specifically), but once Warped, the sample's timing locks and pitch modulation **no longer affects loop length** — the two techniques are mutually exclusive on the same sample. Aggressive warp mode + amount settings mangle the rhythmic and harmonic content, and extreme values can fully obscure the original source — a legitimate destination in its own right, not just a caveat. → [[Simpler]] (Warp ③), [[Granular Synthesis]]
- **Build the same trick across a whole kit: Drum Rack + copy/map to all siblings + a shared macro** — load a [[Drum Rack]] with several one-shots (auto-creates one [[Simpler]] instance per pad), program a simple pattern with every note **legato**, then dial in the loop settings above on just ONE pad's Simpler and right-click → **copy value to all siblings** to push those same settings to every other pad's Simpler in one action. Map that pad's **Length** parameter to a rack **macro**, then right-click → **map to all siblings** to wire the same macro to every other Simpler's Length parameter simultaneously — one knob now drives loop length across the entire kit. Fine-tune per-pad feel afterward by nudging each sample's individual Start/End so every drum's "sweet spot" range still lands right. → [[Drum Rack]], [[Randomized Rack Design]] — asd, [EXPONENTIAL RHYTHMS \[2/5\] Sample Looping in Simpler](https://www.youtube.com/watch?v=QRj6sxdimkQ)
- **Ride the shared macro live against the original pattern for an "exponential groove"** — with the kit-wide Length macro wired up, trigger the ordinary drum pattern while moving that one macro; the effect superimposes the exponential/evolving-rhythm movement onto the existing beat rather than replacing it, so the groove keeps a recognizable backbone while constantly mutating — the series' central "control vs. disorder" balance, and per the source, "only the illusion of things falling apart," not actual chaos. → [[Rhythm and Groove]] (Polyrhythms)
- **Length is a percentage of EACH sample's own length, so one macro produces a genuinely different (polyrhythmic) result per pad** — the single most important structural fact in the technique: because Length is measured relative to each sample's own Start-End span rather than a fixed time value, driving every pad from the same shared macro does NOT produce the same rhythmic rate on every pad — a short sample and a long sample at the identical Length-macro position loop at different rates, so the kit naturally produces **polyrhythm** for free, purely from sample-length variety. The free-run arpeggiator (part 1) can't do this — it repeats only at its indicated, fixed time value regardless of sample length. → [[Rhythm and Groove]] (Polyrhythms section) — asd, [EXPONENTIAL RHYTHMS \[2/5\] Sample Looping in Simpler](https://www.youtube.com/watch?v=QRj6sxdimkQ)
