# You Suck at Producing #48: Using Ableton's Session View

![](https://www.youtube.com/watch?v=1aIOxEcxT7I)
📺 [Watch on YouTube](https://www.youtube.com/watch?v=1aIOxEcxT7I)

## Synopsis

A genuinely substantial Session View workflow lesson — dense enough to warrant a new dedicated technique note. Covers using Session View as a flexible drafting tool for section order/length before committing to a linear arrangement, building smooth intro variations by duplicating and progressively stripping/adding elements, a Session-View-specific per-clip automation mechanic (the clip's own Envelopes button) with an important reset-before-the-next-clip gotcha, managing scene "stop-clip" behavior so new scenes can layer onto what's already playing instead of cutting it off, and finally recording a live Session View performance directly into Arrangement View via the global Record button plus the Session/Arrangement play-source toggle.

## Techniques

- **Draft section order/length in Session View before committing to Arrangement** — scenes let you freely reorder and resize sections by ear before locking into a fixed timeline, something far more cumbersome to do starting cold in Arrangement View. → [[Session View Workflow]], [[Arrangement and Song Form]]
- **Build lead-in variations by duplicating a scene and progressively stripping/adding elements** — an "Intro" duplicated down to a sparse core, then an "Intro Plus" reintroducing a few (not all) elements, smooths the jump into the full section rather than cutting abruptly. → [[Session View Workflow]]
- **Per-clip automation via the clip's own Envelopes button — with a reset needed before the next clip triggers** — automate a device parameter tied to one specific clip/scene rather than the Arrangement timeline; because the parameter snaps back to default when a different clip launches, add a closing automation point at the end of the same clip so the handoff reads as smooth rather than an abrupt reset. → [[Session View Workflow]], [[Automation]]
- **Remove a scene's Stop-Clip slots so it layers onto already-playing clips instead of cutting them off** — by default a new scene implicitly stops any track it doesn't have its own clip for; right-click and remove that stop-clip slot to let previously-triggered clips on other tracks keep playing through the new scene. → [[Session View Workflow]]
- **Record a live Session View performance straight into Arrangement View** — hit global Record, trigger scenes in the desired order, and Ableton lays that performance out as a linear timeline automatically; switch the orange play-source toggle (top-right) from Session to Arrangement afterward to actually hear/edit it. Recommended workflow: draft in Session View first, then move to Arrangement for finer transitions/automation. → [[Session View Workflow]]
