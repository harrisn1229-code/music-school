# Pentatonic Mastery Practice Routine

Part of [[Guitar Positions]]. A three-stage practice progression for breaking a pentatonic scale out of "box shape noodling" and into musical, ear-led playing — each stage restricts the scale further (fewer strings, then reordered note groupings, then a single string) so the fretting hand can't lean on memorized box shapes and the ear has to do the navigating instead. Built on the **A minor pentatonic**, worked across all five movable box positions, and explicitly stated to transpose to any key by moving the same five shapes to a new anchor fret. Compare [[String-Group Pentatonic Bursts]] (a related but distinct two-string-fragment drill that stays *inside one box*, layering fragments together) and the "two strings at a time" baby-step variant in [[Continuous Scale Exercise]] — this routine instead sweeps the *same* narrow string set *across all five positions* to connect them, rather than fragmenting a single position.

## Prerequisite — map all five positions

Before any of the three exercises: be able to play the A minor pentatonic scale through **all five movable box shapes**, position to position up the neck, starting from the familiar first box as the anchor. Same notes throughout, five different shapes/fingerings. Skipping this and jumping straight to the exercises defeats the point — the exercises all depend on knowing where each of the five shapes sits. See [[Guitar Positions]] for the general fretboard-position framework this slots into.

## Exercise 1 — two strings at a time, swept across all five positions

**Restrict each of the five pentatonic box shapes down to just one string pair, and play through all five positions using only that pair, over a chord loop.** Demonstrated over a simple **A7–D7** two-chord vamp:
- Take just the low E and A strings' notes from box position 1, then the same two strings' notes from position 2, then position 3, and so on through all five positions — moving up the neck two-strings-wide rather than jumping between full box shapes.
- Repeat the same sweep for the **middle two strings (D and G)** and again for the **top two strings (B and E)** — three passes total, one per string pair, each covering all five positions.
- **The point is forced ear-reliance:** with only two strings available, there's no room to fall back on a memorized full-box pattern — the player has to hear where the next usable note is and follow the ear up the neck, position to position, rather than running a shape. *(general starting point: loop a static I7–IV7 vamp, e.g. A7–D7 as demonstrated, so the harmonic context stays simple while the physical/aural skill is the focus)*
- Distinct from [[String-Group Pentatonic Bursts]]'s two-string-group method: that technique fragments *one* box into overlapping two-string pieces and layers them back together; this one keeps a *fixed* two-string pair and walks it through *all five* positions to build a connected, ear-led line up the neck.

## Exercise 2 — grouped-note sequencing (4s, 6s, 8s)

**Instead of running a box shape straight up or down, break the descent/ascent into repeating note-groupings, offset by one string per repetition** — a sequencing device credited to Eric Johnson, Joe Bonamasa, and Eric Gales among others (widely used beyond them).
- **Groups of 6, descending:** start the scale on the high E string, play 6 notes (1-2-3-4-5-6), then start the *same* 6-note pattern on the same starting fret one string over (B string), then the G string, then the D string — each repetition shifted one string down, same starting fret, same 6-note shape.
- **Groups of 4:** identical mechanism, 4 notes per repetition instead of 6 — described as more mileage-per-shape and easy to swap in once groups of 6 are solid; **groups of 8** also named as a valid group size to try.
- **Ascending direction works the same way in reverse:** start on a low string, play the N-note group, shift the same group up one string, repeat climbing toward the high strings.
- **Applied across all five box positions**, not just one — run the grouping device through every position for full coverage of the scale.
- **Why it works:** playing straight up/down a box is metrically and melodically predictable; offsetting a repeating group by one string each time creates a syncopated, non-linear contour over the same notes — "adding flare to the box shapes we know," per the source.

## Exercise 3 — single-string pentatonic

**Play the entire A minor pentatonic scale — all five positions' worth of notes — on one string only**, moving up the neck fret to fret rather than crossing strings at all.
- Demonstrated on the **G string**: instead of playing position 1's notes across multiple strings, pull out only the notes position 1 contributes on the G string, then only what position 2 contributes on the G string, and so on — stringing those fragments together climbs the entire scale on that single string.
- **Framed as the routine's highest-value single takeaway** — "the one that really separates an intermediate guitar player from the next level," and the one exercise to keep even if the other two get skipped.
- **Purpose:** removes string-crossing entirely, so the only thing left to navigate is pitch distance on one string — forces the same ear-led, non-box-shape approach as Exercise 1, taken to its logical extreme.

## Why this progression matters

The three exercises restrict the fretboard in escalating ways — two strings across five positions, then a reordered note pattern across strings, then one string across the whole scale — so that by the end, box-shape memorization can't carry the player; the ear has to. Stated explicitly as the fix for "noodling through a scale" without musicality: each stage forces a different kind of attention (position-connecting, rhythmic/melodic reordering, then pure pitch-distance-by-ear) on the exact same five pentatonic shapes already mapped in [[Guitar Positions]].
