# dnksaus - Live 12 has more features than you think...

## Synopsis

A grab-bag alpha-build feature tour of Live 12, filmed before release (so some UI/naming details may shift). The biggest single topic is the piano roll's new **Generate** (Rhythm/Notes/Shape/Stacks/Max for Live generators) and **Transform** (Arpeggiate/Connect/Ornament/Quant/Recombine/Span/Strum/Time Warp) menus — a genuinely new MIDI-composition layer, given its own technique note here. Also covered: the improved file browser (custom tags for key/groove/creator/device-type, tag groups, the saved-search "+" button, and the Similar Files button already seen applied inside Drum Rack in an earlier video this batch); the new dual-engine synth **Meld** (already documented from "Scale-Aware Abuse," extended here with its filter roster, Mix section, and cross-engine modulation); the new multi-stage saturator **Roar** (a from-scratch plugin note); Live-12-wide modulation-matrix upgrades (automate-while-modulated, multiple simultaneous mods with polarity, a Remote fallback); an expanded microtuner/tuning-pool system for non-12-TET work; Granulator 3 going MPE-capable; and new UI themes. Individual tips are routed to whichever specific note they actually belong to rather than dumped in one place, per this channel's grab-bag-video convention.

## Techniques

- **Generate and Transform — Live 12's new piano-roll MIDI-generation system** — Rhythm/Notes/Shape/Stacks generators create MIDI from scratch; Arpeggiate/Connect/Ornament/Quant/Recombine/Span/Strum/Time Warp reshape existing MIDI; suggested order is Generate → Transform → Pitch and Time. Full mechanics on the new dedicated note. → [[MIDI Generate and Transform Tools]]
- **Improved file browser: tags, tag groups, and the saved-search "+" button** — preset + custom tags for key, groove, creator, and device type, with custom tag groups on top, plus a one-click "+" to pin a filtered search term to the sidebar permanently. → [[Sample Browser and Clips Workflow]]
- **Meld: filter roster, Mix section, and cross-engine modulation** — a vowel/formant filter and scale-aware resonator-style filters alongside the classic morphing filter and Phaser; a dedicated Mix section (tone LP/HP, built-in limiter, Drive); one engine's LFO can modulate a parameter on the *other* engine; mapping Spread to filter frequency plays the stacked voices at several different filter frequencies at once. → [[Meld]]
- **Roar — a new multi-stage saturation/distortion device with its own expanded view** — six routing modes (single/serial/parallel/multiband/mid-side/feedback), new Shapers and filters (including a Comb filter), a Noise modulation source, and a feedback mode that can resonate to a specific note. Framed as "a bus of buses" — a bus-level tool, not just a single-track saturator. → [[Roar]]
- **Modulation-matrix upgrades: automate while modulated, multiple mods with polarity, a Remote fallback** — a parameter already being modulated can now also be automated on top; several modulation sources can drive one parameter simultaneously, each with independent polarity; a "Remote" option reverts to the older fully-overriding behavior. → [[Automation]]
- **Expanded tuning pool (Microtuner) for non-12-TET work** — a tuning pool sits above the groove pool, letting a whole track step outside standard 12-tone equal temperament, with a changeable reference pitch (e.g. 432 Hz) affecting all MIDI; freeze-and-flatten now works alongside plain freeze. Niche for Nate's current genre lanes — captured here rather than forced into an existing note.
- **Granulator 3 is now MPE-capable** — extends its per-note modulation options; the same LFO-random/Variation-maxed wild-texture recipe from "granulate EVERYTHING" reapplies here. → [[Granulator 3]]
- **New UI themes** — a system-following default theme plus several warm/neutral/hue-tinted options; cosmetic only, no production technique to route.
