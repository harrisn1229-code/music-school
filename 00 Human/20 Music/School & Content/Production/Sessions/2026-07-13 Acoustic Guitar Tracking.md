# Acoustic Guitar Tracking — 2026-07-13

## Goal
Record clean, keeper acoustic guitar takes ([[Yamaha FG730S]]) — a strummed bed layer and/or fingerpicked part, tracked dry with space added later on sends.

## Setup checklist
- [x] Fresh-ish strings? (dead strings on acoustic = dull takes no EQ fixes — decide before setting up)
- [x] Quiet the room: phone silenced, fan/HVAC off, close the window
- [ ] [[Neumann TLM 102]] in shock mount + pop-filter not needed for guitar; 48V on
- [ ] Apollo: **Unison preamp — UA 610-B for warmth or unprocessed for neutral** ([[Universal Audio Apollo Twin MkII]]); input gain to peak **−18 to −12 dBFS** on the hardest strum
- [ ] Headphones ([[Audio-Technica ATH-M50x]]) — closed-back, no click bleed into the mic
- [ ] Ableton: set project tempo, click + 1-bar count-in, record path named `AcGtr_<song>_<take>`

## Session plan
1. **Mic position — start here:** TLM 102 at the **12th fret, 10–12" out, angled slightly toward the body** (per [[Neumann TLM 102]] Key Parameters). Never point straight at the soundhole (boom).
2. **Tune, then play the actual part at performance energy** while watching levels — set gain on the real dynamics, not noodling.
3. **Listen for the seat/room** in a scratch take: if the room sounds boxy, get 2–4" closer and accept more proximity warmth (thin it later with a gentle low cut, not a farther mic).
4. **Strummed bed part:** it occupies the **[[BED Slot]]** — track it knowing the low end below ~120 Hz gets HPF'd in the mix; don't chase bass in the recording.
5. **Fingerpicked part:** more detail-forward — this can flirt with the **[[MIDS Slot]]**; move the mic 4" closer and drop input gain 3 dB to keep the transients clean.
6. **Double-track the bed** (two full takes, panned L/R later) rather than copying — the differences are the width.
7. **Takes discipline:** 3 takes per part max before a listen-back; comp in Ableton, don't chase a perfect single take.
8. **Optional character pass:** one take through the [[Sony TC-630]] print loop (interface line out → tape → back in) for a tape-y double under the clean takes.
