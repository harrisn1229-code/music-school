# GrainFreeze

![[Images/GrainFreeze.jpg]]

**Category:** Modulation
**Vendor:** Max for Live

## What it is

A Max for Live granular effect that freezes and grains a live or recorded signal into a sustained, evolving texture.

## What it's used for

Creating frozen-pad and glitchy granular textures from any audio source in real time.

## FX chain notes

Runs inline in the signal/MIDI chain at the point it's inserted; combines with whatever device follows.

| # | Parameter | What it is / does | Technique |
|---|---|---|---|
| ① | Freeze (Ready) | Captures + sustains the current audio as grains | Freeze a chord/vowel into an infinite pad |
| ② | Fade | Fade-in/out time of the freeze | Longer fade for a smooth bloom into the pad |
| ③ | Position | Read position within the frozen buffer | Move it to scan across the captured audio |
| ④ | Grain / Spray | Grain rate + random scatter of the grains | Small grains = smooth pad; Spray for a grainier wash |
| ⑤ | Spread / Voices | Stereo spread + number of grain voices | Spread for width; more voices for a denser freeze |
| ⑥ | Tune / Chorus | Pitch of the grains + chorus width | Tune for shimmer; Chorus to widen and animate |
| ⑦ | Dry / Mute | Layer the freeze under the live source (or mute the dry) | Mute dry for a pure frozen pad on a return |
