# Bass Runs and Target Notes

BassBuzz's method for writing a **bass run** — "just another word for a bass fill": cool transition notes layered onto an otherwise-plain bassline at a chord change, aimed at making an on-its-own-not-very-interesting rock/pop bassline read as melodic and forward-moving. Distinct from [[Bass Walkup and Walkdown Fills]] (a fixed two-fret chromatic approach into a single target) and [[Bass Pentatonic Riff-Writing Recipe]] (composing a repeating riff inside one scale shape) — this note covers the more general case: a scale-based melodic run connecting two or more chords, including runs that deliberately span more than one bar. Fill gap: the vault had no note on this device before this pass, despite "fills"/"runs" showing up loosely across [[Bassline Writing]]'s "From videos" log.

## What a bass run is for

A bass run replaces a flat chord-to-chord handoff with a melodic connector. Two weaker default options, both worth naming so the run's value is obvious by contrast:

1. **Jump straight to the new root** — technically correct, reads as abrupt/static.
2. **Sit on the current root until the section changes** — safe, but adds no forward motion.

A run instead **walks a scale between the two roots**, arriving at the new chord's root exactly on time but with real melodic movement along the way. It doesn't need to use every scale degree in order — a run built from scale degrees **1, 2, 3, 5, then 6** (skipping the 4th) still reads as a smooth, connected line, not merely "any notes from the scale."

**A run can also borrow its rhythm from somewhere else in the arrangement** — mimicking the vocal line's rhythm at a transition point (rather than inventing a new rhythmic idea) is a legitimate, cohesive source for a fill's rhythm, distinct from mimicking the guitar/chord rhythm the rest of the band is already outlining.

## Playing over the bar line

**Most fills/runs start and end squarely on beat one of a bar** — the safe default, and where a run naturally resets each time the chord changes. **Playing over the bar line** breaks that default: a single continuous run spans straight through a bar line instead of resetting at it, connecting more than one chord change in one unbroken melodic gesture. (A "bar line" is the notated line separating one measure — one full cycle of the song's beat count, e.g. four beats in 4/4 — from the next; [[Time Signatures & Note Values]] covers the underlying meter this divides.)

**Why a naive attempt at this sounds lost, and the fix:** noodling freely across a bar line with no anchor reads as aimless or "excessively noodling." The fix is to **pick target notes before playing anything else** — the specific notes the run has to land on, at the specific beats where the underlying chords actually change. Everything else in the run is free choice, as long as the targets land correctly and on time.

### The method

1. **Identify every chord change the run needs to cross**, and which beat each one lands on. A run spanning three chords has (at minimum) three targets: the starting chord's root, and the root of each subsequent chord it passes through.
2. **Those target notes and their beat placements are fixed** — this is the non-negotiable skeleton of the run.
3. **Fill in the notes between targets from the prevailing scale**, using stepwise or otherwise smooth motion (see [[Bass Pentatonic Riff-Writing Recipe]]'s "favor sequential motion" step for the same underlying instinct applied to a fixed shape). There is no single correct filling — two different fills over the identical target notes can both work.
4. **A target's rhythmic placement can itself borrow from another part.** In BassBuzz's worked example, the run's final target lands on the "and of two" specifically because that's where an accent already lands in the vocal line — the target isn't only a *pitch*, it's a pitch tied to a *beat*, and that beat can be chosen to line up with an accent elsewhere in the arrangement rather than picked arbitrarily.

### Worked example — Bon Jovi, "Livin' on a Prayer" (chorus run)

The song's biggest run connects three chords — **D, G, and C** — in one continuous line rather than resetting at each chord's downbeat. Targets: **D** on the first beat one, **G** on the next beat one, **C** on the "and of two" (matching the vocal's own accent there). Both filler-note choices demoed in the source draw from the **E minor / G major** scale (the song's relative minor/major pair), keep the same three targets fixed, and vary only the connective notes in between — proof that the target-note skeleton, not a single "correct" line, is what makes the run work. → [[🎵 BON JOVI - Livin' on a Prayer]] — BassBuzz, [[3 Reasons This Bon Jovi Bass Line Kicks Ass (+Full Song Tab)]]
